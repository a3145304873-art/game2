# 边界情况检查清单

本文档列出游戏数值模拟中常见的边界情况和需要澄清的问题，供 Agent 在步骤 2（生成澄清问题列表）时参考。

---

## 一、数值边界

### 1.1 负数处理

**问题模板：**
- 当 HP/MP 减少到负数时如何处理？
  - 选项 A：立即死亡/耗尽（推荐）
  - 选项 B：保留为 0
  - 选项 C：允许负数，但有特殊效果

- 当伤害计算结果为负数时如何处理？
  - 选项 A：设为 0（最低伤害保护，推荐）
  - 选项 B：设为 1（强制破防）
  - 选项 C：允许负伤害（治疗敌人）

- 当属性值为负数时如何处理？
  - 选项 A：不允许属性为负，最低为 0
  - 选项 B：允许负属性，按公式计算

**默认建议：** HP/MP 最低为 0，伤害最低为 0，属性允许负数但有下限

---

### 1.2 上限处理

**问题模板：**
- BUFF 叠加层数是否有上限？
  - 如有，上限是多少？（常见：5/10/99/无限）
  - 达到上限后如何处理？（无法叠加/刷新持续时间/转化为其他效果）

- 属性是否有上限？
  - 攻击力/防御力是否有上限？（常见：无上限/9999/65535）
  - 冷却缩减是否有上限？（常见：40%/50%/80%）
  - 暴击率是否有上限？（常见：100%/无上限）

- 资源是否有容量上限？
  - 金币/钻石是否有持有上限？
  - 体力是否有自然恢复上限？

**默认建议：** BUFF 有上限（10 层），冷却缩减有上限（40%），暴击率上限 100%

---

### 1.3 溢出处理

**问题模板：**
- 当伤害超过目标当前 HP 时，多余伤害如何处理？
  - 选项 A：溢出伤害消失（推荐）
  - 选项 B：溢出伤害传递给其他目标
  - 选项 C：溢出伤害按比例转化为治疗

- 当治疗超过目标最大 HP 时，超额治疗如何处理？
  - 选项 A：过量治疗消失（推荐）
  - 选项 B：转化为护盾
  - 选项 C：溢出部分按比例返还

- 当数值超过整数范围时如何处理？
  - 使用 64 位整数
  - 使用浮点数
  - 设置软上限（超过后收益大幅降低）

## 二、状态边界

### 2.1 多 BUFF 处理

**问题模板：**
- 当多个同类型 BUFF 同时存在时，如何叠加？
  - 选项 A：加法叠加（10% + 20% = 30%）
  - 选项 B：乘法叠加（1.1 × 1.2 = 1.32 = 32%）
  - 选项 C：只取最高值（取 20%）
  - 选项 D：同类加法、异类乘法（推荐）

- 当多个同来源 BUFF 尝试叠加时，如何处理？
  - 选项 A：刷新持续时间（不叠加层数）
  - 选项 B：叠加层数，刷新持续时间（推荐）
  - 选项 C：叠加层数，不刷新持续时间
  - 选项 D：无法叠加，相互覆盖

- 当 BUFF 与 DEBUFF 同时存在时，优先级如何？
  - 选项 A：同时生效，独立计算（推荐）
  - 选项 B：互相抵消
  - 选项 C：优先级高的覆盖低的

**默认建议：** 同类加法、异类乘法，叠加层数并刷新持续时间

---

### 2.2 互斥状态

**问题模板：**
- 是否存在互斥的状态效果？
  - 例如：「无敌」与「脆弱」是否互斥？
  - 例如：「隐身」与「嘲讽」是否互斥？

- 当互斥状态尝试同时施加时，如何处理？
  - 选项 A：后施加的覆盖先施加的
  - 选项 B：后施加的失败
  - 选项 C：先施加的优先级更高
  - 选项 D：根据状态强度决定

---

### 2.3 状态刷新

**问题模板：**
- 当对已有状态的目标再次施加相同状态时，持续时间如何计算？
  - 选项 A：完全刷新（重置为完整持续时间）
  - 选项 B：延长（增加完整持续时间）
  - 选项 C：不刷新，只叠加层数
  - 选项 D：取剩余时间和完整时间的较大值

- 持续时间的结算时点是？
  - 选项 A：回合开始时结算（推荐）
  - 选项 B：回合结束时结算
  - 选项 C：立即结算（DOT/HOT 等）

---

## 三、时间边界

### 3.1 冷却处理

**问题模板：**
- 技能冷却从何时开始计算？
  - 选项 A：释放技能瞬间开始冷却（推荐）
  - 选项 B：技能效果结束后开始冷却
  - 选项 C：下个回合开始时开始冷却

- 冷却时间是否为整数回合？
  - 选项 A：是，向下取整
  - 选项 B：是，向上取整
  - 选项 C：支持小数回合（如 2.5 回合）

- 当冷却时间被减少到 0 以下时，如何处理？
  - 选项 A：冷却立即完成（推荐）
  - 选项 B：冷却设为 0
  - 选项 C：返还冷却时间（特殊机制）

---

### 3.2 回合边界

**问题模板：**
- 回合的开始和结束如何定义？
  - 回合开始：玩家获得行动权时
  - 回合结束：玩家选择「结束回合」时

- 跨回合的效果在何时结算？
  - 选项 A：回合开始时结算（推荐）
  - 选项 B：回合结束时结算
  - 选项 C：在效果施加时的同一时点结算

- 「下回合」指的是？
  - 选项 A：自己的下个回合
  - 选项 B：时间线上的下个回合（可能是敌人的）
  - 选项 C：需要明确说明

---

### 3.3 持续时间

**问题模板：**
- 持续 N 回合的效果，实际生效几次？
  - 选项 A：N 次（施加时立即算第 1 次）
  - 选项 B：N 次（施加后下回合开始算第 1 次，推荐）
  - 选项 C：N+1 次（施加时 + N 回合）

- 持续时间到了之后，效果何时移除？
  - 选项 A：回合开始时移除（推荐）
  - 选项 B：回合结束时移除
  - 选项 C：立即移除

---

## 四、触发条件边界

### 4.1 条件判定

**问题模板：**
- 触发条件的判定时点是？
  - 选项 A：事件发生时立即判定（推荐）
  - 选项 B：回合开始时统一判定
  - 选项 C：回合结束时统一判定

- 当多个条件同时满足时，触发顺序如何？
  - 选项 A：按速度/优先级排序
  - 选项 B：按添加顺序
  - 选项 C：同时触发，按固定顺序结算

- 触发条件是「且」还是「或」的关系？
  - 例如：「HP < 50% 且 回合数是 3 的倍数」
  - 例如：「HP < 50% 或 回合数是 3 的倍数」

---

### 4.2 资源判定

**问题模板：**
- 当资源不足时，技能如何处理？
  - 选项 A：技能无法释放（推荐）
  - 选项 B：技能部分生效（按比例）
  - 选项 C：技能完全失效，但消耗资源
  - 选项 D：透支资源（特殊机制）

- 资源消耗发生在何时？
  - 选项 A：释放技能时立即消耗（推荐）
  - 选项 B：技能效果生效时消耗
  - 选项 C：技能效果结束后消耗

- 当资源在技能释放过程中变化时，如何处理？
  - 例如：释放技能时资源足够，但效果结算前资源被偷取
  - 选项 A：以释放时的资源为准（推荐）
  - 选项 B：以结算时的资源为准
  - 选项 C：技能中断

---

### 4.3 目标判定

**问题模板：**
- 当目标在技能释放过程中死亡时，如何处理？
  - 选项 A：技能失效，消耗照扣
  - 选项 B：技能返还，不消耗资源
  - 选项 C：技能可以选择新目标
  - 选项 D：技能仍然生效（鞭尸）

- 当目标数量不足时，如何处理？
  - 例如：技能要求「3 个敌人」，但只有 2 个
  - 选项 A：技能无法释放
  - 选项 B：技能对现有目标生效（推荐）
  - 选项 C：技能效果按比例调整

- 目标优先级如何判定？
  - 例如：技能描述「攻击血量最低的敌人」，但有多个敌人血量相同
  - 选项 A：随机选择
  - 选项 B：选择速度最快的
  - 选项 C：选择位置最靠前的
  - 选项 D：由玩家手动选择

---

## 五、特殊机制边界

### 5.1 免疫与免伤

**问题模板：**
- 是否存在免疫机制？
  - 免疫伤害类型（物理/魔法/火焰等）
  - 免疫状态效果（眩晕/中毒/沉默等）

- 免疫的优先级如何？
  - 选项 A：免疫优先，完全无效化
  - 选项 B：免疫可被穿透（穿透优先）
  - 选项 C：免疫和穿透按概率判定

- 免伤效果的叠加方式？
  - 选项 A：加法叠加（30% + 20% = 50%）
  - 选项 B：乘法叠加（0.7 × 0.8 = 0.56 = 44% 减伤，推荐）
  - 选项 C：只取最高值

---

### 5.2 反击与追击

**问题模板：**
- 反击的触发时机？
  - 选项 A：受到攻击后立即反击（推荐）
  - 选项 B：受到攻击后在下个回合反击
  - 选项 C：回合结束时统一反击

- 反击是否触发对方的反击？
  - 选项 A：是，可能无限套娃（需设置上限）
  - 选项 B：否，反击不触发反击（推荐）
  - 选项 C：仅限一次（反击的反击不触发）

- 追击的触发条件？
  - 选项 A：攻击后概率追击
  - 选项 B：击杀后追击
  - 选项 C：满足特定条件后追击

---

### 5.3 复活与无敌

**问题模板：**
- 复活的触发时机？
  - 选项 A：HP 归零时立即复活（推荐）
  - 选项 B：HP 归零后延迟复活
  - 选项 C：回合开始时检查复活

- 复活后的状态？
  - 选项 A：恢复到满 HP
  - 选项 B：恢复到一定比例 HP（如 50%）
  - 选项 C：恢复到固定 HP 值

- 无敌的效果？
  - 选项 A：完全免疫所有伤害
  - 选项 B：免疫伤害但承受控制
  - 选项 C：免疫控制但承受伤害
  - 选项 D：强制保留 1 HP

---

## 六、随机性边界

### 6.1 概率分布

**问题模板：**
- 随机分布的类型？
  - 选项 A：均匀分布（推荐）
  - 选项 B：正态分布
  - 选项 C：加权分布

- 随机种子是否需要固定？
  - 选项 A：需要，保证结果可复现
  - 选项 B：不需要，每次运行结果不同

---

### 6.2 随机范围

**问题模板：**
- 伤害浮动的范围？
  - 选项 A：85% - 115%（常见）
  - 选项 B：90% - 110%
  - 选项 C：无浮动

- 浮动是整数还是小数？
  - 选项 A：整数浮动（如 ±15%）
  - 选项 B：小数浮动（如 ±15.3%）
  - 选项 C：离散浮动（如 85%/90%/95%/100%/105%/110%/115%）

## 七、检查清单使用指南

### 使用步骤

1. **初步筛选：** 根据设计方案涉及的机制，筛选出相关的边界情况
2. **生成问题：** 将筛选出的边界情况转化为具体问题
3. **优先级排序：** 按重要性排序，优先询问核心机制的边界情况
4. **默认建议：** 为每个问题提供默认建议，降低策划回答成本

### 问题生成模板

```markdown
## 需要澄清的问题

### [类别] 问题标题

**问题描述：** [具体问题]

**选项：**
- 选项 A：[方案 A]
- 选项 B：[方案 B]
- 选项 C：[方案 C]

**默认建议：** [推荐方案及理由]
```

### 示例

```markdown
### [数值边界] 伤害为负数时的处理

**问题描述：** 当计算出的伤害值为负数时（如攻击力 100 - 防御力 150 = -50），如何处理？

**选项：**
- 选项 A：设为 0（最低伤害保护）
- 选项 B：设为 1（强制破防）
- 选项 C：允许负伤害（相当于治疗敌人）

**默认建议：** 选项 A（设为 0），这是最常见的做法，避免出现负伤害的异常情况。
```

## 附录：常见默认值参考

| 参数 | 常见默认值 | 说明 |
|------|-----------|------|
| 最低伤害 | 0 | 不低于 0 |
| 最高伤害 | 无上限 或 攻击力的 300% | 根据游戏类型 |
| BUFF 最大层数 | 10 | 常见范围 5-20 |
| 冷却缩减上限 | 40% | 常见范围 30%-50% |
| 暴击率上限 | 100% | 有些游戏允许超过 100%（增加暴伤） |
| 伤害浮动 | ±15% | 常见范围 ±10%-20% |
| 保底次数 | 10/50/90 | 根据稀有度 |
| 回合开始判定时点 | 获得行动权时 | 最直观 |
| 状态结算时点 | 回合开始时 | 最常见 |
| BUFF 叠加方式 | 同类加法、异类乘法 | 最平衡 |
