# 数据分析专家指南

本文档指导 Agent 从**数据分析专业视角**解读模拟结果，提供有价值的数值平衡性洞察和建议。

## 一、统计分析基础

### 1.1 关键统计指标解读

**集中趋势指标：**

| 指标 | 含义 | 适用场景 | 解读要点 |
|------|------|----------|----------|
| 平均值 | 所有结果的平均水平 | 对称分布 | 易受极值影响 |
| 中位数 | 排序后中间位置的值 | 偏态分布 | 不受极值影响 |
| 众数 | 出现频率最高的值 | 离散分布 | 可能有多个 |

**离散程度指标：**

| 指标 | 含义 | 解读 |
|------|------|------|
| 极差 | 最大值 - 最小值 | 整体波动范围 |
| 方差 | 各值与平均值差的平方平均 | 波动程度（单位平方） |
| 标准差 | 方差的平方根 | 波动程度（与原数据同单位） |
| 变异系数 | 标准差/平均值 | 相对波动程度（%） |

**示例解读：**
```
总伤害输出：
- 平均值：12,450
- 标准差：1,234
- 变异系数：1,234 / 12,450 = 9.9%

解读：变异系数 < 10%，说明伤害输出较为稳定，随机因素影响较小。
```

---

### 1.2 分布形态判断

**正态分布判断：**
```
if (平均值 ≈ 中位数 ≈ 众数) and (左右对称):
    分布类型 = "正态分布"
    特征 = "随机因素影响均衡"
```

**偏态分布判断：**
```
if 平均值 > 中位数:
    分布类型 = "右偏分布"
    特征 = "存在少量极高值"
    示例 = "暴击伤害分布"

if 平均值 < 中位数:
    分布类型 = "左偏分布"
    特征 = "存在少量极低值"
    示例 = "通关回合数分布"
```

## 二、模拟结果分析框架

### 2.1 数据质量检查

**样本量充足性：**
| 模拟次数 | 可靠性 | 建议 |
|----------|--------|------|
| < 30 次 | 低 | 增加至 100 次 |
| 30-100 次 | 中 | 可用于初步分析 |
| 100-500 次 | 高 | 可用于正式分析 |
| > 500 次 | 很高 | 可用于精细分析 |

**异常值检测：**
```python
# 3σ原则（适用于正态分布）
异常值 = 数据点 where |数据点 - 平均值| > 3 × 标准差

# 四分位距法（适用于任意分布）
IQR = Q3 - Q1
异常值 = 数据点 where 数据点 < Q1-1.5×IQR or 数据点 > Q3+1.5×IQR
```

---

### 2.2 核心指标分析清单

**战斗效率指标：**
- [ ] 平均通关回合数
- [ ] 通关回合数标准差（稳定性）
- [ ] 最快/最慢通关记录
- [ ] 通关率（成功率）

**伤害输出指标：**
- [ ] 总伤害输出
- [ ] 平均伤害/回合（DPT）
- [ ] 伤害波动范围（最大/最小）
- [ ] 伤害变异系数（稳定性）

**暴击分析指标：**
- [ ] 实际暴击率 = 暴击次数 / 攻击次数
- [ ] 理论暴击率 vs 实际暴击率（验证随机算法）
- [ ] 连续暴击最大次数（运气最好情况）
- [ ] 连续未暴击最大次数（运气最差情况）

**BUFF 分析指标：**
- [ ] 平均 BUFF 层数
- [ ] BUFF 覆盖率 = 有 BUFF 回合数 / 总回合数
- [ ] 满层 BUFF 持续时间
- [ ] BUFF 断档次数

## 三、数据可视化解读

### 3.1 直方图分析

**伤害分布直方图：**
```
伤害范围      次数
 9000-10000   ████ (4)    ← 低伤害区间
10000-11000   ████████ (8)
11000-12000   ██████████████ (14)
12000-13000   ████████████████████ (20)  ← 峰值区间
13000-14000   ██████████████ (14)
14000-15000   ████████ (8)
15000-16000   ████ (4)    ← 高伤害区间
```

**解读要点：**
1. 峰值位置 = 最常见的输出区间
2. 分布宽度 = 稳定性（越窄越稳定）
3. 对称性 = 随机因素是否均衡
4. 尾部长度 = 极端情况出现概率

**解读要点：**

## 四、敏感性分析方法

### 4.1 单因素敏感性分析

**方法：** 每次只改变一个参数，观察结果变化。

**示例：攻击力影响**
| 攻击力 | 平均总伤害 | 通关回合数 | 伤害提升 | 回合减少 |
|--------|------------|------------|----------|----------|
| 100 | 8,300 | 7.2 | - | - |
| 125 | 10,400 | 6.1 | +25.3% | -1.1 |
| 150 | 12,450 | 5.3 | +50.0% | -1.9 |
| 175 | 14,500 | 4.6 | +74.7% | -2.6 |
| 200 | 16,600 | 4.1 | +100% | -3.1 |

**敏感性系数计算：**
```
敏感性系数 = (结果变化百分比) / (参数变化百分比)

攻击力从 100→200（+100%）:
- 总伤害：8300→16600（+100%）
- 敏感性系数 = 100% / 100% = 1.0

解读：攻击力与总伤害呈线性关系，敏感性系数 = 1
```

---

### 4.2 多因素敏感性分析

**正交实验设计：**
同时改变多个参数，识别交互作用。

**示例：攻击力 × 技能系数**
| 攻击力 | 技能系数 1.0 | 技能系数 1.5 | 技能系数 2.0 |
|--------|-------------|-------------|-------------|
| 100 | 5,000 | 7,500 | 10,000 |
| 150 | 7,500 | 11,250 | 15,000 |
| 200 | 10,000 | 15,000 | 20,000 |

**交互作用判断：**
```
if (技能系数提升效果) 不随 (攻击力) 变化:
    无交互作用 = "两因素独立"
else:
    有交互作用 = "需要综合考虑"

本例：技能系数 1.0→1.5，提升 50%，与攻击力无关
结论：攻击力和技能系数独立，无交互作用
```

## 五、平衡性评估标准

### 5.1 战斗节奏评估

**通关回合数评分：**
| 平均回合数 | 评分 | 玩家体验 | 调整建议 |
|------------|------|----------|----------|
| < 3 | 太快 | 缺乏策略性 | ↓攻击 20% 或 ↑防御 30% |
| 3-4 | 较快 | 爽快但简单 | ↓攻击 10% |
| 5-6 | 适中 | 策略与节奏平衡 | 保持 |
| 7-8 | 较慢 | 偏拖沓 | ↑攻击 10% |
| > 8 | 太慢 | 无聊烦躁 | ↑攻击 20% 或 ↓防御 30% |

---

### 5.2 随机性评估

**暴击率评分：**
| 实际暴击率 vs 理论值 | 评分 | 解读 | 建议 |
|---------------------|------|------|------|
| 偏差 < 5% | 正常 | 随机算法正常 | 保持 |
| 偏差 5-10% | 可接受 | 正常波动范围 | 观察 |
| 偏差 10-20% | 关注 | 可能存在偏差 | 检查 |
| 偏差 > 20% | 异常 | 算法可能有问题 | 修复 |

**伤害波动评分：**
| 变异系数 | 评分 | 体验 | 建议 |
|----------|------|------|------|
| < 5% | 过于稳定 | 缺乏惊喜 | ↑随机因子 |
| 5-15% | 适中 | 稳定中有变化 | 保持 |
| 15-25% | 波动较大 | 看脸 | ↓随机或↑保底 |
| > 25% | 过于随机 | 体验极差 | 必须调整 |

---

### 5.3 付费深度评估

**养成效果评估：**
| 养成前后提升 | 评分 | 玩家感受 | 建议 |
|-------------|------|----------|------|
| < 20% | 提升不明显 | 养成无意义 | ↑养成效果 |
| 20-50% | 适度提升 | 有成就感 | 保持 |
| 50-100% | 显著提升 | 强烈成就感 | 注意平衡 |
| > 100% | 数值膨胀 | 付费碾压 | ↓养成效果 |

## 六、问题诊断与优化建议

### 6.1 常见问题诊断

**问题 1：战斗拖沓**
```
症状：平均通关回合数 > 8
数据特征:
- DPT（伤害/回合）过低
- 敌人 HP 过高

可能原因:
1. 玩家攻击力不足
2. 技能系数过低
3. 敌人 HP 过高

排查方法:
- 对比"玩家攻击 vs 敌人防御"比例
- 检查技能系数是否 < 1.0

优化建议:
- 提升玩家攻击力 15-25%
- 或提升技能系数 0.3-0.5
- 或降低敌人 HP 20-30%
```

**问题 2：伤害波动过大**
```
症状：变异系数 > 20%
数据特征:
- 最大值/最小值 > 3
- 直方图分布过宽

可能原因:
1. 暴击伤害过高
2. 随机因子过大
3. BUFF 叠加不稳定

排查方法:
- 分离"暴击回合"和"非暴击回合"分别统计
- 检查随机浮动范围是否 > ±20%

优化建议:
- 降低暴击伤害 (2.0→1.8)
- 缩小随机浮动 (±20%→±10%)
- 增加保底机制
```

**问题 3：胜率异常**
```
症状：胜率 < 90% 或 胜率 = 100%（无悬念）
数据特征:
- 低胜率：大量模拟未击败敌人
- 高胜率：所有模拟快速通关

可能原因:
1. 数值设计不合理
2. 边界情况未处理
3. 随机性影响过大

排查方法:
- 查看失败案例的共同特征
- 检查是否有"必败"情况

优化建议:
- 调整核心公式参数
- 增加保底机制
- 设置动态难度
```

## 八、案例分析

### 案例：技能数值调整分析

**原始数据：**
- 平均通关回合：7.2 回合
- 伤害变异系数：18%
- 胜率：85%

**问题分析：**
1. 通关回合 7.2 > 理想值 5-6，战斗偏拖沓
2. 变异系数 18% > 理想值 15%，波动较大
3. 胜率 85% < 理想值 95%，存在失败情况

**敏感性分析：**
| 调整方案 | 回合数 | 变异系数 | 胜率 |
|----------|--------|----------|------|
| 攻击力 +10% | 6.5 | 17% | 88% |
| 攻击力 +20% | 5.8 | 16% | 92% |
| 技能系数 +0.3 | 6.2 | 15% | 90% |
| 暴击伤害 -0.2 | 7.0 | 12% | 87% |

**综合建议：**
```
推荐组合方案:
1. 攻击力 +15% → 回合数降至 6.2，胜率升至 90%
2. 技能系数 +0.2 → 进一步降至 5.8 回合
3. 暴击伤害 -0.1 → 变异系数降至 15%

预期效果:
- 平均通关回合：7.2 → 5.8
- 伤害变异系数：18% → 15%
- 胜率：85% → 93%
```

## 九、总结

作为数据分析专家，Agent 应该：

1. **用数据说话** - 所有结论都有数据支撑
2. **提供对比** - 当前值 vs 理想值 vs 行业标准
3. **给出建议** - 不仅指出问题，还要提供可执行的调整方案
4. **量化效果** - 建议调整后预期改善多少
5. **评估风险** - 调整可能带来的副作用
