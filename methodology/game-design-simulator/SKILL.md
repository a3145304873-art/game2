# Game Design Simulator Skill

## ⚠️ 重要：强制交互规则

**此技能使用严格的 8 步工作流，Agent 必须遵守以下规则：**

1. **每次只执行一个步骤** - 禁止一次性输出多个步骤的内容
2. **每步完成后必须明确等待确认** - 输出"[请确认]"提示语并停止
3. **用户确认后才能继续下一步** - 未收到确认前禁止继续
4. **用户可以修改任何输出** - 接受用户的编辑和反馈

**违反示例（错误 ❌）：**
- 一次性输出"澄清问题 + 实体列表 + 流程链路"
- 生成问题后不等用户回答就直接继续

**正确示例（正确 ✅）：**
- 输出问题列表 → 停止 → 等用户回答 → 继续下一步

## 何时使用此技能

当游戏策划需要将**设计方案转化为可运行的数值模拟代码**时使用此技能。

**适用场景：**
- 验证战斗数值公式（伤害计算、BUFF 叠加、技能冷却等）
- 测试经济系统平衡（资源产出、消耗曲线、成长速率等）
- 模拟随机概率事件（抽卡概率、暴击率、掉落率等）
- 验证回合制逻辑（行动顺序、状态判定、胜负条件等）
- 快速原型验证任何涉及数值计算的游戏机制

**不适用的场景：**
- 需要图形界面的模拟（纯文本/控制台输出）
- 需要真实游戏引擎集成的逻辑（这是独立模拟代码）
- 非数值相关的纯逻辑验证

## 8 步工作流

此技能遵循严格的 8 步交互式工作流，确保策划在每个关键环节都有确认和修改的机会。

### 步骤 1: 解析需求文档

**策划操作：** 将设计文档发送给 Agent（支持 Excel、Word、TXT、Markdown 等任意格式）。

**Agent 操作：**
1. **直接读取文档内容**（使用系统内置工具，无需额外脚本）
2. 识别文档中提到的所有游戏机制、实体、数值、公式
3. **输出：简要总结理解的需求内容（100-200 字）**
4. **停止并等待确认**

**Agent 输出格式：**
```markdown
## 步骤 1/8: 需求理解

**我已理解您的需求：**
- [简要总结需求要点，包括核心机制、主要实体、关键公式等]

**文档中提到的关键信息：**
- 实体：[列出提到的实体]
- 公式：[列出提到的公式]
- 待明确：[列出模糊或未明确的地方]

**接下来：** 我将分析文档中的模糊设定和边界情况，生成澄清问题列表。

---
**[请确认]** 我的理解是否准确？如有偏差请指出，确认后我将进入步骤 2。
```

**⚠️ 注意事项：**
- 如果是 Excel 文件，Agent 应直接使用内置工具读取，不要要求用户安装 pandas/openpyxl
- 如果读取有问题，可以让用户复制粘贴内容，或导出为 CSV 后上传
- 不要强制要求编码转换，直接解析内容即可

**输入格式：** 可以是任何文本格式的设计文档、方案草稿、需求描述。

**⚠️ 强制规则：** 输出总结后**必须停止**，等待用户确认后才能进入步骤 2。

---

### 步骤 2: 生成澄清问题列表

**Agent 操作：**
1. 分析文档中的**模糊设定**和**遗漏边界情况**
2. 生成问题列表，包含：
   - 模糊的数值定义（如"适量"、"大幅度"等）
   - 缺失的边界处理（如"HP 减为负数怎么处理"）
   - 未明确的触发条件（如"何时开始计算冷却"）
   - 潜在的特殊情况（如"最大层数限制"、"多 BUFF 叠加优先级"）
3. **停止并等待用户逐一回答**

**问题模板：**
```markdown
## 步骤 2/8: 需要澄清的问题

我分析了您的文档，发现以下**{N} 个问题**需要澄清：

### 数值定义类
1. 文档中提到"伤害大幅提升"，具体提升幅度是多少？（建议：50%/100%/150%）
2. "短时间内"具体指多少回合/秒？

### 边界情况类
3. 当 HP 减为负数时，是立即死亡还是保留 1HP？
4. BUFF 层数是否有上限？如有，上限是多少？（建议：5/10/无限）
5. 当多个同类型 BUFF 同时存在时，如何叠加？（取最高/累加/乘算）

### 触发条件类
6. 技能冷却从何时开始计算？（释放瞬间/效果结束后/回合开始）

---
**[请回答]** 请逐一回答上述问题（可直接在问题上修改），全部回答完成后我将进入步骤 3。
```

**策划操作：** 逐一回答问题，可直接在问题上修改或补充。

**⚠️ 强制规则：** 输出问题列表后**必须停止**，等待用户全部回答完成后才能进入步骤 3。

### 步骤 4: 生成纯语言流程链路

**Agent 操作：**

4. **停止并等待用户验收**

**流程链路模板：**
```markdown
## 步骤 4/8: 功能运行流程链路

根据您的需求，我梳理了以下功能运行流程：

1. 初始化数据：创建玩家、敌人对象，设置初始数值
2. 回合开始判定：检查是否有先手效果/场地效果触发
3. 玩家行动阶段：
   - 3.1 检查技能是否可用（冷却是否为 0，资源是否充足）
   - 3.2 如果技能可用，执行技能释放逻辑
   - 3.3 如果技能不可用，执行普通攻击逻辑
4. 伤害计算阶段：
   - 4.1 读取攻击力和防御力数值
   - 4.2 应用技能伤害系数
   - 4.3 应用 BUFF 加成系数
   - 4.4 计算最终伤害值 = (攻击力 × 技能系数 × BUFF 系数) - 防御力
   - 4.5 如果伤害 < 0，则设为 0（最低伤害保护）
5. 伤害应用阶段：
   - 5.1 敌人 HP = 敌人 HP - 最终伤害
   - 5.2 如果敌人 HP <= 0，触发死亡逻辑
   - 5.3 如果敌人 HP > 0，检查是否触发反击
6. BUFF 更新阶段：
   - 6.1 所有活跃 BUFF 持续回合数 -1
   - 6.2 如果持续回合 <= 0，移除 BUFF
   - 6.3 检查是否有新 BUFF 触发
7. 冷却更新阶段：
   - 7.1 所有技能的当前冷却 -1
   - 7.2 如果当前冷却 < 0，则设为 0
8. 回合结束判定：
   - 8.1 检查胜负条件
   - 8.2 如果未分出胜负，进入下一回合

---
**[请验收]** 请检查流程逻辑是否合理：
- 如需修改，请直接编辑步骤内容或指出需要调整的地方
- 确认无误后回复"确认"或"流程没问题"，我将进入步骤 5 开始编写代码
```

**策划操作：**

### 步骤 8: 批量数值演算与报告生成

**触发条件：** 用户确认 HTML 原型可以正常运行后。

**Agent 操作：**
1. 使用当前配置参数，**自动运行多次模拟**（默认 10-100 次）
2. 收集所有模拟结果，进行**统计分析**
3. 生成**数值演算报告**，包含：
   - 关键指标分布（平均值、最大值、最小值、标准差）

## 最佳实践

### 1. 提供清晰的需求文档

**好的需求文档：**
- 明确列出所有实体和属性
- 写出具体公式（如"伤害 = 攻击×1.5 - 防御"）
- 说明边界情况（如"最低伤害为 0"）
- 标注可变参数（如"可配置的冷却时间"）

**不好的需求文档：**
- "伤害大幅提升"（模糊）
- "合理的冷却时间"（不明确）
- "正常叠加"（无具体规则）

### 2. 充分利用配置区

- 将所有可能调整的参数放在配置区
- 使用有意义的变量名（如 `SKILL_DAMAGE_MULTIPLIER` 而非 `A = 1.5`）
- 添加注释说明每个参数的含义
- 分组管理相关参数（如"玩家属性"、"技能参数"）

### 3. 验证多场景

- 测试极端情况（如攻击力极高/极低）
- 测试边界值（如 BUFF 叠满、HP 归零）
- 多次运行取平均值（特别是含随机性的模拟）
- 对比不同参数组合的结果

### 4. 逐步迭代

- 先验证核心公式，再添加复杂逻辑
- 每添加一个新机制，先单独测试
- 保留每次验证的代码版本，方便回溯
- 记录关键结论（如"攻击力超过 500 后收益递减"）

## 常见问题

### Q1: 如何添加随机因素（如暴击）？

**答：** 在配置区添加暴击概率参数，在逻辑区使用 `random` 模块：

```python
# 配置区
CRIT_RATE = 0.2  # 20% 暴击率
CRIT_MULTIPLIER = 2.0  # 暴击伤害倍率

# 逻辑区
import random
def calculate_damage(...):
    damage = ...  # 基础伤害
    if random.random() < CRIT_RATE:
        damage *= CRIT_MULTIPLIER
        print("暴击！")
    return damage
```

### Q2: 如何模拟多个敌人？

**答：** 在初始化阶段创建敌人列表：

```python
# 配置区
ENEMY_COUNT = 3
ENEMY_BASE_HP = 2000

# 逻辑区
enemies = [Enemy() for _ in range(ENEMY_COUNT)]
for enemy in enemies:
    enemy.current_hp = ENEMY_BASE_HP
```

### Q3: 如何输出结果到 CSV 文件？

**答：** 添加 CSV 导出功能：

```python
import csv

def run_simulation(...):
    all_stats = []
    # ... 模拟逻辑 ...

    # 导出 CSV
    with open('simulation_result.csv', 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=all_stats[0].keys())
        writer.writeheader()
        writer.writerows(all_stats)
    print("结果已导出到 simulation_result.csv")
```

### Q4: 如何测试多组参数组合？

**答：** 添加参数循环：

```python
# 测试不同攻击力下的通关回合数
for attack in [100, 150, 200, 250, 300]:
    PLAYER_BASE_ATTACK = attack
    result = run_simulation()
    print(f"攻击力 {attack}: {len(result)} 回合通关")
```

### Q5: 策划不会 Python 怎么办？

**答：**
- 配置区参数都是简单的变量赋值，只需修改等号右边的数字
- 可要求 Agent 添加更详细的注释
- 可要求生成 Excel 配置表 + Python 读取的形式
- 可要求生成 Web 界面版本（需额外开发）
