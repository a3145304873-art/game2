# Game Design Simulator - 游戏数值模拟器

## 📌 技能定位

**一键将策划方案转化为可运行的 HTML 模拟界面**，自动运行 100 次模拟并生成数值平衡性报告。

**适用场景：** 战斗数值验证、经济系统平衡、概率事件模拟、回合制逻辑验证

---

## 🎯 核心价值

| 痛点 | 解决方案 |
|------|----------|
| 数值方案难以验证 | 生成 HTML 界面，双击即可运行测试 |
| 需要安装 Python 环境 | 单文件 HTML，无需任何环境 |
| 单次模拟偶然性大 | 自动运行 100 次，统计分析结果 |
| 平衡性判断靠感觉 | 数据驱动报告，提供量化调整建议 |

---

## 🚀 使用流程（8 步强制交互）

```
1. 上传需求文档（Excel/Word/TXT 均可）
   ↓ [Agent 解析需求]
2. 回答澄清问题（模糊数值、边界情况）
   ↓ [确认无误]
3. 确认实体与属性（玩家/技能/BUFF/敌人）
   ↓ [确认无误]
4. 验收功能流程链路（纯文字描述）
   ↓ [确认逻辑]
5. 确认界面设计草图（ASCII 布局图）
   ↓ [确认布局]
6. 确认可配置参数和输出结果
   ↓ [确认完整]
7. 接收 HTML 文件 → 双击运行测试
   ↓ [确认运行正常]
8. 接收数值演算报告 → 查看平衡性分析
   ↓ [完成]
```

**关键特性：** 每步必须等待策划确认后才能继续，策划可随时修改任何输出。

## 💡 示例效果

### HTML 界面预览
- **左侧配置区：** 玩家属性、技能参数、BUFF 参数（滑块/输入框调整）
- **右侧结果区：** 关键指标卡、详细数据表、HP 曲线图、伤害分布图

### 报告核心内容
- **统计分析：** 平均值、标准差、分布、变异系数
- **敏感性分析：** 攻击力/技能系数影响对比表
- **平衡性评估：** 通关时间、暴击频率、伤害稳定性评分
- **调整建议：** 量化调整方案 + 预期效果

---

## ⚠️ 注意事项

1. **文档读取：** 直接上传 Excel/Word/TXT，Agent 会自动读取，无需手动转换编码
2. **环境要求：** HTML 文件双击即可运行，无需安装 Python 或任何库
3. **批量演算：** 默认运行 100 次模拟（可调整），耗时约 2-5 秒
4. **强制交互：** 每步都需要策划确认，确保结果符合预期

## 🎓  expert 能力

技能内置两个专家指南，让 Agent 具备：

**数值策划专家能力：**
- 识别模糊定义和边界漏洞
- 提供专业默认值建议
- 按优先级排序澄清问题（P0/P1/P2）

**数据分析专家能力：**
- 统计分析（平均值/标准差/变异系数）
- 敏感性分析（单因素/多因素）
- 平衡性评估与量化调整建议
