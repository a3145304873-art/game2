# 挑战机制设计参考

## 变量定义
- `实体和机制` (Object): 核心机制提供的用于定义挑战的基础组件
- `解决状态` (State): 挑战被完成或满足条件时的状态
- `位置属性` (Attribute): 关卡设计师设置的实体在游戏世界中的坐标
- `被保护实体` (Object): 需要玩家守护的关键单位或项目（如王、国旗）
- `敌方生产速率` (Float/units_per_time): 敌方单位生成系统的产出速度
- `玩家消灭速率` (Float/units_per_time): 玩家摧毁敌方单位的平均速度
- `策略集合` (Set/strategies): 可用的中间级策略选项（直接消灭/经济干扰/防御/混合等）
- `当前活跃挑战` (Set/challenges): 玩家当前同时考虑的多重挑战

## 约束条件
- 被保护对象通常价值极高
- 不适用于纯线性动作游戏
- 需要系统深度支持多种策略路径
- 需要平衡不同策略的有效性

## 触发条件
- IF (存在脆弱且关键的目标) THEN (应用保护挑战机制)
- IF (游戏包含生产系统) AND (直接消灭敌方单位的速度 < 敌方生产速度) THEN 需要设计隐式的经济/生产系统干扰策略
