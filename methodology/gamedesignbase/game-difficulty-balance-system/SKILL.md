# 游戏难度平衡系统

## 何时使用
- 设计游戏挑战的难度曲线
- 评估和调整关卡难度
- 实现多难度模式系统
- 平衡玩家能力与挑战难度
- 设计关卡间的难度过渡

## 核心框架

### 感知困难度四因素

感知困难度是玩家主观体验到的难度，由以下4个可控因素决定：

1. **固有技能要求** - 完成挑战所需的基础操作与认知能力
2. **压力强度** - 时间限制、生存威胁、资源稀缺性
3. **游戏提供的能力** - 玩家角色可用的技能、装备、道具
4. **游戏内经验** - 玩家通过游戏进程积累的知识和熟练度

不可控因素：玩家的事前经验和天赋

### 涨潮状态目标

根据Csikszentmihalyi的涨潮理论：
- **挑战太难 > 能力** → 玩家焦虑
- **挑战太易 < 能力** → 玩家厌倦
- **挑战 ≈ 能力** → 进入涨潮状态（最佳体验）

## 执行流程

### 1. 评估绝对难度

**基准比较评估法**：

1. 建立基准挑战（同类型最小难度版本）
2. 识别两个维度：
   - 固有技能需求数量
   - 压力强度
3. 计算绝对难度公式：
   ```
   绝对难度 = (目标挑战的固有技能需求 + 压力强度) / (基准挑战的最低技能需求 + 最低压力)
   ```

**固有技能评估方法**：

1. 确定挑战类型（身体任务/精神任务/混合任务）
2. 隔离时间因素（假设无限时间）
3. 评估具体技能要求：
   - **瞄准类**：目标距离越远、目标越小 → 技能要求越高
   - **解谜类**：可用线索越少 → 技能要求越高
   - **知识类**：知识越稀有 → 技能要求越高

### 2. 设计难度模式

**标准配置**：提供三个难度选项（简单/正常/困难）

**调整方法**（动作/动作冒险类）：
- 敌人生命值：困难模式提升50%-100%
- 敌人伤害输出：困难模式提升
- 敌人数量：困难模式增加波次或密度
- AI调整：困难模式更聪明、更敏感

### 3. 控制关卡步调

**步调变化原则**：
- 从高压力挑战开始
- 随后安排休息期（无挑战）
- 接着跟随容易的挑战
- 逐渐再次上升到高压力

**资源平衡逻辑**：
- 玩家消耗资源后变得脆弱
- 在消耗大量资源后立即提供新资源
- 示例：一大群敌人后放置弹药盒或医疗包

### 4. 关卡间过渡

**平滑过渡原则**：
- 禁止在关卡边界处引入突然的难度跳跃
- 下一关卡开局应提供温和的复健机制
- 难度增长率控制在1.0-1.3之间
- 考虑玩家在关卡间的经验衰减

## 关键约束

- 不存在跨类别的通用难度度量单位
- 难度判断因受众而异
- 纯反应时间测试类挑战的固有技能值为0
- 感知难度应保持平滑波动，避免突然上升或下降

## 验证方法

1. 测试玩家在中断30分钟-数小时后重新进入游戏的体验
2. 对每一个挑战尝试尽可能多的动作和动作组合
3. 监控快速提高战斗力的动作（高风险）
4. 确保感知困难度在目标范围内
