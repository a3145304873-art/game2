# 难度计算示例

## 生命值与难度关系

当其他条件相等时，若敌人A的生命值是敌人B的两倍：
- 存活时间 = 2倍
- 击败难度 = 2倍

## 3d6骰子概率分布

- 结果范围：3到18
- 中间值（如10、11）出现概率最高
- 极端值3和18出现概率最低（1/216 ≈ 0.46%）
- 对比单骰子（3-18范围）：每个结果概率 = 1/16 = 6.25%
- 差异：单骰子得到极端值的概率是3d6的约13.6倍

## 难度倍数计算示例

基准敌人：站立不动、不能造成伤害、一次攻击即可击杀

增强敌人：生命值翻倍、四处移动、抵抗攻击并反击

绝对难度 = (双倍攻击次数 + 瞄准技能 + 时间压力 + 生存压力) / (最低技能 + 最低压力)
