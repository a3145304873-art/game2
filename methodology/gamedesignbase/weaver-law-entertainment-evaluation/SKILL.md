# 韦佛定律娱乐质量评估

## 概述

韦佛定律（Weaver's Law）指出：**娱乐质量与时间感知呈反比关系**。当玩家感觉"时间飞逝"时，表明娱乐质量高；当感觉"度日如年"时，表明娱乐质量低。

该定律由 Bethesda Softworks 创始人 Chris Weaver 提出，是评估游戏沉浸感和娱乐效果的核心指标。

## 何时使用

在以下场景应用此技能：

- **玩家反馈负面**：玩家报告游戏"枯燥"、"漫长"或"时间过得很慢"
- **体验质量评估**：需要量化评估游戏 Demo、测试版本或特定关卡的娱乐质量
- **沉浸感诊断**：怀疑游戏节奏或内容密度存在问题，需要客观化评估框架
- **设计验证**：验证核心玩法循环是否成功创造"心流"体验

## 执行步骤

### 1. 收集时间感知数据
通过以下方式获取玩家主观时间感知：

- **直接询问**："你觉得刚才的游戏时间持续了多久？"（对比实际时间）
- **行为观察**：记录玩家是否频繁查看时间、表现出焦躁行为
- **问卷量表**：使用 1-10 分评估"时间过得快/慢"的主观感受

### 2. 应用反比关系分析
根据韦佛定律计算娱乐质量指数：

```
娱乐质量 ∝ 1 / 主观时间感知系数
```

- **主观时间感知系数** = 玩家估计时间 / 实际经过时间
  - 系数 > 1：时间被高估（感觉过得慢）→ 娱乐质量低
  - 系数 = 1：时间感知准确 → 娱乐质量中等
  - 系数 < 1：时间被低估（感觉过得快）→ 娱乐质量高

### 3. 诊断质量等级
根据分析结果判定体验等级：

| 时间感知 | 质量评级 | 体验状态 | 设计含义 |
|---------|---------|---------|---------|
| 飞逝感（系数 0.3-0.7） | 优秀 | 深度沉浸/心流 | 保持当前设计 |
| 正常偏快（系数 0.7-0.9） | 良好 | 专注投入 | 微调优化 |
| 接近实际（系数 0.9-1.1） | 一般 | 普通体验 | 需要改进 |
| 缓慢感（系数 1.1-1.5） | 较差 | 分心/无聊 | 重大调整 |
| 度日如年（系数 >1.5） | 差 | 痛苦体验 | 重新设计 |

### 4. 制定优化方案
根据诊断结果采取行动：

**高娱乐质量（时间飞逝）**：
- 识别并强化当前创造沉浸感的关键机制
- 在类似场景复用成功的设计模式

**低娱乐质量（时间缓慢）**：
- **内容密度**：检查是否内容过于稀疏或重复
- **节奏控制**：分析是否存在过长加载、拖沓动画或强制等待
- **反馈频率**：确保玩家操作获得即时、清晰的反馈
- **目标清晰度**：确认玩家始终清楚当前目标和下一步行动

## 关键指标

- **心流阈值**：当主观时间系数 < 0.5 时，通常表明进入心流状态
- **无聊警戒线**：系数 > 1.2 时，玩家流失风险显著增加
- **个体差异**：注意不同玩家类型（硬核/休闲）的时间感知基准差异

## 注意事项

- 此定律适用于**主观体验评估**，不用于客观物理时间测量
- 时间感知受玩家情绪、疲劳度、外部环境等因素影响，需结合多维度数据
- 某些特定游戏类型（如策略游戏的深度思考阶段）可能故意延长时间感知，需结合游戏类型判断
