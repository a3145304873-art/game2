# 存档系统详细设计

## 存档触发点设计

### 自动保存点
- 关卡开始前
- 重要剧情节点后
- Boss战前
- 进入危险区域前

### 手动保存限制
- 仅在安全区域
- 仅在非战斗状态
- 限制保存次数（如Roguelike）
- 保存消耗资源

## 存档数据结构

### 必须保存的数据
- 玩家位置和状态
- 任务进度
- 物品栏内容
- 角色属性
- 世界状态（已访问区域、NPC状态）
- 剧情分支选择

### 可选保存的数据
- 游戏时间
- 统计数据
- 截图
- 播放记录

## 存档验证机制

### 完整性检查
- 校验和验证
- 数据范围验证
- 依赖关系验证

### 版本兼容性
- 版本号标记
- 数据迁移策略
- 向后兼容处理

## 云存档同步

### 同步策略
- 实时同步
- 定期同步
- 手动同步

### 冲突处理
- 时间戳优先
- 服务器优先
- 客户端优先
- 用户选择

## 对话系统UI设计

### 布局建议
```
┌─────────────────────────┐
│   对话历史窗口          │
│   NPC: ...              │
│   玩家: ...             │
├─────────────────────────┤
│   NPC当前发言           │
├─────────────────────────┤
│   [选项1] (外交)        │
│   [选项2] (恐吓)        │
│   [选项3] (虚张声势)    │
│   [再见]                │
└─────────────────────────┘
```

### 说话方式标记
- **外交**：蓝色，温和语气
- **恐吓**：红色，攻击性语气
- **虚张声势**：黄色，不确定语气
- **幽默**：绿色，轻松语气
