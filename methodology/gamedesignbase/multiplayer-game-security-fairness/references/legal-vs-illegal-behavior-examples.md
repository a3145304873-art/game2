# 合法与非法行为示例

## 合法但非预期行为

### 《雷神之锤》火箭跳
- **行为描述**：玩家使用火箭发射器推动角色前进，达到设计师未预想到的移动速度
- **判定理由**：
  - 使用游戏内正常机制
  - 不修改游戏代码或数据
  - 需要技巧和练习
  - 设计师应预先想到或测试者应发现
- **处理结果**：成为游戏的标准战略，被后续游戏借鉴

### 其他示例
- 利用游戏物理引擎的边界行为
- 发现并利用设计师未注意到的战术组合
- 通过正常游戏机制获得优势的策略

## 非法作弊行为

### 软件入侵
- **行为描述**：修改游戏客户端、注入代码、破解服务器
- **判定理由**：
  - 突破软件安全机制
  - 修改游戏数据或逻辑
  - 违反软件使用协议
  - 可能涉及法律问题
- **处理结果**：必须封禁和防范

### 其他示例
- 使用外挂程序
- 修改内存数据
- 网络包篡改
- 服务器入侵

## 关键区别

| 维度 | 合法非预期行为 | 非法作弊行为 |
|------|--------------|------------|
| 是否修改软件 | 否 | 是 |
| 是否使用外部工具 | 否 | 是 |
| 是否需要技巧 | 是 | 否 |
| 是否违反协议 | 否 | 是 |
| 设计师态度 | 可能接受并采纳 | 必须阻止 |
