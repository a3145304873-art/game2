# 谜题难度调节详细参数

## 形式逻辑谜题参数

### 物体数量影响

| 物体数 | 复杂度 | 示例 |
|-------|--------|------|
| 2-4 | 低 | 简单开关谜题 |
| 5-8 | 中 | 标准魔方 |
| 9-16 | 高 | 复杂机关 |
| 17+ | 极高 | 专家级谜题 |

### 操作方式多样性

- 单一操作（仅旋转）：简单
- 两种操作（旋转+移动）：中等
- 三种以上操作（旋转+移动+组合）：复杂

### 多解评分系统

```
三星制示例：
- 最优解：★★★
- 可行解：★★☆  
- 勉强解：★☆☆
```

## 记忆挑战时间参数

| 难度 | 记忆时间 | 回忆间隔 | 适用场景 |
|------|---------|---------|---------|
| 简单 | 30s | 立即 | 教学关卡 |
| 中等 | 15s | 2分钟 | 标准探索 |
| 困难 | 5s | 10分钟+ | 硬核挑战 |

## 模式识别复杂度分级

### 视觉模式

- 简单：2-3元素重复（红-蓝-红-蓝）
- 中等：4-6元素序列，单一维度
- 复杂：多维度变化（颜色+形状+位置）
- 极复杂：嵌套模式、条件变化

### 敌人AI行为模式

| 阶段 | 模式特征 | 设计目的 |
|------|---------|---------|
| 普通敌人 | 单一可预测行为 | 教学、建立预期 |
| 精英敌人 | 2-3行为轮换 | 测试适应 |
| Boss | 多阶段、模式变化、组合攻击 | 综合考验 |
