# 单位机动性属性定义

## 何时使用

- 设计战术游戏或战争游戏的单位属性
- 定义海战、空战或载具战斗单位的机动性参数
- 平衡单位间的相对优势和劣势
- 实现基于物理或模拟的真实载具行为

## 基础空间属性

### 位置（Position）
- 定义单位在空间中的坐标

### 朝向（Orientation）
- 定义单位面向的方向
- **重要性**：最大炮火输出方向通常为侧向（与运动方向呈90度夹角）

## 视野与可见性

### 观察范围（Sight Range）
- 定义单位的视野
- **物理约束**：受地球曲率影响（桅杆越高看得越远）

### 可见性（Visibility）
- 定义单位被发现的难易程度
- **规则**：大型船舶比小型船只更容易看到

**约束**：这些考虑不适用于信息全部公开的游戏（如国际象棋）

## 速度属性（Speed）
- 公海船只最关键的属性
- **战术价值**：快速逃离敌人有助于求生；大量快速单位可通过"边打边跑"战术击败巨型单位

## 射程属性（Fire Range）
- 定义炮火的最远打击范围（火力范围）
- **战术价值**：射程比敌人远可在被击中前击沉敌人
- **无敌组合**：优越的速度 + 远距离射程（保持在危险距离之外）

## 机动性（转弯速率）
- **定义**：船只的转弯速率（Turn Rate）
- **战术价值**：
  - 转向更快的船只可以从转向更慢的船只身边逃离
  - 更灵活的单位能更快通过障碍地形

## 航程距离（Fuel Range）
- **定义**：单位在补充燃料前可行驶的距离
- **约束**：机动能力受限于返回港口的需求

### 特殊状态：Bingo Fuel
- 当船只仅有足够燃料直接返回基地时达到此状态
- **脆弱性**：此时船只脆弱，因为返回时不能有任何多余操作

## 属性变量汇总

| 属性 | 类型 | 描述 |
|------|------|------|
| position | coordinates | 空间坐标 |
| orientation | angle/direction | 面向方向 |
| sight_range | distance | 观察范围 |
| visibility | probability/level | 被发现难易度 |
| speed | velocity | 移动速度 |
| fire_range | distance | 炮火射程 |
| turn_rate | angular_velocity | 转弯速率 |
| fuel_range | distance | 航程距离 |
