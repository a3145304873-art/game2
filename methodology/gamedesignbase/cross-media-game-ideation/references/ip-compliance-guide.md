# 知识产权合规详细指南

## 法律约束说明

**重要**：本指南主要基于美国司法管辖区法律，其他地区需参考当地法律。

## 模仿与戏仿保护（美国法律）

合法模仿必须满足以下条件：
1. **明显差异性**：作品必须与来源明显不同，不能造成消费者混淆
2. **评论功能**：必须对原作起到评论、批评或教育功能
3. **非恶意性**：不得是诽谤或意图造成损害

## 风险等级评估

### 高风险（严格避免）
- 使用受保护角色的名称、外观或标志性台词
- 复制特定场景的分镜或构图
- 使用原创音乐的旋律或采样
- 直接翻译或复制文本描述
- 使用 trademarked 的符号或标识

### 中风险（谨慎修改）
- 借鉴类型 tropes（如"黑色电影"视觉风格）
- 使用历史事件但采用相似叙事结构
- 参考公共领域作品但使用现代诠释（需确认版权到期日期）

### 低风险（通常安全）
- 借鉴通用概念（如"太空歌剧"设定）
- 受事实历史事件启发
- 对过期IP的重新诠释

## 地区法律差异

- **欧盟**：更严格的道德权利保护，作者可反对歪曲作品
- **日本**：对同人作品有独特的宽容惯例，但商业作品标准严格
- **中国**：强调"思想表达二分法"，保护表达不保护思想

## 尽职调查清单

投入生产前确认：
- [ ] 未使用 trademarked 名称或角色
- [ ] 艺术设计是原创的，非 traced 或 heavily referenced
- [ ] 音频资产是原创或正确授权的
- [ ] 游戏机制实现方式独特，仅概念受启发
- [ ] 已咨询法律顾问（预算允许时）

## 改编案例研究

### 成功案例：GTA Vice City
- **借鉴**：80年代犯罪剧视觉风格、音乐、氛围
- **合规点**：原创角色和故事；对时代类型的整体致敬而非特定复制；未使用《迈阿密风云》具体角色

### 成功案例：No One Lives Forever
- **借鉴**：间谍动作类型、gadget使用、国际阴谋
- **合规点**：原创主角（Cate Archer）；戏仿间谍片套路；对类型本身的评论

### 概念借鉴：The Sims
- **来源**：《建筑模式语言》（建筑学理论书籍）
- **合规点**：从非游戏技术书籍获取系统设计理念；完全转换媒介（书→游戏）；属概念借鉴而非内容复制
