# 印度游戏市场移动优先策略与文化适配

## 使用场景
当以下任一情况时使用此技能：
- 目标市场为印度，需要评估游戏平台选择
- 规划游戏内容在印度市场的本地化
- 判断印度游戏市场的进入时机
- 需要了解印度文化对游戏内容的限制

## 执行流程

### 第一步：市场基础数据分析

收集并分析以下关键指标：
1. **人口规模**：确认印度作为仅次于中国的人口大国，具备巨大潜在用户基数
2. **设备普及率对比**：
   - 计算机数量约为中国的四分之一
   - PC/主机游戏市场基础薄弱
3. **移动设备现状**：
   - 手机总量约4亿部
   - 当前仅10%具备游戏功能（约4000万设备）

### 第二步：平台选择决策

**决策树逻辑**：

```
评估硬件障碍
├─ 家长教育优先级高 → 不愿购买电视 → 主机市场受限
├─ PC拥有率低 → 计算机游戏市场受限
└─ 结论：专注移动平台
```

**移动市场战略定位**：
- 当前：10%游戏手机比例，处于早期阶段
- 预期：未来几年游戏手机比例将显著提升
- 策略：提前布局移动游戏，等待硬件普及率提升

### 第三步：语言与开发策略

**目标用户分析**：
- 中产阶级使用英语
- 游戏制作语言障碍较低

**开发决策**：
- 可直接使用英语开发
- 或简化本地化流程
- 优先发布英语版本

### 第四步：文化内容限制评估

**社会文化特征**：
- 极度保守的社会风气
- 公开亲密行为被严格禁止

**内容审查清单**：
- [ ] 禁止包含公开亲密行为（接吻、拥抱等）
- [ ] 避免挑战传统社会规范的内容
- [ ] 角色服装设计需保守
- [ ] 社交互动功能需符合本地道德标准

### 第五步：市场进入时机判断

**当前阶段**：准备期（仅10%手机支持游戏）

**进入策略**：
1. 轻度游戏优先（适配低性能设备）
2. 建立品牌认知
3. 等待硬件升级周期（智能手机普及）

**长期潜力**：
- 人口红利
- 移动优先趋势
- 英语优势

## 输出成果

完成分析后，输出以下内容：
1. 平台技术规格（适配低性能手机）
2. 内容审查清单（避免公开亲密行为）
3. 英语版本优先发布计划
4. 市场进入时间表

## 约束条件

- 不适用主机游戏和高端PC游戏市场
- 不适用含有公开亲密行为的内容
- 当前智能手机普及率有限（10%）

## 前置条件

- 英语游戏开发能力
- 移动平台技术
- 文化敏感性分析能力
