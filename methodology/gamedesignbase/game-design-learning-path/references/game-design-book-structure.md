# 游戏设计书籍详细结构

## 书籍信息

- **书名**：游戏设计基础 (Fundamentals of Game Design)
- **作者**：Ernest Adams
- **总章节数**：17章
- **教学方法**：从基础认知到设计实践再到专项主题的递进式教学

## 变量说明

- **章节数**：17（本书总章节数量）
- **基础章节范围**：第1-6章（涵盖概述、类型、玩家、设备、商业模式）
- **设计章节范围**：第7-16章（涵盖概念、世界、玩法、角色、叙事、UX、可玩性、机制、平衡、关卡）
- **专项章节**：第17章（专门讨论在线游戏）

## 补充资源

### 独立成册类型的游戏电子书
- **网址**：www.peachpit.com/ernestadams

## 知识体系层次关系

### 第一层次：基础认知
- 游戏是什么
- 游戏如何运作
- 谁玩游戏
- 在哪里玩
- 如何盈利

### 第二层次：设计实践
- 如何构思游戏
- 如何构建世界
- 如何设计角色
- 如何讲述故事
- 如何设计交互
- 如何平衡游戏
- 如何设计关卡

### 第三层次：专项技术
- 在线游戏技术
- 多人游戏设计
- 社会问题处理
