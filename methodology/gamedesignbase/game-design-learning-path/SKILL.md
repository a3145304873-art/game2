# 游戏设计学习路径

## 使用场景
- 制定游戏设计学习计划
- 快速定位特定设计主题
- 理解游戏设计知识体系的层次关系
- 组织游戏设计课程内容
- 评估自身知识掌握程度

## 学习路径概览

本书采用三阶段递进式组织结构，共17章：

```
第一阶段：基础认知 (第1-6章)
    ↓
第二阶段：设计实践 (第7-16章)
    ↓
第三阶段：专项主题 (第17章)
```

## 第一阶段：基础认知 (第1-6章)

### 第1章 游戏概述
- 定义游戏和游戏可玩性 (gameplay) 的正式概念
- 讨论计算机电子游戏带来的改变
- 介绍电子游戏娱乐的重要方式

### 第2章 游戏设计基础
- 电子游戏三大关键组件：核心机制、用户界面、故事讲述引擎
- 游戏可玩性模式概念
- 电子游戏结构
- **重点**：以玩家为中心的设计方法

### 第3章 游戏类型
- 解释游戏类别概念
- 简要介绍游戏的主要类型

### 第4章 游戏玩家
- 从心理特质分析玩家偏好
- 统计玩家分类（男性/女性、男孩/女孩）
- 分析玩家的奉献现象

### 第5章 游戏设备
- 家用游戏机、个人计算机、便携式设备
- 针对不同设备的设计和开发方法

### 第6章 商业模式
- **传统直接支付模式**：零售销售、基于订阅的游戏
- **新型间接支付模式**：免费模式、广告支持的游戏

## 第二阶段：设计实践 (第7-16章)

### 第7章 游戏概念
- 游戏想法的来源
- 重定义方法
- 观众和目标设备对游戏方向的影响

### 第8章 游戏世界
- 游戏可玩性发生的环境
- 设计师作为"游戏世界的上帝"的角色
- 定义要素：时间空间概念、机制和自然法则、逻辑、情感、文化和价值

### 第9章 创造型和表现型玩法
- 游戏支持玩家创造性的方法
- 游戏支持自我表现性玩法的方法

### 第10章 角色设计
- 设计游戏世界中的人或生物
- 代表玩家的角色（化身）设计
- **重点**：吸引人的主人公的重要性（自《荷马史诗》以来的传统）

### 第11章 故事讲述和叙事
- 线性、分支和反送故事结构
- 有脚本的交谈
- 插话式故事结构

### 第12章 用户体验设计
- 玩家体验游戏世界的方式
- 玩家与游戏世界交互的方式
- **警示**：糟糕的用户界面可能会毁掉一个其他方面都很好的游戏

### 第13章 游戏可玩性
- 玩家智力体验的核心
- 玩家面对的挑战
- 克服挑战的动作
- 游戏可玩性中困难度的本质

### 第14章 核心机制的五种类型
1. **物理机制**
2. **内部经济机制**（深入探讨，控制金钱、分数、弹药等资源流动）
3. **进展机制**
4. **战术机动机制**
5. **社交互动机制**

### 第15章 游戏平衡
- 让多玩家游戏对所有玩家公平
- 控制单玩家游戏困难度的过程

### 第16章 关卡设计
- 普遍原理
- 类别特定的原理
- 各种关卡布局
- 关卡设计的过程

## 第三阶段：专项主题 (第17章)

### 第17章 在线游戏
- **定位**：不是独立游戏类别，但是不可或缺的技术
- **核心特征**：让人们与他人一起玩耍或对抗（2人至多人）；与真人竞技但不必面对面
- **对游戏设计的巨大影响**
- **后半部分内容**：
  - 《魔兽世界》这类永恒世界的特殊问题
  - 网络游戏中可能发生的社会问题及预先准备

## 学习建议

### 初学者路径
1. 完整学习第一阶段（第1-6章）建立基础认知
2. 选择第二阶段中感兴趣的主题深入学习
3. 根据需要学习第三阶段专项内容

### 进阶者路径
1. 快速回顾第一阶段，查漏补缺
2. 系统学习第二阶段所有章节
3. 重点关注第14章核心机制和第15章游戏平衡

### 教育者路径
1. 按三阶段结构组织课程
2. 第一阶段作为基础课程（建议6-8周）
3. 第二阶段作为核心课程（建议12-16周）
4. 第三阶段作为选修或专题课程
