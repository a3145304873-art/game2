# 游戏定义框架

## 传统定义的局限性

### Salen & Zimmerman 定义
"游戏是一个系统，玩家在其中进行人为冲突，由规则定义，并产生可量化的结果"

### 局限性分析

| 传统要素 | 局限性 | 反例 |
|---------|--------|------|
| 人为冲突 | 排除合作游戏 | 《模拟人生》 |
| 规则系统 | 忽略玩家体验 | 沙盒游戏 |
| 可量化结果 | 排除情感体验 | 叙事游戏 |

## 广义游戏定义

### 核心要素

1. **活动**：玩家参与的行为
2. **体验**：玩家获得的感受
3. **成就**：玩家达成的目标

### 游戏类型谱系

```
纯竞争 ←───────────────────→ 纯创造
《星际争霸》    《我的世界》

纯规则 ←───────────────────→ 纯体验
《俄罗斯方块》  《风之旅人》

纯愉悦 ←───────────────────→ 纯学习
《马里奥派对》  《飞行模拟器》
```

## 自我表现设计原则

### 选择类型分类

| 选择类型 | 对游戏影响 | 玩家行为预测 |
|---------|-----------|------------|
| 功能性选择 | 影响可玩性 | 可能牺牲优势选择偏好 |
| 外观性选择 | 仅影响外观 | 必然选择偏好 |
| 混合型选择 | 两者皆有 | 倾向于选择偏好 |

### 设计建议

1. **提供足够选项**：至少3-5种不同风格
2. **明确影响范围**：告知玩家选择的影响
3. **尊重玩家选择**：不惩罚非最优选择
4. **支持混合搭配**：允许组合不同元素
