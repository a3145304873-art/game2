# 关卡布局与进展参考

## 变量定义
- `路径数量` (Integer): 平行布局中可用的轨道/路径数量
- `切换点密度` (Float): 玩家可在路径间切换的位置频率
- `mechanism_type` (Enum): 进展机制类型（空间/时间/情节）
- `challenge_type` (Enum): 挑战类型（可选/平衡/难度分级/互斥）

## 约束条件
- 不适用于完全开放式世界设计
- 不适用于纯线性无分支的管道式关卡
- 不适用于完全涌现型（Emergent）的游戏机制设计

## 前提条件
- 明确的关卡起点和终点
- 足够的空间容纳多条并行路径
- 允许玩家在路径间切换的机制
- 已确定游戏的核心玩法概念
- 需要构建游戏事件流程
