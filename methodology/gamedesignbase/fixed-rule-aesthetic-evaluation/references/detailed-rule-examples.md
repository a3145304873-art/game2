# 详细规则示例

## 服装设计规则库

### 图案搭配规则
- 禁止条纹与圆点图案混搭
- 大花图案不宜与小花图案同时使用
- 几何图案可与素色搭配
- 同类图案可重复使用但需控制数量

### 材质协调规则
- 粗糙材质应与光滑材质形成对比
- 透明材质需搭配不透明内衬
- 皮革材质不宜与丝绸材质大面积混用
- 棉麻材质可自由搭配

### 色彩搭配规则
- 遵循60-30-10原则（主色60%，辅助色30%，点缀色10%）
- 互补色使用需谨慎，控制面积
- 同色系搭配最安全
- 暖色调与冷色调需有过渡

## 室内设计规则库

### 色彩规则
- 房间主色调不超过3种
- 墙面颜色应比天花板深
- 地板颜色应比墙面深
- 小房间使用浅色系

### 家具布局规则
- 主要家具不阻挡通行路线
- 沙发与茶几间距保持45-60cm
- 电视观看距离为屏幕尺寸的3倍
- 书桌应靠近自然光源

### 风格统一规则
- 同一空间家具风格保持一致
- 装饰品风格与主风格协调
- 灯具风格与整体风格匹配
- 窗帘与地毯材质呼应
