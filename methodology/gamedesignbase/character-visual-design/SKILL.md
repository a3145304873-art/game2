# 角色视觉设计

## 使用场景
- 设计角色外观和视觉标识时
- 建立角色辨识度时
- 定义卡通风格角色时
- 制作动画参考文档时
- 设计角色服装和配色时

## 角色外在标识物设计

### 四个核心维度

#### 1. 衣着与饰品
- **核心功能**：弥补身体改变的局限性，表达个性
- **设计原则**：确保"很好辨认"——玩家能容易分清谁是谁
- **限制**：对"小角色"（次要/简化角色）不太适合投入过多设计资源

#### 2. 武器选择
- **核心功能**：暗示角色性格、价值观、战斗风格
- **武器类型与角色特质映射**：
  - 切肉刀/斧子 → 粗鲁、血腥、暴力
  - 长剑 → 优雅、决斗的贵族气质
  - 长鞭 → 足智多谋、非致命偏好

#### 3. 发型与珠宝
- **核心功能**：作为"身份的标志"，具有跨服装的稳定性
- **关键特性**：持久性、视觉显著性
- **珠宝特殊价值**：
  - 物理耐久性：不会戴坏
  - 文化/魔法深度：具有历史悠久的魔法、意义和神话色彩
  - 游戏机制应用：可承载可转移的魔法能力

#### 4. 多感官标识
- 视觉层：服装色彩、造型、武器形态、珠宝光泽
- 听觉层：如呼吸声
- 动态层：如披肩的飘动

## 角色调色板设计

### 设计原则
1. **创建专属调色板**：为角色（特别是衣服）设计专属调色板
2. **使用独特标识符**：特定颜色作为角色唯一标识
3. **处理调色板共享**：如果不同角色必须使用同一调色板，必须确保颜色比例不同
4. **映射角色气质**：选择能反映角色姿态、情感气质及所处环境的颜色

### 气质与颜色映射
- **正面/英雄气质**：使用明亮、愉快的颜色（如超人的红/蓝）
- **黑暗/复杂气质**：使用阴森、灰暗的颜色（如蝙蝠侠的深蓝/黑）

## 卡通式角色四大类型

### 1. 酷（Cool）类型
- **核心本质**：超然，从来不会为任何事情过于心烦
- **外观标志**：经常带着太阳镜
- **肢体语言**：无精打采，静止时显得懒散
- **智力特征**：通常都很聪明，使用智慧而非暴力

### 2. 强硬（Tough）类型
- **外观特征**：看起来具有侵略性，夸张的身高和体形
- **姿态特征**：夸张且豪爽，姿势前倾暗示移动
- **行为方式**：喜欢用拳头说话
- **动作特征**：幅度非常大且粗鲁，移动迅速且具有侵略性

### 3. 可爱（Cute）类型
- **造型来源**：按照人类或动物幼崽的例子绘制
- **比例特征**：大眼睛、超大号的头
- **身体形状**：圆形的，不是有棱有角的
- **服装特征**：穿着明亮的衣服
- **动作特征**：允许获得实际不可能得到的东西

### 4. 蠢笨（Goofy）类型
- **比例特征**：比例有一点奇怪，看起来很好笑
- **动作特征**：走路和其他动作都很慢，行为含有很多喜剧成分
- **游戏中的幽默运用**：在不影响游戏体验的地方引入幽默

### 类型转换规则
- 基本原则：通常一个角色不能仅仅局限于一个特点
- 转换触发条件：根据环境的需要
- 转换方向：能够从一种类型转换为另一种类型

### 文化适应性规则
- **日本动画特征**：大眼睛和小嘴，大喊大叫时嘴张得非常大
- **欧洲卡通特征**：美国人认为丑陋和奇怪
- **手指数量**：西方卡通通常为4，日本市场需改为5
- **设计建议**：如果希望游戏在多国销售，必须仔细研究各国本土卡通和喜剧样式

## 模型板制作

### 制作目的
- 展示角色多种姿势和情感态度
- 确保角色在不同场景中保持一致性
- 作为动画师绘制连续动作时的标准参考

### 制作规范
1. **页面布局**：在一个页面上系统性地排列同一个人物的多个不同姿势
2. **表情绘制**：通过不同的面部表情明确表示角色的不同情感状态
3. **姿态绘制**：通过身体语言展示角色的不同态度和动作状态
4. **多角度展示**：包含正面、侧面、背面及关键动作姿势
5. **一致性检查**：比较多个姿势以确保角色比例、服装细节和特征的一致性
6. **整体感觉呈现**：通过姿势的集合呈现人物的"整体感觉"和性格特征

## 设计决策流程

1. **确定角色类型**：写实/卡通/混合
2. **选择卡通类型**（如适用）：酷/强硬/可爱/蠢笨
3. **设计外在标识物**：衣着、武器、发型、珠宝
4. **创建调色板**：专属颜色、气质映射
5. **制作模型板**：多姿势、多表情、多角度
6. **文化适配检查**：目标市场的审美差异
7. **一致性验证**：确保所有视觉元素和谐统一
