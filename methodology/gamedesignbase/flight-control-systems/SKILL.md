# 飞行控制系统设计

## 何时使用

- 实现固定翼飞机或直升机的操纵杆控制
- 处理二维输入设备控制三维空间移动的问题
- 设计简化的飞行物理以提升游戏可访问性

## 固定翼飞机控制

### 俯仰控制（纵向轴）
- **操纵杆向前**：飞机前端朝下，下降
- **操纵杆向后**：飞机前端抬起，爬升
- **物理原理**：控制飞机倾斜，等价于摄像机倾斜

### 翻滚控制（横向轴）
- **操纵杆向左**：向左翻转，保持航线（不改变方向）
- **操纵杆向右**：向右翻转，保持航线（不改变方向）
- **关键特性**：单纯翻滚不会导致转向

### 转向机制（复合操作）
执行水平转向必须同时操作：
1. 向期望方向翻转（左或右）
2. 同时向后拉操纵杆（抬起前端）
3. 结果：产生倾倒回旋（banked turn）

### 引擎与油门
- **油门控制**：滑动开关或按键，设置前进速度
- **引擎作用**：推动飞机向机头方向前进
- **中性位置**：操纵杆回中后，飞机恢复直向水平飞行

## 直升机简化控制

### 水平面运动（操纵杆）
- **左右移动**：绕垂直轴转动（偏航），单纯转动不飞行
- **前后移动**：向前推动或后退

### 高度控制
- **独立控制**：滑动开关或按键控制上升/下降
- **与固定翼区别**：不依赖俯仰角度，可垂直起降

### 悬停行为
- 操纵杆回中后，利用空气摩擦逐渐下降
- 最终在固定点上盘旋（悬停）

### 未实现功能提示
- 真实直升机的侧向飞行（扫射）通常未实现
- 需要额外控制，仅少数游戏支持

## 三维导航通用解决方案

### 核心问题
- 飞行需要控制3个维度（X/Y/Z轴）
- 标准操纵杆仅提供2个输入维度
- **维度不匹配**：3D控制需求 vs 2D输入设备

### 第三维度处理方案

**方案A：独立机制**
- 使用额外控制器按钮切换模式
- 或按钮组合实现第三维度操作

**方案B：附加硬件**
- 双操纵杆设置（THRUSTMASTER等）
- 操纵杆+油门组合
- 滑动开关（绝对位置保持）

### 实现策略原则
- 使用与真实飞机对应的机制
- 驾驶舱内部第一人称视角增强沉浸感

## 控制变量参考

| 变量 | 类型 | 说明 |
|------|------|------|
| 操纵杆纵向输入 | float | 向前为负，向后为正，控制俯仰 |
| 操纵杆横向输入 | float | 向左为负，向右为正，控制翻滚/偏航 |
| 油门设置 | float | 控制引擎速度，决定前进速度 |
| 高度控制输入 | float | 直升机独立控制上升/下降 |
| 飞机前端朝向 | vector3 | 决定引擎推进方向 |
