# 游戏故事与叙事设计

## 适用场景
- 游戏设计前期策划阶段
- 需要深化游戏世界观叙事
- 需要评估是否需要故事元素及故事深度
- 需要编写完整的叙事设计需求规范

## 前置条件
- 初步的游戏概念或核心玩法
- 基本的故事背景或角色设定
- 已确定游戏类型和目标玩家群体

## 核心原则

**游戏可玩性第一**
- 必须时刻记住"游戏可玩性第一"原则
- 故事叙述不应掩盖游戏可玩性的光芒，不能让玩家做的事情很少
- 警示：基于电影或书籍特许权制作的早期游戏容易犯此错误

**交互性优先**
- "交互性"是人们玩游戏的原因
- 避免编写电影或者小说风格的故事
- 故事结构必须依赖于在概念设计阶段设计的"游戏可玩性"和"游戏类别"

## 工作流程

### 第一阶段：评估故事需求

**评估因素**

1. **长度**
   - 游戏越长，从故事获益越多
   - 故事可将较长的游戏中几个独立的部分组合成连贯体验并保持玩家兴趣

2. **角色**
   - 如果游戏关注于单独一个玩家可了解的角色，可从故事获益
   - 如果游戏循环包含大量无名人物（如《主题公园》游客），添加故事较难

3. **真实度**
   - 抽象游戏一般不添加过多故事，表现型游戏经常添加
   - 例外1：高度模拟仿真的交通工具和运动游戏通常不包含故事
   - 例外2：抽象游戏《吃豆小姐》因包含角色，讲述了小故事

4. **情感丰富程度**
   - 单人游戏可玩性通常只激发胜利、失败、决心等有限情感
   - 若需激发更深的情感（通过角色认同），需编写故事

5. **差异化**
   - 编写故事可将游戏与有相似游戏可玩性机制的游戏区分开

### 第二阶段：编写故事需求规范

**目的**
- 描述故事在游戏中如何操作，以及它应该达成什么目的
- 帮助找到想要实现的目标

**内容**
- 考虑要解决的问题
- 记录设计决定
- 解决关于设计化身角色的问题

### 第三阶段：评估情感与道德维度

**1. 评估感情维度**
- 确认游戏中是否存在典型的情感因素，并明确游戏世界中将会包含的具体情感类型
- 分析情感因素对游戏可玩性的辅助作用
- 判断其是否为剧情的主要组成因素，以及是否会激励游戏角色或者玩家本身
- 明确希望在玩家心中产生的具体情绪，规划实现方法，并确定最关键的因素

**2. 评估道德维度**
- 定义游戏中的对错标准，明确玩家的哪些动作会得到奖励，哪些动作会受到惩罚
- 规划向玩家解释游戏世界伦理道德的方式
- 界定斗争或竞技的性质（如暴力、竞赛完成、赢得一场金融竞争、用策略击败对手）
- 确定玩家的选择范围，判断完成任务是否同时存在暴力和非暴力两种方式
- 设定关于伤亡的奖惩机制
- 决定是否定义一个特定的通关条件
- 审查游戏世界中是否存在其他伦理问题（如说谎、欺诈、盗窃、违背诺言或出卖他人）
- 考虑是否存在伦理模糊或者道德困境的局面
- 评估暴力画面的逼真度，判断其是否符合游戏的娱乐性

## 故事质量标准

**基础目标**
- 确保游戏故事是一个可信的、连贯的和有戏剧意义的故事

**为了获得更大的满足感**
- 必须制作一个好的故事来保持玩家的兴趣
- 故事应展示出玩家的成长
- 故事应展示出叙事元素的平衡和游戏可玩性
- **最重要**：保持游戏玩起来很有趣

## 输出成果
- 故事需求评估报告
- 《交互式故事需求规范》文档
- 情感与道德维度设计指南
- 完整的游戏叙事设计需求规范

## 注意事项
- 没有绝对"正确"的方式设计互动故事，每种方法都有优缺点
- 选择最适合玩家娱乐的方式即可
- 不适用于无剧情或无交互背景的纯技术测试环境
