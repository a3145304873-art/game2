# 动态趋势系统实现细节

## 趋势曲线算法

### 基础波动模型
使用带噪声的正弦波模拟趋势变化：

```
trend_value(t) = base_value + amplitude * sin(2π * t / period) + noise(t)
```

其中：
- `noise(t)` 为随机游走噪声，防止完全预测
- `period` 根据属性设定（10年或20年游戏时间）
- `amplitude` 控制变化幅度（如0-1之间）

### 多属性耦合
某些属性可能存在相关性：

```python
if material_trend == "natural":
    color_trend.prefer("earth_tone")  # 天然材料偏好大地色系
```

## 研究机制详细设计

### 派对八卦系统
- **触发条件**：玩家参加特定社交活动
- **信息生成**：AI根据当前`trend_state`生成暗示性文本
- **噪声注入**：30%概率提供过时或错误信息
- **示例文本模板**：
  - "听说顶级设计师都在使用[当前 trending_material]..."
  - "今年的秀场上[ trending_hem_height ]款式特别多"

### 杂志生成系统
- 定期生成包含趋势暗示的文本内容
- 信息完整度与玩家订阅等级挂钩
- 包含历史对比（"与去年相比..."）帮助玩家推断变化方向

### 工作室参观机制
- **观察精度**：停留时间越长，获取信息越准确
- **反间谍设计**：被参观的NPC可能展示"假设计"迷惑竞争对手
- **学习成本**：需要消耗游戏内资源（金钱、关系值）

## 评价计算公式

```
fashion_score = Σ (attribute_match_i * weight_i) * research_bonus

其中：
- attribute_match_i = 1 - |player_value_i - trend_value_i|
- research_bonus = 1 + (research_progress * 0.2)  # 研究提供20%额外加成
```

## 边缘情况处理

### 趋势极端值
当趋势接近属性边界（如底边高度已达最大/最小）：
- 触发"风格革命"事件，重置趋势周期
- 或引入新属性维度替代旧维度

### 玩家滞后惩罚
连续3个周期未更新设计：
- 评价衰减系数：0.7^cycles
- 触发"过时设计师"负面标签

### 预测性平衡
为防止玩家过度囤积信息：
- 研究信息有效期：2-3个周期
- 趋势随机跳跃概率：5%（模拟黑天鹅事件）
