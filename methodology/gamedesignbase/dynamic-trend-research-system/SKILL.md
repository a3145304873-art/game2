# 动态趋势研究与预测系统

实现一个随时间动态变化的趋势系统，玩家必须通过研究行为发现隐藏的潮流信息，并据此调整创作策略以获得最佳评价。

## 何时使用

- 游戏时间跨度较长（10-20年游戏内时间尺度）
- 玩家需要持续面对创造性挑战（如服装设计、产品开发）
- 希望增加研究/探索玩法维度
- 需要多属性评价体系，且标准随时间演变
- **不适用于**：短期或一次性游戏体验

## 核心实现流程

### 1. 趋势属性定义

将玩家产品的每个美学属性映射到独立变化的趋势曲线：

- 识别可量化的美学维度（如：底边高度、材料类型、颜色、剪裁风格）
- 为每个属性分配独立的变化率参数
- 建立属性值与趋势状态的映射关系

### 2. 时间尺度与变化规律

配置不同属性的变化周期：

- **短期趋势**（约10年尺度）：快速变化属性（如服装底边高度）
- **中期趋势**（约20年尺度）：慢速变化属性（如材料偏好：人造→天然）
- **变化特征**：引入随机噪声，确保周期"不是完全有规律或可预测的"

### 3. 信息隐藏与研究机制

**初始状态**：所有趋势信息对玩家完全隐藏。

**解锁方式**：设计多种研究行为供玩家获取线索：

- **社交情报**：参加游戏内派对，听取AI生成的八卦（包含潮流线索）
- **媒体监测**：阅读自动生成的时尚杂志和报纸寻找趋势暗示
- **实地调研**：参观其他设计者的工作室，观察其工作过程（间谍/学习机制）

**信息控制**：玩家只能获取"部分"线索，保持不完全信息状态，避免趋势被完全预测。

### 4. 评价应用

根据当前趋势状态检验玩家作品：

- 计算作品属性与当前潮流状态的匹配度
- 符合趋势 → 高评价/奖励
- 违背趋势 → 低评价/过时标签
- 趋势波动机制：今日的成功标准可能明日失效，迫使玩家持续研究

## 关键变量

| 变量 | 类型 | 说明 |
|------|------|------|
| `trend_cycle` | 时间变量 | 特定美学属性的流行周期（10年/20年） |
| `change_rate` | 浮点数 | 属性趋势变化的速率参数 |
| `research_progress` | 百分比 | 玩家对当前趋势信息的掌握程度 |
| `trend_state` | 状态向量 | 各美学属性当前的流行趋势值 |

## 快速示例：时尚设计游戏

**属性映射**：
- 底边高度：10年周期，当前处于"上升"阶段
- 材料偏好：20年周期，正从"人造"转向"天然"

**玩家体验**：
1. 玩家设计人造纤维短裙 → 符合底边趋势但违背材料趋势 → 中等评价
2. 玩家参加派对听到"天然材料回归"的八卦 → 研究进度+20%
3. 玩家调整设计为天然纤维长裙 → 双重符合 → 高评价
4. 10年后底边趋势反转 → 原设计过时 → 需重新研究

## 注意事项

- 确保后台数据模拟复杂度可控
- 平衡信息获取难度，避免玩家因信息匮乏而挫败
- 趋势变化需有视觉或数值反馈，让玩家感知到"时代变迁"
