# 输入映射模式详解

## 连续输入的映射策略

### 直接映射（线性）
```
输出 = 输入 × 灵敏度系数
```
适用：精确控制场景（飞行模拟、瞄准）

### 曲线映射（非线性）
```
输出 = sign(输入) × |输入|^曲线指数 × 最大输出
```
- 指数 > 1：小输入精细，大输入快速（适合瞄准辅助）
- 指数 < 1：小输入响应快，大输入饱和（适合赛车转向）

### 死区处理
```
if |输入| < 死区阈值:
    输出 = 0
else:
    输出 = (输入 - sign(输入)×死区) / (1 - 死区)
```

## 离散输入的转换模式

### 即时触发（Instant）
- 物理事件直接映射为游戏行动
- 风险：硬件抖动导致重复触发
- 缓解：UI层实现去抖动（debounce）

### 状态触发（State）
- 跟踪物理按键状态，每帧检测边沿
- 支持：JustPressed / Held / JustReleased

### 缓冲触发（Buffer）
- 接受提前输入，在行动可执行时触发
- 典型应用：格斗游戏输入缓冲窗口（通常50-200ms）

## 复合输入识别

### 序列识别（Command）
```
↓↘→ + 拳 → 波动拳
```
- 实现：有限状态机或时间窗口缓冲
- 容差：方向输入允许±22.5°误差

### 和弦识别（Chord）
- 多键同时按下识别为独立行动
- 注意：与单键行动的优先级处理

### 手势识别（Gesture）
- 触摸/体感输入的轨迹分析
- 核心机制接收：手势类型 + 参数（速度、方向、位置）

## 平台适配实例

| 游戏语义行动 | PC键鼠 | 游戏手柄 | 触屏 |
|-----------|--------|---------|------|
| 移动 | WASD/鼠标 | 左摇杆 | 虚拟摇杆 |
| 瞄准/视角 | 鼠标移动 | 右摇杆 | 滑动屏幕 |
| 主攻击 | 鼠标左键 | RT | 点击/长按 |
| 跳跃 | 空格 | A | 专用按钮 |
| 交互 | E | X | 点击目标 |

核心机制统一接收：`Move(Vector2)`, `Aim(Vector2)`, `Attack()`, `Jump()`, `Interact(target)`
