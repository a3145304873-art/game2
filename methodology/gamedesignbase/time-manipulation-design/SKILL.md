# 游戏时间操控设计

## 何时使用

- 设计需要时间加速或跳过的模拟游戏
- 开发支持时间操控的单人游戏
- 实现多人游戏的时间同步机制
- 需要区分单人和多人模式的时间规则

## 单人游戏时间操控（完全自由）

### 时间流速设定
- 可按照许多倍现实时间的流速制定游戏时间
- 允许玩家在现实时间中一小时或更少内体验到一整天的感觉

### 动态速度调整
- 在战斗模拟器等场景中，允许玩家飞往战斗区域时**加速时间**
- 到达后将时间降低为真实时间

### 时间段跳跃
- 可完整跳跃时间段
- **示例**：当化身睡觉时，屏幕空白显示一段时间，然后显示文本"8小时以后……"，然后继续游戏

### 暂停控制
- 玩家可自由地暂停和开始游戏

## 多人游戏时间同步（严格限制）

### 禁止行为
- **禁止差异化流速**：不允许一些玩家使用与其他玩家不同的时间速度移动
- **禁止个体时间跳跃**：除非使所有玩家同时跳过某段时间，否则不能跳过

### 强制统一步调
- 游戏时间对所有人必须同时开始并保持同一个步调
- 即使游戏时间比现实时间更快，也必须同步

### 实时同步要求
- 所有玩家共享同一时间流
- 无法独立操控

## 决策流程

```
IF (游戏模式 = 多人游戏) THEN
    强制执行时间同步规则
    禁止个体时间操控
ELSE (单人游戏) THEN
    允许自由时间缩放
    允许时间段跳跃
    允许暂停控制
END IF
```

## 变量参考

| 变量 | 类型 | 说明 |
|------|------|------|
| 游戏模式 | enum | 单人游戏或多人游戏 |
| 时间流速倍数 | float | 游戏时间相对于现实时间的流速比率 |
| 同步玩家数 | integer | 需要保持时间同步的玩家数量 |
