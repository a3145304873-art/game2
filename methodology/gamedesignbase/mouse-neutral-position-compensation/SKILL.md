# 鼠标中立位置缺失补偿设计

## 何时使用

- 使用鼠标作为主要输入设备控制交通工具
- 交通工具需要默认中立状态（直线行驶、水平飞行）
- 需要补偿鼠标硬件缺乏自回中机制的限制

## 核心问题

鼠标与操纵杆/方向盘的关键差异：

| 特性 | 鼠标 | 操纵杆 |
|------|------|--------|
| 停止输入后的状态 | 保持当前位置 | 自动回到中心 |
| 中立位置 | 无 | 有（物理弹簧） |
| 默认行为触发 | 需手动对准 | 松手即恢复 |

## 补偿方案设计

### 1. 识别适用场景

确认交通工具是否需要默认中立状态：
- **直线行驶**：车辆默认应保持前进方向不偏转
- **水平飞行**：飞行器默认应保持姿态水平
- **其他需归零状态**：任何需要"不操作即恢复默认"的行为

### 2. 设计重置机制

创建额外的控制器功能：

```
输入绑定设计：
- 主绑定：鼠标移动 → 控制方向/姿态
- 辅助绑定：专用按键 → 立即恢复默认状态
```

### 3. 实现细节

**功能命名建议**：
- "回中校正"
- "水平稳定"
- "方向归零"
- "自动驾驶辅助"

**触发效果**：
- 按下瞬间：交通工具立即跳转到默认状态
- 按住期间：可选保持默认状态（类似临时开关）
- 释放后：恢复鼠标直接控制

### 4. 设计验证清单

- [ ] 玩家能否快速找到并使用重置按钮
- [ ] 重置操作是否打断游戏流畅性
- [ ] 是否有视觉/听觉反馈确认状态恢复
- [ ] 是否提供灵敏度调节适应不同玩家习惯

## 替代方案评估

若重置机制仍无法满足体验需求，考虑：
- 改用具有自回中特性的操纵杆/方向盘
- 实现自适应辅助系统（自动趋向默认状态）
- 重新设计载具物理，降低对精确中立的需求
