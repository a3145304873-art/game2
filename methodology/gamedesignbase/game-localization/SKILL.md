# 游戏本地化

## 应用场景

- 游戏需要在原始设计国家以外的国家/地区发布
- 准备进入国际市场
- 评估本地化需求和成本

## 本地化范围界定

将游戏修改为可在目标国家出售的完整过程

## 内容修改要求

对软件和游戏内容进行大量修改，包括但不限于：
1. 将所有文本翻译为目标国家使用的语言
2. 将话外音翻译为目标国家使用的语言
3. 调整文化相关内容以适应目标市场

## 本质特征

目标国家不在原本设计游戏时考虑的范围内，需要进行跨文化适配

## 执行流程

1. 确定目标国家/地区市场
2. 评估本地化需求（文本、话外音、文化内容）
3. 选择本地化团队或服务提供商
4. 执行翻译和文化适配
5. 测试和验证本地化版本
6. 发布本地化版本
