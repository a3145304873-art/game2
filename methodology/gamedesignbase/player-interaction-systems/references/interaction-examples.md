# 玩家交互系统详细案例

## NPC物理交互示例

### 对抗性交互
```
玩家动作：攻击
触发条件：接近NPC + 攻击按键
NPC反馈：
  - 播放受伤动画
  - 生命值减少
  - AI状态切换为战斗模式
```

### 支持性交互
```
玩家动作：治疗
触发条件：接近受伤NPC + 治疗物品/技能
NPC反馈：
  - 生命值恢复
  - 播放治疗动画
  - AI状态切换为友好模式
```

## 物体拾取放置示例

### 层级1：简单拾取放置（国际象棋）
```
流程：
  1. 玩家点击棋子
  2. 棋子跟随光标
  3. 玩家点击目标位置
  4. 系统验证移动合法性
  5. 放置棋子或拒绝移动
```

### 层级3：RPG物品管理系统
```
流程：
  1. 玩家接近环境物体
  2. 显示拾取提示
  3. 玩家按下拾取键
  4. 物体进入物品仓库
  5. UI更新物品栏
  6. 玩家可从仓库给予NPC或出售
```

### 关键物品保护机制
```
关键物品标记：不可丢弃
替代方案：
  - 物品回收机制
  - 游戏结束检查
  - 自动存档提醒
```

## 固定物体操作示例

### 基于化身的游戏
```
流程：
  1. 玩家接近电灯开关
  2. 距离 < 2米
  3. 显示操作提示"按下E键操作"
  4. 玩家按下E键
  5. 化身播放按下动画
  6. 开关状态：开 → 关
  7. 灯光熄灭
  8. 播放音效
```

### 状态循环示例（窗帘）
```
状态序列：全开 → 半开 → 关闭 → 全开
操作：每次点击切换到下一状态
```

## 数值操作界面示例

### 蒸汽朋克风格
```
界面元素：
  - 黄铜转盘代替滑动滑块
  - 压力表代替数字显示
  - 齿轮按钮代替标准按钮
效果：数字输入看起来像游戏世界的一部分
```

### 隐喻化界面
```
场景：谈判价格调整
传统方式：输入数字框
隐喻方式：
  - 天平称重：一边放筹码代表价格
  - 筹码堆叠：直观显示金额
效果：保护玩家幻想，增强沉浸感
```

## 角色定制示例

### 游戏内模式（理发店）
```
流程：
  1. 玩家进入理发店
  2. 与NPC理发师对话
  3. 进入定制界面
  4. 选择发型、颜色
  5. 实时预览效果
  6. 确认并支付
  7. 角色外观更新
优势：沉浸感强，符合游戏世界观
```

### Shell菜单（角色创建）
```
流程：
  1. 在主菜单选择"创建角色"
  2. 进入独立定制界面
  3. 选择种族、性别、外观
  4. 分配属性点
  5. 预览角色
  6. 确认并开始游戏
优势：便捷，可随时访问
```

## 交通工具定制示例

### 视觉定制
```
选项：
  - 车身颜色
  - 车轮毂样式
  - 车身贴纸
  - 尾翼类型
```

### 技术属性调整
```
选项：
  - 引擎：影响最高速度和加速
  - 悬挂：影响操控性和稳定性
  - 轮胎：影响抓地力和制动

关键要求：
  - 提供性能预览
  - 显示属性变化对比
  - 玩家理解调整直接影响性能
```

## 交互启动方式对比

### 接近自动提示
```
优点：直观，易于发现
缺点：可能误触发
适用：重要交互
```

### 特定按键
```
优点：精确控制
缺点：需要学习
适用：频繁交互
```

### 上下文菜单
```
优点：信息丰富
缺点：操作步骤多
适用：复杂交互
```

### 直接点击
```
优点：快速直接
缺点：需要精确点击
适用：策略游戏、点击冒险
