# 闭合经济循环与囤积失效机制

## 何时使用

- 设计持久世界游戏的虚拟经济系统
- 评估闭合经济可行性
- 设计资源循环和物品损耗机制
- 预防经济系统崩溃

## 理想闭合循环流程

```
采矿(生铁) → 熔炼(铁) → 锻造(武器) → 使用损坏 → 分解返回资源池
```

### 循环平衡假设
- 物品必须实际使用并损坏才能返回资源池
- 资源总量理论上保持恒定
- 自包含的闭合系统

## 失效模式：玩家囤积

### 现象
玩家将铁和武器**储藏起来而不使用**

### 关键机制缺陷
> 没有使用的物品**不能返回到池子里**

### 后果
被储藏物品无法通过损坏返回资源池 → **铁矿石快速用完**

## 经济崩溃连锁反应

| 阶段 | 现象 |
|------|------|
| 1 | 资源池枯竭 |
| 2 | 市场流通资源稀缺 |
| 3 | 通货膨胀蔓延 |
| 4 | 铁的价格过高 |
| 5 | **市场陷入窘境**，经济系统无法正常运作 |

## 解决方案：转向开放经济

### 机制
在服务器中**周期性地增加新的资源**

### 历史案例
> 《网络创世纪》经营者最终只能采取此方案

## 设计教训

| 对比维度 | 单人游戏 | 永恒世界 |
|---------|---------|---------|
| 经济设计难度 | 容易 | 困难 |
| 玩家行为控制 | 严格公正 | 无法控制（成千上万玩家以意外方式互动） |
| 闭合经济可行性 | 可行 | **难以维持** |
