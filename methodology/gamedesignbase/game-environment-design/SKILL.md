# 游戏环境设计框架

## 使用时机
- 需要构建游戏世界的环境背景、视觉风格、文化设定或氛围营造
- 游戏核心玩法已确定
- 目标受众明确
- 游戏类型定义完成

## 九维度环境设计检查框架

### 维度1：时空定位与真实性

**确定具体设定**
- 明确"什么时候，什么位置"（特定的历史时期或地理位置）

**现实关联判断**
- 是否为"现实世界替换到游戏中的"（基于现实改编）？

**差异性定义**
- 如果是基于现实，必须明确"它如何区别于我们的现实世界"（关键差异点设计）

### 维度2：社会结构与组织架构

**人物外貌设定**
- 定义"这些人物的外貌是什么样的"

**社会复杂度评估**
- 高度组织化的复杂社会
- 简单的种族部落式社会

**治理机制**
- 设计"他们如何进行自我管理"的政治/社会体系

**环境适应性**
- 验证"体现他们实际环境的社会结构是如何运作的"（环境决定论应用）

**阶层与职业**
- 是否存在不同阶层的人？
- 是否有工会或者特殊职业？

### 维度3：核心价值观与生存方式

**价值导向选择**
- 从"贸易、格斗能力、帝国主义、和平"中确定世界倚重的核心
- 什么是游戏世界中的人们所倚重的？

**玩法对齐**
- 设计"什么样的玩法引导玩家去追求这些目标"（机制与叙事一致性）

**生存模式分类**
- 狩猎者
- 游牧者
- 农耕者
- 工业化
- 信息化时代的人

**物质文化影响**
- 分析"这些背景如何影响他们的建筑和服饰"（生活方式决定物质文化）

### 维度4：宗教信仰体系

**信仰存在性**
- 游戏人物是否有宗教信仰？

**宗教表现层**
- 是否"体现出他们的宗教团体或宗教活动"？

**建筑需求**
- 是否存在宗教建筑？

**符号系统**
- 人们是否需要佩戴护身符或者显示精神的徽章？（视觉识别元素）

### 维度5：审美观念与形式语言

**风格倾向二元选择**
- 色彩："艳丽的还是保守的"
- 秩序："混乱的还是秩序的"
- 气质："聪明的还是狡猾的"

**色彩偏好**
- 明确"他们喜欢什么样的颜色"（主色调与配色方案）

**形态偏好**
- 确定"直线还是曲线"（形式语言基础）

### 维度6：非人实体设计

**触发条件**：当维度2答案为"无须设置人物"时执行

**实体类型**
- 会设置什么东西？（替代性存在物）

**视觉特征**
- 定义"它们是什么样的"（形态学设计）

**行为逻辑**
- 设计"有什么样的行为表现"（AI或交互模式）

### 维度7：场景空间类型学

**空间分类**
- 室内
- 室外
- 两者都有

**室内细节（如适用）**
- 家具和内部装饰是什么样的？

**室外细节（如适用）**
- 地形和建筑是什么样的？

### 维度8：风格氛围与多感官设计

**整体调性**
- 定义"游戏风格和氛围是什么样的"

**跨媒介实现**
- 规划"如何用相适应的画面、声音和音乐去创建它们"（视听语言统一）

### 维度9：细节密度与技术平衡

**细节级别决策**
- 色彩丰富的
- 稀疏整洁的

**性能影响评估**
- 预判"这些细节会对游戏的运行方式产生什么样的影响"（LOD与优化考量）

## 自然环境设计要素

### 避免单一环境类型
- 仅设置由机械加工的物体组成的城市或室内环境会导致枯燥无味的感觉

### 自然环境元素检查清单
- 动物种类与分布
- 植物类型与植被密度
- 土壤类型与质地
- 岩石形态与分布
- 小山/山脉地形
- 天空特征与天气

### 气候条件评估

**温度维度**
- 热 vs 冷

**湿度维度**
- 干 vs 湿

### 土壤质量判定
- 肥沃土壤 → 支持茂密植被，农业文明
- 贫瘠土壤 → 荒凉景观，生存挑战

### 地形特征判定
- 平坦地形 → 适合建造，视野开阔
- 多山地形 → 垂直探索，路径限制

## 验证规则

- 每个维度必须产出明确的设计决策文档
- 维度6为条件触发项（仅在无人物时执行）
- 维度9必须与技术团队交叉验证

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| historical_period | string | 游戏设定的历史时期或架空时代背景 |
| geographical_location | string | 地理位置或架空世界地图定位 |
| social_complexity_level | enum | 社会复杂度：复杂社会/部落社会/无社会结构 |
| core_value_system | enum | 核心价值：贸易/格斗/帝国主义/和平 |
| subsistence_mode | enum | 生存方式：狩猎/游牧/农耕/工业/信息时代 |
| religion_existence | boolean | 是否存在宗教信仰体系 |
| aesthetic_style | object | 审美参数：色彩倾向(艳丽/保守)、秩序度(混乱/秩序)、形态偏好(直线/曲线) |
| scene_type | enum | 场景类型：室内/室外/混合 |
| detail_density | enum | 细节密度：丰富多彩/稀疏整洁 |
| entity_type | enum | 实体类型：人类/非人实体/混合 |
| climate_type | enum | 气候类型：热/冷, 干/湿的组合 |
| soil_fertility | enum | 土壤肥力：肥沃或贫瘠 |
| terrain_type | enum | 地形类型：平坦或多山 |

## 输出结果

输出《环境维度设计规范文档》，包含：
- 9个维度的明确设计决策
- 视觉参考指引
- 技术实现约束
- 与世界观一致性检查清单
- 完整自然环境参数集
