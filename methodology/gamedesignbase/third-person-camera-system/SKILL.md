# 第三人称摄像机系统

## 适用场景

- 开发第三人称视角游戏
- 需要处理摄像机被场景物体遮挡的情况
- 需要允许玩家手动调整观察角度以查看化身周围环境
- 需要支持化身跳跃前的方向调整

## 自动遮挡处理

当检测到场景物体（墙壁、障碍物）插入到化身和摄像机之间时，根据游戏需求选择以下方案之一：

### 方案一：透明度处理（推荐）

保持摄像机在正常位置，将阻挡物设置为半透明：

1. 检测遮挡发生后，保持摄像机当前空间坐标
2. 将插入物体的不透明度降至 0.3-0.5（`object_opacity` 变量控制）
3. 允许玩家透过阻挡物观察世界，同时保持对障碍物存在的感知
4. **恢复机制**：当化身移动导致遮挡消失时，平滑恢复物体不透明度至 1.0

### 方案二：位置调整

将摄像机重新定位到化身后方并调整角度：

1. 将摄像机位置调整至化身与阻挡物之间（靠近化身背部）
2. 提升摄像机高度（向上吊起）
3. 向下倾斜摄像机角度，俯视化身前方区域
4. **恢复机制**：当遮挡消失时，使用插值将摄像机平稳移回正常跟随位置

### 方案三：头部透明

将视角调整至化身头部后方并透明化处理：

1. 立即将摄像机方向调整至化身头部正后方
2. 将化身头部模型设置为半透明（或隐藏）
3. 保持此状态直到化身移动到允许正常摄像机位置的区域
4. **恢复机制**：当空间充足时，恢复头部透明度并将摄像机移回标准跟随位置

## 手动调整机制

为玩家提供手动控制摄像机的输入方式（控制器左右肩键、屏幕滑动或专用按钮）：

### 模式A：摄像机环绕（标准模式）

适用于环境观察和角色展示：

1. 根据输入方向（左/右）使摄像机围绕化身水平旋转
2. 始终保持化身位于屏幕中心位置
3. 允许玩家从 360 度角度观察化身和周围环境
4. 释放输入后，可选择是否自动回归默认后方视角

### 模式B：化身旋转（动作模式）

参考《玩具总动员 2》实现，适用于平台跳跃和方向调整：

1. 输入控制使化身在原地左右旋转（改变朝向）
2. 摄像机跟随化身旋转，始终保持在化身正前方
3. 同时改变化身面对方向和摄像机观察方向
4. 特别适用于调整化身跳跃或移动前的朝向

## 实现建议

- **优先级**：优先实现自动遮挡处理（方案一），手动调整作为补充功能
- **平滑过渡**：所有摄像机位置变化和透明度调整应使用插值（lerp）实现平滑过渡，避免突兀跳跃
- **输入冲突**：当自动遮挡处理激活时，暂时禁用或限制手动调整功能，防止逻辑冲突
- **性能优化**：遮挡检测使用射线检测（raycast）从摄像机向化身头部发射，检测中间碰撞体
