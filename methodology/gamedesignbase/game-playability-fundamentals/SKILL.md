# 游戏可玩性基础理论

## 何时使用
- 设计游戏核心玩法时
- 编写游戏设计文档时
- 分析游戏娱乐元素时
- 区分叙事紧张与游戏紧张时

## 可玩性定义与核心特征

### 可玩性本质

**表象形式（非可玩性）**
- 媒体：书籍、电影、戏剧
- 特征：作者娱乐观众，内容固定
- 交互性：观众无法修改文本

**参与形式（可玩性）**
- 媒体：游戏
- 特征：自娱自乐，玩家选择影响事件过程
- 交互性：需要活跃的玩家参与

### 自由与限制

**自由维度**
- 行动的自由
- 行动选择上的自由
- 每次游玩可有不同体验

**限制维度**
- 自由受游戏规则限制
- 非毫无限制

### 玩家要求
- 在游戏过程中变得更聪明
- 更具想象力
- 操作更加熟练

## 交互模型定义与分类

### 核心关系定义
规定玩家的按键与作为结果的行动之间的关系

### 标准交互模型类型

**多处存在模型**
- 无论什么时候，玩家都可以在游戏世界的不同地方采取行动
- 从"外面"进入"里面"

**基于化身的模型**
- 玩家以一个在游戏中已经存在的人物身份出现
- 玩家在游戏中所采取的行动通过这个人物来实现

**竞争模型**
- 作为标准交互模型之一

### 动态调整机制
- 交互模型不是一成不变的
- 依赖于当时所发生的事情
- 随游戏进程改变

## 十大挑战类型分类体系

### 类型1：身体协调性挑战
- 反应速度和时间：《俄罗斯方块》
- 精确度（驾驶、射击）：《超越海岸线》《彩虹六号》
- 时机和节奏：《舞力全开》
- 学习组合动作：《街头霸王Ⅱ》

### 类型2：形式逻辑挑战
- 推理和解码：《扫雷》《珠玑妙算》

### 类型3：模式识别挑战
- 静态模式：《脑力训练》《宝石迷阵》
- 移动和改变的模式：《刺猬索尼克》敌人行为模式

### 类型4：时间压力挑战
- 时间限制：《青蛙过河》《美女餐厅》
- 在其他玩家之前完成任务：《极品飞车》

### 类型5：记忆和知识挑战
- 各种游戏细节：《死亡医生》
- 物体或模式的记忆：《脑力训练》

### 类型6：探索挑战
- 识别空间关系：《Descent》三维空间导航
- 寻找钥匙：《创世纪》
- 找到隐藏的密道：《毁灭战士》
- 迷宫和不合逻辑的空间：《魔域帝国》

### 类型7：斗争挑战
- 战略、战术和后勤：《魔兽争霸》
- 求生：《吃豆人》
- 消灭敌方军队：《太空侵人者》
- 保护易受攻击的物体和单位：《古堡迷踪》
- 偷袭：《刺客信条》

### 类型8：经济性挑战
- 积累资源或游戏分数：《文明》
- 建立高效的生产系统：《工人物语》
- 在游戏中达到稳定或平衡：《模拟地球》
- 照料生物：《模拟人生》

### 类型9：概念性推理挑战
- 从迷雾中寻找线索：《法律与秩序》
- 查明隐藏的线索：《异域镇魂曲》
- 理解社会关系：《劝架》
- 逆向思维：《不可思议的机器》

### 类型10：创造/构建性挑战
- 美学成就：《模拟人生》组合相册
- 有功能目标的建设：《我的世界》

## 戏剧性紧张 vs 游戏可玩性紧张

### 戏剧性紧张

**定义**
- 读者阅读或观察者观看故事时
- 感到某些重要的事情处于危险之中
- 夹杂着想知道接下来会发生什么的欲望

**特征**
- 是故事进行讲述的本质
- 不依赖于媒体形式（书籍、影视、戏剧等均可产生）
- 被动接收

**关键要素**
- 悬念：章节或集结尾处的刺激状况，提升紧张感
- 高潮点：行动方向改变，紧张程度开始下降

### 游戏可玩性紧张

**定义**
- 玩家玩游戏时
- 感到某些重要的事情处于危险之中
- 想知道接下来会发生什么的欲望

**核心来源**
- 玩家战胜挑战的欲望
- 是否会成功或失败的不确定性

**多玩家游戏额外来源**
- 玩家不知道对手接下来会干什么的不确定性

### 关键对比

| 维度 | 戏剧性紧张 | 游戏可玩性紧张 |
|------|-----------|---------------|
| 体验者 | 读者/观察者 | 玩家 |
| 核心来源 | 故事叙事本身 | 挑战胜负的不确定性 |
| 互动性 | 被动接收 | 主动参与 |
| 多玩家特殊因素 | 无 | 对手行为的不确定性 |

## 设计决策流程

1. **确定核心挑战类型**：从十大类型中选择2-4种主要挑战类型
2. **设计交互模型**：选择适合游戏类型的交互模型
3. **平衡紧张类型**：根据游戏目标平衡戏剧性紧张和游戏可玩性紧张
4. **验证可玩性优先**：确保可玩性是主要的娱乐元素
