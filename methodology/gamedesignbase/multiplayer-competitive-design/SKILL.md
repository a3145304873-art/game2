# 多人与竞技游戏设计

## 使用场景
- 设计多人游戏
- 处理规则修改需求
- 评估游戏公平性
- 分析游戏平衡性
- 识别统治性策略

## 多人游戏社交模式分类

### 核心前提
游戏本质上是一种社会性活动，多人游戏设计需围绕社交属性展开

### 四种多人游戏模式

#### 本地多人游戏
- **定义**：同一地点两人或以上一起玩
- **硬件特征**：经典家庭控制台，每个玩家有自己的控制器，共享同一屏幕
- **屏幕显示方式**：
  * 分屏模式：每个玩家有独立屏幕部分
  * 同屏模式：所有玩家面对同一游戏世界

#### 网络游戏（分布式多玩家游戏）
- **定义**：玩家分布在不同地点，通过网络彼此对战
- **同步型网络游戏**：每个玩家必须同时登录在线（如MMORPG、《使命召唤》系列）
- **异步型网络游戏**：任意玩家可在不同时间登录，不发生实时交互（如Facebook上的游戏）

#### 局域网游戏（LAN游戏）
- **定义**：一群人聚在一个房间内，通过局域网将计算机彼此连接
- **社交特征**：可以相互对话，但看不到其他人的计算机屏幕

#### 集体游戏
- **定义**：一组人聚集在一个房间内玩单人游戏
- **核心机制**：
  * "战斗座椅"：给定时间内使用控制器的玩家位置
  * 观众参与：其他玩家观看并提供建议
  * 控制器传递：随游戏进程，控制器从一个人传给另一个人
  * 技术匹配：技术更高的人应对当前挑战
- **流行群体**：孩子间特别流行

### 设计原则
- 必须考虑供人们娱乐的社交功能
- 扩展娱乐性的工具：聊天机制、公告栏、其他交流工具
- 目标：社交功能带来的娱乐性远超单靠游戏可玩性

## 游戏公平性原则与规则修改机制

### 定义游戏公平性
- 公平性不是游戏的基本元素，而是置于"魔法圈"之外的一定文化结构下的观念
- 它是"超规则"，即用来对规则自身做出判断的规则
- 不同社会和玩家对公平与非公平有不同的观点

### 玩家对公平性的反应
- 如果玩家觉得规则不公平，或者规则允许了不公平行为，他们会本能地决定改变规则
- 为了使所有人满意，玩家必须对游戏公平性的各个组成条件达成一致

### 规则修改机制

**一般原则**：规则能否被修改通常由不成文的社会习惯决定

**特殊机制**：在某些特殊情况下，规则的修改由规则本身规定并鼓励

**规则分类**：
- **可变规则**：游戏中可以被修改的规则
- **非可变规则**：包括对可变规则在什么时候改变及如何改变的说明

**示例**：哲学家 Peter Suber 创建的《Nomic》游戏就是基于这种机制

### 电子游戏中的公平性标准

**背景差异**：电子游戏不像传统游戏，即使玩家不喜欢规则，通常也不提供改变规则的方式

**多人游戏公平性**：被广泛接受的定义是——一旦游戏开始，所有的玩家赢得胜利的机会必须都是相同的
- *实现方法*：最简单的方法是使游戏对称

**单人游戏公平性**：较为复杂，涉及游戏自身平衡和玩家的自身期望等

## 统治性策略的定义与特征

### 核心定义
一种策略强度达到"保证绝对胜利"或"玩家很少有理由使用其他策略"的程度

### 识别统治性策略的关键指标
1. **绝对胜利保证**：使用该策略可以确保获胜（罕见）
2. **相对优势过大**：策略的期望收益显著高于其他所有替代策略
3. **策略替代性丧失**：理性玩家缺乏动机尝试其他策略

### 典型出现场景分类

#### RTS游戏案例：《命令与征服：红色警戒》坦克流
- **具体机制**：苏维埃阵营玩家将所有资源投入早期坦克部队量产
- **执行方式**：集结坦克部队对正在成形的敌军基地发动协同攻击
- **效果特征**：
  * 对未准备对手："总是能获得成功"（100%胜率）
  * 对有经验对手：可被防御，但防御成本过高或游戏体验受损
- **后果**：严重破坏游戏乐趣，社区自发形成"禁止坦克流"的房规

#### 体育模拟游戏案例：《麦登橄榄球》系列
- 特定版本存在"不能阻挡的进攻玩法"
- 适用条件：仅针对AI控制的对手时保证胜利
- 暗示：PvP环境下可能因人类适应性而不成立

#### 格斗游戏案例：设计缺陷导致的角色统治性
- 《超级街头霸王Ⅱ加速版》秘密角色Akuma
- 具体技能："空气火球"攻击被定义为"无敌"
- 后果："没有给其他角色留下任何机会"——完全压制所有对策
- 社区解决方案：锦标赛正式规则禁止使用Akuma

### 统治性策略与游戏类型的关联规律
- **高组合复杂度游戏风险更高**：格斗游戏和足球游戏存在"大量的进攻和防守动作的可能组合"
- **测试覆盖难题**：组合爆炸导致"很难测试所有的可能"
- **角色设计风险**：单个角色设计失误可破坏整体平衡

### 玩家与开发者应对策略对比

**玩家层面（非正式）：**
- 社区自律规则（如"不允许坦克流"房规）
- 锦标赛禁用名单（如Akuma禁止）

**开发者层面（正式）：**
- 通过"平衡方法"系统性避免或移除
- 后续小节将展开具体方法

## 执行流程

### 设计多人游戏
```
1. 选择游戏模式（本地/网络/局域网/集体）
2. 设计社交功能（聊天、公告栏等）
3. 确定公平性标准
4. 设计规则结构（可变/非可变）
```

### 处理公平性问题
```
1. 识别公平性观念的文化背景
2. 确定公平性标准（多人：对称性；单人：平衡性）
3. 设计规则修改机制（如需要）
4. 确保规则明确且一致
```

### 识别统治性策略
```
1. 分析策略胜率优势
2. 评估策略替代动机
3. 检查组合复杂度
4. 确定干预强度（无干预/房规自律/正式禁用/官方补丁）
```
