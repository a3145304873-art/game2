# 游戏修改管理变量定义

## 品牌风险变量

| 变量名 | 类型 | 描述 |
|-------|------|------|
| brand_exposure | integer | 游戏启动画面和界面中公司标识的显示频率和显著程度 |
| mod_spread | string | mod在社区中的传播广度和公开程度 |
| content_violation_type | enum | 色情、暴力、歧视等违规内容分类 |

## 知识产权变量

| 变量名 | 类型 | 描述 |
|-------|------|------|
| mod_creation_effort | string | 玩家制作mod时投入的劳动和资源程度 |
| commercial_intent | boolean | 出版商或玩家是否有将mod商业化的计划 |
| jurisdiction | string | 适用的知识产权法律管辖区（如美国、欧盟、中国等） |

## EULA关键条款模板

### Mod所有权条款

```
[选项A：出版商拥有所有权]
玩家制作的所有mod及其衍生作品的知识产权归[公司名称]所有。

[选项B：玩家保留所有权，授予许可]
玩家保留mod的知识产权，但授予[公司名称]永久、不可撤销、全球范围内、免版税的使用许可，包括但不限于复制、修改、分发、展示和商业利用的权利。

[选项C：共同所有权]
玩家和[公司名称]共同拥有mod的知识产权。
```

### 商业利用条款

```
[选项A：禁止商业化]
玩家不得将任何mod用于商业目的。

[选项B：允许玩家商业化]
玩家可以在遵守本协议的前提下，将mod用于商业目的，但需向[公司名称]支付[X]%的收入分成。

[选项C：出版商独家商业化]
[公司名称]拥有将mod商业化的独家权利。
```

### 内容审核与删除条款

```
[公司名称]有权在任何时候，无需通知，删除或下架任何违反本协议或可能损害[公司名称]声誉的mod。玩家可对删除决定提出申诉，申诉将在[X]个工作日内处理。
```
