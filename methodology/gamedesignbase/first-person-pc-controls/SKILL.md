# 第一人称PC游戏控制方案

## 何时使用

- 开发PC平台第一人称游戏
- 需要实现鼠标+键盘控制方案
- 设计需要精确视角控制的3D导航

## 标准控制配置

### 鼠标控制（视角控制）- 右手操作

**水平方向（X轴）**
- 向左移动鼠标 → 化身原地向左转动
- 向右移动鼠标 → 化身原地向右转动
- 转动程度由鼠标移动距离决定
- **关键特性**：化身位置不变，仅改变面对方向

**垂直方向（Y轴）**
- 向上移动鼠标 → 摄像机向上倾斜（仰视）
- 向下移动鼠标 → 摄像机向下倾斜（俯视）
- **应用场景**：攀爬或下降时至关重要
- **限制**：不改变化身位置，仅改变视角角度

**核心优势**
- 允许玩家不移动化身即可观察四周
- 比操纵杆系统灵活得多

### 键盘控制（移动控制）- 左手操作

**标准键位（WASD）**

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** | 向前移动 | 向化身当前面对方向移动，按住持续移动 |
| **S** | 向后移动/刹车 | 与W键相反方向 |
| **A** | 向左扫射 | 向左侧向滑动（Strafing） |
| **D** | 向右扫射 | 向右侧向滑动（Strafing） |

### 左手玩家适配方案

当左手使用鼠标、右手使用键盘时：
- **替代键位1**：使用箭头键（↑↓←→）
- **替代键位2**：使用 I/J/K/L 键
  - I = 向前（对应W）
  - K = 向后（对应S）
  - J = 向左（对应A）
  - L = 向右（对应D）

## 与操纵杆系统的对比

| 维度 | 鼠标+键盘 | 操纵杆 |
|------|-----------|--------|
| 空间维度 | 2D平面移动+自由视角 | 3D全空间移动（飞行） |
| 输入设备 | 鼠标(2D)+键盘 | 操纵杆(2D)+额外机制 |
| 第三维度 | 不需要（跳跃/下蹲为离散动作） | 必须连续控制（高度/滚转） |
| 视角 | 可自由观察不移动 | 通常锁定驾驶舱第一人称 |

## 实现变量

- **鼠标X轴位移**：决定化身水平转动角度
- **鼠标Y轴位移**：决定摄像机俯仰角度
- **按键状态**：W/A/S/D或替代键的按下/释放状态
- **化身面对方向**：W键移动的目标方向基准
