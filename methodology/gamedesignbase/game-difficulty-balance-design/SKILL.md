# 游戏难度平衡设计

## 核心概念

| 概念 | 定义 |
|------|------|
| 绝对难度 | 挑战本身的客观难度 |
| 相对难度 | 绝对难度减去玩家获得的能力 |
| 感知困难度 | 玩家主观感觉到的难度 |
| 玩家经验 | 随时间积累的游戏内技能和知识 |

## 难度曲线设计流程

### 步骤1：分析绝对难度的构成

绝对难度 = 固有技能 + 压力

- **固有技能**：无时间压力下克服挑战所需的技能水平
- **压力**：由时间限制产生的紧迫感

### 步骤2：应用技能-压力反比原则

当设计挑战时，保持技能水平与压力成反比：

- 高技能要求 → 给予更长执行时间（降低压力）
- 低技能要求 → 施加更多时间压力

### 步骤3：计算相对难度

```
相对难度 = 绝对难度 - 玩家能力
```

**关键规则**：提高绝对难度的速率必须略高于玩家能力增长速率。

### 步骤4：考虑玩家经验的影响

- 游戏开始时：感知困难度 ≈ 相对难度（无经验）
- 游戏进行中：经验增加，若相对难度不变，感知困难度下降
- **设计目标**：通过提高绝对难度，抵消经验带来的难度下降

## 特殊场景处理

### 街机风格游戏（经典步调机制）

1. 单关内：步调持续提高，关卡结束时达到峰值
2. 关卡间：下一关开始步调 > 上一关开始步调
3. 终局设计：步调持续提高直到压倒玩家（刷分导向，非通关导向）

**现代适用性**：仅推荐用于怀旧游戏、网页休闲游戏、移动端短时玩法。

### 永恒世界（MMO/长期运营游戏）

- 每个玩家拥有独立的能力值
- 面对过高难度任务时：提前警告或排除玩家
- 成长设计：多样化提升方式、降低切换门槛、有意义的里程碑

## 验证检查清单

- [ ] 绝对难度增长斜率 > 能力增长斜率
- [ ] 技能要求与时间压力成反比
- [ ] 考虑了目标玩家群体的年龄和反应能力
- [ ] 非典型关卡已设为可选（非强制）
- [ ] 永恒世界已设计安全存储机制防"骡子"滥用

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 能力增长与绝对难度同步 | 感知难度因经验积累而下降 | 提高绝对难度增速 |
| 强制单一挑战类型关卡 | 部分玩家无法通关 | 设为可选隐藏关卡 |
| 无经验补偿的难度设计 | 后期游戏过于简单 | 引入经验系数调整 |
