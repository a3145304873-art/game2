# 玩家偏好类型与难度设计

## Bartle 玩家分类应用

| 类型 | 偏好特征 | 难度设计策略 |
|------|---------|------------|
| 成就者/方块 | 遵循规则，追求完成 | 清晰的技能-压力配比，可量化的进步 |
| 探索者/黑桃 | 与世界互动，发现机制 | 隐藏的深度系统，可探索的难度调节 |
| 社交者/红心 | 与其他玩家互动 | 协作难度，社交压力替代时间压力 |
| 杀手/梅花 | 对其他玩家采取行动 | PVP匹配系统，竞技排名难度 |

## 年龄因素调整

- 青少年/年轻人：可承受更高压力，最佳视觉动作技能
- 儿童：降低压力，简化技能要求
- 老年人：降低反应时间要求，允许更从容的决策
