# 难度计算公式详解

## 绝对难度计算

绝对难度由两个维度组成：

```
绝对难度 = f(固有技能, 压力)
```

### 固有技能分级

| 等级 | 描述 | 示例 |
|------|------|------|
| 低 | 基础操作，无需练习 | 点击按钮开门 |
| 中 | 需要一定熟练度 | 精准跳跃到平台 |
| 高 | 复杂序列操作 | 格斗游戏连招 |
| 极高 | 极限反应+精准 | 无伤通关Boss |

### 压力来源

- 时间限制（倒计时）
- 资源消耗（生命值/弹药递减）
- 环境威胁（持续伤害区域）
- 对手压迫（AI主动攻击）

## 相对难度动态模型

```
相对难度(t) = 绝对难度(t) - 玩家能力(t)

其中：
- 玩家能力(t) = 基础能力 + 获得能力(t)
- 获得能力(t) 通常随等级/装备提升
```

### 理想曲线特征

- 绝对难度：指数增长或分段线性增长
- 玩家能力：线性或对数增长
- 相对难度：缓慢上升或保持稳定
- 感知困难度：通过提高绝对难度来抵消经验效应
