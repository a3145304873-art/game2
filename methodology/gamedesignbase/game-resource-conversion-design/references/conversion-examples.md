# 资源转换详细示例与计算公式

## 基础示例

### 磨坊（小麦→面粉）
**配置**：
- 输入：1袋小麦
- 输出：1袋面粉  
- 比例：1:1
- 生产时间：20秒

**速率计算**：
```
生产速率 = 60 / 20 = 3袋面粉/分钟
```

### 冶炼厂（标准配方）
**配置**：
- 输入：1单位铁矿 + 1单位煤
- 输出：1根铁条
- 生产时间：30秒

**速率计算**：
```
铁条产出：60/30 = 2根/分钟
煤消耗：2单位/分钟
铁矿消耗：2单位/分钟
```

## 替代输入与效率调整

### 数学原理
当替代资源效率不同于基准资源时：

```
替代资源数量 = 基准资源数量 × (基准效率 / 替代效率)
```

### 冶炼厂（替代配方）示例
**场景**：允许使用碳代替煤，碳效率为煤的33%

**计算**：
- 基准：1单位煤（效率1.0）
- 替代：碳（效率0.33）
- 需要碳数量：1 × (1.0/0.33) ≈ 3单位

**最终配方**：
- 输入：1单位铁矿 + 3单位碳
- 输出：1根铁条
- 生产时间：30秒（不变）

## 经济平衡公式

### 价值计算
```
输出价值 = Σ(输入i数量 × 输入i单位价值) × 转换溢价系数 / 时间系数
```

**时间系数调整**：
- 快速（<10秒）：×0.8（需要玩家持续关注）
- 标准（10-60秒）：×1.0
- 慢速（>60秒）：×1.2（补偿等待时间）

### 多输出分配
当单个配方产生多种输出时，按价值比例分配输入成本：
```
输出A成本 = 总输入成本 × (输出A价值 / 所有输出价值总和)
```
