# 游戏资源转换机制设计

设计将输入资源转换为输出资源的生产机制，建立具有明确时间和数量关系的转换系统。

## 适用场景

- 创建生产建筑（磨坊、冶炼厂、精炼厂、加工站）
- 设计制造或合成机制
- 平衡基于时间的资源生成经济流
- 实现具有不同效率的替代输入材料
- 需要计算每分钟产出速率进行经济平衡

## 设计流程

### 1. 定义转换器实体

建立一个特定实体（建筑、机器或处理单元），其功能是将一种或多种资源变为其他类型的资源。

### 2. 设定输入输出比

确定消费的资源和产出的资源之间的数量关系：

- **标准转换**：1:1比例（例如，1袋小麦 → 1袋面粉）
- **复杂转换**：多输入合成（例如，1单位铁矿 + 1单位煤 → 1根铁条）

### 3. 配置生产时间

确定完成一次转换所需的实时时间（秒）。

- 示例：将一袋小麦转换为一袋面粉花费20实时秒

### 4. 计算生产速率

根据生产时间计算单位时间内的产出量，用于经济系统平衡：

**公式**：
```
生产速率 = 60秒 / 单次生产时间（秒）
```

**示例**：60秒 / 20秒 = 每分钟3袋面粉

### 5. 处理替代输入资源（效率差异）

当允许使用不同类型的输入资源时，根据效率差异调整消耗比例：

- 低效率材料需要更高数量才能获得相同产出
- 示例：使用碳代替煤时，由于碳效率比煤低，每生产1根铁条需要消耗3个单位的碳（而非1个单位的煤）

## 关键变量

| 变量 | 类型 | 说明 |
|------|------|------|
| 输入输出比 | Ratio | 消费资源与产出资源的数量比例关系 |
| 生产时间 | Time | 完成一次资源转换所需的实时秒数 |
| 生产速率 | Rate | 每分钟产出的资源数量（60/生产时间） |

## 注意事项

- 必须明确生产速率以确保经济系统平衡
- 必须明确输入输出比以避免资源无限生成或消耗
- 替代材料的效率系数需在参考文档中详细计算
