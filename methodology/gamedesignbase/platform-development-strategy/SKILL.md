# 平台开发策略

## 使用场景
- 评估游戏开发平台选择
- 分析PC与家用游戏机的开发差异
- 确定项目平台定位和预算策略
- 设计实验性或独立游戏项目

## 平台对比分析

### 家用游戏机

**硬件特性**
- 图形硬件与PC相当，但CPU较慢，RAM较小
- 硬件固定不变（"第X代"形式）
- 成本控制：售价200-400美元，需削减硬件成本

**开发限制**
- 必须从制造商获取设计许可证
- 游戏设计需通过制造商审批
- 发布前必须提交大量测试
- 需签署保密协议（NDA）
- 必须购买昂贵的开发工具包

**市场优势**
- 低廉价格带来更大市场
- 易于维护

### 个人计算机（PC）

**硬件特性**
- 可使用PC全部功能（假设玩家未运行其他应用）
- 硬件持续发展，可利用最新硬件创新
- 视觉表现最为壮观

**开发优势**
- 开放平台，无需制造商许可
- 无需购买特殊硬件
- 任何人都可以编程
- 处于游戏创新前沿

**市场定位**
- 高端路线：限制市场规模，目标为专业游戏爱好者
- 中间地带：许多独立游戏取得成功

## 决策流程

### 1. 评估项目类型
```
IF 实验性项目 OR 独立游戏 OR 创新交互形式
THEN 选择PC平台

IF 商业游戏 AND 预算充足 AND 需要大市场
THEN 考虑家用游戏机
```

### 2. 分析内容风险
```
IF 游戏内容包含可能引发争议的话题
THEN PC平台更灵活（避免审批限制）

IF 游戏内容符合主流标准
THEN 家用游戏机可行
```

### 3. 确定预算范围
```
IF 预算有限（无法购买开发工具包）
THEN 选择PC平台

IF 预算充足且追求大市场
THEN 考虑家用游戏机
```

### 4. 评估技术需求
```
IF 需要利用最新硬件创新
THEN PC平台更合适

IF 需要稳定硬件环境
THEN 家用游戏机更合适
```

## 平台选择建议

### 选择PC平台当：
- 项目为实验性、创新性或独立游戏
- 预算有限，无法承担开发工具包成本
- 需要快速迭代和创新
- 内容可能引发争议
- 需要利用最新硬件特性

### 选择家用游戏机当：
- 追求大市场规模
- 预算充足，可承担开发工具包和许可成本
- 游戏内容符合主流标准
- 需要稳定的硬件环境
- 有发行商支持

## 移动平台对比
- 移动设备也能进行简单且廉价的开发
- 但尚未达到PC端相同的表达能力水平
- 持续关注移动设备技术发展趋势
