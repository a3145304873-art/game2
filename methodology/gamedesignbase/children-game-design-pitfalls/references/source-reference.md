来源：Carolyn Handler Miller, Digital Storytelling (2nd ed.)

详细案例分析：

死亡之吻 #1（可爱误区）
- 反例：过度圆润、无害化的角色设计
- 正例：兔八哥的狡黠、歪心狼的执着失败，角色有"边缘性"特质

死亡之吻 #2（说教误区）
- 核心洞察：儿童对广告的反感类比——不想在娱乐时间被推销
- 设计原则：教育元素必须完全内嵌于玩法，不可外显为"学习任务"

死亡之吻 #3（低幼误区）
- 关键区分：简单≠幼稚，复杂≠成人化
- 迪士尼多层叙事：表层冒险故事+深层情感主题

死亡之吻 #4（过度安全误区）
- 发展心理学依据：儿童通过安全距离体验危险来学习应对
- 禁忌主题处理：死亡、背叛、恐惧作为叙事元素而非禁止内容

死亡之吻 #5（均一化误区）
- 市场细分建议：按认知发展阶段（皮亚杰理论）而非单纯年龄
- 能力差异：同一年龄段可能相差2-3个发展阶段

死亡之吻 #6（过度解释误区）
- 学习风格差异：探索型学习者 vs 指导型学习者
- 妥协方案：可选教程+即时可玩

死亡之吻 #7（角色完美误区）
- 角色弧光必要性：缺陷→成长→克服
- 反英雄策略：不完美角色的代入感优势
