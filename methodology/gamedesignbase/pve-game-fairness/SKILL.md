# PvE游戏公平性设计原则

## 适用场景
- 正在设计或评估PvE游戏的公平性
- 游戏挑战来源于环境而非其他玩家
- 处于游戏设计或平衡性调整阶段

## 六项核心原则

### 1. 难度一致性
- 游戏应按照始终如一的难度级别向玩家提供挑战
- 严禁出现突然的高潮或者低谷
- 玩家认为难度上突然大幅度地改变是不公平的

### 2. 避免突然死亡（无警告失败）
- 玩家不应该在没有警告且不是因为自身错误的前提下突然输掉游戏
- 摒弃"通过死亡学习"的设计方法（即让玩家通过反复死亡来获取信息）
- 必须提前向玩家提供足够的警告，以便玩家很容易地避免死亡

### 3. 消除平局（软锁状态）
- 不应该出现平局状态（即玩家未输掉游戏，但也无法获得胜利的状态）

**常见原因：**
- 死锁
- 阻止玩家获胜/失败的特定条件组合（如通过单向门后无法返回获取关键物品）

**解决方案：**
a. 仔细研究机制，确保不存在完全排除胜利可能但不满足失败条件的状态
b. 如果存在，将该状态改变为失败条件
c. 最佳方案：重新设计机制来阻止游戏进入这种状态（例如：设计为不捡起物品就无法前进，或捡起后不允许放下）

### 4. 信息充分性
- 游戏不能要求玩家在没有得到足够信息的条件下做出重要决定
- 必须提供给玩家他们需要的信息，避免玩家只能通过反复实验来寻找结果

### 5. 知识内包性
- 赢得游戏需要的所有事实性知识都应该限制在游戏中
- 玩家不应该研究游戏世界之外来赢得游戏
- **例外：** 问答游戏是唯一允许外部知识的例外

### 6. 类型一致性
- 游戏不应要求玩家克服本不该出现在该游戏类别中的挑战（例如：在飞行模拟游戏中出现形式逻辑谜题）
- 如果游戏属于混合类别，必须在开始玩游戏之前清楚地告知玩家

## 执行流程

1. **检查难度一致性**：确认游戏难度级别始终如一，无突然变化
2. **验证警告机制**：确保所有失败都有提前警告，避免无警告死亡
3. **排查平局状态**：检查是否存在软锁状态，应用解决方案消除
4. **评估信息提供**：确认玩家在做出重要决定前有足够信息
5. **验证知识内包**：确保获胜所需知识都在游戏内（问答游戏除外）
6. **检查类型一致性**：确认挑战类型符合游戏类别，混合类别需明确告知

## 约束条件
- 问答游戏允许外部知识
- 明确标注的混合类型游戏允许跨类别挑战
