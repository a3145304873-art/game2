# 游戏道德系统对比分析

## 适用场景

- 撰写游戏研究论文中的道德系统分析章节
- 进行游戏伦理设计评估
- 撰写游戏批评文章中的道德机制评论
- 比较不同游戏的道德选择设计理念

## 前提条件

- 已玩过或深入了解两款道德系统对比鲜明的游戏
- 或已获得指导老师/编辑分配的游戏对象
- 具备学术写作或批评写作能力

## 核心流程

### 第一步：样本选择与对比维度确认

选择两款道德系统**成鲜明对比**的游戏：

| 对比维度 | 示例A | 示例B |
|---------|-------|-------|
| 道德结构 | 二元道德（如《质量效应》楷模/叛逆） | 复杂道德（如《巫师》灰色选择） |
| 伦理框架 | 结果论道德（看结果） | 义务论道德（看动机） |
| 反馈方式 | 明确道德反馈（数值显示） | 隐性道德后果（延迟或隐藏） |

> ⚠️ 约束：不适用于道德系统相似或单一道德观的游戏对比

### 第二步：奖励机制系统记录

为每款游戏建立奖励动作清单：

**机械奖励**
- 经验值、金钱、装备获取
- 能力解锁、属性加成

**叙事奖励**
- 剧情分支开启
- NPC好感度变化
- 特殊对话选项
- 结局变化

**美学奖励**
- 视觉特效变化
- 音乐/音效调整
- 场景氛围改变

**标注要求**：每个被奖励动作需标记道德属性（利他/利己/中立/邪恶等）

### 第三步：惩罚机制系统记录

为每款游戏建立惩罚动作清单：

**机械惩罚**
- 属性降低、资源损失
- 能力锁定、难度增加

**叙事惩罚**
- NPC敌对状态
- 剧情线锁定
- 负面结局、社会排斥

**元游戏惩罚**
- 成就无法解锁
- 内容锁定
- 重玩限制

**标注要求**：每个被惩罚动作需标记道德属性

### 第四步：道德系统结构分析

构建每款游戏的道德矩阵：

```
              ┌─────────────┬─────────────┐
              │   机械反馈   │   叙事反馈   │
├─────────────┼─────────────┼─────────────┤
│ 利他行为    │  +10道德点   │  NPC感谢    │
│ 利己行为    │  金钱奖励    │  孤立结局   │
│ 邪恶行为    │  能力解锁    │  敌对状态   │
└─────────────┴─────────────┴─────────────┘
```

**识别道德逻辑**：
- 提取游戏的"道德算法"（如"帮助平民=+10道德点"）
- 对比两款系统的：道德严格性、反馈即时性、系统透明度

### 第五步：现实世界道德关系分析

分析游戏道德与现实道德行为的关联：

| 分析维度 | 关键问题 |
|---------|---------|
| 行为一致性 | 游戏选择是否反映玩家现实道德观？ |
| 后果认知 | 游戏简化后果如何影响道德判断？ |
| 道德学习 | 奖励机制是否强化/削弱现实道德倾向？ |
| 文化相对性 | 游戏道德系统是否反映特定文化背景？ |

**可选理论框架**：道德脱离理论、移情理论、社会学习理论

### 第六步：论文结构组织

```
1. 引言：两款游戏及其道德系统概述
2. 方法论：观察奖励/惩罚的具体方法
3. 游戏A分析：奖励/惩罚清单与逻辑
4. 游戏B分析：奖励/惩罚清单与逻辑
5. 对比分析：系统异同并置
6. 现实关联：游戏道德与现实道德行为关系
7. 结论：发现总结与设计启示
```

## 输出规格

结构化分析论文，包含：
- 两款游戏的完整奖励/惩罚清单
- 道德系统对比矩阵
- 游戏道德与现实道德关系的深度分析
