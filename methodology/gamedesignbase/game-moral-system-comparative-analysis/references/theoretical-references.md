# 理论应用指南

## 道德脱离理论（Moral Disengagement Theory）

**核心概念**（Bandura, 1999）：
个体通过认知重构使不道德行为显得可接受的心理机制。

**游戏中的体现**：
| 脱离机制 | 游戏设计实例 | 分析角度 |
|---------|-----------|---------|
| 道德辩护 | "为了拯救世界"的叙事框架 | 游戏是否为暴力行为提供正当理由 |
| 委婉标签 | "处决"而非"谋杀"，"清除"而非"屠杀" | 术语选择如何影响道德认知 |
| 有利比较 | "敌人更残忍"的叙事设定 | 相对化玩家的道德责任 |
| 责任转移 | 跟随命令的NPC队友 | 代理感与道德责任的分配 |
| 责任分散 | 群体决策机制 | 个人选择在集体中的稀释 |
| 后果扭曲 | 敌人尸体消失、无痛觉表现 | 暴力后果的视觉淡化 |
| 非人化 | 敌人被标记为"感染者""异形" | 他者化与道德排斥 |

**应用提示**：分析游戏是否设计机制促进或抑制道德脱离

## 移情理论（Empathy Theory）

**核心概念**：
情感移情（感受他人情绪）与认知移情（理解他人观点）

**游戏分析维度**：
- **角色塑造深度**：NPC是否有足够背景故事激发移情
- **互动历史长度**：长期关系 vs 一次性遭遇的道德权重
- **视角转换机制**：是否强制玩家体验不同立场
- **反馈的情感标记**：受害者是否有痛苦表现

**关键问题**：
> 游戏设计是增强还是抑制了对特定角色的移情？这种移情操纵如何影响道德选择？

## 社会学习理论（Social Learning Theory）

**核心概念**（Bandura）：
通过观察他人行为及其后果进行学习

**游戏中的应用**：
- **观察学习**：NPC的道德行为及其结果展示
- **替代性强化**：看到他人因[行为]获得[结果]
- **自我效能**：玩家对自己道德决策能力的信心

**分析框架**：
```
游戏展示了[行为模型] → 玩家观察到[后果] → 
形成[结果预期] → 影响[未来行为倾向]
```

## 自我决定理论（Self-Determination Theory）

**核心需求**：自主性、胜任感、归属感

**与游戏道德系统的关系**：
| 需求 | 游戏设计影响 | 道德选择意义 |
|-----|-----------|-----------|
| 自主性 | 有意义的选择 vs 虚假选择 | 道德选择是否真实影响叙事 |
| 胜任感 | 道德系统的可学习性 | 玩家能否掌握道德"规则" |
| 归属感 | 与游戏内群体的关系 | 道德选择的社会后果 |

## 理论选择建议

| 分析焦点 | 推荐理论 |
|---------|---------|
| 玩家为何能轻松实施游戏暴力 | 道德脱离理论 |
| 游戏如何操纵玩家对特定角色的态度 | 移情理论 |
| 游戏道德教育效果 | 社会学习理论 |
| 道德选择的真实感与满足感 | 自我决定理论 |
| 道德系统的文化偏见 | 文化心理学、道德基础理论 |
| 玩家身份与道德行为的关系 | 虚拟身份理论、自我知觉理论 |
