# 常见道德框架与游戏案例

## 二元道德系统（Binary Morality）

**核心特征**：明确的善恶两极，数值化道德计量

| 游戏 | 系统名称 | 机制特点 |
|-----|---------|---------|
| 质量效应系列 | 楷模/叛逆 | 对话选择积累点数，影响外观与剧情 |
| 星球大战：旧共和国武士 | 光明/黑暗 | 原力点数决定技能与结局 |
| 声名狼藉系列 | 英雄/恶棍 | 行为改变市民反应与能力外观 |
| 辐射3 | 业报系统 | 正负数值影响NPC态度与随机事件 |

**分析要点**：
- 道德选择的可逆性（能否洗白/黑化）
- 中间状态的缺失或模糊处理
- 极端选择的叙事奖励是否失衡

## 复杂/灰色道德系统（Complex/Gray Morality）

**核心特征**：无明确善恶标签，后果难以预测

| 游戏 | 机制特点 |
|-----|---------|
| 巫师系列 | 选择无明确标识，后果延迟显现，"没有正确选择" |
| 龙腾世纪系列 | 同伴道德观冲突，无全局道德值 |
| 行尸走肉系列 | 情境伦理，保护谁牺牲谁的艰难抉择 |
| 极乐迪斯科 | 意识形态光谱而非道德光谱 |
| 这是我的战争 | 生存压力下的道德妥协 |

**分析要点**：
- 信息不对称：玩家是否知道选择的道德含义
- 后果延迟：短期收益 vs 长期代价
- 悲剧性选择：是否所有选项都有负面后果

## 伦理学框架映射

### 功利主义（Utilitarianism）
**游戏体现**：最大化整体幸福/最小化伤害的选择被奖励
- 例：《底特律：变人》中牺牲少数仿生人拯救更多人类
- 分析点：游戏是否计算"效用总和"，玩家能否接受结果论逻辑

### 义务论（Deontology）
**游戏体现**：某些行为本身错误，无论结果如何
- 例：《辐射：新维加斯》中某些派系拒绝妥协的绝对立场
- 分析点：规则的可违反性，动机与结果的分离

### 美德伦理（Virtue Ethics）
**游戏体现**：培养特定品格特质，而非遵循规则
- 例：《女神异闻录》系列中社交属性与品格培养
- 分析点：角色性格发展是否影响道德选项可用性

### 关怀伦理（Care Ethics）
**游戏体现**：关系网络的维护优先于抽象原则
- 例：《质量效应》中与特定角色的忠诚任务
- 分析点：偏袒与公正的冲突，特殊关系的道德权重

## 对比组合推荐

| 组合 | 对比焦点 |
|-----|---------|
| 质量效应2 vs 巫师3 | 二元数值化 vs 灰色情境化 |
| 声名狼藉 vs 这是我的战争 | 超级英雄道德 vs 平民生存伦理 |
| 辐射3 vs 辐射：新维加斯 | 全局业报 vs 派系声望 |
| 底特律：变人 vs 行尸走肉 | 明确标识选择 vs 无意识道德时刻 |
| 旧共和国武士 vs 极乐迪斯科 | 原力道德 vs 政治意识形态 |
