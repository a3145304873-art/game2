# 首个游戏项目技术选型建议

## 适用场景
在以下情况之一或组合时应用此技能：
- 开发者处于学习阶段
- 这是开发者的首个游戏项目
- 计划使用诞生不到一年的新游戏引擎或开发框架

## 核心规则

### 1. 首个项目规则
- **强制要求**：首个游戏项目必须是2D游戏。
- **禁止事项**：不要在首个项目中尝试3D图形开发。

### 2. 新引擎类别限制
- **识别标准**：检查游戏引擎或框架的诞生时间是否少于1年。
- **限制措施**：不要在"新生代"游戏开发类目中制作3D游戏。

## 执行步骤

1. **评估项目背景**
   - 确认是否为开发者的首个游戏项目。
   - 确认使用的引擎/框架是否属于新类别（< 1年）。

2. **应用选型规则**
   - 如果满足任一适用场景，强制推荐2D游戏开发。
   - 明确告知用户避免3D开发。

3. **风险提示**
   - 说明同时学习新引擎和3D开发会导致学习曲线过于陡峭。
   - 强调技术难度过高可能导致项目失败。

4. **建议学习路径**
   - 建议先通过2D项目掌握基础知识。
   - 建议先熟悉新引擎的基本功能和工具链。
   - 建议在掌握基础后，再挑战3D开发。

## 输出建议模板
> 建议选择2D游戏作为首个项目，避免在新引擎中使用3D，降低学习难度和项目风险。
