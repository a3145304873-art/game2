# PC游戏分发类型分类

## 使用场景
当需要为PC游戏产品确定分发策略、选择部署架构或制定平台方案时，使用此技能进行类型分类决策。

## 前置条件
- 目标平台为个人计算机
- 已确定基本技术架构方向（本地安装或Web技术）

## 约束条件
- 不适用于主机游戏
- 不适用于移动应用商店分发

## 分发类型

### 类型A：独立游戏

**定义**：玩家像其他程序一样安装在自己计算机上的游戏

**特征**：
- 本地安装到用户计算机
- 直接运行在操作系统上
- 需要下载安装包
- 拥有完整的硬件访问权限

**适用场景**：
- 需要高性能计算的游戏
- 复杂图形渲染需求
- 需要完整系统资源访问
- 大型3D游戏或AAA级游戏

### 类型B：基于浏览器的网页游戏

**定义**：在网络浏览器内运行的游戏

**特征**：
- 无需本地安装
- 通过浏览器访问即可运行
- 基于Web技术（HTML5/WebGL等）
- 即点即玩

**适用场景**：
- 轻量级游戏
- 即点即玩需求
- 高跨平台访问需求
- 休闲游戏或小游戏

## 决策流程

1. **评估游戏复杂度**
   - 高性能需求 → 考虑独立游戏
   - 轻量级需求 → 考虑网页游戏

2. **分析目标用户行为**
   - 愿意下载安装 → 独立游戏
   - 追求即时访问 → 网页游戏

3. **考虑技术架构**
   - 原生开发 → 独立游戏
   - Web技术栈 → 网页游戏

4. **评估分发渠道**
   - Steam/Epic等平台 → 独立游戏
   - 网站直接分发 → 网页游戏

## 决策输出

根据以下维度进行最终决策：
- 游戏复杂度和性能要求
- 目标受众的使用习惯
- 技术团队能力
- 商业模式和分发策略

**决策原则**：
- 若需高性能和完整系统访问 → 选择独立游戏模式
- 若追求即点即玩和低门槛访问 → 选择浏览器模式
- 可基于游戏复杂度、目标受众和技术要求进行综合评估

## 关键差异

| 维度 | 独立游戏 | 网页游戏 |
|------|---------|---------|
| 安装方式 | 本地安装 | 无需安装 |
| 运行环境 | 操作系统 | 浏览器 |
| 技术栈 | 原生开发 | Web技术 |
| 性能上限 | 高 | 中等 |
| 用户门槛 | 较高 | 低 |
| 分发渠道 | 游戏平台 | 网站链接 |
