# 游戏商业模式设计

## 何时使用
- 开发者希望通过广告盈利
- 游戏为网络游戏或免费模式
- 游戏背景允许商业植入
- 获得赞助商合作
- 采用间接盈利模式
- 游戏为数字分发/在线游戏
- 目标平台支持微交易
- 需要维持玩家市场占有率

## 执行步骤

### 1. 选择商业模式

根据游戏类型、目标受众和平台特性选择合适的商业模式：

| 模式 | 适用场景 | 核心特征 |
|------|----------|----------|
| 广告变现 | 网络游戏、免费游戏 | 通过浏览或点击广告获得收入 |
| 赞助植入 | 体育游戏、赛车游戏、现代背景游戏 | 将赞助信息植入游戏内部场景 |
| 免费增值 | 数字分发、在线游戏、移动应用 | 部分功能免费，高级内容付费 |
| 免费游戏 | 社交游戏、移动端F2P | 短期升级机制维持留存 |

### 2. 实施广告变现策略

**广告布局：**
- 将广告放置在游戏屏幕旁边
- 确保玩家在屏幕上能看到它

**数量控制：**
- 严格控制广告数量
- 不能插入太多，以免干扰玩家体验

**盈利机制：**
- 通过玩家看到（浏览）或点击某个广告来获得收入

**免费模式实施：**
- 如果广告模式成功，可以免费开放游戏
- 所有运营费用从广告收入中获取
- 案例：脸书和雅虎上的许多游戏

**去广告变现（增值服务）：**
- 出售没有广告的相同版本游戏
- 目标群体：针对不喜欢广告且宁愿出钱消除它们的玩家

### 3. 实施赞助植入策略

**植入方式：**
将赞助公司的信息（广告）直接植入到游戏内部场景中。

**盈利模式判定：**

| 销售渠道 | 付费方式 |
|----------|----------|
| 零售或网购销售 | 赞助商按照游戏出售的数量支付费用 |
| 网络游戏销售 | 当广告出现在游戏旁边时，按照浏览数量或者点击进入的数量支付费用 |

**适用场景分析：**
- **推荐场景：** 仿真体育游戏或赛车游戏。原因：现实世界比赛项目中已有广告标语，电子游戏中自然出现。
- **排除场景：** 设置在没有广告的理想世界或者过往的古老时代的游戏（不适用此模式）。

**设计约束：**
- 必须确保游戏内容不能让赞助商们失望
- 注意：在体育游戏中通常问题不大，但仍需考虑这一点

### 4. 实施免费增值模式

**模式定义与核心结构：**
- 免费增值(Freemium) = 免费(Free) + 额外费用(Premium)的组合模式
- 发布策略：先发布软件/游戏的**部分功能版本**供免费下载和使用
- 付费机制：允许消费者通过**内部应用购买(IAP)**获取**更高级、更加有用的版本**或额外内容

**历史参照与边界定义：**
- 首次取得广泛成功的产品类别：**杀毒系统套装**
- 负面边界情况（必须避免）：如果免费版本功能太弱导致不能很好地使用，此类免费版本被称为**'功能不全的共享软件'(Crippleware)**

**游戏行业具体实施方式：**
- 基础策略：分发游戏本体免费，但在游戏中提供IAP项目
- 内容交付形式：通过**可供下载的内容(DLC)**实现

**DLC内容分类：**

| 类别 | 内容 | 目的 |
|------|------|------|
| 内容扩展类 | 额外的等级/关卡、附加的游戏模式 | 延长游戏时间 |
| 装饰定制类 | 化身特色的新衣服、角色外观物品 | 玩家自我表达 |
| 功能道具类 | 游戏中的新物品（武器、能源、游戏内货币） | 增强游戏体验 |
| 体验更新类 | 跳舞游戏中的额外音乐 | 保持新鲜体验 |

**技术运营要求：**
- 在线依赖：游戏的后续部分或服务器需要"周期性地连接"
- 渠道限制："大多数的销售模式只适合用在网上进行推销的游戏"

### 5. 实施免费游戏留存机制

**目标群体定位：**
- 针对'不太重要的玩家'（低参与度玩家或潜在流失用户）的游戏积极性进行应对
- 目标：保持玩家市场占有率（retention rate）

**短期升级机制设计（快速反馈循环）：**
- 在短时间内提供一系列的游戏升级（rapid progression/leveling）
- 典型案例：《黑帮战争》(Mafia Wars)模式
- 操作极简主义：有时这意味着玩家们除了点击按钮进行升级以外，不用干别的事情

**设计风险与心理影响（关键警告）：**
- 内容空洞化风险：这些设置常常会使玩家无事可做
- 极端化与异化：有时候会过度甚至于极端，以至于玩家们甚至觉得在这个时候自己就像是一只正在被训练按按钮的动物
- 心理学机制：此描述指向斯金纳箱(Skinner Box)效应/操作性条件反射(Operant Conditioning)的滥用

**模式边界定义：**
- 免费模式的游戏与免费增值类(Freemium)的游戏联系紧密
- 许多免费模式的游戏也包含了一些增值的内容供玩家购买

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| ad_placement | Layout | 广告在屏幕旁边的具体位置 |
| player_action | Event | 玩家的浏览或点击行为 |
| sales_channel | Enum | 零售/网购 或 网络游戏 |
| game_setting | Context | 游戏背景设定（现代/体育/古代等） |
| 基础版本功能覆盖率 | percentage | 免费版本提供的功能占完整版的比例 |
| IAP项目类型 | enum | 可下载内容的分类：装饰性/功能性/内容扩展性 |
| DLC更新频率 | time_period | 新内容发布的周期 |
| 付费点深度 | integer | 玩家在开始游戏后多久遇到第一个付费提示 |
| 升级频率 | Frequency | 短时间内提供的升级次数 |
| 按钮点击机制 | Interaction_Type | 极简交互，仅需点击即可完成游戏循环 |
