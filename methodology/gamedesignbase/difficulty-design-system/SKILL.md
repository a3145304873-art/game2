# 游戏难度设计系统

## 适用场景
- 评估玩家实际感受到的挑战难度
- 根据玩家经验调整关卡平衡
- 设计游戏难度进阶
- 调整关卡节奏

## 第一部分：感知困难度计算模型

### 理解核心公式

**感知困难度 = 绝对难度 - ( 提供的能力 + 游戏内经验 )**

*注：相对难度 = 绝对难度 - 提供的能力，因此感知困难度 = 相对难度 - 游戏内经验。*

### 定义关键变量

**游戏内经验：** 指玩家在**当前游戏**中克服类似挑战所花费的时间。随着玩家前进，他们学会更高效使用UI并理解核心机制。

**绝对难度：** 挑战本身的客观难度。

**提供的能力：** 游戏赋予玩家的能力（如技能、道具等）。

### 分析变量关系
- 玩家拥有的游戏内经验越多，认为给定类型的挑战越简单
- 游戏内经验作为减项，直接降低感知困难度

### 应用设计补偿原则
关卡设计师在构建关卡时，必须考虑玩家对相同类型挑战拥有的游戏内经验数量。

**IF** 玩家对该类型挑战已拥有大量游戏内经验，**THEN** 关卡设计师应考虑提高挑战的绝对难度来进行补偿。

### 执行限制与注意事项
- 该公式未提供任何标准计量单位
- 若需计算实际值，必须在游戏中依据计划包含的挑战，为这些量找到一种量化的方式
- 该公式的作用更像是一个有助于理解的原则，而不是一个实际可以计算的值

## 第二部分：难度进阶与节奏控制指南

### 确定目标受众与基础策略

**一般原则：** 整个游戏过程中感知困难度要么保持不变，要么上升（大部分游戏中是上升的）

**特殊人群例外：** 对于年纪小的孩子、一般玩家（对挫折忍受能力比核心玩家低）或行动障碍者（在物理协调性挑战中获益较少），要尽力保持感知困难度在整个游戏过程中**基本保持不变**或者上升得非常慢。

**验证方法：** 不要相信设计者自己的主观判断（作为专业级玩家很难判断难度）。必须观察**目标受众玩家试玩游戏的测试结果**来正视游戏难度。

### 实施难度进阶指导方针

**绝对难度：** 随着时间的推移提高挑战的绝对难度。

**玩家能力：** 按照稍微低一点的速率来提高玩家克服这些挑战可用的能力。

**经验与相对难度：** 保证玩家获得的经验不会快到让他们感觉挑战变得越来越简单。隔开这些挑战，使**相对难度的上升速率**比游戏内经验增加的速率稍微快一些。

**平滑度检查：** 试玩游戏，检查并消除挑战感知困难度的**突然升高或者降低**。注意：游戏困难度的突然非预期升高会让很多玩家感到气馁，即使后续难度下降，也可能阻止玩家完成游戏。

### 构建关卡节奏（锯齿形曲线）

**关卡起始难度：** 每一个关卡刚开始时的感知困难度应该比前面一个关卡结束时的感知困难度稍微低一点。

**关卡内趋势：** 在每一关的过程中要提高感知困难度。

**时长与增长率：** 通过每一个关卡的时间应该越来越长，且每一关内困难度的增长率也应该比上一关稍微高一点。

## 前提条件
- 已确定目标受众群体
- 已完成基础游戏原型
- 已确定挑战的绝对难度
- 已确定游戏提供的能力
- 已量化玩家的游戏内经验

## 约束
- 不包含玩家在其他游戏中的事前经验
- 公式本身未提供标准计量单位
- 包含超过五个关卡的游戏内，难度曲线不应过于陡峭
- 该指南仅说明游戏的一般难度趋势，不包含关卡内的具体难度起伏

## 输出
生成一条平衡的、具有锯齿状节奏的感知困难度曲线，确保玩家获得成就感且不感到过度挫败
