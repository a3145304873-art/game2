# 感知困难度计算模型详细说明

## 公式详解

### 基础公式
```
感知困难度 = 绝对难度 - ( 提供的能力 + 游戏内经验 )
```

### 衍生公式
```
相对难度 = 绝对难度 - 提供的能力
感知困难度 = 相对难度 - 游戏内经验
```

## 变量详细定义

### 绝对难度
- **类型：** 数值
- **定义：** 挑战本身的客观难度设定
- **示例：** 敌人数量、障碍复杂度、时间限制严格程度

### 提供的能力
- **类型：** 数值
- **定义：** 游戏赋予玩家用于应对挑战的能力
- **示例：** 武器威力、技能等级、道具效果

### 游戏内经验
- **类型：** 数值
- **定义：** 玩家在当前游戏中克服类似挑战花费的时间
- **关键特征：** 仅计算当前游戏内的经验，不包含其他游戏的事前经验
- **增长方式：** 随着玩家前进，他们学会更高效使用UI并理解核心机制

### 感知困难度
- **类型：** 数值
- **定义：** 玩家实际感觉到的难度
- **特点：** 这是主观感受，但可以通过公式进行量化分析

## 设计应用示例

### 场景1：早期关卡
- 绝对难度：50
- 提供的能力：30
- 游戏内经验：5
- 感知困难度：50 - (30 + 5) = 15

### 场景2：后期关卡（玩家已熟练）
- 绝对难度：80（提高）
- 提供的能力：50（提高）
- 游戏内经验：25（大幅提高）
- 感知困难度：80 - (50 + 25) = 5

**问题分析：** 虽然绝对难度提高了，但由于玩家能力提升和经验积累，感知困难度反而降低了。

**解决方案：** 提高绝对难度到100，使感知困难度保持在25左右。

## 计算性质说明

该公式是一个**概念指导模型**，而非精确计算工具：

1. **无标准计量单位：** 公式未提供统一的计量标准
2. **需要自定义量化：** 设计师需要根据具体游戏为变量定义量化方式
3. **主要作用：** 帮助理解各变量之间的关系，而非得出精确数值

## 补偿原则应用

### 补偿触发条件
当玩家对某类挑战拥有大量游戏内经验时

### 补偿措施
提高该类挑战的绝对难度

### 补偿目标
保持感知困难度在合理范围内，避免挑战变得过于简单
