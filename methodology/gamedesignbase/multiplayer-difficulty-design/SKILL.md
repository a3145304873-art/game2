# 多人游戏难度设计

决定是否及如何为多人游戏提供难度选择选项。

## 何时使用

- 设计多人游戏难度系统初期
- 评估现有难度模式是否适合游戏类型
- 处理玩家技能差异过大的匹配问题
- 在PvP与PvE元素间分配难度控制权

## 核心原则

> 在多数多人游戏中，**玩家技能确定了其他玩家打败他的难度，或者他打败其他玩家的难度**。

这意味着：PvP场景下，难度应由匹配系统和玩家间互动自然生成，而非人工预设静态难度。

## 决策流程

```
多人游戏
    │
    ▼
核心挑战来源是玩家对抗（PvP）？
    ├── 是 → 不提供难度模式 → 依赖匹配系统
    │
    └── 否 → 核心挑战是环境/AI（PvE）？
              ├── 是 → 提供环境难度选择
              │         └── 调整：AI强度、环境危害、资源稀缺度
              │
              └── 否 → 玩家群体差异极大？
                        ├── 是 → 谨慎提供可选难度 + 分池匹配
                        │         ⚠️ 代价：可能损害高手体验
                        │
                        └── 否 → 参考单人游戏标准做法
```

## 具体规则

### 规则1：PvP游戏不提供难度模式
- 依赖ELO/Glicko等匹配算法创造公平对局
- 玩家通过提升自身技能"降低难度"
- 静态难度选项会破坏竞技公平性

### 规则2：环境挑战型游戏提供环境难度
适用类型：赛车游戏、合作生存游戏、合作解谜游戏

| 游戏类型 | 环境难度调整对象 |
|---------|---------------|
| 赛车游戏 | AI对手强度、赛道 hazards、时间压力 |
| 合作生存 | 敌人波次强度、资源刷新率、环境惩罚 |
| 合作解谜 | 提示频率、时间限制、错误惩罚 |

### 规则3：特殊群体场景谨慎处理
**触发条件**：玩家类型存在显著差异（如儿童vs成人）

**设计妥协**：
- 允许自选难度级别
- **必须配套**：分池匹配机制（休闲/排位分离）
- **风险提示**："虽然这对于高手玩家来说是一种障碍"

**缓解措施**：
- 难度仅影响非核心奖励（外观、称号）
- 高难度提供额外挑战而非强制路径
- 明确标识"推荐难度"引导选择

## 执行检查清单

- [ ] 明确游戏的核心挑战来源（PvP/PvE/混合）
- [ ] PvP游戏：验证匹配系统能否替代难度选择
- [ ] PvE游戏：列出所有可调整的环境难度参数
- [ ] 混合游戏：明确哪些元素受难度影响，哪些由玩家技能决定
- [ ] 若提供难度选择：验证分池匹配机制是否到位

## 常见错误

- 在纯PvP游戏中添加"简单/困难"模式，导致匹配池分裂
- 环境难度调整影响玩家间平衡（如合作游戏中仅削弱主机玩家敌人）
- 忽视高手玩家在"照顾新手"设计中的负面体验
