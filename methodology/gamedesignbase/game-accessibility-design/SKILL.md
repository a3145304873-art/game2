# 游戏玩家功能受损四大类别识别与辅助设计义务

## 何时使用

- 游戏概念设计阶段确定无障碍目标
- 分析目标用户的可访问性需求
- 规划游戏辅助功能优先级
- 评估游戏对残障玩家的包容性

## 四大功能受损类别

| 类别 | 描述 |
|------|------|
| 视觉障碍 | 视力受限或失明玩家 |
| 听觉障碍 | 听力受限或失聪玩家 |
| 移动性障碍 | 运动神经控制受限或肢体残疾玩家 |
| 认知障碍 | 认知处理或学习能力受限玩家 |

## 行业背景与问题根源

### 传统假设
> 街机游戏和运动游戏的起源产生了一个毫无疑问的假设：**游戏只适用于具有优秀的视力和良好的运动神经的人**

### 后果
- 游戏业在辅助功能方面远远落后于操作系统和办公产品
- 许多不具备这些能力的人也想玩游戏

### 设计义务
**必须质疑此传统假设**，考虑让游戏更容易接近这些受损玩家群体的方式
