# 玩家情感类型分析

基于Chris Bateman 2008年对1000+玩家的调查研究，帮助理解和应用十大玩家情感类型。

## 使用时机
- 需要选择游戏情感设计目标时
- 需要分析玩家情感需求时
- 需要评估游戏情感体验时
- 进行玩家体验研究时

## 分析步骤

### 1. 确定情感需求场景
根据游戏类型和目标玩家，确定需要激发的情感类型。

### 2. 参考情感类型优先级
根据Bateman的研究结果，考虑以下维度：
- **普遍程度**：该情感在玩家中的普遍性
- **渴求程度**：玩家对该情感的期待值
- **设计优先级**：该情感在游戏设计中的重要性

### 3. 选择情感类型
从10种情感类型中选择适合的情感组合。

### 4. 设计实现方案
根据选定情感类型的设计建议，制定具体实现方案。

## 注意事项
- 情感排名基于2008年数据，可能随时代变化
- 不同游戏类型可能侧重不同情感组合
- 普遍程度与渴求程度可能不一致（如惊喜感最渴求但不是最普遍）
