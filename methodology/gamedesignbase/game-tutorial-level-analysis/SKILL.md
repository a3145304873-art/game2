# 游戏教程关卡分析

本技能用于分析游戏中的教程关卡或数据关卡，评估其如何有效地向玩家传达游戏机制并建立玩家技能。

## 前置条件

- 选择一款你实际玩过的游戏
- 确定该游戏中的教程关卡或数据关卡

## 执行步骤

### 1. 确定分析对象

- **选择游戏**：选择一款你熟悉并实际玩过的游戏。
- **定位关卡**：找到该游戏专门用于教学的数据关卡或初始教程关卡。

### 2. 分析核心教学机制

- **移动方式教学**：分析教程关卡如何让玩家了解并掌握游戏的移动方式。
- **功能介绍**：分析游戏功能是如何逐步介绍给玩家的。
- **通用原则应用**：检查设计是否遵循了游戏设计的通用原则。

### 3. 评估玩家体验与兴趣

- **兴趣维持**：分析教程关卡通过什么手段保证玩家对游戏保持足够的兴趣。

### 4. 深度机制分析

- **技能建立机制**：
  - 判断玩家的技能是在与游戏环境的交互过程中建立的？
  - 还是通过完全独立的、孤立的动作建立的？

### 5. 系统与内容分析

- **化身个性化**：
  - 确认游戏是否支持玩家自主个性化他们的化身（Avatar）。
  - 如果支持，分析个性化设置是如何在教程阶段呈现的。
- **发现性内容**：识别除教程关卡明确教授的内容外，还有哪些游戏元素是留给玩家自己去发现的。

## 输出结果

根据上述分析维度，撰写一份**两到三页**的分析报告。报告应涵盖以下核心内容：

1. 移动方式与功能的教学设计
2. 通用原则的应用情况
3. 玩家兴趣的维持策略
4. 技能建立的具体模式（交互式 vs 独立式）
5. 化身个性化系统的设计
6. 发现性内容的留白设计
