# 教程关卡分析维度详解

## 1. 移动方式教学
- **分析点**：玩家如何学习移动？
- **关注细节**：是否有视觉提示？是否有强制引导？操作反馈是否及时？

## 2. 功能介绍
- **分析点**：核心机制如何拆解教学？
- **关注细节**：是否遵循循序渐进原则？是否结合了实际场景？

## 3. 通用原则
- **分析点**：是否符合游戏设计基础理论？
- **关注细节**：如反馈机制、目标清晰度、难度曲线等。

## 4. 兴趣保证
- **分析点**：如何避免教程枯燥？
- **关注细节**：叙事结合、奖励机制、视觉吸引力、操作爽快感。

## 5. 技能建立机制
- **交互过程中建立**：玩家在尝试解决实际问题的过程中自然学会技能（例如：通过跳过障碍学会跳跃）。
- **完全独立动作**：玩家在安全环境中重复练习特定动作（例如：靶场练习射击）。

## 6. 化身个性化
- **支持情况**：是/否。
- **设置方式**：是在教程开始前、教程中还是教程后？是否影响游戏体验？

## 7. 发现性内容
- **定义**：游戏未明确告知，需要玩家探索或尝试才能发现的内容。
- **作用**：增加游戏深度和重玩价值。
