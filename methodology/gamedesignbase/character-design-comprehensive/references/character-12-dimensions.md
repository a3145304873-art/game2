# 角色设计十二维评估框架

本框架提供12个相互关联的设计维度，用于全面评估和规划游戏角色设计。每个维度需独立分析后再进行整体协调性检查。

## 维度1：背景基础评估
- 检查项目：艺术背景（视觉设计渊源）+ 故事背景（叙事起源）
- 关键问题：角色是否有预设的视觉风格来源？是否有既定的世界观设定？

## 维度2：艺术风格定位
- 风格选项：卡通风格 / 漫画超级英雄风格 / 真人写实风格 / 野蛮人风格
- 夸张化处理决策：可爱化处理 / 刚毅化处理 / 其他类型化处理
- 执行要点：风格选择必须与目标玩家群体的审美偏好匹配

## 维度3：模型复杂度与功能性
- 模型类型判断：一眼可辨别的老版简化模型 vs. 精细化高细节模型
- 若选择精细化模型：必须明确说明"外貌如何在游戏中体现其作用"——即视觉细节与游戏机制的关联性

## 维度4：外观-行为一致性
- 核心检验：玩家能否仅凭外观预测角色行为方式
- 双重检查：
  - 是否存在剧情背景支撑外观-行为关联？
  - 是否存在游戏可玩性机制支撑外观-行为关联？
- 风险点：若外观与行为脱节，会导致玩家认知失调

## 维度5：化身-协助者系统设计（如适用）
- 存在性判断：是否提供玩家化身？化身是否有协助者？
- 协助者功能类型：信息提供 / 建议指导 / 体能援助
- 互补性设计：协助者如何与化身在能力、性格、视觉上形成互补
- 视觉区分要求：玩家必须能迅速从视觉上区分化身与协助者

## 维度6：个性特征呈现方式选择
- 呈现渠道选项：
  - 直接描述（旁白、界面文本）
  - 对话内容（角色台词设计）
  - 游戏可玩性（玩家操作体现性格）
  - 背景故事（叙事揭示）
  - 其他创新方式
- 决策原则：基于剧情背景角色的重要性选择主渠道

## 维度7：兴趣吸引力设计
- 目标：设计能激发玩家探索欲和持续关注的化身特征
- 考量因素：神秘感、能力憧憬、成长潜力、独特视觉标识

## 维度8：情感亲和力设计
- 目标：设计能让玩家产生喜爱和情感依附的化身特征
- 考量因素：共鸣点设计、缺陷美、陪伴感、价值观认同

## 维度9：角色成长轨迹规划
- 成长维度选择（可多选）：
  - 身体方面：外观变化、能力提升可视化
  - 情感方面：关系发展、情绪成熟度
  - 智力方面：知识积累、决策复杂度
  - 无变化：静态角色设计（需有充分理由）
- 关键决策：整个游戏时间轴上的变化节奏设计

## 维度10：原型 archetype 分析
- 坎贝尔神话原型检验：角色是否符合英雄之旅中的经典原型（英雄、导师、门槛守护者、盟友、变形者等）
- 复合角色分析：若原型成分少，则需识别：
  - 融合了哪些人物的特征？
  - 各来源特征的占比和交互方式？
- 设计意图：明确原型使用是为了唤起集体无意识共鸣还是刻意打破预期

## 维度11：声音与音乐设计
- 声音类型选择：配音风格、音效特征、语音处理方式
- 背景音乐匹配：风格、情绪、节奏与角色特征的对应关系
- 听觉识别目标：玩家仅凭声音即可识别角色身份
- 执行标准：建立"声音签名"（Sonic Signature）

## 维度12：语言特征设计
- 设计要素：
  - 语法特征（句式复杂度、语序习惯）
  - 词汇选择（专业术语、俚语、时代用语）
  - 语气特征（正式/随意、热情/冷漠、自信/犹豫）
  - 说话方式（口头禅、语速、停顿习惯）
- 功能目标：玩家通过语言特征即可推断角色背景、性格、情绪状态

## 整体性检验
完成12维度分析后，必须进行跨维度一致性检查——确保各维度的设计决策相互支撑而非矛盾。
