# 角色设计综合工作流程

## 适用场景
- 游戏包含主要角色且处于早期设计阶段
- 需要创建角色设计文档供美术和动画团队执行
- 需要对角色设计进行系统性评估和审查
- 非第一人称视角游戏（角色可见性高，设计重要性显著提升）

## 前置条件
- 已确定主游戏可玩性模式
- 已确定交互模型视角
- 已确定游戏类型和目标受众

## 工作流程

### 第一阶段：早期角色设计

**1. 设计目标设定**
- 核心目标：让玩家喜欢并关注这个角色，关心她会遇到什么
- 特殊重要性：非第一人称视角下，玩家将持续观察角色，因此角色必须有趣且值得观看

**2. 设计维度（必须同时考虑）**

**外貌设计**
- 脸部设计
- 身体设计
- 整体视觉吸引力

**行为设计**
- 可采取的行动：角色能够执行什么动作
- 情感表达能力：通过脸和身体语言可以表达哪些情感
- 语言特征：使用的语言和词汇风格

**3. 视角关联性判断**
- IF (视角 = 第一人称) THEN 外貌重要性相对较低
- IF (视角 = 第三人称或其他非第一人称) THEN 外貌和行为设计都至关重要

### 第二阶段：角色设计文档编写

**核心内容模块**

1. **角色外表展示**
   - 形式：概念艺术图
   - 目的：展示角色的外观视觉特征

2. **移动集合（最关键内容）**
   - 定义：记录角色怎样移动的动画列表
   - 分类：
     * 自发的移动（主动、有意识的动作）
     * 无意识的移动（被动、下意识的动作，如呼吸、待机小动作）
   - 重要性：这是角色设计文档"最重要"的内容

3. **概念艺术（多角度展示）**
   - 不同姿势下的角色形象
   - 不同面部表情下的角色形象

4. **背景信息**
   - 角色历史/背景故事
   - 价值观
   - 喜好
   - 优点和缺点

### 第三阶段：十二维评估框架

应用十二维评估框架对角色设计进行系统性审查，确保各维度相互支撑而非矛盾。详见 `references/character-12-dimensions.md`

## 输出成果
- 完成主要角色的早期设计方案
- 完整的角色设计文档，包含视觉参考、动画规范列表和角色背景设定
- 十二维评估报告，确保设计决策的一致性和完整性

## 注意事项
- 必须在早期设计阶段完成，而非后期
- 不适用于无主要角色的游戏
- 移动集合是角色设计文档中最关键的内容
- 完成十二维度分析后，必须进行跨维度一致性检查
