# 游戏设计学习准备度评估

验证用户是否具备学习游戏设计所需的背景知识和能力，确保能够有效利用游戏设计教材或课程资源。

## 何时使用

- 用户询问"我适合学习游戏设计吗"或"我需要什么基础才能学游戏设计"
- 用户准备开始阅读游戏设计书籍或参加相关课程
- 用户希望评估自身是否具备完成游戏设计项目的先决条件
- 用户需要了解游戏设计学习路径的入门要求

## 执行步骤

### 1. 确认目标受众匹配度

判断用户属于以下哪类人群：
- **主要受众**：对电子游戏设计感兴趣但不知如何上手的初学者、大学生、初涉游戏行业的从业人士
- **次要受众**：经验丰富的专业人士（可将教材作为参考手册使用）

若用户完全不了解电子游戏（从不玩游戏），则**不适合**继续。

### 2. 验证核心先决条件

逐一检查以下三项基础能力：

**A. 游戏知识基础**
- 必须了解一些电子游戏知识，特别是著名游戏案例
- 必须熟悉基本的电子游戏类型和常见游戏硬件
- *验证方式*：询问用户是否能列举3-5个知名游戏并描述其基本机制

**B. 数学基础**
- 必须熟悉基本的高中代数运算
- 必须理解基础概率论概念
- *重要性*：在学习"核心机制"和"游戏平衡性"等章节时至关重要
- *验证方式*：确认用户能理解简单的数学公式和概率计算（如骰子概率、百分比计算）

**C. 写作能力**
- 必须能够简明扼要地将设计想法书面表达出来
- *原因*：这是游戏设计师的核心技能，书中许多练习题为写作类
- *验证方式*：要求用户尝试用2-3句话描述一个游戏创意

### 3. 理解教学假设与方法论

向用户说明学习框架的核心假设：
- **独立设计师模式**：本教材假设读者正在独立设计一个完整的游戏
- **原因一（技能全面性）**：为成为熟练设计师，需熟悉设计的所有方面，因此教材覆盖完成所有工作的主题
- **原因二（教学简化）**：团队组织和管理依赖于团队文化和个人技能，通用教材无法教授；从教学材料观点看，假设一个人完成所有工作是最简单的方法

### 4. 制定学习行动计划

若用户满足上述条件：
1. **角色定位**：以独立游戏设计师的身份进行学习，而非仅作为理论学习者
2. **实践要求**：必须完成章节末尾的习题，特别是写作类练习
3. **项目导向**：将学习过程与实际游戏项目结合，边学边做
4. **自我检测**：定期回顾先决条件中的薄弱环节，必要时补充学习（如概率论基础）

## 输出结果

- **准备就绪**：用户具备所有先决条件，可立即开始以独立设计师身份学习
- **条件不足**：明确指出缺失的具体条件（游戏知识/数学/写作），并提供补充学习建议
- **角色建议**：建议用户以独立设计师视角阅读，完成所有写作练习以检验理解程度
