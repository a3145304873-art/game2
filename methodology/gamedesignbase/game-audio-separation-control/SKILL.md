# 游戏音频文件分离与控制规范

## 何时使用此技能

- 设计游戏音频系统架构和技术实现方案
- 准备游戏多语言本地化，需要替换人物对话时
- 实现无障碍功能，支持听力受损玩家独立控制音频层级
- 开发移动端游戏，需要提供公共场合静音解决方案
- 制定音频资源准备阶段的技术规范

## 核心原则

**禁止预混合**：开发阶段不得将不同类型的音频预先混合。背景音乐(BGM)、声音效果(SFX)、人物对话必须在独立文件中保存，仅在游戏运行时动态混合播放。

## 实施步骤

### 步骤1：建立音频分离架构

配置三类独立的音频通道：

1. **背景音乐通道 (BGM)**
   - 使用独立音频文件存储
   - 配置 `BGM_Volume` 参数（Float类型，范围建议0.0-1.0）
   - 支持循环播放和动态切换

2. **音效通道 (SFX)**
   - 所有环境音、动作音、UI音效独立存储
   - 配置 `SFX_Volume` 参数（Float类型）
   - 支持多实例同时播放

3. **对话/叙述通道 (Dialogue)**
   - 人物语音、旁白独立存储
   - 配置 `Dialogue_Volume` 参数（Float类型）
   - 与BGM分离，避免混音

### 步骤2：配置本地化支持

为降低本地化成本，实施以下流程：

- **资源替换流程**：对话音频单独存放于 `/Audio/Dialogue/{LanguageCode}/` 目录
- **动态加载**：游戏运行时根据语言设置加载对应对话文件，无需重新混音
- **版本控制**：不同语言对话文件使用相同命名规范，仅通过路径区分
- **避免重新混音**：确保对话轨道与BGM在引擎层面混合，而非在DAW中预混

### 步骤3：实现无障碍音量控制

支持听力受损玩家（如耳鸣患者）：

- **独立控制界面**：在设置菜单提供三个独立滑块分别控制BGM、SFX、对话音量
- **预设配置**：提供"听力辅助"预设，自动降低BGM音量（建议降至30%以下），保持SFX和对话清晰
- **完全静音选项**：允许单独关闭BGM，保留其他音效和对话
- **视觉反馈**：音量调节时提供视觉指示器，确保玩家知晓当前音频状态

### 步骤4：移动端静音适配

针对公共场合游玩场景：

- **全局静音按钮**：在游戏主界面和暂停菜单提供一键静音按钮
- **系统监听**：响应设备静音开关和音量键
- **恢复机制**：记录静音前各通道音量设置，取消静音后自动恢复
- **后台处理**：应用进入后台时自动暂停音频，返回前台时恢复（除非处于静音状态）

## 技术参数规范

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `BGM_Volume` | Float | 0.8 | 背景音乐主音量，范围0.0-1.0 |
| `SFX_Volume` | Float | 1.0 | 音效主音量，范围0.0-1.0 |
| `Dialogue_Volume` | Float | 1.0 | 对话主音量，范围0.0-1.0 |
| `Master_Mute` | Boolean | false | 全局静音开关 |

## 验证检查清单

- [ ] BGM、SFX、对话分别存储为独立音频文件，无预混音
- [ ] 运行时音频引擎支持三通道独立音量控制
- [ ] 本地化流程验证：替换对话文件无需重新导出BGM
- [ ] 无障碍测试：可独立关闭BGM且不影响SFX和对话清晰度
- [ ] 移动端测试：静音按钮可立即切断所有音频输出
- [ ] 音量设置持久化：玩家偏好保存在本地配置文件中
