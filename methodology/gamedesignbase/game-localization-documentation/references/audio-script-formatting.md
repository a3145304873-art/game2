# 音频对话脚本排版规范

## 字体与字号

| 元素 | 规格 | 说明 |
|-----|------|------|
| 角色名 | 14-16pt 粗体 | 左对齐或独立行 |
| 对话内容 | 12-14pt 常规 | 每句独立成行 |
| 提示信息 | 10pt 斜体 | 括号标注，灰色显示 |

## 行距设置

- 最小行距：1.5倍
- 推荐行距：2倍
- 角色之间：空一行分隔

## 页面布局

```
[角色名]                    ← 14pt 粗体

对话内容第一行              ← 12pt，2倍行距
对话内容第二行

（情绪提示：愤怒）          ← 10pt 斜体

[下一个角色]
...
```

## 打印建议

- 使用浅色纸张（米白/浅黄）减少反光
- 单面打印，避免背面透影
- 预留装订边距（左侧2.5cm）
- 页码置于右下角
