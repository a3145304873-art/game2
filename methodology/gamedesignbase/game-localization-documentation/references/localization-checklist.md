# 本地化文档交付核查清单

- [ ] 包含所有UI文本（主菜单、设置、暂停界面）
- [ ] 包含所有游戏内文本（HUD、提示、通知）
- [ ] 包含所有剧情文本（对话、旁白、过场）

- [ ] 所有配音行已编号

- [ ] 源文件（Word/Google Docs）
