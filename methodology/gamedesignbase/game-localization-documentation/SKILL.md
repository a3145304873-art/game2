# 游戏本地化文档编制

为需要外语本地化的游戏创建完整的屏幕文本和音频对话文档，供当地承包商进行翻译和配音。

## 何时使用

- 游戏需要支持多语言本地化
- 游戏包含音频对话录音
- 开发过程中需要维护本地化素材
- 准备将内容交付给海外翻译/配音团队

## 前置条件

- 所有屏幕文本内容已确定（UI文本、对话、旁白）
- 音频对话脚本内容已编写
- 游戏达到Alpha测试版本

## 执行步骤

### 1. 确定文档组织方式

根据游戏规模选择文档结构：

| 游戏规模 | 组织方式 |
|---------|---------|
| 小型游戏 | 屏幕文本 + 音频脚本合并为单一文档 |
| 大型游戏 | 拆分为两个独立文档便于管理 |

### 2. 编制屏幕文本文档

记录所有显示在屏幕上的文字内容：

- **UI文本**：菜单、按钮、提示信息、系统消息
- **角色文字**：书面对话、信件、日记、公告
- **旁白内容**：剧情叙述、场景描述

**维护要求**：
- 整个开发过程中持续更新
- 确保与Alpha版本内容同步
- 作为翻译的唯一权威来源

### 3. 编制音频对话脚本

编写所有配音人员需要录制的对话行：

**格式规范（关键）**：
- 使用**大号字符**输出
- 设置**宽行距**（建议1.5-2倍行距）
- 每行台词独立成行，避免换行

> **原因**：录音棚环境较暗，宽间距和大字体便于配音人员快速定位下一句，减少录制中断。

**内容要求**：
- 标注角色名称
- 包含情绪/语气提示
- 注明特殊发音要求

### 4. 交付准备

向当地承包商提供：
- 完整的屏幕文本记录（最新版本）
- 格式化的音频对话脚本
- 术语表和风格指南（如有）

## 注意事项

- 仅在确认需要外语本地化时启动此流程
- 音频脚本的特殊格式直接影响录音效率
- 文档滞后会导致翻译版本与游戏内容不一致
