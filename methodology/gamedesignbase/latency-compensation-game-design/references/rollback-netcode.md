# 回滚式网络同步（Rollback Netcode）

## 核心原理

当检测到输入冲突或延迟到达时：
1. 回滚到过去的状态
2. 应用正确的输入序列
3. 快速重放到当前时间
4. 玩家通常无感知

## 关键实现要素

### 状态保存
- 定期保存完整游戏状态（每1-6帧）
- 或保存确定性输入序列用于重建

### 回滚触发条件
```
if (remoteInput.arrivalTime > predictedExecutionTime):
    rollbackToFrame(remoteInput.originalFrame)
    reapplyAllInputs()
```

### 视觉平滑
回滚导致的画面跳变需要处理：
- 位置插值渐变（非瞬移）
- 特效/音效的延迟触发或取消

## 适用游戏类型

| 适合 | 不适合 |
|-----|-------|
| 格斗游戏（GGPO标准应用） | 开放世界游戏 |
| 2D平台对战 | 大规模MMO |
| 确定性物理游戏 | 复杂AI决策游戏 |

## 著名实现案例

- **GGPO**：开源格斗游戏回滚库
- **Mortal Kombat 11**：自定义回滚实现
- **Street Fighter V**：基于回滚的延迟补偿

## 性能考量

- 内存：每状态保存大小 × 保存数量
- CPU：回滚重放的开销
- 建议：状态保存间隔与回滚最大距离的权衡
