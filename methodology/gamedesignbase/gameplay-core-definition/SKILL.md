# 游戏可玩性核心定义

## 核心公式

游戏可玩性 = 挑战 + 动作

## 何时使用
- 游戏设计初期定义核心玩法机制
- 评估游戏可玩性是否完整
- 设计或审查游戏目标
- 分析游戏为何缺乏可玩性

## 执行步骤

### 1. 定义挑战（Challenge）

挑战是玩家为达到游戏目标所必须面对的障碍或困难。

**关键特征：**
- 必须是达成目标所必需的
- 构成游戏的核心阻力
- 可以从简单到复杂（如捡球到做生意）

**挑战类型：**
- 独一无二的挑战（如BOSS战）
- 重复出现的挑战（如杀死相同敌人）
- 连续性的挑战（如持续躲避攻击）

### 2. 定义动作（Action）

动作是允许玩家采用以应对挑战的行为。

**动作分类：**
- **强制性动作**：规则要求必须使用以克服挑战的动作
- **禁止性规则**：在特定情况下禁止的动作
- **可选性动作**：不直接用于克服挑战，但能增加乐趣的动作（如GTA中在车里听广播）

### 3. 确保挑战与动作关联

**设计原则：**
- 挑战和动作必须同时设计，缺一不可
- 仅有有趣的挑战而无克服动作 → 不足够
- 仅有令人兴奋的动作而无对应挑战 → 不足够
- 游戏可玩性的精髓在于"挑战和动作的关联"

### 4. 设计游戏目标

**核心要求：**
- 目标达成必须需要"非同一般的努力"（身体或精神）
- 目标不能在片刻之间便可达到
- 玩家必须具有娴熟的技术才能做好

**难度匹配：**
- 考虑目标受众的技能水平差异
- 确保挑战处于"娴熟的技术"可应对但非轻而易举的区间

**特殊情况：**
- 创造类游戏（如《模拟城市》）：创造设计理念本身对玩家就是一项挑战

### 5. 验证设计

**检查清单：**
- [ ] 每个挑战都有对应的克服动作
- [ ] 每个动作都有对应的挑战
- [ ] 目标需要身体或精神付出
- [ ] 目标难度匹配玩家技能水平
- [ ] 可选动作增加了乐趣但不破坏平衡

## 重要说明

**关于幻想和想象：**
- 幻想和想象是游戏体验的重要组成部分
- 但在此定义中，玩家幻想应独立于游戏可玩性进行定义
- 原因：避免定义过于复杂；挑战可能隐含角色幻想，但无需将其列为基本要素

**电子游戏与传统游戏的动作差异：**
- 传统游戏：允许所有未被禁止的动作
- 电子游戏：仅提供软件中已构建的固定动作集合，玩家应对方式受限
