# 挑战类型详细说明

## 挑战层级结构

可以使用更小的挑战来定义某个挑战。

**示例：** 总挑战是走完有障碍的路程，由以下小挑战组成：
- 翻越栅栏
- 爬出屏障
- 过隘口

**规则：** 除非游戏极为简单（如井字三连棋），否则玩家必须面对道路上的所有挑战。

## 挑战角色

### 主要角色
对玩家完成任务的直接阻碍。

### 可选角色
加入可选性挑战以帮助玩家练习，或提供更多可做的东西（如体育运动游戏中阻碍对手得分）。

## 挑战与规则的关系

游戏中的挑战由规则建立，但规则不能总是精确规定挑战。

### 隐含挑战
玩家可能需要通过逻辑思考或试玩后才能发现真正的挑战。

**示例：奥赛罗/黑白棋**
- 规则仅说明翻转棋子和目标是己方颜色最多
- 实际主要挑战是控制棋盘角落（因为角落极有价值，不会被翻转）

## 挑战难度标准

挑战必须非常重要，而不一定非常困难。
- 儿童和没有经验的玩家更喜欢挑战难度低的游戏
- 难度应根据目标受众调整
