# 叙事紧张设计

## 使用场景
- 设计师将戏剧性紧张与游戏可玩性紧张视为同一概念
- 设计师认为二者可简单互换
- 需要在游戏中创造戏剧性紧张
- 分析游戏中的紧张感来源

## 两种紧张类型的核心定义差异

### 戏剧性紧张（Dramatic Tension）
- 依赖于【读者对角色的认同】+【对角色命运的好奇心】
- 必须建立在故事上下文中且结果关系到特定角色

### 游戏可玩性紧张（Gameplay Tension）
- 【不要求任何角色存在】
- 源于玩家对自身能否完成某个挑战的不确定性
- 例如：飞镖玩家猜想能否击中靶心

## 关键区分测试——角色必要性检验

```
问：此紧张感是否必须依附于某个角色的命运才能存在？

是 → 戏剧性紧张
否 → 游戏可玩性紧张
```

## 随机性与重复性耐受度对比

### 戏剧性紧张
- **面对随机性和重复性时会消褪**
- 原因：读者对角色的认同需要有意义的叙事发展
- 效果：随机事件和重复模式会破坏叙事连贯性和角色发展的可信度

### 游戏可玩性紧张
- **可以很容易更长时间地忍受随机性和重复性**
- 典型案例：
  * 扑克牌（强随机性）
  * 《俄罗斯方块》（大量重复）
- 效果：这些游戏仍保持高游戏可玩性紧张

## 常见错误识别——《红矮星号》对话案例分析

### 瑞默的错误
将《Risk》游戏中的游戏可玩性紧张（"我会征服伊尔库茨克吗？"）误认为戏剧性紧张

### 利斯特的洞察
"真正有意思的地方和无聊的地方一模一样"——说明缺乏角色认同的纯机制事件对旁观者无戏剧性价值

### 瑞默的辩护
"它对我来说非常有趣"——强调游戏可玩性紧张是【第一人称体验】，对参与者有效但不对观察者产生戏剧性效果

## 设计启示

### 核心原则
1. 不要假设游戏机制自动产生戏剧性紧张
2. 游戏可玩性紧张可以独立存在
3. 戏剧性紧张需要额外的叙事建构工作

### 创造戏剧性紧张的方法
若要在游戏中创造戏剧性紧张，必须建立：
1. 【玩家对游戏内角色的认同】
2. 【角色命运的不确定性】

### 设计决策流程
```
IF (需要创造紧张感)
THEN 判断紧张类型：
  IF (为核心机制驱动)
  THEN → 游戏可玩性紧张
  ELSE IF (为角色命运驱动)
  THEN → 戏剧性紧张
  ELSE IF (混淆二者)
  THEN → 需重新设计叙事层或机制层
```

## 执行流程

### 分析现有设计中的紧张类型
1. 识别紧张感的来源
2. 应用角色必要性检验
3. 确定紧张类型

### 设计新的紧张体验
1. 明确目标紧张类型
2. 若为游戏可玩性紧张：设计挑战和不确定性
3. 若为戏剧性紧张：建立角色认同和命运悬念
4. 避免混淆两种紧张类型
