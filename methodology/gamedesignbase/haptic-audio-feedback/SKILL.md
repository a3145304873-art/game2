# 触觉与音频反馈系统

## 何时使用

- 实现控制器震动反馈（力反馈）
- 设计3D空间音频定位系统
- 需要增强游戏沉浸感和紧张氛围
- 开发生存类、恐怖类或动作类游戏

## 控制器震动反馈设计

### 控制参数
- **震动强度**：0.0-1.0或硬件支持的具体范围
- **持续时间**：建议0.1-2.0秒之间

### 时机与场景选择
- 在适当的时机和地点插入到关联的游戏世界中
- 出其不意的力反馈效果可制造紧张感

### 适用游戏类型
特别适合：
- 生存类游戏
- 恐怖类游戏
- 隐形类游戏

### 频率控制（关键限制）
- **不要经常使用**：玩家会学着适应并忽略它，失去效果
- **过度使用后果**：玩家的手会开始不自觉地颤抖，导致身体不适

### 最佳使用场景
- **大事件触发**：爆炸、恶性事件（如赛车刮蹭墙壁）
- **避免**：微小或频繁的事件上使用

### 技术定义注意
虽然力反馈在技术上不是音频元素，但玩家通常可以听到并感觉到它，应视为多感官体验的一部分

## 3D空间音频（场音频）系统

### 系统定义
通过不同扬声器的声音音量差异，在三维空间中定位声源位置的系统

### 硬件配置
- **高端配置**：最多支持7个扬声器（7.1环绕声）
- **基础配置**：最基本的两扬声器立体声也可帮助定位声源
- **约束**：必须确认目标平台支持多声道输出

### 实施步骤
1. 为游戏世界中的所有相关声源分配3D坐标
2. 根据玩家相对于声源的位置和朝向计算各扬声器的音量分布
3. 实时调整不同扬声器的音量以模拟声源位置（距离衰减和方位角计算）
4. 确保音频引擎支持HRTF或类似空间化算法

### 游戏设计收益
- 在3D空间中正确定位声源帮助玩家确定方向
- 帮助玩家找到搜寻目标（小河、动物、队友）
- 增强沉浸感和空间感知能力

### 适用范围
特别推荐用于第一人称或第三人称游戏

## 变量参考

| 变量 | 类型 | 说明 |
|------|------|------|
| 震动强度 | float | 0.0-1.0 |
| 持续时间 | float | 秒数 |
| 事件类型 | enum | 爆炸/碰撞/惊吓/坠落等 |
| 扬声器数量 | int | 2-7个或更多 |
| 声源3D坐标 | vector3 | 声音来源位置 |
| 玩家位置与朝向 | transform | 听者当前状态 |
| 音量分布矩阵 | array | 各声道音量权重 |
