# 女性玩家暴力元素接受度评估

## 何时使用

- 设计目标受众包含女性玩家的游戏时
- 审查或修改现有暴力场景内容时
- 需要判断特定暴力表现是否过度时
- 区分"有意义的暴力"与"无意义的暴行"时

## 核心原则

> **关键认知纠正**：女性玩家并非排斥所有暴力，而是排斥特定类型的暴力表现（暴行/Atrocity）。

## 评估流程

### 第一步：识别拒绝类型（立即否决）

检查是否存在以下暴行特征，任一满足即判定为**不可接受**：

| 拒绝类型 | 具体表现 | 设计检查点 |
|---------|---------|-----------|
| 永无休止的暴力 | 无终点、无意义的持续战斗 | 战斗是否有阶段性目标？ |
| 重复性暴力 | 缺乏变化，机械重复同一动作 | 暴力表现是否有变化？ |
| 无含义视觉爆炸 | 为特效而特效，脱离叙事/玩法 | 爆炸/特效是否服务于机制或剧情？ |
| 极度血腥残忍 | 偶然的、残虐的、极度血腥的暴力 | 血腥程度是否超出必要？ |

> **Elling 判定标准**：当暴力越来越**偶然、残虐、极度血腥**时，暴力就变成了**暴行（Atrocity）**。

### 第二步：确认可接受类型

满足以下任一类别，且通过第一步检查，则判定为**可接受**：

- **防守性质的暴力**：保护自身或他人的反击行为
- **挑衅性质的暴力**：有明确动机和目标的主动对抗
- **卡通化的暴力**：风格化处理，降低真实感和血腥度

### 第三步：意义性验证

通过以下问题验证暴力的必要性：

1. 暴力是否服务于**叙事推进**？
2. 暴力是否支撑**核心玩法机制**？
3. 移除该暴力后，游戏**体验是否受损**？

## 快速判定表

```
IF (无意义重复 OR 极度血腥残忍) 
   → 拒绝（暴行）
   
IF (防守/挑衅/卡通化 AND 有意义) 
   → 接受（可接受的暴力）
```

## 设计检查清单

在提交暴力场景设计前，确认：

- [ ] 暴力不是永无休止、毫无意义的
- [ ] 暴力表现有变化，避免机械重复
- [ ] 视觉特效（爆炸等）有实际叙事或机制含义
- [ ] 血腥程度控制在必要范围内，避免升级为"暴行"
- [ ] 暴力具有防守、挑衅或卡通化的正当性基础
- [ ] 暴力服务于核心玩法或叙事目标

## 注意事项

- **文化背景差异**：不同地区对血腥、暴力的容忍度存在显著差异，需本地化评估
- **个体差异**：本规则不适用于极端暴力厌恶者（需额外用户分层）
- **想象力刺激**：无意义的暴力无法刺激想象力，导致厌烦但不会立即放弃游戏——这是隐性流失风险
