# 关卡布局设计

## 布局类型选择矩阵

| 布局类型 | 核心特征 | 适用游戏类型 | 叙事能力 | 探索自由度 |
|---------|---------|------------|---------|----------|
| 线性 | 固定顺序，无分支 | 轨道射击、叙事驱动 | 强 | 低 |
| 网络 | 多路径连接 | 探索RPG、文本冒险 | 弱 | 高 |
| 开放式 | 几乎无限制移动 | 战争游戏、户外RPG | 中 | 极高 |
| 环形 | 路径返回起点 | 竞赛游戏 | 无 | 中 |
| 组合 | 外层线性+内层网络 | 大型RPG、冒险游戏 | 中 | 中高 |
| 不合逻辑空间 | 打破常规空间连接 | 特殊叙事/谜题 | 需解释 | 低 |

## 布局设计流程

### 步骤1：确定核心体验目标

- **严格控制叙事顺序** → 线性布局
- **最大化探索自由度** → 网络或开放式布局
- **多次通过相同空间** → 环形布局
- **兼顾叙事与探索** → 组合布局

### 步骤2：实施具体布局

#### 线性布局

1. 玩家按固定顺序体验空间
2. 使用单向门阻止回溯（确保收集完整）
3. **关键约束**：若区域包含必需物品，不得将玩家锁在区域外

#### 网络布局

1. 空间通过多种方式连接
2. 现代图形游戏需呈现建筑逻辑性
3. 叙事必须容忍非线性体验
4. **全连接网络**：每个空间连接所有其他空间，适合死亡配对竞赛

#### 开放式布局

1. 玩家享有几乎完全不受限制的移动
2. 可包含特定受限小区域（需特殊路径进入）
3. 室内/地下场景可切换为网络或组合布局

#### 环形布局

1. 确保路径返回出发点形成闭环
2. 形状灵活（椭圆、扭曲均可）
3. **关键设计**：捷径需更困难但耗时更少

#### 组合布局

1. 外层：线性布局承载核心叙事（故事总线）
2. 内层：网络布局提供子情节/探索空间
3. 可选：线性奖励关卡嵌入网络区域

#### 不合逻辑空间（谨慎使用）

1. 区域间无合理空间联系
2. **必须提供解释**（如"时空裂缝"）
3. 3D引擎实现困难，建议保守使用

### 步骤3：验证设计约束

- [ ] 布局与游戏类型匹配
- [ ] 叙事需求与布局能力一致
- [ ] 空间连接符合建筑逻辑（不合逻辑空间除外）
- [ ] 竞赛游戏捷径难度平衡

## 布局切换策略

| 场景 | 切换策略 |
|------|---------|
| RPG户外→室内 | 开放式 → 网络/组合 |
| 冒险游戏章节 | 组合布局（主线+支线） |
| 竞赛游戏多圈 | 环形布局固定 |
| 特殊叙事需要 | 临时使用不合逻辑空间（需解释） |
