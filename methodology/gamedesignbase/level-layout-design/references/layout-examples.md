# 布局设计实例参考

## 经典游戏布局分析

### 《半条命2》- 线性+组合

- 整体：线性叙事推进
- 局部：战斗区域提供有限探索空间
- 技术：Hammer地图编辑器支持

### 《星际争霸》战役 - 组合布局

- 外层：线性任务解锁顺序
- 内层：任务内多目标、可选支线
- 工具：战役编辑器支持自定义

### 《我的世界》- 开放式

- 核心：完全自由的3D空间
- 变体：下界/末地切换空间规则
- 建造：玩家自创关卡编辑器功能

### 《雷神之锤》死亡配对 - 全连接网络

- 结构：少量主要空间全连接
- 效果：最大移动自由，最小探索挑战
- 战术：防止单点无限防守

## 环形布局捷径平衡公式

```
捷径价值 = (常规路径时间 - 捷径时间) / 捷径难度系数

设计目标：捷径价值 ≈ 1.2-1.5（有吸引力但非必选）
```

| 常规路径时间 | 捷径时间 | 捷径难度 | 价值系数 | 设计评价 |
|------------|---------|---------|---------|---------|
| 10s | 6s | 低(1.0) | 4.0 | 过高，必选 |
| 10s | 6s | 中(1.5) | 2.7 | 合理 |
| 10s | 6s | 高(2.0) | 2.0 | 合理 |
| 10s | 8s | 高(2.0) | 1.0 | 过低，无吸引力 |
