# 游戏魔法圈概念及其边界机制

## 何时使用

- 分析游戏沉浸感和玩家心理契约
- 设计多人游戏的共同假想建立机制
- 评估虚拟交易对游戏边界的影响
- 处理现实利益与游戏规则的冲突

## 核心概念

魔法圈 = 现实世界与假想世界的分界线

### 功能
- 区分游戏内意义与现实意义
- 允许假想现实中不可能的事物
- 建立临时的人造场景规则

### 建立与生效
| 场景 | 机制 |
|------|------|
| 单机游戏 | 玩家简单选择进入 |
| 多人游戏 | 玩家交流协商，共同接受规则 |
| 生效条件 | 玩家遵循规则扮演角色 |
| 消失条件 | 放弃游戏或游戏结束 |

## 边界模糊性判定

**关键测试**：真实世界是否因游戏内事件受到影响？

| 边界清晰 | 边界模糊 |
|---------|---------|
| 纯娱乐游戏 | 赌博（涉及真钱输赢） |
| 无内购游戏 | 游戏内购（真金白银购买优势） |

### 设计启示
- 涉及现实利益时，魔法圈界限自动模糊
- 玩家对"假想的接受度"降低
- 需要额外的公平性和透明度设计

## 术语选择

- "假想世界"：通俗易懂
- "魔法圈"：专业接受度高，源自Johan Huizinga《Homo Ludens》
