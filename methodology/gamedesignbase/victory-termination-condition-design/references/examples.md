# 胜利条件与终止条件示例详解

## 双人对抗示例

### 国际象棋
- **胜利条件**：将对方主将死（checkmate）
- **终止条件**：一方被将死时立即终止
- **关系**：重合（一方获胜即结束）

### 限时运动（篮球/足球）
- **胜利条件**：时间结束时得分高的球队
- **终止条件**：计时器归零
- **关系**：重合（时间结束同时触发胜利判定和游戏终止）
- **附加机制**：如平局可进入加时赛（tie-breaker）

## 多人竞技示例

### 跑步比赛
- **胜利条件**：第一个通过终点线的选手
- **终止条件**：最后一名选手通过终点线（或特定比例选手完成）
- **关系**：分离（第一名产生后比赛继续）
- **说明**：当第一个选手冲线时，比赛并未结束，持续至最后一名完成

### 大逃杀类游戏（如PUBG）
- **胜利条件**：最后存活的玩家/队伍
- **终止条件**：仅剩一个存活单位时
- **关系**：重合（虽然多人参与，但淘汰制使得最后一人产生时自然终止）

### 赛车游戏（完整排名模式）
- **胜利条件**：第一个完成规定圈数并冲过终点线的车手
- **终止条件**：最后一名完成比赛或时间限制到达
- **关系**：分离（冠军产生后，其他车手继续完成比赛以确定第2、3名等）

## 变量定义参考

| 变量名 | 类型 | 说明 |
|--------|------|------|
| player_count | integer | 玩家数量，决定终止条件与胜利条件是否重合的关键变量 |
| victory_condition | string | 胜利条件定义（如将死、高分、收集完成、存活到最后） |
| termination_trigger | string | 游戏结束触发器（如第一名产生、最后一名完成、时间耗尽） |
| ranking_mode | boolean | 是否需要完整排名（true=持续至所有名次确定，false=第一名产生即结束） |
