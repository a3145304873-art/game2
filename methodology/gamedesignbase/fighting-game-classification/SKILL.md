# 格斗游戏分类与识别

## 何时使用
- 游戏专注于近身打斗
- 需要判断游戏是否属于格斗游戏类型
- 区分格斗游戏与体育类游戏（如拳击）
- 设计格斗游戏子类型

## 执行步骤

### 1. 检查排除项

游戏不应涉及以下元素（这是与其他动作游戏的主要区别）：
- 探索
- 射击
- 解谜

### 2. 检查核心技能要求

必须很大程度上要求玩家的物理技能，特别是：
- 反应时间
- 时机把握

### 3. 确认战斗模拟类型

通常模拟近身的打斗。

### 4. 确认动作风格

含糊地使用亚洲武术技巧做出非常夸张的动作。

### 5. 应用排除规则

**拳击游戏应归类为体育类游戏：**
- 原因：拳击游戏尽量真实地模拟了拳击的技术
- 动作风格：写实（格斗游戏通常夸张）

### 6. 识别游戏子类型

| 子类型 | 描述 |
|--------|------|
| 竞技场模式 | 玩家之间单对单的比赛 |
| 混战模式 | 一两个玩家合作去对付一大群的敌人 |

### 7. 确认武器使用规则

- 允许使用局部效果的武器（例如剑和盾牌）
- 允许使用有限数量的其他武器

## 判定流程

```
IF (游戏专注于近身打斗
    AND 不包含探索/射击/解谜
    AND 要求反应时间和时机技能
    AND 使用夸张的亚洲武术动作)
THEN 识别为格斗游戏

IF (是拳击游戏)
THEN 归类为体育类游戏
```

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| 核心玩法元素 | 列表 | 游戏包含的玩法类型（如探索、射击等） |
| 动作真实性 | 定性 | 动作是夸张的还是写实的（格斗游戏通常夸张，拳击游戏写实） |
