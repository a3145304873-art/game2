# 游戏平衡变量

## 参数值（parameter_value）

**类型：** numeric

**描述：** 游戏中可调整的数值属性

**示例：**
- 角色生命值
- 武器伤害
- 移动速度
- 资源产出率

## 调整幅度（adjustment_magnitude）

**类型：** enum

**选项：**
- 加倍（double）
- 减半（halve）
- 大步长调整（large step）

**使用建议：**
- 初始调整使用加倍或减半
- 接近目标值时使用小步长

## 测试结果（test_result）

**类型：** observation

**描述：** 每次参数修改后的游戏表现

**记录内容：**
- 玩家体验变化
- 游戏平衡性改善
- 新出现的问题
- 与预期结果的对比
