# 2D引擎视角限制规则

## 适用场景

- 使用2D图形引擎开发游戏项目
- 评估相机视角方案时
- 在2D显示限制下设计核心玩法
- 需要判断第一人称或第三人称视角是否可行

## 决策流程

### 步骤1：确认技术限制

识别2D图形引擎的核心限制：**无法提供真实的三维深度渲染能力**，因此无法支持需要三维空间信息的相机视角。

### 步骤2：排除禁止视角

如果确认使用2D引擎，**必须排除**以下视角：

- **第一人称视角(First-person)**：需要3D引擎模拟玩家眼睛在三维空间中的真实视野
- **第三人称视角(Third-person)**：需要3D引擎渲染玩家角色在三维空间中的位置、动作和周围环境

### 步骤3：选择兼容视角

改用以下2D兼容视角：

- **固定视角(Fixed camera)**：摄像机位置固定不动
- **侧视视角(Side view)**：横向卷轴视角
- **俯视视角(Top-down view)**：从上方俯视游戏世界
- **等距视角(Isometric)**：2.5D伪3D视角（2D引擎可实现）

## 关键约束

即使游戏世界在**逻辑上是全三维构建**的（3D world），只要**显示层使用2D引擎**，就不能使用第一人称和第三人称视角。

## 快速检查清单

- [ ] 确认图形引擎类型为2D
- [ ] 放弃第一人称视角方案
- [ ] 放弃第三人称视角方案
- [ ] 从2D兼容视角中选择替代方案
- [ ] 验证核心玩法在选定视角下可行
