# 多年龄段角色设计案例

## 儿童时期特征示例

### 身体比例
- 头身比：1:3 或 1:4
- 眼睛：超大，占据面部大部分空间
- 四肢：短小、圆润

### 行为特征
- 好奇心强
- 注意力短暂
- 情绪表达直接
- 学习能力强

### 表情示例
- 开心：大笑、眼睛眯成月牙
- 悲伤：大哭、眼泪明显
- 惊讶：嘴巴张大、眼睛瞪圆

## 青年时期特征示例

### 身体比例
- 头身比：1:6 或 1:7
- 眼睛：正常大小
- 四肢：开始发育、比例接近成人

### 行为特征
- 身份认同探索
- 情绪波动大
- 社交需求强
- 独立意识增强

### 表情示例
- 开心：微笑、眼神明亮
- 悲伤：皱眉、眼神黯淡
- 愤怒：咬牙、眼神锐利

## 成年时期特征示例

### 身体比例
- 头身比：1:7 或 1:8
- 眼睛：正常大小
- 四肢：完全发育、比例协调

### 行为特征
- 责任感强
- 情绪控制好
- 社会功能完善
- 目标明确

### 表情示例
- 开心：轻微微笑、眼神温和
- 悲伤：轻微皱眉、眼神深沉
- 思考：眼神专注、表情平静

## 触发事件示例

### 儿童时期触发事件
- 获得糖果 → 开心表情
- 摔倒受伤 → 哭泣表情
- 看到新玩具 → 惊讶表情

### 青年时期触发事件
- 考试通过 → 开心表情
- 被朋友误解 → 愤怒表情
- 遇到喜欢的人 → 害羞表情

### 成年时期触发事件
- 工作晋升 → 满足表情
- 面临重大决策 → 思考表情
- 失去亲人 → 悲伤表情
