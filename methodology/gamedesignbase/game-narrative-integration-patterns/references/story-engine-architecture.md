# 故事讲述引擎详细架构

## 组件关系图

```
┌─────────────┐
│  用户界面   │

       │
       ▼
┌─────────────┐     触发器     ┌──────────────┐
│  核心机制   │◄──────────────►│ 故事讲述引擎 │
└─────────────┘                 └──────────────┘
```

## 触发器机制

触发器是连接故事讲述引擎和核心机制的双向信号机制：
- **核心机制 → 故事引擎**：报告玩家事件、游戏状态变化
- **故事引擎 → 核心机制**：指示何时提供特定的游戏可玩性

## 事件类型详解

### 玩家事件
由玩家主动产生的行为，如：
- 移动化身
- 发起对话
- 使用物品
- 做出选择

### 故事内事件
由游戏内系统产生的事件，如：
- AI驱动的NPC动作
- 环境变化
- 时间流逝触发的事件

### 叙事事件
由故事讲述引擎管理的事件，如：
- 过场动画
- 对话
- 剧情分支切换

## 设计注意事项

- 故事讲述引擎不是简单的电影播放器
- 必须能够跟踪故事进度
- 必须能够动态决定下一步情节
- 必须与核心机制紧密协作
