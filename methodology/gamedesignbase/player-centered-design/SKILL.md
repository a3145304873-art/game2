# 以玩家为中心的游戏设计

## 使用场景
- 设计或评估游戏中的任何元素或特征
- 需要扩大游戏受众至女性群体
- 设计角色扮演系统
- 分析玩家在游戏中的行为特征

## 核心设计原则

### 最高目标
游戏设计的最高目标是"娱乐玩家"。设计者不应以牺牲其他特点为代价来寻求单一特点的最大化，而应整合所有特点以支持该目标。

### 五个关键领域
确保游戏设计涵盖以下领域：
1. **虚构体验**：必须呈现虚构的、连贯的体验
2. **商业潜力**：必须要有好的销量，考虑玩家喜好
3. **许可证利用**：如果是许可证游戏，必须懂得许可证带来的好处
4. **技术质量**：必须提供智力挑战和流畅的、无漏洞的体验
5. **美学风格**：必须能吸引人

## 特征筛选流程

### 测试问题
对每一项元素、每一个特征进行测试：
1. "这一项有助于娱乐玩家吗？"
2. "它能给予玩家娱乐了吗？"

### 决策规则
```
IF (测试问题答案为肯定)
THEN 保留这些元素或特征
ELSE IF (特征为游戏其他部分工作所必需 OR 由许可证颁发者要求)
THEN 保留但降低对玩家的影响
ELSE 删除
```

### 设计陷阱
避免像设计师 Brian Moriarty 所批评的那样，"将毫无理由的特征堆砌起来，仅仅是为了炫耀它们"，这表明没有以玩家为中心进行设计。

## 角色扮演与玩家行为

### 角色扮演的范围
- 不仅限于 RPG 游戏
- 角色类型包括：战士、芭蕾舞演员、科学家、飞行员，或其他奇奇怪怪的东西（如《吃豆人》中的大嘴怪）

### 玩家投入度特征
很多玩家对现实中的表演并不感兴趣，但一旦投入到游戏的角色中，便会相当认真、敬职敬业。

### 玩家角色塑造行为
玩家会主动进行以下行为：
1. 为人物角色添置个性化的服装和物品
2. 编写相关的人物背景故事
3. 使用动画表情（在聊天时向其他玩家表示情感的特殊动画）

## 性别包容性设计原则

### 核心原则
不要生硬地按刻板印象设计（如女性=时尚/购物，男性=怪物/卡车），而应消除阻碍任一群体的障碍。

### 设计禁忌清单（针对女性玩家需避免）

1. **超性感的女性化身和角色**
   - 理由：物化女性，造成排斥感

2. **重复单调乏味的游戏**
   - 理由：女性玩家对纯重复性玩法容忍度更低

3. **缺乏有意思的游戏目标**
   - 具体表现：仅追求最高分数排行榜
   - 理由：分数竞争对女性吸引力不足

4. **缺乏玩家互动**
   - 例外情况：若制作的就是单机游戏，则此为固有局限，需在其他方面补偿

### 关于女性主角的争议处理
- 事实：少数男性玩家反对以女性为主角的游戏
- 应对策略：完全可以忽略这部分反对声音
- 反驳依据："如果真是个好游戏，他们一定会玩的"

## 技术操作复杂度误区纠正

### 核心误区
认为"女孩不喜欢计算机游戏是因为计算机的操作性太强"

### 纠正逻辑
- 事实基础：虽然大多数女性对计算机技术细节方面的兴趣确实远不及男性
- 关键区分：对技术细节兴趣低 ≠ 因此不玩游戏

### 类比论证
现象：有很多女性一看到汽车说明书就立即放弃开车的念头
推论：这代表她们对技术文档反感，但不代表她们不驾驶或不使用技术产品

### 设计启示
- 不应将技术复杂性作为女性不玩游戏的主要原因
- 避免在游戏设计中过度强调技术操作细节作为门槛
- 关注游戏内容本身的吸引力而非界面复杂度
