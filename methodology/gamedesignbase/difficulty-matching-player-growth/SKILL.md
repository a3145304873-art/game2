# 控制正反馈：提高绝对难度

## 何时使用

- 设计PvE/RPG的成长系统
- 需要维持长期有意义的挑战
- 玩家通过成功获得经验值/金钱等成长资源
- 需要平衡成就感与持续挑战

## 核心循环机制

```
成功战斗 → 获得经验值和金钱 → 能量增长 → 提高敌人强度和数量 → 更大奖励 → 循环持续
```

## 关键设计：双难度概念

### 绝对难度 (Absolute Difficulty)
> "游戏接近结尾时，玩家打斗的敌人要比游戏开始时**难几百倍**"

- 数值上的巨大增长
- 客观可量化的强度

### 感知困难度 (Perceived Difficulty)
> "绝对难度和提供的能量进行了匹配，所以感知困难度**还是在控制之中**"

- 玩家主观感受的挑战程度
- **保持稳定**

## 成就感来源

> "这也给他了**巨大的成就感**" — 玩家直观感受到从弱到强的成长

## 设计要点

| 要点 | 说明 |
|------|------|
| 曲线匹配 | 绝对难度曲线与玩家能力曲线平行或略高 |
| 避免停滞 | 绝对难度停滞 → 玩家感到无聊 |
| 避免过快 | 增长过快 → 玩家感到挫败 |
| 奖励升级 | 更强敌人提供更大奖励，维持循环可持续性 |

## 适用范围限制

- **主要适用于PvE**
- PvP适用性有限（对手也是成长中的玩家）
- 需要设计难度曲线与成长曲线匹配
