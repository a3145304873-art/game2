# UI翻译空间预留设计

## 使用场景
当满足以下条件时使用此技能：
- 设计包含文本的用户界面
- 该界面需要支持多语言或本地化
- 处理菜单项、按钮标签、文本元素等需要翻译的UI组件

## 核心原则

### 语言长度差异
- 同一词汇在不同语言中的字符长度差异显著
- 英语中非常短的菜单项在德语中可能变得非常长
- 德语通常比英语长20-30%，某些词汇可能长50%以上
- 法语、西班牙语等也可能比英语长

### 设计规范要求
- 不要把文本元素放置得太拥挤
- 为每个文本元素预留扩展空间
- 避免固定宽度过小的文本框
- 考虑使用自动调整大小的文本容器

## 实施步骤

### 1. 按钮设计
- 确保按钮宽度可扩展
- 设置最小宽度以容纳最长语言版本
- 避免使用固定宽度的按钮

### 2. 标签布局
- 避免多行文本紧贴边界
- 为标签预留足够的左右边距
- 考虑使用弹性布局

### 3. 列表项设计
- 行高需考虑文本换行情况
- 列宽应能容纳扩展后的文本
- 避免文本截断

### 4. 字体大小设置
- 避免使用刚好填满空间的字体大小
- 预留20-30%余量
- 使用相对单位而非固定像素

## 验证方法

### 伪本地化测试
- 使用伪本地化工具测试UI扩展性
- 模拟最长文本场景

### 实际语言测试
- 使用最长语言（通常是德语）进行实际测试
- 检查所有UI元素的显示效果

### 问题检查
- 检查文本截断问题
- 检查文本重叠问题
- 检查布局溢出问题

## 预期结果
UI布局应能适应从最短到最长语言版本的文本显示，无截断、重叠或溢出。
