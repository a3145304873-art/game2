# 输入设备技术规格

## 压敏按钮参数

- **pressure_value**: 压力数值，范围通常为0.0(未按下)到1.0(完全按下)
- **spring_constant**: 弹簧加载的机械特性，决定回中速度
- **analog_resolution**: 模拟信号分辨率(如8位、10位)

## 数据伴随动作变量

- **输入数值**: 模拟设备产生的数值量级信息(如鼠标移动距离)
- **数据实体**: 用于存储和操作输入数据的结构化实体
- **面对方向属性**: 化身的方向属性，根据输入数据做适当改变

## 鼠标决策变量

- **rotation_type**: 旋转类型（无限旋转或有限角度）
- **interaction_mode**: 交互模式（持续控制或频繁切换）
