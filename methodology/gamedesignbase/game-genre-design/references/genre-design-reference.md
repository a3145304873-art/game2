# 游戏类型设计参考

## 冒险游戏检验清单
- [ ] 非竞争性叙事体验
- [ ] 单一主角互动故事
- [ ] 戏剧化而非数据化角色成长
- [ ] 核心玩法为探索+解谜
- [ ] 战斗元素极少或不存在

## 变量定义
- `分类主体` (Enum): 开发商/卖家/玩家，决定分类视角
- `时间维度` (Temporal): 游戏类型随时间演变的动态性
- `平台维度` (Platform): 特定平台可能导致分类标准固化
- `protagonist_type` (Categorical): 主角类型：玩家化身 vs 独立虚构人物
- `growth_model` (Categorical): 成长模式：戏剧化成长 vs 数据化成长
- `core_challenge_type` (Array): 核心挑战类型：探索、解谜、观念挑战的组合
- `交通工具类型` (Enum): 真实或虚构
- `逼真性要求` (Boolean): 是否需要与现实紧密联系
- `物理限制` (List): 引力、重力、燃油储备量等
