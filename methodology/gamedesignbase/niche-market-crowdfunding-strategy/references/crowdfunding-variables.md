# 众筹策略评估变量

| 变量名 | 类型 | 描述 |
|-------|------|------|
| market_type | enum | 主流市场 vs 缝隙市场 |
| design_autonomy_need | boolean | 开发者是否需要保持完全的设计控制权 |
| target_audience_loyalty | string | 特定玩家群体的热情程度和支持意愿 |

## 典型缝隙市场游戏类型

### 指向点击冒险游戏
- **特征**：叙事驱动、解谜为主
- **受众**：忠实粉丝群体，热情度高
- **市场表现**：不会大范围流行，但在核心玩家中受欢迎
- **众筹适用性**：高

### 其他适合类型
- 文字冒险游戏
- 模拟经营游戏（特定主题）
- 复古风格游戏
- 艺术性强的独立游戏

## 众筹平台选择

### Kickstarter
- **优势**：游戏项目数量多，用户基数大
- **适合**：有创意展示能力的项目
- **费用**：平台费5% + 支付处理费3-5%

### Indiegogo
- **优势**：灵活的资金模式（固定或灵活）
- **适合**：需要灵活资金安排的项目
- **费用**：平台费5% + 支付处理费3-5%

### Fig.co
- **优势**：专注于游戏，允许股权众筹
- **适合**：需要大量资金的项目
- **费用**：根据融资模式而定

## 众筹成功案例特征

1. **明确的受众定位**
2. **吸引人的视觉展示**
3. **可信的团队背景**
4. **合理的众筹目标**
5. **有吸引力的奖励层级**
6. **积极的社区互动**
7. **透明的项目进展更新**
