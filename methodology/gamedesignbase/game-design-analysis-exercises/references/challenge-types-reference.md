## 原子挑战（Atomic Challenge）定义

原子挑战是游戏中最小的、不可再分的挑战单元。多个原子挑战可以组合成更复杂的挑战层次结构。

### 原子挑战示例
- 跳过单个平台
- 击败单个敌人
- 解开单个谜题
- 收集单个物品
- 避开单个障碍

### 挑战层次结构
```
关卡（Level）
├── 中间层级挑战（Intermediate Challenge）
│   ├── 原子挑战1
│   ├── 原子挑战2
│   └── 原子挑战3
├── 中间层级挑战2
│   ├── 原子挑战4
│   └── 原子挑战5
└── 关键性挑战（Critical Challenge/Boss）
    ├── 原子挑战6
    ├── 原子挑战7
    └── 原子挑战8
```
