# 对话系统详细案例

## 角色声音设计案例

### 《辛普森一家》
- **荷马**：词汇有限、句子简单 → 教育不高，爱好食物和啤酒
- **马芝**：居中词汇 → 中产阶级展望，关心工作、朋友和孩子
- **丽莎**：词汇量大、长难句 → 学者，喜欢阅读、写作、音乐
- **巴特**：语言随情况变化 → 无忧无虑的享乐主义者，后现代角色

### 《星际争霸》
- **Arctums Mengsk**：南部贵族说话方式
- **Jim Raynor**：西部州长说话方式
- **飞行员 Wraith**：民航飞行员般简洁、单一的措辞
- **运输机飞行员**：中西部欢快、能干的女服务生风格
- **骑手 Vulture**：无政府的偏激的自行车骑手风格

## 动态列表系统示例

### 基本流程
```
开始操作：添加对话交互 1, 2, 3, 4, 5 到菜单
玩家选择：对话交互 3
系统显示：NPC回复
执行操作：删除对话交互 1, 2, 3, 4
执行操作：添加对话交互 6, 7, 8, 9
更新菜单：5, 6, 7, 8, 9
```

### 特殊选项处理
- **永久选项**："这就是我想要知道的一切" - 始终保留
- **重复选项**："再告诉我关于X的事" - 首次提出后添加，直到删除

## 条件分支示例

### 响应端条件
```
IF charisma > 12 THEN
  显示响应A："我很乐意帮助您，阁下。"
ELSE
  显示响应B："哼，我才不管你的事。"
```

### 菜单端条件
```
IF diplomacy > 10 THEN
  添加菜单选项："我可以用外交手段解决这个问题。"
```

## 对话选择影响示例

### 态度变量
- **player_character_attitude**：玩家角色态度属性值
- **npc_attitude_to_player**：NPC对玩家的态度参数

### 选择类型
- 积极回应：增加友好度
- 礼貌回应：增加尊重度
- 幽默回应：增加好感度

### 后果链
```
玩家选择 → 改变角色态度属性 → 改变NPC对玩家态度 
→ 打开/关闭对话分支 → 影响游戏引擎状态 → 影响后续剧情
```

## 技术实现建议

### 对话树复杂度管理
- 大型对话树可能难以处理
- 参考《Game Writing: Narrative Skills for Videogames》第14章
- 考虑精简建议

### 条件逻辑实现
- 在响应行或操作行包含if语句
- 支持嵌套条件
- 支持多条件组合（AND/OR）
