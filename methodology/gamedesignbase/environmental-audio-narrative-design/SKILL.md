# 环境声音叙事与定位设计

## 何时使用

- 玩家进入新区域需要即时识别环境类型
- 视觉信息不足或需要强化空间感知
- 构建具有辨识度的世界氛围和地理特征
- 实现"听觉HUD"——无需UI即可传达位置信息

## 核心设计原则

### 1. 环境-声音映射表

为每种环境类型定义独特的"声音指纹"：

| 环境类型 | 特征声音元素 | 功能说明 |
|---------|------------|---------|
| 城市街道 | 交通车辆、行人嘈杂、建筑回声 | 标识人口密度和文明程度 |
| 丛林 | 猴子叫声、异域鸟鸣、植被摩擦 | 标识野生状态和危险等级 |
| 沙漠 | 风声、沙粒流动、远处寂静 | 标识空旷和生存压力 |
| 工业区 | 机械运转、金属碰撞、蒸汽释放 | 标识人造环境和功能用途 |
| 室内空间 | 混响特征、结构吱嘎、外部渗透音 | 标识建筑材质和封闭程度 |

### 2. 真实性验证清单

- [ ] 该物体在现实世界中是否发出独特声音？
- [ ] 游戏内声音是否与玩家预期一致？
- [ ] 声音是否能在闭眼状态下识别环境？
- [ ] 多个环境的声音指纹是否存在明显区分度？

### 3. 空间存在感构建

将环境声音视为"听觉主视野"：

1. **基础层**: 持续的环境底噪（风、水、远处城市嗡鸣）
2. **特征层**: 标志性元素（特定动物、机械、人群活动）
3. **动态层**: 玩家交互引发的变化（脚步声回响、物体碰撞）

## 执行流程

```
Step 1: 定义环境类型 → 提取现实参考 → 建立声音元素清单
Step 2: 设计声音层次 → 测试闭眼识别度 → 调整特征突出度
Step 3: 验证跨环境区分度 → 集成到音频系统 → 玩家测试
```

## 快速决策

| 场景 | 行动 |
|-----|------|
| 玩家反馈"不知道自己在哪" | 增强特征层声音的独特性和响度 |
| 环境切换感觉突兀 | 设计过渡混音和中间态声音 |
| 声音过于嘈杂干扰玩法 | 降低动态层，保持基础+特征层 |
| 不同环境听起来相似 | 重新设计声音指纹，确保频谱差异 |
