# 对话树工具选择

## 使用场景
- 需要设计复杂对话树或交互式故事
- 评估专业对话设计软件工具
- 确定项目预算、平台和技术要求

## 工具评估矩阵

### articy: draft
- **适用场景**: 复杂分支逻辑、需要中间件集成的专业商业项目
- **平台**: 仅Windows
- **许可**: 商业软件
- **核心优势**: 嵌套结构支持复杂对话网络，可导出XML，支持中间件集成

### Chat Mapper
- **适用场景**: 语音录制工作流程、需要脚本格式导出
- **平台**: Windows（有免费限量版）
- **许可**: 商业软件（提供免费试用版）
- **核心优势**: GUI构建对话树，支持多种格式导出

### Twine
- **适用场景**: 简单超文本叙事、预算有限的项目
- **平台**: Windows和OS X
- **许可**: 完全免费
- **核心优势**: 非程序员易用，跨平台支持

### Scapple
- **适用场景**: 记录关联想法的轻量级需求
- **平台**: OS X（Windows版开发中）
- **许可**: 便宜工具
- **限制**: 非专为游戏开发设计

### Scrivener
- **适用场景**: 通用叙事内容管理
- **平台**: OS X和Windows
- **许可**: 商业软件
- **限制**: 不适合结构化对话系统

## 决策流程

1. **评估预算约束**
   - 预算有限 → 选择Twine或Scapple
   - 专业商业项目 → 选择articy: draft或Chat Mapper

2. **确认平台要求**
   - Windows用户 → 可使用全部工具
   - OS X用户 → 限于Twine、Scapple和Scrivener

3. **匹配复杂度需求**
   - 复杂嵌套逻辑 + 中间件集成 → articy: draft
   - 简单超文本叙事 → Twine
   - 语音录制工作流程 → Chat Mapper

4. **验证技术集成**
   - 确认导出格式（XML/脚本/其他）
   - 评估与编程团队的协作需求

## 输出结果
根据项目需求、预算、平台和技术要求，推荐最适合的工具方案。
