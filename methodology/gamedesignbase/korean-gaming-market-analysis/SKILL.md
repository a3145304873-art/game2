# 韩国游戏市场分析

## 使用场景

当遇到以下情况时应用此技能：
- 分析韩国游戏市场特征
- 规划游戏发布策略针对韩国市场
- 评估电竞项目在韩国的市场潜力
- 设计面向韩国的多人在线游戏
- 运营网吧/游戏场所业务

## 适用范围

**适用对象：**
- 韩国游戏市场
- PC bang（计算机房）
- 多人在线游戏
- 职业电竞项目
- 即时战略游戏

**不适用场景：**
- 单机剧情向游戏
- 成人色情游戏内容策略
- 家庭主机游戏市场（主要适用于PC网游）

## 分析流程

### 1. 评估市场需求基准

确认韩国市场的核心特征：
- 韩国对游戏的需求相对日本较小
- 韩国社会较为保守，色情内容的游戏不受欢迎
- **行动：** 避免将色情内容作为游戏卖点

### 2. 识别核心游戏场所特征 - PC bang模式

**PC bang定义：**
- 大型公共空间，配备大量桌子和局域网计算机
- 规模大于普通网咖

**核心特征：**
- 韩国人在公共空间玩游戏是最大特征
- 与日本等国家的家庭游戏文化形成鲜明对比

**技术要求：**
- 游戏必须适应局域网环境
- 支持大规模公共空间的社交游戏需求

### 3. 确定流行游戏类型优先级

在PC bang环境中，以下类型特别流行：
- 角色扮演游戏（RPG）
- 实时策略类游戏（RTS）
- 大型多人联网角色扮演类游戏（MMORPG）

### 4. 评估职业化/电竞潜力指标

**判断标准：**
- 游戏寿命不是障碍：即使是较老的游戏也能维持强大的电竞生态（如《星际争霸》）
- 游戏需要具备作为职业竞技项目的潜力：
  - 平衡性
  - 观赏性
  - 竞技深度

### 5. 制定市场进入策略

**核心策略：**
1. 优先开发适合公共空间多人游玩的游戏
2. 确保游戏支持局域网（LAN）环境
3. 考虑游戏的长期电竞生态潜力，而非仅关注短期销售
4. 内容审查：严格遵守韩国保守的社会标准，避免色情内容

## 关键变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| gaming_venue | enum | 游戏场所类型：home/PC_bang/public_space |
| game_genre | enum | 游戏类型：RPG/RTS/MMORPG/other |
| esports_potential | boolean | 是否具备职业电竞潜力 |
| game_age | integer | 游戏发布年限（在韩国，老游戏也可维持电竞热度） |
| sexual_content_level | enum | 色情内容等级：none/mild/explicit（韩国市场应avoid explicit） |

## 输出建议

针对韩国市场的游戏开发建议：
1. 优化PC bang多人联机体验
2. 优先考虑RPG/RTS/MMORPG类型
3. 设计长期电竞生态支持
4. 删除或降低色情内容
5. 确保局域网兼容性
