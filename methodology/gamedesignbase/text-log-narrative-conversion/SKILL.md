# 文本日志叙事转换机制

## 何时使用

- 技术预算极低，无法承担美术资源
- 团队希望快速实现MVP级别的故事生成
- 目标用户群体有文字创作意愿和能力
- 需要完全由玩家控制叙事视角和风格

## 核心流程

### 1. 自动文本记录
在系统后台捕获所有玩家活动：
- 移动、战斗、对话选择等游戏动作
- 保持严格的时间顺序
- 记录原始游戏动作和角色对话

### 2. 提供编辑界面
允许玩家自由处理日志：
- 删除无意义的重复操作（如反复进出房间）
- 保留关键剧情节点
- 完全开放的编辑权限

### 3. 叙事形式转换
玩家将机械日志转化为文学叙事：
- 添加场景描写和心理活动
- 选择叙事视角（第一人称/第三人称）
- 控制细节丰富度和文学风格

## 关键优势

| 维度 | 特性 |
|------|------|
| 技术门槛 | 最低（纯文本实现） |
| 美术需求 | 无 |
| 玩家控制度 | 完全自由（视角、风格、详略） |
| 表现力上限 | 依赖玩家文字能力 |

## 注意事项

- 完全依赖文字表现力，无视觉辅助
- 需要玩家具备主动编辑意愿
- 可能失去画面的直观性和即时反馈
