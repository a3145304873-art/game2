# 第一人称3D游戏Y轴视角反转设计

## 适用场景

当满足以下条件时，使用此技能设计视角控制方案：
- 开发第一人称3D游戏（FPS）或需要精确视角控制的游戏
- 使用鼠标或操纵杆（joystick）控制相机/视角
- 需要处理不同玩家群体的操作习惯差异
- 仅针对Y轴（上下方向）的控制逻辑设计

## 核心决策逻辑

```
IF (游戏类型为第一人称3D游戏) AND (使用鼠标或操纵杆控制视角) 
THEN 必须提供Y轴控制反转选项
```

## 两种心理模型

玩家对"向上看"的操作存在两种截然不同的认知模式，必须同时支持：

### 类型A：屏幕主导模式（Screen-Based）
- **操作逻辑**：向上推动鼠标/操纵杆 → 角色向上看
- **心理模型**：直接映射，推=向上移动
- **玩家来源**：习惯2D游戏、现代FPS玩家
- **行业默认**：现代FPS游戏通常采用此模式作为默认设置

### 类型B：飞机操纵杆模式（Aircraft Joystick）
- **操作逻辑**：向下拉动鼠标/操纵杆 → 角色向上看
- **心理模型**：模拟飞机控制，拉杆=机头抬起=视角向上
- **玩家来源**：飞行模拟游戏玩家、部分传统游戏玩家
- **别称**：反转模式（Inverted Y-axis）

## 实现步骤

### 1. 添加配置变量
创建布尔值变量 `y_axis_inverted` 存储玩家偏好。

### 2. 实现信号映射逻辑
- **正常模式**（`y_axis_inverted = false`）：输入Y+ → 视角向上旋转
- **反转模式**（`y_axis_inverted = true`）：输入Y+ → 视角向下旋转

### 3. 设计设置界面
- 在"控制设置"（Control Settings）分类下添加选项
- 使用复选框或切换开关，标签为"反转Y轴"（Invert Y-axis）或"飞行控制模式"
- 与以下功能放置在同一配置界面：
  - 鼠标灵敏度调节
  - 鼠标左右键交换（Left/Right Hand Mode）
  - 操纵杆死区设置

### 4. 实时应用与保存
- 更改后立即生效，无需重启游戏
- 保存到玩家配置文件，跨会话保持

## 默认设置策略

根据游戏类型选择默认模式：

| 游戏类型 | 推荐默认 | 理由 |
|---------|---------|------|
| 现代FPS/射击游戏 | 屏幕主导模式（关闭反转） | 符合主流玩家习惯 |
| 飞行模拟/空战游戏 | 操纵杆模式（开启反转） | 符合飞行控制直觉 |
| 混合类型（如《星际公民》） | 根据主要玩法选择 | 必须提供一键切换 |

## 验证检查点

- [ ] 设置菜单包含独立的"反转Y轴"选项（仅影响上下，不影响左右）
- [ ] 切换后视角控制立即响应新设置
- [ ] 默认设置符合游戏类型惯例
- [ ] X轴与Y轴控制独立配置（不要强制同时反转X轴）
- [ ] 支持分别保存鼠标和手柄的配置（如PC版）

## 注意事项

- **仅适用于Y轴**：此设置专门处理上下视角，X轴（左右）通常保持标准映射
- **平台差异**：主机版（手柄）与PC版（鼠标）可分别设置不同偏好
- **预设配置**：考虑提供"飞行模式"和"射击模式"预设，允许玩家一键切换整套控制方案
- **新手引导**：在首次启动或教程中提示玩家可调整此设置
