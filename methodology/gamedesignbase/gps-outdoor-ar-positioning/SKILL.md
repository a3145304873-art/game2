# GPS室外定位与AR开发

在开发基于位置的增强现实体验或需要绝对地理定位功能时，使用GPS技术获取设备位置并计算运动参数。

## 适用场景判断

**使用条件**（满足任一即适用）：
- 需要获取设备的绝对地理位置信息（纬度、经度、海拔）
- 需要计算玩家的移动速度和方向
- 开发基于位置的大型尺度增强现实游戏或体验
- 需要在城市尺度上追踪用户位置变化

**不适用场景**：
- 室内环境或卫星信号遮挡区域（如隧道、密集高楼间）
- 需要亚米级精度的精细定位（如桌面AR、近距离交互）
- 设备无GPS硬件模块

## 前置条件检查

实施前确认以下硬件与环境条件：

1. **硬件要求**
   - 设备配备GPS模块（智能手机、平板或专用便携式设备）
   - 支持位置服务API（iOS Core Location / Android LocationManager）

2. **环境要求**
   - 室外开阔区域或卫星信号可接收区域
   - 避免密集城市峡谷或室内环境

3. **权限配置**
   - 获取设备的位置权限（精确位置）
   - 确保应用后台定位权限（如需要持续追踪）

## 实施步骤

### 1. 获取基础定位数据

调用设备GPS接口获取原始坐标：

```
获取以下数据字段：
- latitude (float): 设备纬度坐标（-90 到 90）
- longitude (float): 设备经度坐标（-180 到 180）
- altitude (float): 设备海拔高度（米）
- timestamp: 数据采集时间戳
```

**关键检查点**：
- 验证horizontalAccuracy值，确认精度在可接受范围（通常5-10米）
- 如accuracy > 20米，提示用户移动到更开阔区域

### 2. 计算动态运动参数

基于连续位置采样计算速度与方向：

**速度计算**：
```
speed = distance(lat1, lon1, lat2, lon2) / (t2 - t1)
```
- 使用Haversine公式计算两点间距离
- 建议采样间隔：1-5秒（根据运动速度调整）

**方向计算**：
```
direction = bearing(lat1, lon1, lat2, lon2)
```
- 返回0-360度方位角（0为北，90为东）
- 静止状态下方向数据不可靠，需添加速度阈值过滤（如speed < 0.5m/s时忽略方向）

### 3. 集成到AR体验

**大尺度AR游戏设计**：
- 将GPS坐标映射到游戏世界坐标系（使用UTM投影或局部坐标系转换）
- 设置兴趣点(POI)触发半径（建议>10米以补偿GPS误差）
- 实现基于距离的游戏逻辑（如"接近目标50米内触发事件"）

**数据平滑处理**：
- 应用卡尔曼滤波或滑动平均减少GPS抖动
- 结合设备IMU数据（加速度计、陀螺仪）进行传感器融合，提升运动轨迹平滑度

## 技术限制与应对方案

### 限制1：信号接收限制
- **问题**：依赖轨道卫星信号，室内、隧道、密集建筑群中无法工作
- **应对**：
  - 设计降级方案：进入信号盲区时切换至纯惯性导航或视觉定位
  - 提供用户提示："请移动到室外开阔区域以继续体验"
  - 使用Wi-Fi/蓝牙信标作为室内补充定位（需额外部署）

### 限制2：精度限制（数米级）
- **问题**：民用GPS精度通常为3-10米，不适合精细空间对齐
- **应对**：
  - 设计大尺度交互（如城市级寻宝、区域触发）
  - 避免要求用户精确对准特定小物体的玩法
  - 使用视觉锚点（QR码、图像识别）在近距离提供精确相对定位

### 限制3：功耗与启动时间
- **问题**：持续GPS定位耗电高，冷启动定位需30秒以上
- **应对**：
  - 采用间歇式采样（如每5秒更新一次）而非持续追踪
  - 预加载星历数据（A-GPS）加速首次定位
  - 提供低电量模式选项

## 未来技术展望

**欧洲伽利略系统(European Galileo)**：
- 设计目标精度：1米（显著优于当前GPS的数米精度）
- 兼容性：现代智能手机通常支持多星座定位（GPS + Galileo + GLONASS + 北斗）
- 建议：在支持设备上启用多星座模式以提升精度和可用性

## 调试与验证

**测试清单**：
- [ ] 室外开阔区域：定位精度<5米
- [ ] 步行速度计算：与实际速度误差<20%
- [ ] 方向变化：行走时方向数据连续稳定
- [ ] 室内环境：优雅降级或明确提示用户
- [ ] 功耗测试：连续使用1小时电量消耗<30%

**常见问题排查**：
- 位置漂移：检查是否启用了Wi-Fi辅助定位（可能提供错误室内位置）
- 速度突变：增加速度变化率限制（如每秒变化不超过5m/s）
- 方向抖动：仅在speed > 1m/s时更新方向值
