# 非游戏可玩性动作的分类与定义

## 何时使用

- 设计不直接涉及核心挑战的玩家交互
- 规划游戏软件控制功能
- 区分挑战性动作与非挑战性动作
- 设计社交、创造性或叙事参与机制

## 五大分类

### 1. 无组织的玩法
**定义**：不为挑战，仅为有趣而执行

| 行为 | 示例 |
|------|------|
| 移动乐趣 | 化身在世界中随意移动 |
| 观光 | 到达无挑战新区域纯探索 |
| 角色扮演 | 包含动作只因是角色一部分 |

**经典示例**：驾驶游戏中按喇叭（不完成任何事，但没有感觉不完整）

### 2. 创造性和自我表现
**定义**：允许玩家创造和定制，包括化身

- 建设和管理模拟游戏的主要组成
- 受游戏内部经济限制

### 3. 社交的动作
**适用**：多玩家游戏，特别是在线游戏

**功能需求**：
- 相互交流方式
- 组队方式
- 比较比分方式
- 参与社区活动方式

### 4. 参与故事的动作
**定义**：参与交互对话、NPC交互、影响故事情节的决定

**效果**：提供越多，玩家越感觉参与到故事中（即使不影响挑战）

### 5. 控制游戏软件的动作
**定义**：控制游戏软件各方面的动作

| 操作 | 说明 |
|------|------|
| 调整虚拟摄像机 | 视角控制 |
| 暂停和保存游戏 | 会话管理 |
| 选择难度级别 | 影响挑战但非为挑战而执行 |
| 设置音量 | 音频控制 |

## 分类应用

识别当前动作类型，确保：
- 非游戏玩法动作得到适当设计资源
- 不将其与核心挑战机制混淆
- 为每类设计合适的反馈和可用性标准
