# 关卡气氛构建七大工具

## 何时使用
- 需要为特定关卡创造美学上的一致性时
- 需要创造合适的意境/氛围时
- 设计关卡视听体验时
- 增强玩家沉浸感时

## 关卡设计师角色定位

关卡设计师承担电影中4～5种工作的职责：
- 场景设计师
- 灯光设计师
- 特效设计师
- 配音编辑
- 摄影师

通过七大工具按美学一致性装配元素

## 工具1：灯光

### 位置和方向创造场景基调
- 晴天、月夜、黑暗的小巷

### 具体效果示例
- 暖洋洋的晨光透过窗户 → 温暖和舒适的感觉
- 机房中古怪炽热的灯光 → 危险的感觉
- 黄色的钠蒸气路灯/办公室刺目的荧光灯 → 特定环境氛围

### 关键原则
- "你选择不照亮的某些东西和照亮的某些东西一样重要"

## 工具2：调色板

### 功能
- 反映关卡的意境
- 类似化身服饰反映性格

### 构成
- 物体的原始颜色（艺术师在中性灯光条件下创造）
- 添加的灯光效果

### 参考方法
- 研究电视商业如何使用颜色传达情绪
- 冷静、兴奋、吸引注意力

### 目标
- 创造效果或引起玩家的某种反应

## 工具3：天气和大气效果

### 元素
- 雾、雨、雪、风

### 常见设计失误
- 很多户内空间游戏忘记天气对情绪的重要性

### 具体效果
- 阴暗、多云的天空预示暴风雨 → 本能想到"避雨"
- 雾 → 神秘的气氛
- 大风 → 预示动乱和骚动

## 工具4：特殊的视觉效果

### 示例
- 武器后坐力
- 急刹车轮胎冒烟
- 诅咒产生五彩烟花
- 血迹溅过城墙

### 功能
- 使玩家震惊
- 扰乱他们
- 使他们大笑
- 奖励他们

## 工具5：音乐

### 执行方式
- 与音频导演合作为关卡选择音乐
- 关卡设计师不编写音乐

### 音乐的作用
- 节奏 → 设置步调
- 音色和音调 → 设置意境

### 原则
- "通常，但并不总是，音乐在整个关卡中应该保持一致，这也是关卡整体基调的一部分"

## 工具6：环境声音

### 功能
- 帮助关卡整体意境
- 根据地点和时间改变
- 帮助玩家辨别方向和位置

### 示例
- 高尔夫游戏：鸟叫声和蟋蟀声 → 高尔夫球场的宁静气氛
- 强大的蒸汽机引擎搅动声 → 力量和危险的感觉
- 猫头鹰叫声和狐狸嚎叫 → 指示时间为夜里
- 谈话叫嚷和卖家大喊大叫 → 放置在集市中

## 工具7：特殊音效

### 核心观点
- "音效对耳朵的作用就像视觉效果对眼睛的作用一样，在某些方面甚至能提供更重要的信息"

### 关键示例
- 从汽车内部无法看到轮胎打滑
- 但"轮胎的长而尖的声音则告诉你正位于危险的边缘——你正在把交通工具推向它的极限"

## 设计流程

1. **确定关卡基调**：明确关卡需要传达的情绪和氛围
2. **选择灯光方案**：设计灯光位置、方向和强度
3. **配置调色板**：选择符合基调的颜色组合
4. **添加天气效果**：根据需要添加雾、雨、雪、风等效果
5. **设计特殊视觉效果**：为关键交互添加视觉反馈
6. **选择音乐**：与音频导演合作选择合适的背景音乐
7. **配置环境声音**：添加符合场景的环境音效
8. **添加特殊音效**：为关键状态和危险添加提示音效
9. **测试整体效果**：验证所有元素协同工作，营造一致的氛围

## 设计检查清单

- [ ] 灯光设计符合关卡基调
- [ ] 调色板与灯光效果协调
- [ ] 天气效果增强氛围
- [ ] 特殊视觉效果提供适当反馈
- [ ] 音乐节奏和音调匹配意境
- [ ] 环境声音帮助定位和氛围营造
- [ ] 特殊音效提供关键信息
- [ ] 所有元素保持美学一致性
