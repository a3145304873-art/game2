# 输入设备详细参考

## 鼠标数据变量
- `X_value` (float): 鼠标在X轴方向的相对移动距离
- `Y_value` (float): 鼠标在Y轴方向的相对移动距离
- `previous_position` (coordinate): 鼠标上一个采样时刻的位置

## 触摸设备变量
- `设备类型` (enum): 触摸感应屏或触摸板
- `输入工具` (enum): 手指或尖笔
- `触摸点数` (integer): 硬件同时检测的触摸点数量
- `使用时长` (duration): 连续使用时间，用于评估人体工程学风险

## 控制台设备示例
- 转向车轮：赛车游戏专用
- 吉他：音乐游戏专用
- 康加鼓：节奏游戏专用
- 钓鱼竿：钓鱼模拟游戏专用
- 平衡板：体感健身游戏专用
