# UI设计一般原则与创新规范

## 何时使用

- 设计或重构游戏用户界面
- 评估现有UI的可用性问题
- 决定是否打破行业惯例
- 优化控制器按键布局

## 10项核心原则

### 1. 遵循惯例与创新控制
- 惯例存在时，遵守或尽量贴近
- 不强迫玩家学习不熟悉UI，除非有实质性改进
- 打破常规必须创建教程关卡，让新手和老手彻底测试
- 测试无实质改进 → 回到原计划
- **必须允许玩家自定义界面**

### 2. 保持一致
- 美学和功能性一致
- 相同动作 = 相同按钮/菜单项（跨游戏模式）
- 指示器、菜单、物体名称各处相同
- 颜色、大小写、字体、布局相关区域一致

### 3. 提供好的反馈
- 玩家交互时游戏立即反应（至少确认）
- 不可用按钮按下时也应有听觉回应
- 激活按钮外观暂时或永久改变

### 4. 尊重玩家控制权
- 玩家是发号施令的人
- **绝不抢夺化身控制**，让其做玩家不希望的事
- 接受随机事件/NPC行为，但绝不接受化身随机动作

### 5. 限制动作步骤数
- 激活任何移动的最大按钮数：**3个**
- 例外：打斗游戏组合移动
- 不要让玩家层层菜单找常用命令

### 6. 允许简单动作撤销
- 玩家犯错应允许撤销
- 例外：严重影响游戏平衡
- 益智游戏应有撤销/重做列表，可设置步数限制

### 7. 最小化身体压力
- 常用动作 → 最容易触摸的按钮
- 目的：减少损害，延长游戏时间，提升喜爱度

### 8. 保护短期记忆
- 不要求玩家一次记住太多
- 提供查找信息的方法
- 永久反馈元素显示始终需要的信息

### 9. 分组控制与反馈
- 屏幕控制和反馈机制分组
- 目的：扫视获得信息，而非全屏寻找

### 10. 提供快捷键
- 熟悉游戏后，不通过多层菜单找命令
- 最常用动作提供快捷键
- **必须包含重新配置特性**
