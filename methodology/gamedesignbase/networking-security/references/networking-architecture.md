# 网络架构对比

## 单机游戏架构

```
游戏世界（全部数据）
    ↓
客户端（本地存储）
    ↓
软件限制访问
    ↓
玩家视图
```

## 在线游戏架构

```
游戏世界（全部数据）
    ↓
服务器端数据过滤
    ↓
仅发送可见数据
    ↓
客户端（仅接收可见数据）
    ↓
玩家视图
```

## 安全性对比

| 特性 | 单机游戏 | 在线游戏 |
|------|----------|----------|
| 数据存储 | 本地全部 | 服务器全部 |
| 数据传输 | 无 | 过滤后传输 |
| 作弊难度 | 低（可修改本地数据） | 高（服务器不发送隐藏数据） |
| 安全性 | 依赖软件限制 | 依赖架构设计 |
