# 视觉设计资源详细清单

## 专业书籍详细清单

### 《数字建模》（Digital Modeling）
- **作者**：William Vaughan
- **年份**：2012
- **出版社**：New Riders
- **内容**：
  - 数字建模基础
  - 建模技术
  - 工作流程
  - 最佳实践

### 《数字角色动画3》（Digital Character Animation 3）
- **作者**：George Maestri
- **年份**：2006
- **出版社**：New Riders
- **内容**：
  - 角色动画基础
  - 动画原理
  - 角色绑定
  - 动画工作流程

## 免费工具详细清单

### GIMP
- **官方网站**：https://www.gimp.org/
- **功能**：
  - 位图图像编辑
  - 图层管理
  - 滤镜和效果
  - 插件支持
- **适用场景**：
  - 游戏贴图制作
  - UI设计
  - 概念艺术

### Inkscape
- **官方网站**：https://inkscape.org/
- **功能**：
  - 矢量图形编辑
  - 路径编辑
  - 文字工具
  - SVG支持
- **适用场景**：
  - 游戏图标设计
  - UI元素设计
  - 矢量艺术

### Blender
- **官方网站**：https://www.blender.org/
- **功能**：
  - 3D建模
  - 雕塑
  - 动画
  - 渲染
  - 视频编辑
- **适用场景**：
  - 游戏角色建模
  - 环境建模
  - 动画制作

### Sculptris
- **官方网站**：https://pixologic.com/sculptris/
- **功能**：
  - 数字雕塑
  - 动态拓扑
  - 笔刷系统
- **适用场景**：
  - 角色概念雕塑
  - 高细节建模

## 学习路径建议

### 初学者路径
1. **学习基础**：阅读专业书籍
2. **使用免费工具**：GIMP/Inkscape/Blender
3. **练习项目**：完成小型项目
4. **进阶学习**：学习行业标准软件

### 职业发展路径
1. **学习基础**：阅读专业书籍
2. **掌握免费工具**：熟练使用Blender等
3. **学习行业标准**：Maya/3ds Max学生版
4. **作品集建设**：创建专业作品集
5. **求职准备**：申请相关工作
