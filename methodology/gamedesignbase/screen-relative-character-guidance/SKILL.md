# 以屏幕为主导的引导机制

## 何时使用

- 固定摄像机视角游戏
- 随意漫游型摄像机（不跟随化身）
- 上下视角或等距视角游戏
- 2D滚轴平台游戏
- 特定3D例外（非标准第三人称）

## 通用规则

> 玩家向屏幕上方移动操纵杆 → 化身向屏幕上方移动

## 按视角类型的实现

### 上下视角和等距视角
- 玩家从上面观察化身
- 操纵杆向屏幕边缘移动 → 化身立即转身 → 向该方向移动
- **经典示例**：《Gauntlet》

### 2D滚轴游戏
| 维度 | 控制方式 |
|------|---------|
| 水平移动 | 操纵杆左右 |
| 垂直移动 | 独立按钮（跳上平台） |
| 向上推杆 | 加强向上跳效果 |
| 向下推杆 | 未定义（2D世界无深度） |

### 3D游戏（例外情况）
> 通常3D使用以化身为主导，但存在例外如《古惑狼》

| 输入 | 效果 |
|------|------|
| 向上推 | 化身向屏幕上方移动（3D环境前方，远离玩家） |
| 向下推 | 化身转身面对玩家，向玩家移动 |
| 向左/右 | 化身转动方向后朝该方向移动 |

**摄像机特性**：左右移动时摄像机角度不变，从侧面显示化身（区别于化身为主导的摄像机跟随转向）
