# 角色设计评估变量

| 变量名 | 类型 | 描述 |
|-------|------|------|
| target_audience_age | enum | 青少年 vs 成熟玩家 |
| target_audience_gender | enum | 男性专属 vs 混合性别 |
| differentiation_strategy | string | 依赖技术、设计还是美术风格 |

## 风险等级判定标准

### 高风险
- 目标市场包含女性玩家
- 目标市场包含成熟玩家
- 游戏依赖技术创新
- 市场已有大量类似设计

### 中风险
- 目标市场主要为青少年男性
- 游戏有明确风格定位
- 性感设计符合叙事需求

### 低风险
- 目标受众明确且狭窄
- 性感设计是游戏核心卖点
- 有明确的差异化策略

## 正面案例：劳拉·克劳馥设计分析

### 设计特征
- **装备**：旅游靴、背包
- **服装**：黄褐色衣服
- **整体风格**：功能性、冒险感、可信度

### 成功要素
- 符合角色职业（考古学家）
- 服装具有功能性
- 性感但不失得体
- 建立了强烈的角色识别度

## 负面案例：常见性感角色设计问题

### 设计特征
- **装备**：锁甲似的比基尼
- **服装**：紧身皮衣
- **整体风格**：纯粹性感、功能性缺失

### 问题分析
- 不符合游戏世界设定
- 服装缺乏功能性
- 过度暴露显得不真实
- 排斥女性玩家
