# 游戏类别与步调设计

根据游戏类别确定关卡步调设计基调，确保玩家体验符合类型预期。

## 何时使用

- 开始关卡设计前确定节奏基调
- 评估现有关卡节奏是否符合类型标准
- 设计混合类型游戏时需要明确主次节奏
- 玩家反馈节奏与预期不符时进行诊断

## 核心原则

不同游戏类别对应不同的步调强度，违背类型节奏预期会导致玩家流失。

## 步调等级参考

### 最快步调
| 类别 | 特征 | 设计要求 |
|------|------|---------|
| 老派2D横版滚轴 | 持续移动+射击 | 玩家必须不停操作才能生存 |
| 纵版射击游戏 | 高密度弹幕/敌人 | 反应时间极短，无停顿空间 |
| 多人死亡竞赛FPS | 持续高强度对抗 | 如《雷神之锤》，重生即战斗 |

### 慢节奏特例
同类别内可存在步调变体，但需明确设计意图：
- **隐形战术射击**（如《彩虹六号》）：以慢速计划移动为主，遇敌时短暂爆发
- 设计关键：计划阶段的紧张感必须转化为遇敌时的释放感

### 最慢步调
| 类别 | 元素 | 设计特征 |
|------|------|---------|
| 冒险游戏 | 交互对话 | 对话即"动作"，非挑战克服 |
| | 自由探索 | 低精力消耗，无时间压力 |
| | 解谜 | 玩家自主控制解决时长 |

## 执行步骤

1. **确定游戏类别**：明确目标类型及子类型
2. **研究标杆作品**：亲自体验该类别代表作的节奏特征
3. **设定步调范围**：根据上表确定可接受的节奏波动区间
4. **应用到关卡**：确保关键战斗/探索/对话段落符合步调预期
5. **验证一致性**：检查是否存在违背类型节奏的突兀段落

## 常见错误

- 在快节奏射击游戏中强制加入长时间无提示探索
- 在冒险游戏中设置时间压力谜题而未提供暂停思考机制
- 混合类型时未明确主次节奏，导致体验混乱

## 验证标准

> 玩家是否能在不看说明书的情况下，凭直觉感受到"这游戏的节奏就该是这样"？
