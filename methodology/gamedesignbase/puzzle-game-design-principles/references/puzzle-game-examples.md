# 解谜游戏设计案例

## 典型游戏案例

### 《愤怒的小鸟》
- **类型**：试错型解谜游戏
- **核心机制**：通过物理弹射试错达成目标
- **设计特点**：简单易懂的物理机制，多次尝试的乐趣

### 《割绳子》
- **类型**：试错型解谜游戏
- **核心机制**：通过切割绳子试错让糖果落入目标位置
- **设计特点**：直观的操作，精确的时机把握

### 《宝石迷阵》
- **类型**：模式识别类解谜游戏
- **设计复杂度示例**：
  - 基础机制：匹配三个相同宝石从网格删除
  - 动态反馈：旧宝石消失后新珠宝立刻出现补齐
  - 策略深度：多种可能性需要玩家动脑规划

## 市场背景（2000年左右）
- 基于网页和智能手机的游戏兴起带来黄金时期
- 发行量飙升成为休闲游戏主要类型
- 不需要过于追求娱乐性和成功即可立足市场

## 常见设计缺陷
- 范围过大或过小
- 逻辑合理性不足
- 非典型关卡可选性差
- 信息展示节奏不当
- 缺乏观众意识
