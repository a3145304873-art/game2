# 游戏机制设计15项检查清单

1. **确定游戏机制类型**：从五种主要机制中选择或定义自定义机制
2. **定义实体与资源**：列出所有实体和资源，区分构成方式
3. **识别罕见实体**：明确游戏中哪些实体比较罕见
4. **识别组合实体**：确定哪些实体由别的实体组成
5. **定义实体属性**：确定分辨实体种类的属性，区分数值型和符号型
6. **区分有形与无形及状态转换**：检查资源是否可从一种状态转变为另一种状态
7. **定义关系机制**：确定控制实体之间关系的机制，定义符号实体状态映射
8. **定义全局机制**：确定是否存在全局机制，明确模式转换机制
9. **定义来源机制**：确定实体和资源是否有来源，明确生成速率控制
10. **定义消除机制**：确定是否存在消除渠道，明确引发消除的条件
11. **分析转换与交易**：明确转换条件，描述交易过程，检查反馈循环
12. **评估平衡状态**：确定平衡类型（静态/动态/衰退/混乱）
13. **设置挑战机制**：设置生成主动挑战的机制，建立探测机制
14. **设置动作机制**：设置实现动作的机制，确保每个动作在核心机制上体现
15. **定义自主实体行为**：定义控制自主性实体行为的机制和AI机制

## 模糊规则精确化示例：沼泽毒气机制

### 原始模糊描述
"玩家如果花费过长的时间而没有通过沼泽地，他将会受到惩罚"

### 精确化后机制
```
When 化身进入沼泽时：
  黑色的毒菌开始释放玩家可以看到的有毒气体
  气体填充整个屏幕，从屏幕底部开始
  以每3秒占领游戏世界中1英寸的速度上升
  
If 在最后的3分钟，那个时候化身仍然处在沼泽里：
  化身就会死亡
  
If 化身后来又返回到这片沼泽：
  气体就会消失
  重复上面的过程
```

### 关键参数
- 时间间隔：每3秒
- 总时长：3分钟
- 上升速度：每3秒1英寸
- 起始位置：屏幕底部
- 临界高度：化身面部高度
- 视觉元素：黑色毒菌、可见气体

## 模式一般化示例：环境依赖生物

### 具体实例
- 沼泽水蛭：离开水每分钟失去10点生命值
- 沙罗曼蛇（火蜥蜴）：离开火每分钟失去5点生命值

### 提取的通用属性系统

**属性A：environment_type（符号类型）**
- 作用：说明生物依赖的环境类型
- 取值：'water'、'fire'、'none'（表示不依赖任何环境）

**属性B：hp_loss_rate_per_minute（数值类型）**
- 单位：点数/分钟
- 示例：水蛭=10，火蜥蜴=5
- 特殊值：0（当生物不依赖环境时）

### 通用代码逻辑
```
IF (生物当前位置 != environment_type指定环境) THEN
  每分钟扣除 hp_loss_rate_per_minute 数值的生命值
```

### 实体配置
| 生物 | environment_type | hp_loss_rate_per_minute |
|------|-----------------|------------------------|
| 沼泽水蛭 | 'water' | 10 |
| 沙罗曼蛇 | 'fire' | 5 |
| 普通生物 | 'none' | 0 |
