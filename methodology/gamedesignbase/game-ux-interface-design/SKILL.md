# 游戏用户体验与界面设计

## 使用场景
- 设计游戏用户界面
- 评估玩家体验质量
- 进行UI创新或优化
- 设计游戏控制系统

## 核心理念转变

### 传统观念
UI设计 = 设计屏幕和菜单（界面元素本身）

### 现代观念
UE设计 = 设计玩家体验（玩家感受和娱乐效果）

**关键区别**：目标从"设计界面"转向"娱乐玩家"

## 用户体验构成要素

1. **输入和输出设备**（硬件交互层）
2. **游戏内其他玩家的交互**（社交层，如适用）
3. **软件本身、画面、音效等**（统称为"用户界面"UI）

## 执行步骤

### 步骤1：确定设计目标
- 核心目标：创造流畅的、令人享受的用户体验
- 关注点：玩家需要什么才能舒服地玩游戏

### 步骤2：应用以玩家为中心的设计原则
对每个设计决定进行反复测试：
- 测试问题一："这会让玩家感觉如何？"
- 测试问题二："这会让玩家有娱乐感吗？"

### 步骤3：理解游戏UI的本质
- 游戏UI比大多数程序UI更复杂
- UI不应告诉玩家游戏中发生的一切
- UI不应给予玩家游戏的最大控制权
- UI充当"窗口"角色，连接游戏内部与玩家

### 步骤4：执行界面创新策略

#### 鼓励创新的领域
- 主题
- 游戏世界
- 故事讲述
- 美工
- 声音
- 游戏可玩性

#### 谨慎创新的领域
- **用户界面设计**，特别是控制器和键盘上真实按钮的分配

**原因**：大部分游戏类型已演化出了一套实用的、适合其本身游戏可玩性的反馈元素和控制技术。

### 步骤5：研究与采用现有系统
1. 通过玩选定类别的其他游戏来研究这些系统
2. 采纳你认为适合自己游戏的所有元素
3. 特别注意同类游戏中广受好评的那一款游戏

## 设计检验标准

### UI对玩家认知的影响
- [ ] 满意度：令人满意 vs 令人失望
- [ ] 品质感：优雅 vs 粗俗
- [ ] 情感体验：有趣 vs 令人沮丧

### 创新合理性检验
- [ ] 创新是否发生在鼓励创新的领域？
- [ ] 是否采纳了同类成功游戏的成熟控制技术？
- [ ] 玩家是否能够舒适地玩游戏？

## 关键概念

- **交互模型（interaction model）**：玩家与游戏系统交互的基本模式
- **视角（camera model）**：游戏中观察游戏世界的视觉呈现方式
- **游戏类型（game genre）**：决定了演化出的标准控制技术
- **控制映射（control mapping）**：控制器或键盘上的按钮分配方案
