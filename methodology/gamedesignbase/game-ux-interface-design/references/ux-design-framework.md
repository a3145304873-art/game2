## 游戏UI的本质

### 与工具软件的区别
游戏UI具有娱乐性而非纯粹的工具性。

### UI的定位
- UI充当"窗口"角色
- 连接游戏内部与玩家
- 旨在让玩家体验游戏的趣味性和故事性

### UI的限制
- 不应告诉玩家游戏中发生的一切
- 不给予玩家游戏的最大控制权
