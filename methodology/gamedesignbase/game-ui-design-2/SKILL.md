# 游戏用户界面设计

## 使用场景
- 设计游戏用户界面
- 区别于普通计算机软件的UI设计
- 系统化分析或设计游戏UI
- 评估现有UI清晰度

## UI的双重核心功能

### 功能对比
| 维度 | 普通软件 | 游戏软件 |
|------|---------|---------|
| 设计目标 | 尽可能高效 | 娱乐玩家 |
| 信息呈现 | 清晰呈现工作 | 分阶段揭示 |
| 玩家行为 | 假定高效 | 被挑战阻碍 |

### 游戏UI的两个功能
1. **功能一**："让游戏操作更方便"——降低操作门槛，提升可用性
2. **功能二**："娱乐玩家"——提供情感体验和沉浸感

### 关键原则
两个功能必须同时满足，不可偏废。

## UI的两个基本特征

### 特征一：视角（Perspective/Viewpoint）
- 定义：玩家观察游戏世界的方式和位置
- 作用：决定信息呈现的空间关系和沉浸程度
- 常见类型：第一人称、第三人称、俯视、侧视等

### 特征二：交互模型（Interaction Model）
- 定义：玩家操作与游戏世界响应之间的映射规则
- 作用：决定玩家如何影响游戏状态
- 常见类型：直接操控、指令式、菜单驱动等

### 两个特征的关系
- 相互独立：同一视角可配合不同交互模型
- 共同定义：两者组合形成完整的UI体验特征
- 设计决策：改变任一特征将根本改变游戏体验

## 相机模型与视角设计

### 适用性判断
```
IF (游戏包括模拟的物理空间或游戏世界)
THEN 使用图像向玩家显示这一空间，并定义相机模型
ELSE (例如商业模拟游戏)
THEN 相机模型不适用，必须在设计文档中对游戏屏幕上出现的各种元素做出详细的解释
```

### 相机行为类型
1. **静态相机模型**：相机总是从固定的角度显示虚拟空间
2. **动态相机模型**：相机会根据游戏世界中玩家的动作或事件移动

### 视角类型
- **3D游戏世界**：第一人称视角、第三人称视角
- **2D游戏世界**：自上而下视角、横向滚轴视角、平视图

## 主视图设计原则

### 尺寸要求
主视图必须是屏幕上最大的元素

### 布局选项
- **选项A**：主视图出现在具有其他用户界面元素的窗口里，这些元素围绕着它
- **选项B**：主视图占据整个屏幕，其他用户界面元素出现在它的上部

### 叠加层文本显示规范
- 必须使用不透明或几乎不透明的叠加层
- 原因：半透明覆盖层中的文本很难阅读，因为下面的图像会混淆文本

### 窗口视图（Windowed View）特性

**定义与特征：**
- 最古老也最简单的选择
- 主视图仅占据屏幕的一部分
- 屏幕其他部分显示反馈和控制机制的面板

**适用游戏类型：**
- 建设和管理模拟游戏
- 角色扮演游戏(RPG)
- 策略游戏
- 原因：这些游戏需要非常多的屏幕上控制

**沉浸性影响：**
- 负面效果：使玩家感觉好像是通过一个窗口观察游戏世界，在某种程度上损害了沉浸性
- 平台分布：相比控制台游戏，更多地会在PC游戏中见到这种视图

**适用性权衡：**
- 不适用场景：玩家的大部分动作都发生在窗口里的高速游戏——沉浸性损失非常不受欢迎
- 适用场景：游戏要求大量通过内部经济进行控制，以及玩家一直都需要使用所有控制时

## UI模糊性风险因素与规避策略

### 风险因素一：美工过于积极
- 问题描述：艺术师希望用户界面能尽可能地令人愉悦与和谐，但有时会产生很吸引人的 UI 元素，却没有传达任何意义
- 核心矛盾：美观性 vs. 功能性/可理解性
- 规避策略：建立审核机制，确保每个UI元素在吸引人的同时具备明确语义

### 风险因素二：减少UI屏幕使用空间的压力
- 具体表现：使用图标而不是文本标签、使用小图标
- 问题后果：图标不能像文本那样传达复杂的信息、小图标不容易辨认
- 关键原则：当你减少 UI 需要使用的空间大小时，一定要保证这样做不会使它们的功能变得模糊

### 风险因素三：开发者对材料的熟悉度
- 问题根源：你知道你的图标是什么意思，以及它们是怎样运行的——你创建了它们。那就是说你不是判断它们对其他人清楚程度的最佳人选
- 关键认知偏差：创造者熟悉度偏差（Curse of Knowledge）
- 强制规避策略：要始终使用不熟悉你的游戏的人来测试 UI
- 测试方法：
  * 观察测试者"能否判断出各种东西的运行情况"
  * 评估标准："如果他要求很多实验，那么你的 UI 就太模糊了"

## UI核心价值

### 重要性评估
当游戏评论者高度赞扬一个游戏时，他们最经常引用它的用户界面，把它作为使这个游戏取得巨大成功的特征。

### 核心价值判断
游戏可玩性可能具有创新精神，游戏场景可能非常壮观，故事可能很生动，但是只有一个"平稳的和直觉的用户界面"才能提高玩家对游戏的认知。

### 界面管理要素
在设计和管理界面时，需综合处理以下方面：
- 界面的复杂度
- 游戏中使用的很多视觉和听觉元素
- 输入设备
- 导航技术

### 完善与反馈机制
如果在调整并完善用户界面，以使它达到完美的顶峰，那么用户会立即注意到这一点；只要付出了努力，工作就会得到认可。
