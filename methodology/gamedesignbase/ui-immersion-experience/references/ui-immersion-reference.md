# UI与沉浸设计参考

## 变量定义
- `界面深度` (Integer): 用户到达目标选项所需的菜单层级数
- `界面宽度` (Integer): 单次展示给用户的选项数量
- `访问频率` (Categorical): 功能被使用的频繁程度（高/低），用于决定菜单层级
- `沉浸类型` (Enum): 战术性、策略性、空间性、叙事性
- `挑战时长` (Time): 战术性沉浸中单个挑战的解决时间（约0.1秒）
- `口头内容长度` (Categorical): 短片段或长句子，决定变体数量策略
- `重复频率` (Frequency): 触发次数，决定是否需要切换为视觉反馈
- `游戏主题/时代背景` (Categorical): 决定演员口音和表演风格的适配性

## 控制台游戏约束
- 控制台游戏机因按钮少且无鼠标，创建宽界面机会较少
