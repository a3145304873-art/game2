# 符号与数值关系机制

## 何时使用

- 需要根据数值改变符号状态（如警告灯）
- 需要根据符号状态进行数值计算（如变速器齿轮比）
- 实现载具模拟中的挡位系统
- 设计离散状态与连续数值交互的机制

## 基本原则

虽然不能对符号值执行算术操作，但可以使用数字数据来定义符号实体如何从一种状态变为另一种状态，或建立符号到数值的映射。

## 状态转换机制（数值→符号）

### 基于数值阈值的状态切换
- 定义符号实体的离散状态（如：燃料警告值可以是"关"或"开"）
- 基于关联的数值数据定义状态转换规则

### 示例：燃料警告系统
- **规则1**：当燃料容量 < 2加仑时，燃料警告值变为"开"
- **规则2**：当燃料容量 ≥ 2加仑时，燃料警告值变为"关"

## 数学函数映射（符号→数值）

### 映射表机制
如果存在机制将符号实体和数字联系起来，符号实体可对数学函数起作用。

### 示例：交通工具变速器
- **符号实体**：变速器状态（挡位）
- **数值实体**：齿轮比

**映射关系**：
| 符号状态 | 数值输出（齿轮比） |
|----------|-------------------|
| 一档 | 3.83:1 |
| 二档 | 2.01:1 |
| 三档 | 1.46:1 |
| 倒档 | 4:-1 |

### 特殊处理
- **负值作用**：倒档中的负值使驱动轴反转

## 实现模式

### 模式1：阈值触发器
```
IF (数值数据 < 阈值) THEN
    符号状态 = 状态A
ELSE
    符号状态 = 状态B
END IF
```

### 模式2：查表映射
```
数值结果 = 映射表[符号状态]
```

## 变量参考

| 变量 | 类型 | 说明 |
|------|------|------|
| 符号状态 | Symbolic | 离散状态（开/关、挡位） |
| 数值数据 | Numeric | 触发状态转换的连续值 |
| 映射结果 | Numeric | 符号状态对应的数值输出 |
