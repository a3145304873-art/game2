# 关卡设计师角色定义与原型化构建

## 何时使用

- 定义关卡设计师职责范围
- 执行关卡原型化阶段
- 规划从概念到最终关卡的流程
- 协调关卡与故事情节的匹配

## 核心职责

### 1. 空间创造
- 创造游戏发生的空间
- 空间陈设和背景设定

### 2. 情感上下文构建
- 创造影响玩家体验和感受的情感氛围

### 3. 设计原理应用
| 类型 | 要求 |
|------|------|
| 通用原理 | 保证玩家总是知道短期目标和冒险的后果 |
| 特定类型原理 | 针对特定游戏类型的专门设计原理 |

### 4. 跨职能协作
- 与游戏设计师紧密联系
- 确保关卡布局与故事情节匹配

### 5. 目标达成
通过上述工作创造吸引玩家参与的气氛和步调

## 原型化构建流程（7步骤）

### 前提条件
- 游戏引擎部分功能可运行以载入原型
- 初始关卡计划已完成

### 执行步骤

| 步骤 | 内容 | 注意事项 |
|------|------|---------|
| 1. 基础场景 | 3D建模工具创建基本几何结构 | 2D世界展示2D场景布局 |
| 2. 临时纹理 | 放置临时纹理提供表面视觉效果 | **最终会被艺术师纹理替代** |
| 3. 临时物体 | 放置道具模型（树、家具、建筑、NPC） | 确定场景中位置 |
| 4. NPC路径 | 设置AI驱动NPC的计划路径 | 明确行进区域 |
| 5. 灯光设计 | 至少达到一般意义上的效果 | 早期氛围建立 |
| 6. 事件触发 | 确定关键事件触发点位置 | 记录触发设备作为传动装置 |
| 7. 音效处理 | 优先使用最终音效；否则用临时音效并记录更换需求 | |

### 关键约束
- **原型模型最终不会出现在游戏中**
- 仅作为蓝图供艺术团队参考

## 完整流程提示

- 遵循从最初移交到用户测试的完整流程
- 避免设计过程中常见问题
- **绝对不能忽视观众的见解**
