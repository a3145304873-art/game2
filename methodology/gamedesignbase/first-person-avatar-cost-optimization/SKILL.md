# 第一人称视角美术成本优化

## 适用场景

在以下情况下使用此技能：
- 项目采用第一人称视角（First-Person Perspective）
- 游戏存在玩家化身/角色，但常规 gameplay 中不可见
- 需要降低美术开发成本或优化动画资源分配
- 评估是否值得为例外场景（如过场动画）投入额外资源

## 前提条件

- 确认游戏视角为第一人称（非第三人称或过肩视角）
- 确认玩家有化身设定（即使不可见）
- 确认常规 gameplay 中不需要展示化身身体部位

## 执行步骤

### 1. 识别例外场景清单

列出所有**必须**展示玩家化身的特殊情况：
- 剧情过场动画（cutscenes）中可见化身的镜头
- 镜子、水面或其他反射表面中的化身反射
- 影子投射（如需要精确的身体轮廓）
- 照片模式（photo mode）功能
- 装备检视/背包界面中的身体部位展示
- 任何剧情需要的第三人称镜头

### 2. 资源削减决策矩阵

根据例外场景数量决定资源投入策略：

**完全削减（零投入）：**
- 完整身体高模/低模（如无反射需求）
- 常规循环动画：行走、奔跑、 idle、跳跃落地
- 身体部位贴图和材质
- 物理布料模拟（披风、衣摆等）

**保留开发（为例外场景投入）：**
- 简化的身体模型（仅用于反射/过场，可降低面数）
- 特定情境动画（仅覆盖已识别的例外场景）
- 第一人称可见部位（手、手臂、持枪/持物模型）

### 3. 成本效益计算

估算节约比例：
```
动画预算削减比例 = 1 - (例外场景动画数量 / 常规第三人称所需动画总量)
模型预算削减比例 = 1 - (例外场景模型复杂度 / 完整化身模型复杂度)
```

**决策原则：**
- 如果例外场景占总游戏时长 < 5%：采用极简方案（仅基础模型+必要动画）
- 如果例外场景占 5-20%：平衡方案（中等精度模型+关键动画）
- 如果例外场景 > 20%：重新评估第一人称视角的成本优势是否成立

### 4. 风险检查

确认以下情况不会导致问题：
- [ ] 游戏后期不会改为第三人称模式
- [ ] 多人模式中其他玩家看不到该化身（或已有独立的多人模型方案）
- [ ] 没有计划添加需要展示全身的 DLC 内容
- [ ] 镜子/反射场景确实很少出现（或可用模糊/特效替代）

## 输出模板

生成资源规划报告：

**可削减资源清单：**
- [资源类型]：[原预算] → 0（节约 100%）

**必须保留资源清单：**
- [资源类型]：[简化方案预算]（为例外场景：[具体场景列表]）

**成本节约估算：**
- 动画预算节约：[X]%
- 模型预算节约：[Y]%
- 总美术开发成本降低：[Z]%

**风险提示：**
- 已识别的例外场景：[列表]
- 潜在变更风险：[如有]

## 限制与注意事项

- **不适用情况：** 频繁切换至第三人称的游戏、过场动画占比较高的叙事游戏、需要频繁照镜子或使用反射解谜的游戏
- **技术债务：** 如果后期改为支持第三人称，需要补做全部资源，成本将高于一开始就采用第三人称方案
- **多人游戏：** 其他玩家看到的化身模型需要单独考虑，本优化仅针对第一人称玩家自身的视角
