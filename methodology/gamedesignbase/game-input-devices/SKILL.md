# 游戏输入设备分类与设计

## 使用场景
- 分析或设计游戏输入系统
- 选择合适的输入设备
- 开发体感游戏
- 编写输入处理代码

## 输入设备分类体系

### 第一维度：信号类型分类

**数字设备：**
- 条件：设备只能返回两种特定信号，没有其他信号
- 典型信号翻译：开(ON)和关(OFF)
- 示例：按钮、按键（按下=开，松开=关）

**模拟设备：**
- 条件：设备发送很多可能值中的一个（连续或离散的多值）
- 历史背景：游戏行业称这些设备为"模拟设备"，尽管所有底层技术都是数字的
- 关键注意点："模拟设备"是行业术语，不要与技术实现混淆

### 第二维度：数据维度分类
数据维度与信号类型（数字/模拟）完全独立，可任意组合：

- **一维设备**：发送一个数据值（如：单一轴的操纵杆、鼠标滚轮）
- **二维设备**：发送两个数据值（如：双轴操纵杆、D-pad）

### 第三维度：数值参考系分类

**绝对值设备：**
- 定义：返回设备的当前位置与中立位置的相对距离
- 物理特征：有中立位置，向任意方向移动有限距离
- 数值范围：只能发送从零到最大值之间的任意值
- 典型示例：操纵杆、触摸屏
- 关键机制：弹簧压载技术——玩家松手后自动返回中立位置

**相对值设备：**
- 定义：返回设备相对于上一个位置移动的距离（变化量）
- 物理特征：无限制的移动，没有中立位置概念
- 数值特征：可无限累积，无固定范围限制
- 典型示例：鼠标滚轮、轨迹球

### 特殊说明——鼠标
- 鼠标是明显的例外，不默认处于中立位置
- 鼠标移动属于相对值输入（返回相对于上一帧的位移）

## 设备分类示例

| 设备 | 信号类型 | 维度 | 数值类型 |
|------|---------|------|---------|
| 普通按钮 | 数字 | 一维 | - |
| 模拟扳机键 | 模拟 | 一维 | 绝对值 |
| 双轴操纵杆 | 模拟 | 二维 | 绝对值 |
| 鼠标移动 | 模拟 | 二维 | 相对值 |
| 鼠标滚轮 | 模拟 | 一维 | 相对值 |
| 四向D-pad | 数字/模拟* | 二维 | 绝对值 |

*注：D-pad实现方式可能不同，经典实现为数字（四方向+中立共5状态）

## Kinect设备技术架构

### 硬件数据采集
- Kinect使用相机和红外传感器检测玩家身体部位在三维空间中的位置
- 不同于传统控制器发送按钮或操纵杆位置信号

### 内置智能处理
- 设备内置相当大的智能处理能力
- 可自主组装数据，不对Xbox主机的CPU造成负担
- 备选方案：开发人员如需可直接从摄像机读取原始数据流

### 多人识别能力
- 能够识别六个单独的玩家
- 可同时跟踪其中两个玩家的移动
- 支持一个玩家局部覆盖另一个玩家时的跟踪（遮挡处理）

### 骨架跟踪系统
- 人体内部模型由二十个独立的身体部位组成
- 以骨盆为初始参考点
- 以四肢形式组织成层次结构
- 可提供每个骨架相对于层次结构中下一个更高骨架的旋转角度信息

### 输入方式扩展
- 核心设计理念：无控制器游戏
- 支持手势控制
- 支持语音命令（通过内置麦克风阵列）

### 与Wii Remote对比优势
- Wii Remote仅通过加速度计知道自己的运动
- 若Wii Remote在玩家手中，无法传送玩家脚的位置
- Kinect知道更多关于玩家的整体动作信息

### 主要缺点——缺乏触觉反馈
- Wii Remote按下按钮时有即时触觉反馈
- Kinect仅显示屏幕上的手势结果
- 玩家可感觉到手移动，但感觉不到运动中的阻力

### 与Xbox控制器组合使用问题
- 理论上可结合使用
- 实践中不令人满意的原因：
  * Xbox控制器设计为两手握持
  * 双手靠近时操作颇为勉强
  * 不允许做出大幅度的手势

### 精度演进
- 最初版本：不是很精确
- 最新版本（宣布）：能够识别面孔和个人手指位置

### 疲劳问题——长期使用的根本限制
- 任何手势界面长期使用都会让玩家感到疲劳
- 舞蹈和锻炼游戏中体力消耗是设计的一部分（可接受）
- 射击或战略游戏中玩家可能做出数百个动作
- 期望玩家连续几小时挥舞手臂是不合理的

### 开发建议
- Kinect正确使用是一项伟大的技术成就
- 可提供有趣而直观的游戏体验
- 不适合所有游戏类型
- 定位：更像专业控制器而非通用游戏设备
- 优化领域：舞蹈和其他运动活动
- 不适合领域：拍卖中投标、指定单位生产等精细操作
- 核心原则：围绕Kinect的优势开发，以物尽其用

## 执行流程

### 设备分类判定
```
1. 确定信号类型：数字或模拟
2. 确定数据维度：一维或二维
3. 确定数值类型：绝对值或相对值
4. 输出分类标签：[信号类型]-[维度]-[数值类型]
```

### 输入处理代码编写
根据分类标签确定数据类型：
- 数字设备：布尔值
- 模拟绝对值设备：0-1浮点数或-1~1范围
- 模拟相对值设备：无界增量值

### Kinect适用性判断
```
IF (需要无控制器体感输入 AND 游戏类型适合身体活动)
THEN 考虑使用Kinect作为输入设备
ELSE 考虑其他输入设备
```
