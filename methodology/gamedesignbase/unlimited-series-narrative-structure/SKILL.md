# 无限制系列剧叙事结构设计

## 何时使用

- 计划发布多部分故事内容，但希望玩家可以自由选择游玩顺序
- 设计游戏系列，每部作品需要独立成章又可扩展
- 开发插话式内容（Episodic Content），如季度更新、DLC章节
- 需要降低新玩家入坑门槛，无需前作经验也能享受当前内容

## 核心原则

**独立成章，统一世界观**

每集/每部游戏讲述完整故事，但共享同一主题或背景设定。

## 执行步骤

### 1. 确立系列统一框架

定义贯穿全系列的不变元素：
- **世界观背景**：时间、地点、规则设定
- **主题基调**：情感氛围、核心议题、风格特征
- **标志性元素**：视觉风格、音乐主题、标志性角色或组织

> 示例：《神秘海域》系列统一框架——现代寻宝冒险、历史谜题、动作电影风格

### 2. 设计单集独立结构

每集必须包含完整叙事闭环：

| 要素 | 要求 |
|------|------|
| 情节引入 | 新玩家能立即理解当前情境 |
| 冲突发展 | 独立的核心矛盾，不依赖前作铺垫 |
| 高潮解决 | 本集主要问题得到明确解决 |
| 角色弧光 | 本集内完成角色成长或揭示 |

### 3. 确保任意顺序可游玩

检验清单：
- [ ] 移除对前作情节的直接依赖
- [ ] 避免"接上回"式的开场
- [ ] 关键设定在本集内重新介绍
- [ ] 角色关系通过对话自然建立，而非预设玩家已知

### 4. 处理续作关联（可选）

如需声称剧情延续：
- 使用松散关联：同一角色的新冒险、同一世界的新事件
- 彩蛋式呼应：提及前作事件但不影响理解当前剧情
- 状态继承：仅保留角色基础设定，不涉及前作具体情节

### 5. 规划扩展空间

利用结构优势规划内容：
- 每集使用相同制作管线，降低边际成本
- 预留支线角色可发展为后续主角
- 世界观角落可探索为新故事舞台

## 快速检验

用以下问题验证设计：
1. 从未玩过本系列的玩家能否直接享受这一集？
2. 调换任意两集的顺序，体验是否仍然完整？
3. 关闭本集后，玩家是否感到故事已结束而非中断？

三项皆为"是"，则结构正确。
