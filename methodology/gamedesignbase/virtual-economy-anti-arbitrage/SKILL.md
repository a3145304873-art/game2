# 虚拟经济反套利原则

## 使用时机
当以下情况时应用此原则：
- 设计游戏经济系统
- 允许玩家创造/制作物品
- 存在物品交易或NPC回购机制
- 检查经济系统平衡性
- 防止玩家利用漏洞获取无限资源

## 核心原则

在任何经济系统中，玩家不能凭空创造出一些物品，这是十分基本的原则。如果这样做了，他们就不能将这些物品用比最初花费高的价格返回到系统。

## 违反原则的后果

### 后果链
1. **允许套利**：玩家以零成本或低成本创造物品，以高于成本的价格返售给系统
2. **系统化利用**：玩家会找到方法来实施这一过程
3. **无限资源流动**：创造出一个没有限制的资源流动
4. **经济崩溃**：破坏游戏内经济平衡，导致恶性通货膨胀

## 实施约束条件

### 防止套利的基本要求

1. **创造成本明确**
   - 所有可售回系统的物品必须有明确的创造成本
   - 成本包括：时间、材料、货币
   - 成本不可降低或规避

2. **回购价格限制**
   - 系统回购价格 ≤ 创造该物品的最低总成本
   - 确保玩家无法通过制作-销售循环获利

3. **禁止无中生有**
   - 禁止"creation from nothing"的套利循环
   - 所有创造必须有对应的资源消耗

## 设计检查清单

### 制作配方检查
- [ ] 检查所有制作配方：输入资源总价值 ≥ 输出物品系统回购价？
- [ ] 检查时间成本：玩家时间投入是否足以阻止大规模自动化套利？
- [ ] 检查外部性：是否存在利用BUG或设计漏洞的零成本创造路径？
- [ ] 检查边际成本：是否存在规模效应导致边际成本趋近于零？

### 回收系统检查
- [ ] 回收价格是否低于制作成本？
- [ ] 是否存在可循环利用的漏洞？
- [ ] 回收是否会产生额外资源？

### 交易系统检查
- [ ] 玩家间交易是否可能被用于套利？
- [ ] 是否存在可利用的价格差异？
- [ ] 交易税是否足以阻止套利行为？

## 例外情况管理

### 允许"无中生有"的情况
如果允许某些"无中生有"（如任务奖励、随机掉落），则这些物品必须：

1. **标记为不可交易**（account bound）
2. **设置为不可售回系统**（无NPC收购价）
3. **通过其他机制防止进入经济循环**

### 特殊设计考虑

1. **时间成本折算**
   - 将玩家时间投入折算为经济成本
   - 确保时间成本足以阻止自动化套利

2. **机会成本**
   - 考虑玩家制作物品的机会成本
   - 确保其他活动更有利可图

3. **稀缺性机制**
   - 限制某些材料的获取量
   - 通过稀缺性控制经济流动

## 与闭合经济的关系

### 独立性
- 此原则独立于资源循环机制
- 即使在开放经济（周期性注入资源）中，此原则仍然适用

### 底线规则
- 是防止经济系统崩溃的底线规则
- 违反此原则必然导致经济失衡

## 监控与调整

### 经济指标监控
1. **货币供应量**：监控游戏内货币总量变化
2. **物价指数**：监控关键物品价格波动
3. **玩家财富分布**：监控贫富差距
4. **交易量**：监控异常交易活动

### 异常检测
1. **套利行为检测**：识别异常的创造-销售模式
2. **漏洞利用检测**：识别可能的BUG利用
3. **机器人检测**：识别自动化脚本

### 调整机制
1. **动态调整**：根据经济数据动态调整价格
2. **紧急修复**：发现严重套利漏洞时立即修复
3. **回滚机制**：在严重情况下考虑经济回滚

## 输出结果

生成包含以下内容的评估报告：
1. 套利风险评估：识别所有可能的套利路径
2. 经济健康检查：评估当前经济系统的平衡性
3. 风险警告：如果arbitrage_margin > 0，发出高风险警告
4. 调整建议：具体的调整方案（制作成本、回购价格等）
5. 监控计划：持续监控经济健康的指标和方法
