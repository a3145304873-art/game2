# 反套利系统变量定义

| 变量名 | 类型 | 描述 |
|-------|------|------|
| creation_cost | float | 物品创造总成本（材料成本+时间成本折算+机会成本） |
| sellback_price | float | 系统回购价格或市场平均交易价格 |
| arbitrage_margin | float | 套利空间计算：售回价 - 创造成本（必须≤0） |
| exploit_risk | boolean | 是否存在系统化批量套利的可能性 |

## 套利空间计算公式

```
arbitrage_margin = sellback_price - creation_cost

如果 arbitrage_margin > 0，则存在套利风险
理想状态：arbitrage_margin ≤ 0
```

## 创造成本计算

```
creation_cost = material_cost + time_cost + opportunity_cost

其中：
- material_cost：所有输入材料的市场价值总和
- time_cost：玩家时间投入的经济价值（可按平均时薪折算）
- opportunity_cost：玩家在此期间可获得的替代收益
```

## 常见套利漏洞类型

### 1. 材料价值低估
- **问题**：某些材料的市场价值低于实际价值
- **后果**：玩家可低成本制作高价物品
- **解决**：定期更新材料价值评估

### 2. 时间成本忽略
- **问题**：未考虑玩家时间投入的经济价值
- **后果**：自动化脚本可无限套利
- **解决**：引入时间成本或制作冷却

### 3. 规模效应
- **问题**：批量制作降低单位成本
- **后果**：大规模生产导致套利
- **解决**：引入边际成本递增机制

### 4. 回收漏洞
- **问题**：物品回收价值高于制作成本
- **后果**：创造-回收循环套利
- **解决**：确保回收价值 < 制作成本

## 经济健康指标

### 关键指标
1. **货币供应量增长率**：月度货币供应量变化百分比
2. **通货膨胀率**：关键物品价格指数变化
3. **基尼系数**：玩家财富分配不平等程度
4. **交易活跃度**：日均交易量和交易额

### 警戒阈值
| 指标 | 正常范围 | 警戒范围 | 危险范围 |
|------|---------|---------|---------|
| 货币增长率 | < 5%/月 | 5-10%/月 | > 10%/月 |
| 通货膨胀率 | < 3%/月 | 3-5%/月 | > 5%/月 |
| 基尼系数 | < 0.4 | 0.4-0.5 | > 0.5 |
