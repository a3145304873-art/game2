## 石头-剪子-布改进案例详解

### 蜥蜴-蛙-老鼠赛跑

**基础设定**
- 蜥蜴：多岩石路面表现最好
- 蛙：沼泽地表现最好  
- 老鼠：多草土地表现最好

**影子成本设计**
- 蛙：其他地形上稍微有点慢
- 老鼠：游泳时每隔15秒停下来呼吸
- 蜥蜴：地形转变处速度急速下降

**赛道设计关键**
混合岩石地、草地和沼泽，给玩家**部分而非全部**自由选择路线的权力

### 《VR战士3》动作循环
攻击动作 → 打败 → 投掷动作 → 打败 → 阻碍动作 → 打败 → 攻击动作

### 《上古战争艺术》单位循环
骑士 → 克制 → 野蛮人 → 克制 → 弓箭手 → 克制 → 骑士
