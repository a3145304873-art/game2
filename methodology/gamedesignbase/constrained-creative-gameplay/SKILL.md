# 受限创造型玩法设计

## 何时使用
- 游戏类型为建设/管理模拟或创造型游戏
- 规则设定了经济限制
- 需要玩家建造功能性物体
- 提供基础创造力工具但需要约束框架

## 执行步骤

### 1. 应用经济限制机制

**定义框架：**
如果玩家只能在规则规定的人为限制里进行创造，称为"受限的创造型玩法"。这种限制为玩家的创造力提供了一个框架，而非单纯地限制创造力。

**经济限制逻辑：**
- 玩家不能快速完成整个创造过程（如建造整个城市）
- 每一项操作（如圈占每一小块空地）都需要消耗金钱
- 玩家只能使用"已获得的金钱"进行消费

**成长与循环机制：**
- 随着创造物（如城市）的繁荣，玩家赚取更多的钱
- 利用增加的资金建立新的区域（如附近的新城区）
- 当资金积累到足够程度后，可以建立初期昂贵的新设施（如体育场和机场）
- 只要经济持续增长，创造物就可以变得越来越大，并加入更多设施

**系统类比与核心挑战：**
- **类比RPG：** 如同角色扮演游戏中玩家获得经验以学习新魔法技能
- **类比战略游戏：** 如同战略游戏中玩家获得资源进行研究以获得更好武器
- **核心差异：** 在创造型游戏中，经济限制了玩家的"创造能力"
- **主要挑战：** 成功的经济管理是游戏的主要挑战
- **回报机制：** 创造力变成了成功的回报

**工具进阶奖励：**
- 一旦玩家掌握了已有的工具，系统会奖励技能
- 给予玩家"更刺激、更强大的工具"
- 注：教育软件也使用了这种方法

### 2. 应用物理标准约束机制

**核心设计模式：**
给玩家提供完整的工具和资源库，但强制要求建造物符合特定物理标准

**标准类型包括：**
- 结构完整性（如必须有脊柱骨干）
- 功能安全性（如过山车不能损坏或伤人）
- 性能指标（如刺激度）

**成功案例分析：**

**《孢子》(Spore)案例：**
- 提供标准部件：手臂、腿部、眼睛、耳朵、爪（武器）
- 物理约束：每个生物必须有脊柱骨干；必须是陆地生物
- 明确禁止：无骨骼生物（如昆虫）、软体动物（如章鱼）
- 反馈机制：投入游戏世界战斗/社交，赢得"DNA点数"解锁新特征

**《过山车大亨》系列案例：**
- 双重约束：物理标准 + 经济预算限制
- 物理标准细则：过山车不能损坏、不能使乘客受伤、必须提供刺激体验
- 辅助学习工具：《过山车大亨2》提供高度和陡峭度可视化显示，支持玩家通过实验计算结果

**关键设计原则——失败反馈机制：**
- "在任何时候如果你要求玩家依照一个标准建造，然后测试他的建造物，那他失败的时候就会想知道原因。否则他就无法学会这个建立在标准之上的规则"
- 必须提供可观测、可分析的反馈数据，使玩家能够通过实验迭代改进

**物理标准的灵活性：**
- 游戏物理不必符合真实世界物理定律
- 《我的世界》案例：拥有丰富但完全不同于现实的物理规律，支持构建电脑等复杂装置
- 设计要点：内部一致性 > 真实世界准确性

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| earned_money | currency | 玩家已获得的金钱，用于支付建设成本 |
| creative_capability | capacity | 玩家能够建造的规模和复杂度，受经济状况限制 |
| 工具资源库 | 集合 | 玩家可用的建造部件和材料 |
| 物理标准集合 | 规则集 | 必须满足的结构、功能、安全等约束条件 |
| 测试反馈机制 | 系统 | 显示失败原因和性能数据的功能 |
| 经济约束 | 数值 | 可选的预算限制，与物理标准形成复合挑战 |
