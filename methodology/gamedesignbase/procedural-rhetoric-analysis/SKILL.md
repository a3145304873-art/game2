# 程序修辞分析

## 何时使用

当你需要评估以下类型游戏的信息传达方式时：
- **广告游戏**（Advergames）：推广产品或服务的游戏
- **政治/宣传游戏**：传达政治观点或促进特定事业的游戏  
- **公益教育游戏**：非营利组织用于推广特定议题的游戏

**触发条件**：游戏具有明确的非娱乐目的（传达信息、改变观点、推广事业），需要分析其说服方式。

**不适用场景**：纯娱乐游戏，无明确传达意图的项目。

## 核心概念

### 程序修辞（Procedural Rhetoric）
通过**游戏机制**（规则、交互、系统）本身来传达信息或观点，而非依赖文本、对话或剧情等**明确叙述**手段。玩家通过"游玩过程"理解论点，而非通过"阅读/观看"。

### 明确叙述（Explicit Narration）
通过文本、语音、过场动画直接讲述故事或传递信息。即使移除游戏机制，仅保留叙述内容，信息仍然完整。

## 分析步骤

### 步骤1：验证适用性
确认该游戏属于"有说服力的游戏"范畴：
- [ ] 主要用途是否为传达特定信息、观点或推广特定事业？
- [ ] 应用场景是否为产品广告、政治事业促进或慈善机构推广？
- [ ] 游戏是否不仅限于娱乐功能？

**如果以上任一答案为"否"，停止分析**——该技能不适用于纯娱乐游戏。

### 步骤2：解构信息传达渠道
分别识别游戏通过哪些层面传达核心信息：

| 层面 | 判定标准 | 检查项 |
|------|---------|--------|
| **程序层** | 机制即论点 | 游戏规则、胜利条件、可选范围、交互反馈是否本身构成论证？ |
| **叙述层** | 文本即论点 | 是否依赖对话、剧情、说明文字、过场动画传达核心信息？ |

### 步骤3：判定程序修辞属性
**符合程序修辞的标准**（需同时满足）：
1. 核心信息主要通过**游戏机制**进行传达
2. 玩家通过**交互过程**（而非被动观看）理解信息
3. 若移除所有文本/对话，游戏仍能传达其核心观点或立场

**排除标准**（符合以下任一即为"明确叙述主导"）：
- 信息主要通过文本、语音或过场动画直接陈述
- 游戏机制仅为叙事载体，核心论点在剧情中显性表达

### 步骤4：输出分类结论
根据分析结果，将游戏归类为：

**A类：强程序修辞**
- 机制本身构成说服逻辑
- 玩法过程即论证过程

**B类：混合模式**
- 机制与叙述共同作用
- 但机制具有独立表意功能

**C类：叙述主导**
- 核心信息依赖明确叙述
- 机制仅提供娱乐包装

## 分析示例：汉莎航空《虚拟飞行》

**项目背景**：基于网页的飞行员地理知识测验游戏

**表面形式**：
- 测验玩家对欧洲城市名称和地理位置的知识
- 问答式互动玩法

**程序修辞识别**：
1. **机制设计**：题目仅包含汉莎航空开通航班的城市
2. **隐性传达**：通过"可被选中的城市集合"这一机制，巧妙促进飞行员对汉莎航线地图的内化认知
3. **无强制叙述**：没有文本直接宣传"汉莎航线覆盖广泛"，而是通过可选城市范围让玩家在游玩中自行领悟网络覆盖度

**判定结果**：典型的程序修辞应用——通过游戏机制（可选城市范围）而非明确广告文本传达商业信息。

## 输出模板

```
游戏名称：[名称]
说服意图：[广告/政治/公益/其他]
程序修辞判定：[强程序修辞/混合模式/叙述主导/不适用]

机制分析：
- 核心机制：[描述关键规则/交互]
- 传达的信息：[机制隐含的论点]
- 移除文本后是否仍能传达：[是/否]

叙述分析：
- 主要手段：[文本/对话/过场动画/无]
- 传达的信息：[显性陈述的内容]

结论：
该游戏通过[程序修辞/明确叙述/混合方式]实现说服目的。
[具体说明机制如何支持或削弱核心信息的传达]
```

## 常见误区提醒

- **误区**：游戏包含教育内容即等于程序修辞  
  **纠正**：若教育内容通过文字说明或对话直接呈现，仍属于明确叙述

- **误区**：广告游戏自动具备程序修辞  
  **纠正**：若广告仅作为游戏背景或剧情元素出现，而玩法与产品无关，则属于叙述层植入

- **误区**：机制复杂即等于修辞有效  
  **纠正**：关键在于机制是否与论点同构（isomorphic），而非复杂度
