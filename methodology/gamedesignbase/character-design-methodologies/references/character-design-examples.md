# 角色设计详细案例

## 艺术驱动设计案例

### 卡通风格游戏
- **优势**：对于简单角色效果最佳，便于跨媒体商业化
- **典型应用**：喜剧书、玩具等衍生产品开发
- **设计者类型**：倾向于视觉的设计者

### 不适用案例
- 《半条命》戈登·弗里曼：第一人称不可见，无视觉设计需求
- 无实体角色：仅通过耳机、心灵感应等方式沟通

## 故事驱动设计案例

### 《力量高尔夫》设计要点
- 包含自定义角色的能力
- 故事线设计
- 丰富的内嵌小游戏
- 玩家选择角色并开始了解她，增强沉浸感
- 非线性情节：玩家可任意选择朋友或敌人，选择影响游戏可玩性

### 角色交互的重要性
- 角色间的交互是故事中最有趣的方面
- 将优秀故事与简单作文区别开来
- 增加故事的趣味和微妙之处

## 命名风格对比

### 显眼名字集合
- **特点**：每个名字都精挑细选表示一个种族或老套人群
- **效果**：削弱真实性，增强卡通感
- **适用**：卡通风格游戏

### 含蓄命名策略
- **劳拉·克劳馥**：暗示英国上层人气质
- **西尔维斯特（Sly）**：昵称暗示狡黠个性
- **时代感命名**：使用"左轮手枪"等用语唤起20世纪三四十年代侦探小说感

## 特征设计警告
- **过多特征**：超过3个特征会让角色显得可笑
- **刻板印象**：避免使用令人反感的刻板印象
- **网络用语**：注意时效性，发行6个月后可能过时
