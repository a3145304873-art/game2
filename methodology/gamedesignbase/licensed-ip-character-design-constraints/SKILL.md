# 授权IP角色设计约束

## 何时使用

当你正在设计以下类型的游戏时，使用此技能：
- 授权IP游戏（漫威英雄、迪士尼公主等）
- 影视改编游戏
- 漫画改编游戏
- 任何使用已有版权形象而非原创角色的项目

## 核心原则

**禁止覆盖已建立的玩家-化身关系**

玩家已通过电影、漫画、电视等其他媒体与角色建立了关系。这种跨媒介的预先存在关系决定了玩家对游戏化身的期望。

## 执行步骤

### 1. 识别适用对象
确认角色是否符合以下条件：
- [ ] 角色在电影、漫画、电视等其他媒体中已存在
- [ ] 玩家已通过其他媒介接触过该角色
- [ ] 非全新创作的原创角色

### 2. 评估既有关系
分析角色在原始媒介中的特征：
- **IP来源**：电影、漫画、动画等原始媒体类型
- **既有关系类型**：角色与受众建立的关系模式（英雄、反派、喜剧角色等）
- **个性深度**：角色是否具有完全指定的独立人格

### 3. 应用设计约束
根据既有形象限制设计选择：

| 角色类型 | 禁止的设计 | 必须延续的特征 |
|---------|-----------|--------------|
| 完全指定角色（如钢铁侠） | 设计为沉默的非指定化身 | 保持其特定性格、说话方式、行为模式 |
| 标志性角色（如米老鼠） | 设计为自私、阴沉或违背核心特质的行为 | 保持其乐观、友好的标志性个性 |

### 4. 验证合规性
检查你的设计是否：
- [ ] 尊重角色在其他媒体中的既定形象
- [ ] 延续已建立的角色个性和行为模式
- [ ] 维持与受众的既定关系动态
- [ ] 未尝试"重新设计"玩家与角色的关系

## 关键警告

⚠️ **高风险**：如果违背玩家对授权IP角色的既有认知，将导致玩家拒绝和负面反馈。

## 设计自由度说明

相对于原创角色，授权IP的设计自由度极低：
- 无法控制机制（直接/间接）与指定化程度的组合
- 角色已有的个性深度已固定
- 必须接受并延续跨媒介的既定关系
