# 分支故事技术架构详细说明

## 运行时跟踪机制

故事讲述引擎必须持续跟踪：
- 玩家在任何给定时间正在跟随的具体情节线
- 当前活跃的情节线状态
- 游戏事件与正确叙事路径的关联

## 分支触发流程

1. 故事到达分支点
2. 核心机制向故事讲述引擎发送触发信息
3. 触发信息明确告知玩家将进入哪一个可能的分支
4. 判定依据为游戏事件：
   - 玩家事件（Player Events）：由玩家主动产生的行为
   - 核心机制事件（Core Mechanism Events）：由游戏内系统产生的事件

## 情感结果差异

基于挑战的分支与基于选择的分支会产生不同的情感结果：
- 挑战分支：成功带来成就感，失败带来挫败感
- 选择分支：反映玩家价值观，可能带来道德冲突或认同感

## 示例参考

- 《猴岛的秘密》：反送故事结构
- 《星球大战4：新希望》：欧比旺之死作为不可避免事件
- 《哈姆雷特》改编：单一结局限制策略的应用场景
