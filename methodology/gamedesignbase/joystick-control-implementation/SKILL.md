# 操纵杆核心机制与数据输出

## 何时使用

- 设计交通工具驾驶控制（飞机、车辆）
- 需要同时控制方向和速率的场景
- 评估移植鼠标游戏到控制台的方案可行性
- 配置Sony SIXAXIS等双操纵杆控制器

## 物理结构与数据输出

### 结构特征
- 单个垂直杆，底部锚定
- 任意方向有限倾斜
- **弹簧加载机制**：松手自动返回中心

### 数据输出
| 轴 | 含义 | 数据类型 |
|---|------|---------|
| X值 | 左右倾斜度 | 绝对模拟值 |
| Y值 | 前后倾斜度 | 绝对模拟值 |

## 核心优势：交通工具驾驶

### 默认值恢复
- 操纵杆回中 = 恢复默认值（如水平飞行）

### 速率控制特性
| 输入 | 解释 |
|------|------|
| 轻微左倾 | 缓慢左转 |
| 大幅左倾 | 快速左转 |
| 回中 | 停止转向，恢复直行 |

**关键**：倾斜幅度与转向速率正相关

## 精确指向的局限性 ⭐关键限制

### 根本问题
玩家放手 → 操纵杆回中心 → 光标指向别处

### 对比：鼠标优势
- 玩家做其他事情时
- 光标保持不动

### 移植警告
> 将基于鼠标的游戏移植到控制台使用操纵杆控制，**成功率非常低**

## 现代配置

Sony SIXAXIS控制器：底部双小操纵杆（圆形对象）

飞行战斗模拟操纵杆：额外数字按钮或滑动开关
