# 游戏设计基础概念

## 核心定义

### 电子游戏的定义
- **判定标准**：通过计算机运行的游戏
- **计算机范围**：从微型设备（如电子宠物）到大型电玩环境
- **关键区分**：游戏（规则、机制、体验）vs 游戏软件（实现游戏的程序代码）

### 游戏可玩性（Gameplay）
- **核心构成**：挑战 + 动作
- **本质关系**：挑战与用来克服这些挑战的动作之间的关系
- **判定规则**：如果一项活动没有游戏可玩性，即使有趣，也不是游戏

## 游戏基本组成要素

1. **玩（操作）**：玩家与系统的交互方式
2. **假想**：游戏构建的虚构世界或情境
3. **任务目标**：玩家需要达成的具体目的
4. **游戏规则**：限制和指导玩家行为的规范

## 娱乐与乐趣的区别

- **娱乐**：含义比"有趣"更广泛，包括感动、沉思或启发性的体验
- **游戏侧重**：大部分游戏专注于传递"乐趣"

## 判定流程

```
检查是否通过计算机运行 → 否 = 非电子游戏
                          ↓ 是
检查是否具备游戏基本要素 → 否 = 计算机应用但非游戏
                          ↓ 是
确认为电子游戏
```

## 应用场景

- 建立游戏设计理论框架
- 分析游戏本质特征
- 区分游戏与游戏软件
- 评估某活动是否属于游戏
