# 游戏UI文本字体与格式规范

## 适用场景
- 游戏UI设计阶段
- 文本排版阶段
- 本地化游戏文本处理
- 商业游戏项目开发

## 核心规范

### 1. 字体尺寸规则

**罗马文本**：
- 屏幕显示的最小尺寸应约为12个像素点
- 如果字体比它还小，文字就不容易辨认

**非罗马文本（如日语）**：
- 12像素点是绝对最小值
- 一般建议以16像素点为宜

### 2. 大小写使用规则

**混合大小写**：
- 对于任何长于3个或4个单词的文本块，必须混合使用大写和小写字母
- 混合大小写更易于阅读

**全大写限制**：
- 玩家发现全部设置为大写字母的文本不容易阅读
- 全大写会创造出一种不适当的紧张感（例如"SHOUTING"）

**例外情况**：
- 在确实要求紧张感的情况下，例如"DANGER"（危险）警告信息，就非常适合使用大写字母

### 3. 字体许可检查
- 虽然计算机经常带有各种免费字体，但许多字体必须获得使用许可
- **强制要求**：在发布商业游戏之前，请确保你有权使用计划选用的字体
- 保留所有字体许可文档

### 4. 字体选择策略

**主题和谐**：
- 仔细选择字体，使其与游戏主题看起来很和谐

**数量控制**：
- 避免使用太多不同的字体
- 否则看起来会显得业余
- 建议：整个游戏使用2-3种字体即可

**分类区分**：
- 需了解表现性字体（用于标题）和普通的衬线字体及非衬线字体（用于文本块）之间的区别
- 表现性字体：用于标题、特殊强调
- 衬线/非衬线字体：用于正文、UI文本

### 5. 字体类型选择

**避免等宽字体**：
- 避免使用像Courier这样的等宽（或者固定宽度）字体

**推荐均衡字体**：
- 取而代之的是使用像Times这样的均衡（比例）字体

**例外情况**：
- 除非你需要显示一个表格，其中的字体一定要在一列中排成行

**原因**：
- 对于其他用途，固定宽度的字体会浪费空间
- 看起来过时且不能吸引人

## 约束条件
- 不适用于纯艺术性文字设计（需特殊处理）

## 输出成果
生成符合清晰度、可读性和版权要求的UI文本设计方案。
