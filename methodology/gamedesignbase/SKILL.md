# 游戏设计专业技能集合

本技能集合源自专业游戏设计书籍，涵盖了游戏设计的完整知识体系。从核心机制设计、叙事构建、角色塑造到多人游戏架构、平台策略和商业模式，为游戏设计师、开发者和学习者提供系统化的设计指导。这些技能帮助用户解决从概念构思到产品发布的各类设计挑战。

## Available Skills

| Skill | Description | Use When |
|-------|-------------|----------|
| [game-design-foundations](game-design-foundations/SKILL.md) | 建立游戏设计作为可学习手艺的认知基础，应用核心机制的简单与优雅原则 | 学习游戏设计理论、设计核心游戏系统或分析现有游戏 |
| [core-game-mechanism-design](core-game-mechanism-design/SKILL.md) | 从早期设计文档提取、定义和精确化游戏核心机制的系统化方法 | 游戏设计初期需要将模糊概念转化为可实现的精确机制 |
| [game-ui-design](game-ui-design/SKILL.md) | 设计游戏用户界面，包括屏幕按钮、菜单系统和按键配置 | 游戏过程过于复杂无法仅用控制器按钮完成，或需要实现按键重设置功能 |
| [game-narrative-design](game-narrative-design/SKILL.md) | 设计游戏叙事系统，包括故事编写阶段规则、结局设计逻辑 | 设计游戏故事、确定结局机制、集成叙事与游戏可玩性 |
| [character-design-comprehensive](character-design-comprehensive/SKILL.md) | 游戏角色设计的完整工作流程，包括早期设计规范、文档编写标准 | 包含主要角色的游戏，特别是非第一人称视角游戏 |
| [multiplayer-game-design](multiplayer-game-design/SKILL.md) | 设计多人游戏系统，包括本地多人游戏的技术限制、在线聊天系统设计 | 设计本地多人游戏、实现多人聊天功能、或需要管理玩家通信行为 |
| [level-design-workflow](level-design-workflow/SKILL.md) | 关卡设计从概念移交到最终测试的完整工作流程 | 关卡设计师需要系统化设计关卡、与团队协作移交 |
| [platform-development-strategy](platform-development-strategy/SKILL.md) | 分析和选择游戏开发平台（PC vs 家用游戏机），评估硬件特性 | 评估开发平台选择、分析不同平台开发成本与流程 |
| [game-audio-design](game-audio-design/SKILL.md) | 设计游戏音效和音乐系统 | 游戏需要设计音效系统、需要为特定游戏事件添加声音反馈 |
| [game-genre-design](game-genre-design/SKILL.md) | 理解电子游戏分类体系、冒险游戏核心特征以及交通工具模拟游戏设计原则 | 游戏类型分类、特定类型游戏设计和游戏类型学研究 |
| [game-business-models](game-business-models/SKILL.md) | 选择和实施游戏商业模式（广告、赞助、免费增值、免费游戏） | 网络游戏、免费游戏、移动端F2P游戏、需要盈利策略的游戏项目 |
| [game-localization](game-localization/SKILL.md) | 帮助游戏开发团队将游戏适配到目标国家/地区市场 | 游戏需要在原始设计国家以外的国家/地区发布 |
| [player-centered-design](player-centered-design/SKILL.md) | 以玩家为中心的游戏设计原则，包括特征筛选流程、角色扮演机制 | 设计或评估游戏中的任何元素、需要扩大受众群体 |
| [game-development-process](game-development-process/SKILL.md) | 游戏开发全流程管理，包括预生产原型开发、正式生产阶段职责 | 游戏项目管理者、游戏设计师需要管理开发流程 |
| [game-world-design](game-world-design/SKILL.md) | 当需要构建游戏世界的视觉表现和内在逻辑、或设计关卡环境 | 需要建立一致世界观的游戏项目 |
| [game-accessibility-design](game-accessibility-design/SKILL.md) | 当进行游戏辅助功能设计或分析游戏可访问性需求时使用 | 识别四大功能受损类别，制定查阅IGDA等专业资源的研究计划 |

## How to Use

这些技能可以通过以下方式使用：

1. **直接引用**：在对话中明确提及技能名称，例如"请使用 `game-ui-design` 技能来帮我设计这个游戏的用户界面"

2. **场景触发**：描述你的设计任务或问题，系统会自动识别并调用最相关的技能

3. **浏览探索**：通过上方的分类导航浏览相关技能，找到适合你当前需求的技能

4. **组合使用**：对于复杂项目，可以组合使用多个技能，例如先使用 `game-concept-generation` 生成创意，再用 `core-game-mechanism-design` 定义核心机制

每个技能都包含详细的指导原则、设计方法和最佳实践，帮助你在游戏设计的各个阶段做出专业决策。
