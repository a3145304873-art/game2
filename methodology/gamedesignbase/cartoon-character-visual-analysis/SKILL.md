# 卡通角色视觉分析法

## 使用时机
当需要以下情况时使用此技能：
- 分析现有卡通角色设计
- 进行竞品角色分析
- 为新角色设计提供参考
- 评估角色视觉吸引力

## 前置条件
- 选择从未玩过的游戏（确保没有游戏机制干扰视觉判断）
- 准备卡通风格角色样本
- 具备视觉分析能力
- 了解玩家心理学基础

## 分析流程

### 第一步：初始视觉印象采集
严格选择"从未玩过的游戏"，观察并记录：
- 角色的一般外形（General Appearance）
- 第一印象
- 视觉符号
- 色彩方案
- 造型比例
- 风格特征

### 第二步：吸引力特征分析
深入分析角色吸引玩家的视觉要素：
- 造型语言
- 色彩心理学应用
- 身体比例
- 服饰配饰
- 标志性特征
- 识别哪些视觉元素成功传达了角色个性

### 第三步：目标玩家类型匹配
确定视觉风格与玩家群体的关联性：
- 分析视觉风格（可爱、酷炫、搞笑等）
- 匹配特定玩家群体偏好（儿童、青少年、硬核玩家等）
- 评估设计的受众定位准确性

### 第四步：设计优化建议
基于纯视觉分析提出改进方案：

**添加分析（Additions）**：
- 识别是否有想要添加的内容
- 必须详细说明添加的理由（基于视觉逻辑或吸引力增强）

**删除分析（Deletions）**：
- 识别是否存在想要删除的内容
- 解释删除的理由（基于冗余、冲突或减损吸引力）

## 输出结果
结构化分析报告，包含：
1. 视觉印象记录
2. 吸引力要素拆解
3. 目标玩家画像
4. 带理由的设计增删建议

## 重要约束
- 必须基于视觉外形分析而非实际游戏体验
- 必须考虑玩家类型匹配
- 必须提出具体的添加/删除建议及理由
