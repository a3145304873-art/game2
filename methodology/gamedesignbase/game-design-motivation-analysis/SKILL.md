# 游戏设计动机分析

## 何时使用
- 需要分析游戏项目的开发驱动力
- 评估项目风险
- 确定设计重心
- 分析游戏失败原因
- 制定开发策略

## 执行步骤

### 1. 识别设计动机类型

根据游戏开发的主要驱动力和目标，将游戏设计动机分为以下五类：

#### 1. 市场驱动型

**定义：** 为特定市场专门制作，并在设计中包含某些元素以提高市场销售。

**常见误区：** 认为任何为销售而制作的游戏都是市场驱动型。

**风险：**
- 大多数市场驱动型游戏并不成功
- 不能简单地投入所有可玩性的流行元素
- 否则游戏会缺乏独特性，感觉不到是一款特定的游戏

**成功关键：** 最好的游戏是设计者想象力的表达，这能使游戏与众不同。

#### 2. 设计者驱动型

**定义：** 设计者保留所有的创造性支配，并在微小的创造性决定中扮演个人角色。

**动机：** 设计者相信自己的创造能力优于其他人。

**风险：**
- 忽视可玩性或忽视集体智慧的好处
- 结果总是得到很拙劣的游戏

**案例：** 游戏《大刀》常被引用作为失败的例子。

#### 3. 许可证型

**定义：** 使用许可证（特殊的知识产权，如书籍《指环王》、电影《虎胆龙威》、运动商标"NHL Hockey"）代理开发游戏。

**优势：**
- 利用已存在的角色和世界进行创造性工作
- 为该世界材料的规则做贡献

**缺点：**
- 没有完全按自己想法设计的自由
- 许可证所有者有批准发行的权利，也有要求修改的权利

**风险：** 存在自满风险。单靠一个好的许可证不足以保证成功，设计出的游戏必须像没有许可证时一样优秀。

#### 4. 技术驱动型

**定义：** 为了展示特殊的技术成就（通常是图形或硬件部件）而设计。

**目的：**
- 除了取悦玩家外，有意展示技术功能并鼓励其他开发者采用
- 在新平台发布时展示新机型特征

**风险：** 花费大量时间关注技术，但这不能保证设计出的游戏真正好玩。单靠新技术无法保证成功。

#### 5. 艺术驱动型

**定义：** 为了展示某些人的艺术作品和审美情趣。

**特点：** 视觉上的创新。

**风险：**
- 设计者在考虑呈现素材上花费的时间多于考虑玩家对游戏体验
- 很很少有非常优秀的

**成功关键：** 游戏必须要有令人愉悦的可玩性，这与强烈的视觉效果同样重要。

**案例：** 《神秘》是一款带有很强可玩性的艺术驱动型游戏。

### 2. 评估项目风险

根据识别出的动机类型，评估项目可能面临的风险：

| 动机类型 | 主要风险 | 成功关键 |
|----------|----------|----------|
| 市场驱动型 | 缺乏独特性 | 设计者想象力的表达 |
| 设计者驱动型 | 忽视集体智慧 | 平衡个人创意与可玩性 |
| 许可证型 | 自满，依赖IP | 游戏本身必须优秀 |
| 技术驱动型 | 重技术轻玩法 | 技术服务于可玩性 |
| 艺术驱动型 | 重艺术轻体验 | 可玩性与视觉效果并重 |

### 3. 确定设计重心

根据动机类型，确定设计应该关注的重点：

- **市场驱动型：** 关注独特性和差异化
- **设计者驱动型：** 关注可玩性和集体智慧
- **许可证型：** 关注游戏本身质量，不依赖IP
- **技术驱动型：** 确保技术服务于可玩性
- **艺术驱动型：** 平衡视觉效果与可玩性

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| driving_force | Enum | 驱动游戏设计的主要因素（市场/设计者/许可证/技术/艺术） |
| market_elements | List | 为提高销售而包含的特定市场元素 |
| license_ip | String | 所使用的知识产权（如书籍、电影、商标） |
| tech_feature | String | 试图展示的特殊技术成就（如图形、硬件） |
