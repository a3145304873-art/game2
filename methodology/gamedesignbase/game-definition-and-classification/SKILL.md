# 游戏定义与分类

## 使用场景
- 需要定义什么是游戏
- 需要区分游戏与玩具/智力谜题
- 进行游戏设计理论分析
- 研究儿童认知发展轨迹
- 分析文化现象中的游戏元素

## 游戏的四个核心特征

判断某活动是否为游戏，需同时具备以下四个特征：

1. **非强制性** - 区别于工作，游戏是自愿参与的活动
2. **娱乐性** - 具有使人放松、获得愉悦的功能
3. **社会性** - 具有显著的社会性，多玩家游戏需要社交协作
4. **假想性** - 玩家能够建立并操控虚拟世界，该世界不同于现实且可被随意创造、抛弃或改变

## 游戏的两个基本元素

- **玩（Play）**：宽泛概念，指非必需的、具有娱乐性且具有显著社会性的人类活动
- **假想（Pretending）**：智力能力，表现为帮助玩家建立并操控虚拟世界的能力

## 区分玩具、智力谜题与游戏

使用以下维度进行判断：

| 维度 | 玩具 | 智力谜题 | 游戏 |
|------|------|----------|------|
| 游戏规则 | 无 | 有（指定任务目标） | 有（各种规则） |
| 任务目标 | 无 | 有（明确目标） | 有（明确目标） |
| 实现方法限制 | 无限制 | 无限制（可尝试所有方法） | 受规则限制 |
| 假想要求 | 低 | 中等 | 高 |
| 玩家成熟度要求 | 最低 | 中等 | 更高 |
| 社交协作 | 不一定 | 不一定 | 多玩家游戏需要 |

## 判断流程

### 判断是否为游戏
检查是否同时具备：
1. ✓ 游戏规则
2. ✓ 任务目标
3. ✓ 玩
4. ✓ 假想

### 区分活动类型
- **玩具**：无规则、无目标、无方法限制（如球、棍子、布娃娃）
- **智力谜题**：有规则、有明确目标、无方法限制（可尝试所有方法）
- **游戏**：有规则、有明确目标、受规则限制

## 儿童发展视角

儿童活动发展顺序反映认知和社交能力的发展：

```
玩玩具 → 玩智力谜题 → 玩游戏
(低结构化) → (中等结构化) → (高结构化)
(低成熟度) → (中等成熟度) → (高成熟度)
```

## 约束条件

- 不适用于强制性的工作活动
- 不适用于无规则无目标的纯玩具玩耍
