# 设计文档关键要素

## 具体参数示例

### 行为参数
- **警戒距离**：50米
- **脱离警戒时间**：30秒
- **优先级规则**：最高优先级

### 时间参数
- **前期设计时间**：1-6个月（PC或控制台游戏）

### 团队规模阈值
- **小型团队**：可简化文档
- **大型团队**：必须严格文档化（如《麦登橄榄球》或《战地》系列的数百人规模）
