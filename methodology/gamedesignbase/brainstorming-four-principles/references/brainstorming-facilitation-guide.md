# 头脑风暴引导指南

## 会议准备清单
- [ ] 指定一名主持人（facilitator）
- [ ] 指定一名记录人员
- [ ] 准备白板、便利贴、马克笔
- [ ] 设定明确的时间限制（通常30-60分钟）
- [ ] 准备明确的主题或问题陈述

## 主持人职责
1. 在会议开始前明确宣布四个原则
2. 确保没有人批评他人的想法
3. 鼓励沉默的参与者发言
4. 当讨论偏离主题时引导回归
5. 控制时间节奏

## 常见问题处理

### 问题：有人开始批评想法
**应对**：
- 温和提醒："现在我们只记录想法，稍后再评估"
- 如果持续批评，可以私下提醒

### 问题：想法太少
**应对**：
- 提出引导性问题："如果没有任何限制，会怎样？"
- 使用随机词或图片作为灵感触发
- 鼓励"疯狂"的想法

### 问题：有人主导讨论
**应对**：
- 轮流发言机制
- 鼓励其他人基于已有想法进行扩展

## 后续评估阶段
头脑风暴结束后，进入评估阶段：
1. 整理所有想法
2. 去除重复项
3. 分类归纳
4. 根据项目目标进行筛选
5. 优先级排序

## 评估标准建议
- 可行性（技术、资源、时间）
- 创新性
- 与目标的一致性
- 潜在影响力

## 团队规模建议
- 最佳规模：5-8人
- 最少：3人
- 最多：12人（超过则考虑分组）
