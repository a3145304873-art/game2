# 严肃游戏设计

## 使用场景
- 需要解决现实世界中的具体问题
- 需要降低培训成本或风险
- 需要提高学习者的参与度
- 进行高成本或高风险的职业培训

## 定义严肃游戏

### 核心内容
以解决现实问题为主要内容

### 设计目的
不是纯粹为了娱乐，而是要应用在现实世界中并完成更有意义的事情

### 实现手段
最有效的解决手段是娱乐，即"通过令人愉快的游戏来达到目的"

## 应用形式：教育和培训

### 核心机制
**隐性学习**：设计师寻求各种方法来激励玩家进行学习，或者通过这种形式教授玩家知识，而玩家们甚至都不会察觉到这竟是在授课

### 适用对象
- 不仅限于儿童
- 很多需要培训的职业也会使用游戏作为教学工具

### 适用场景
特别适用于那些耗费巨大或者在现实中隐含危险的训练情况：
- 医护人员
- 危险品应急处理团队
- 军事人员

## 设计策略

### 以腹腔镜外科医师为例

**目标**：提高在环境中的操作技巧

**方法**：游戏中的内容根本不是对腹腔镜手术的现实模拟，但它会使用一些方法来更好地锻炼那种环境下所需的实际技能

### 关键原则
1. 不需要完全模拟现实场景
2. 专注于锻炼目标技能
3. 利用游戏机制提高参与度
4. 让玩家在不知不觉中学习

## 执行流程

### 确定适用性
```
IF (需要解决现实问题 OR 需要进行高成本/高风险的职业培训)
THEN 应用严肃游戏设计原则
ELSE 不适用
```

### 设计严肃游戏
```
1. 明确现实问题或培训目标
2. 识别需要锻炼的核心技能
3. 设计隐性学习机制
4. 创建非现实模拟的游戏内容
5. 确保娱乐性和教育性的平衡
6. 测试学习效果
```

### 输出成果
确定采用严肃游戏方案，利用隐性学习机制，针对特定高风险场景设计非现实模拟的技能训练内容
