# 高等概念文档模板

## 文档目的

作为进一步讨论和开发的基础，比原始创意更具体，但比完整设计文档更抽象。

## 必须包含的内容

### 1. 游戏概念描述
- 初始创意的"更加有血有肉的版本"
- 足以让读者理解游戏是关于什么的

### 2. 潜在玩家问题分析
- 识别目标玩家可能面临的问题或需求
- 明确的答案，不能模糊或待定

### 3. 游戏设备/平台说明
- 明确游戏将运行的硬件平台或设备类型
- 考虑平台技术限制

### 4. 目标人群定义
- 核心玩家群体特征
- 人口统计学特征
- 投入程度分类
- 情感偏好分析

## 详细程度控制

- 不必完成所有的细节
- 不应陷入具体机制、数值或技术实现的细节
- 必须达到"能理解你的游戏是关于什么的"程度

## 文档用途

- 向团队成员传达设计意图
- 帮助把想法出售给发行商
- 作为后续开发讨论的基础
