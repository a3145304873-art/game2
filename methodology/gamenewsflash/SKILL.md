# 游戏行业资讯速递🔥

每日游戏圈情报站——新游爆料、版号喜讯、大厂动向、电竞赛事、黑科技、政策风向，一网打尽。

---

## 执行流程

依次访问 `sources/media.md` 中各媒体来源，按以下步骤完成全流程：

1. **抓取**：优先请求 RSS 地址；RSS 失败或内容为空时，直接访问媒体主页提取文章标题和链接
2. **时间过滤**：保留 24h 内发布的条目；若某分类内容不足，扩大至 48h 重试一次
3. **关键词分类**：按下方分类规则将条目归入对应分类（一条只归一类）
4. **去重**：按标题相似度去重，每分类保留最新 5 条
5. **渲染输出**：使用 `templates/daily-report.md` 格式输出日报

**预期耗时**：18 个来源依次抓取（含请求间隔），约 1～3 分钟。

若某来源访问受限或返回空，直接跳过，不中断整体流程。

## 降级策略

| 情况 | 处理方式 |
|------|----------|
| RSS 失败或内容为空 | 访问媒体主页直接抓取 |
| 某分类内容不足 | 扩大时间窗口至 48h 重试一次 |
| 重试仍无结果 | 跳过该分类，不在日报中展示 |
| 网络连接失败 | 终止并告知用户，建议检查网络后重试 |

---

## 分类规则

按优先级顺序匹配，首次命中即归类，未匹配归入「其他要闻」。

| 分类 | 纳入标准 | 关键词（示例）|
|------|----------|---------------|
| 📋 版号政策（P1）| 国内版号批复、审批规则调整 | 版号、审批、游戏审核、game license |
| 💰 厂商财报（P2）| 上市/知名厂商财务事件 | 财报、营收、裁员、收购、IPO、revenue、layoffs |
| 🏆 电竞赛事（P3）| 主流赛事赛况与结果 | 电竞、赛事、冠军、LPL、LCK、tournament |
| 📜 行业政策（P4）| 监管动态、平台规则、未保新规 | 监管、防沉迷、平台抽成、regulation |
| ⚙️ 技术突破（P5）| 引擎、AI、新硬件等显著进展 | 引擎、光线追踪、VR、game engine |
| 🎮 大作动态（P6）| 知名 IP 发售、更新、预告 | 发售、DLC、预告、公测、release、trailer |
| 🌐 其他要闻（兜底）| 具有行业影响力但不属于以上分类的事件 | — |

## 输出规范

- 使用 `templates/daily-report.md` 格式（空分类自动跳过）
- 每分类最多 **5 条**，按发布时间降序排列
- 日报开头附「今日概览」：基于实际有内容的分类动态生成，最多 3 条
- 结尾附信息源链接汇总（如可获取）
- 每条格式：`**标题（≤30字）**（来源）` + 摘要（≤80字，不添加来源未提及的信息）
- 若全部分类均无内容，输出「今日暂无游戏行业资讯」
- **严禁**为无内容的分类输出任何占位文本（包括「暂无」「无内容」「（空）」等）
