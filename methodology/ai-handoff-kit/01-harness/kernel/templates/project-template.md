# Project Spec Custom Template

> 此文件是项目级自定义检查项的说明模板。
> 用户在 `{project}/.claude/spec-custom.md` 中按此格式编写。

---

## 文件位置

`{project_root}/.claude/spec-custom.md`

如果此文件不存在，`/write-spec` 命令仅使用全局模板。创建后自动生效。

---

## 格式

使用 Markdown 格式，分为以下几个可选段落：

```markdown
# {Project Name} Spec Custom

## 项目特有验收标准模式

列出本项目通用的验收标准模板，每次 /write-spec 时自动附加：

- 所有 API 必须有错误处理
- 所有用户输入必须做 XSS 防护
- 数据库操作必须用只读模式（读时）
- ...

## 领域相关边界条件

列出本项目特有的边界条件，提醒 AI 在写 Spec 时注意：

- SQLite 并发写入限制
- 端口号范围 8501-8509
- 前端禁止使用 emoji
- ...

## 自定义 QA 测试矩阵

定义本项目特有的测试场景：

| 场景 | 测试步骤 | 预期结果 |
|------|---------|---------|
| T1: 登录 → 建对话 → 发消息 | ... | ... |
| T2: 切换历史对话 → 新建 → 再切回 | ... | ... |

## 非功能需求

- 前端首屏加载 < 3s
- API 响应 < 500ms
- 支持 1000 条数据无卡顿
```

---

## 注意事项

- 文件使用 UTF-8 编码
- 段落可自由增删，只有存在的段落才会被合并
- 修改后立即生效，不需要重新部署
- AI 不会自动修改此文件，由用户直接编辑
