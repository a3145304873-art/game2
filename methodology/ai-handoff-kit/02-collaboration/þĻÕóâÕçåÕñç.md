# 环境准备（安装指南）

> 面向**协作者（Windows）**。开工前按本文件装好两样东西：Claude Code + 协同 Harness。
> 装一次即可，后续所有需求都复用。

---

## 你需要装什么

| # | 组件 | 必需性 | 说明 |
|---|------|--------|------|
| 1 | **Claude Code** | 必需 | AI 编程助手终端，你与 AI 交互的入口 |
| 2 | **协同 Harness** | 必需 | 多轮自主审核工具包（kit 里的 `01-harness/`），提供 `/kickoff` 等命令 |
| 3 | 项目运行环境 | 可选 | 想跑通 main 代码验证想法时才需要（多数情况不用） |

---

## 一、安装 Claude Code（必需）

Claude Code 是 Anthropic 出的命令行 AI 助手。

1. **获取**：从项目负责人处获取安装方式（内部统一分发，或官方渠道）。
2. **安装**：按提供的指引装到 Windows 上。
3. **验证**：打开 PowerShell，运行：

   ```powershell
   claude --version
   ```

   能显示版本号 = 装好了。

> 如果 `claude` 命令不识别，通常是 PATH 未生效——关闭 PowerShell 重开，或重启电脑。仍不行找项目负责人。

---

## 二、安装协同 Harness（必需）

Harness 是 kit 里的 `01-harness/` 文件夹，它会给 Claude Code 增加 `/kickoff`（自动规划+多轮审核）等命令。

### 安装步骤

1. **找到安装脚本**：kit 解压后的 `01-harness\install.ps1`。
2. **打开 PowerShell**（普通权限即可）。
3. **进入 harness 目录并运行**：

   ```powershell
   cd "解压路径\01-harness"
   .\install.ps1
   ```

4. 脚本会自动：
   - 把 harness 的命令复制到 `C:\Users\你的用户名\.claude\commands\`
   - 把审核 agent 复制到 `C:\Users\你的用户名\.claude\agents\`
   - 把共享资源复制到 `C:\Users\你的用户名\.spec-workflow\`
   - **若发现同名文件已存在，自动备份**（加 `.bak-手份日期` 后缀），不会强覆盖你的东西。

5. **验证安装**：打开 Claude Code（在任意目录运行 `claude`），输入 `/`，应能看到：

   ```
   /kickoff   /ship   /write-spec   /write-plan   /write-tasks
   /implement-spec   /review   /qa   /merge-ready
   ```

   看到 `/kickoff` = harness 装好了。

### 安装失败怎么办

| 现象 | 处理 |
|------|------|
| PowerShell 报"禁止运行脚本" | 用 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 放开当前用户，再重跑（这是 Windows 安全策略） |
| 提示路径不存在 | 确认你 `cd` 到了正确的 `01-harness` 目录，用 `dir` 看有没有 `install.ps1` |
| 装完 `/kickoff` 还是看不到 | 关掉 Claude Code 重开（命令列表在启动时加载） |
| 其他报错 | 截图发项目负责人 |

## 三、项目运行环境（可选，多数情况不需要）

《代码差异分析》主要靠**读代码**，不一定非要跑通项目。只有当你想实际运行 main 代码验证想法时，才需要：

1. **Python**（后端）：装 Python 3.x，在 main 代码根目录运行 `pip install -r requirements.txt`。
2. **Node.js**（前端）：装 Node.js，在 `frontend/` 目录运行 `npm install`。
3. **`.env` 配置**：API key 等由项目负责人提供。

> 不确定要不要装 → 先不装，等真的需要跑代码时再问项目负责人。**绝大多数非代码交付场景用不到。**

- [ ] 拿到了最新 main 代码
- [ ] 拿到了需求 Issue（ISSUE.md）
- [ ] `02-collaboration/` 已重命名为 `collaboration` 放进 main 代码根目录

全部勾选 → 回到 [快速开始.md](./快速开始.md) 开始第 2 步。

## 一次性 vs 每次需求

| 事项 | 频率 |
|------|------|
| 装 Claude Code | 一次 |
| 装 Harness | 一次（除非项目负责人发了新版本 harness 让你升级） |

| 跑 `/kickoff` 产出文档 | 每个需求一次 |
