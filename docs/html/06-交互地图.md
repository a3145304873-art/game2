# 06 - 交互地图（借鉴 visual-flow-to-ui 交互契约）

> 方法论来源：`visual-flow-to-ui-complete-toolkit` 的 `interaction-qa.md` / `qa-checklist.md`。
> 原则："可见的控件就是契约"——每个可点击面都要有稳定的目标、动作、成功信号与已验证路径。
> 原型为单文件（`web/index.html`），"页面"即 `show()` 的状态切换，无独立 URL；地图仍按屏列出。

## 1. 页面（状态）清单

| 状态 | 含义 | 进入路径 |
|------|------|----------|
| `scr-start` | 开场/标题 | 初始、`backToStart()` |
| `scr-p1` | 末世前 Day 1~30 | `newP1Game()` / `continueGame()` / 日终 `nextDay()` |
| `scr-morning` | 冰封后日报 | `enterMorning()` |
| `scr-assign` | 任务分配 | `goAssign()` |
| `scr-day` | 日间日志 | `startDay()` |
| `scr-night` | 夜间安排 | `goNight()` |
| `scr-report` | 日终结算 | `goReport()` / `endP1Day()` |
| `evtOverlay` | 事件/剧情弹窗 | `presentEvent()` |
| `dlgOverlay` | 对话窗 | `openDlg()` |
| `manualOverlay` | 生存手册 | `openManual()` / 快捷键 `?` |
| `end-screen` | 结局 | `showEnd()` |

## 2. 控件交互地图

### scr-start（开场）
| 控件 | ID | 动作 | 成功信号 |
|------|----|------|----------|

### scr-morning / scr-assign / scr-day
| 控件 | ID | 动作 | 成功信号 |
|------|----|------|----------|
| 📋 安排今日任务 | — | `goAssign()` | 显示 scr-assign |

### scr-night / scr-report
| 控件 | ID | 动作 | 成功信号 |
|------|----|------|----------|
| 守夜人选 ×成员 | `.watch-chip` | 设 `S.watch` | `.on` 高亮；影响夜袭概率 |

| → 第 N 天 | `nextDayN` | `nextDay()` | p1：enterP1 / Day>30 → transitionP2；p2：enterMorning |

### 弹窗（evt / dlg / manual / end）
| 控件 | ID | 动作 | 成功信号 |
|------|----|------|----------|
| 继续 ▸（事件） | `evtNext` | `evtAdvance()` | 逐句推进台词，播完隐藏并渲染选项 |
| 选项按钮 | `#evtChoices .choice` | 执行 `opts[i].run(S)` | 关窗、状态结算、队列续播下一个事件 |
| 继续 ▸（对话） | `dlgNext` | `dlgAdvance()` | 对话推进，播完出选项 |
| 对话选项 | `#dlgChoices .choice` | 执行 `choices[i].run(S)` | 关窗；p1 时刷新 `renderP1()` |
| 合上手册 | — | `closeManual()` | manualOverlay 关闭 |
| 回到开始 | — | `backToStart()` | 清空存档提示 → scr-start |

## 3. 键盘路径

| 键 | 效果 |
|----|------|
| `Esc` | 关闭手册 / 对话窗 |
| `?` | 打开手册 |

## 4. 层级与命中规则

- `evt/dlg/manual` 为 `z-index:50` 模态，`end-screen` 为 `z-index:80`；无装饰性全屏层，不存在"装饰层挡点击"问题。
- 氛围层 `.vignette`（暖/冷光）与 `.snow`（飘雪）为固定定位装饰层，均 `pointer-events:none`、`z-index:0`，内容区 `.wrap` 位于 `z-index:1`——符合 toolkit"装饰层不得拦截指针"规则。
- 事件弹窗按设计**不提供关闭/跳过**：剧情选择是唯一出路（保证状态一致），属有意偏离 QA 清单的"模态必须有可见关闭路径"——已记录为已知设计决策。
