# 00 · HTML 原型范围（已定稿）

> 依据 2026-XX 与用户沟通确认。玩法唯一真相 = `docs/phase2/`，本文只定义"原型范围"。

## 一、原型目标

做一个**可玩的单日循环垂直切片**：日出→任务分配→日间执行(事件插入)→夜间→日终结算，可连续玩多天直到结局判定。横屏桌面优先（1280~1920 宽），单文件 HTML，零图片依赖（头像色块占位，后补 AI 头像只换背景）。

## 六、设计原则（继承自参考项目）

1. **一套真相**：数值只来自 phase2 文档，代码里数据表是唯一实现。
2. **配置即数据**：所有数值/事件/任务写成 JS 对象（笨勇者 ACTS 模式）。
3. **教程进世界观**：规则说明做成游戏内"生存手册"弹窗。
4. **UI 零图片**：全部 CSS 绘制；危险信息伴随可执行建议。
