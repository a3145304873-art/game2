# 04 · 可玩性与末世感优化方案

> 现状诊断结论：骨架完整（日循环/任务/事件/结算都通了），但**决策无取舍、无成长、无空间、无叙事重量**。本文给出优化清单与优先级。

---

## 一、设计原则（末世题材的四个引擎）

1. **取舍即玩法**：资源永远不够，每个决策都意味着放弃另一个。（Frostpunk：烧煤 vs 建暖炉）
2. **成长曲线**：投入→变强→环境更难→更大的投入。30 天要有"越活越像样"与"越活越绝望"交替。
3. **风险定价**：高风险高回报，玩家自己选安全线还是赌命线。
4. **道德有成本**：末世感=每个善举都要付代价，每个恶行都有回声。

## 三、TOP 4 具体机制设计

### 1. 搜刮地点化（解决"按钮搜刮"）
```
地点池（按距离/风险/资源）：
- 楼下便利店：食物多，风险低，只能搜 2 次（被抢空）
- 社区诊所：药品，中等风险，1 次
- 加油站：燃料，低风险，2 次
- 五金店：工具/废金属，低风险，2 次
- 北街超市：食物/水大量，高风险（强盗出没），3 次
- 学校食堂：食物，中风险，2 次
- 邻居王家：随机，特殊事件（发现尸体/日记），1 次
- 城外仓库：木材/金属大量，极高风险，3 次
```
- 出队 = 选**地点** + 选**成员**（负重：老王 15 / 阿杰 12 / 小雨 6 / 其他人 10）+ 选**带什么**（工具→能撬锁拿更多；武器→遇袭战力+）
- 结果 = 地点资源池抽取 + 地点特殊事件 + 遇袭判定（风险率）
- 地点会**耗尽**：家门口搜完了必须去更远 → 风险自然爬升

### 2. 木材 + 建造（解决"无成长"）
- 新增资源**木材**：砍家具、拆门、搜刮获得；每日供暖可**烧木材顶替燃料**（0.5 天燃料 = 2 木材）
- 安全屋升级（消耗木材/废金属/工具 + 指派人力 1 天）：
  | 升级 | 效果 |
  |------|------|
  | 火炉改造 | 燃料消耗 -25% |
  | 墙体隔热 | 室内 +2°C |
  | 医疗角 | 治疗效率 +50%（需药品×2） |
  | 工坊 | 解锁"制作"：工具/简易武器/捕兽夹 |
  | 种植架 | 每 5 天 +0.5 食物（需种子） |
- 取舍实例：暴风雪夜，木材只剩 6——烧了保证今晚不冻伤，还是留着修好隔热墙？

### 3. 遭遇战斗（简化版）
- 触发：夜袭 / 远地点搜刮 / 巡逻发现
- 战力 = 人数 + 武器数 + 刘哥(+2) + 陷阱(+1)
- 三选：**打**（按战力差结算：击退/受伤/减员）/**逃**（放弃部分物资，低伤）/**给物资**（-0.5 食物，保平安）
- 战后掉落：武器/物资/俘虏（可选收留）

### 4. 道德事件链（末世感的核）
- **陌生人求助**（已有）→ 续集：收留的人 3 天后可能生病需要药、偷食物被抓、或者报恩（帮你修好火炉）
- **处理尸体**：有人死亡后必须选择——火葬（消耗燃料，士气+2）/雪埋（士气-3，3 天后疾病风险）/不管（士气-8，疾病+）
- **最后的口粮**：食物=0.5 天时触发"谁吃这顿"——喂孩子（士气+5 主角精神+8）/平分/主角不吃
- **远处火光**：看到远处有人放信号弹——去救（可能救回人/中埋伏）或不去（士气-5，电台后续剧情）

### 5. 氛围叙事（低成本高感知）
- 每日日出加一句**日记体**："第 43 天。今天数了数，罐头还剩 11 个。"
- 电台改**连载**：《北方广播电台》每 3 天更新一段故事（一个家庭的逃亡史）
- 细节文案：食物卡注语从"配给标准"改成"罐头 11 个 · 米 4 斤"；火炉描述"烧的是小美的椅子腿"

| 批次 | 内容 | 预计 |

| **P4（本次推荐）** | 搜刮地点化 + 木材/建造 + 遭遇战 + 道德事件链 + 氛围文案 | 一次大迭代 |
