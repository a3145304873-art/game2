## 4. 三大闭环（系统咬合点）

```
搜刮闭环：选点位（倾向）→ 搜刮（食物/材料）→ 制作（武器/陷阱/保暖）→ 夜袭结算（成果生效）
威胁闭环：暴露度↑/物资多 → 局势标签警告 → 夜袭概率↑ → 加固/守夜/陷阱反制
政策闭环：制度卡抉择（D35/40/45/50/55）→ 全局系数 → 每日结算 + 制度面板
```
