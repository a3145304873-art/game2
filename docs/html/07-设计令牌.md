# 07 - 设计令牌（借鉴 visual-to-spec token-schema）

> 原型 UI 的全部视觉值收敛在 `web/index.html` 的 `:root` / `body[data-phase]` 两组 CSS 变量里。
> 约定：组件样式**只引用变量，不硬编码颜色/字号**；换主题 = 换变量，不改组件。
> 标注格式借鉴 DTCG：`source: code-defined`（非截图提取，置信度天然 high），`strictness: required`（两套调色板是转场演出契约，必须精确）。

## 2. 字体排印

| 令牌 | 值 | 用途 |
|------|----|------|
| `--serif` | Kaiti SC / KaiTi / STKaiti / Songti SC / SimSun | 标题、台词、电台（手账感） |
| `--num` | Consolas / SF Mono | 数字 |
| `--fs-title` / `--fs-body` / `--fs-small` | 21 / 14 / 12 px | 层级；≤480px 时 body 提升到 16px |

## 3. 间距 / 圆角 / 阴影

| 令牌 | 值 |

## 5. 规则

1. 组件只准用变量；新角色头像按上表追加 `data-id` 规则。
2. p2 是 p1 的"冻结"映射：同布局、同圆角、同阴影结构，只换色板——这是"冰封降临换季"演出的实现契约，不可破坏。
3. 数字一律 `--num` 等宽字体，台词/标题一律 `--serif`。
4. 对照：`docs/html/03-迭代看板.md` 跟踪 UI 迭代；`docs/phase2/14-小说玩法参考.md` 跟踪玩法。

## 6. 组件库（CSS 组件代替生图）

> 依据 visual-flow-to-ui 规则"装饰层与语义层分离"：以下氛围组件全部 `pointer-events:none`，
> 不拦截任何点击；未接入生图期间用纯 CSS 组件顶替位图素材，接入后按原位置替换即可。

| 组件 | 实现 | 说明 |
|------|------|------|
| `.vignette` | 固定定位双径向渐变 | 暖光（p1）/冷光（p2）氛围层，随 `body[data-phase]` 自动换 |
| `.snow` | 7 个 `<i>` 粒子 + `fall` keyframes | 冰封后飘雪（约 10~14s 循环），末世前隐藏；reduced-motion 自动禁用 |
| `.day-chip` 双层框 | 内嵌 inset box-shadow 描边 | 日历铭牌 |
| `.panel h3` 文件夹标签 | 负位移 + 半圆角边框 | 面板标题"夹"在卡片上沿 |
| `.choice .lab::first-letter` | 首字母键位章 | 选项 A/B/C/D 变成彩色按键 |
| `.avatar .role-ico` | 圆形小徽章 | 角色职业 emoji（👷🩺🍳⚡🚗🎖📻…），映射表见 JS `ROLE_ICO` |
| `.big-btn::after` | 顶部高光渐变 | 立体按钮釉面 |
| 卡片悬浮 | translateY(-2px) | 资源卡/成员卡/任务块 hover 抬升 |
| `.log-box .day` | 虚线边框铭牌 | 日终结算头行 |
| `.start-screen .title` 雪花 | ::before/::after ❄ | 开场标题点缀 |
