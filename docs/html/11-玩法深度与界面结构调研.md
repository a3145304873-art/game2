# 11 - 玩法深度与界面结构调研

> 两个问题：① 玩法深度不足；② 系统堆砌在一页。调研外部游戏如何解决，给出可落地方案。

## 1. 深度从哪来（标杆做法）

### 冰汽时代：双树系统
- **科技树**（解锁建筑/能力）+ **法典**（政策倾向集合，改变全局规则，互斥选择）。
- 深度 = 可选路线 + 互斥选择，玩家每局走出不同"社会形态"。

### 这是我的战争：科技线 + 昼夜双循环 + 角色差异
- **工作台 3 级升级解锁配方**（2 级才能造园子、造武器……），成长感极强；
- 白天建造/夜晚探索，**两种节拍**交替；
- 每个角色有特性加成（厨师省食材、记者交易加成、扒手无声），人员选择即策略。

### 环世界：系统耦合 + 事件导演
- 角色特质 × 状态 × 环境 × 随机事件**自由组合**涌现故事；"AI 故事叙述者"按局势投放事件。
- 深度 = 组合爆炸，而不是内容量——**系统互相咬合**。

### 中国式家长：有限回合的路线规划 + 梗系统
- 40 回合的**时间资源分配**（学什么/玩什么）；"面子战斗"把文化梗做成系统。
- 深度 = 有限资源下的路线选择 + 阶段性反馈（每阶段结算成长报告）。

### 缺氧：房间系统 + 自动化物流
- 深度 = 工程问题（气体/液体/电力链）。

> **共性**：核心循环都很简单，深度来自 **① 路线选择（科技/法典/配方）② 系统耦合 ③ 按局势投放事件**，而不是堆更多按钮。

## 2. 界面结构（怎么解决堆砌）

- 网易游戏学堂《窗口界面设计规范》：先定**全屏界面 vs 窗口界面**；横向结构固定三区域——**标题区 / 页签区 / 功能区**。
- GameRes《游戏界面设计(二)结构设计》：第一步就是选全屏/窗口，随后信息按层归类。
- 标杆实践：TWoM 分"避难所视图 / 夜图 / 物品栏"；Frostpunk 分"城市 / 科技树 / 法典 / 情报"**独立全屏页**；中国式家长分"日程板 / 活动选择 / 事件 / 成长报告"。
- 结论：**按系统拆屏，主循环用时间线串联**。单页堆砌 = 信息架构缺失。

## 3. 我们的差距诊断

| 问题 | 现状 | 标杆对应 |
|------|------|----------|
| 深度不足 | 系统扁平：任务分配→结算→随机事件，无路线选择/无成长线 | 科技树/法典/配方树 |
| 堆砌一页 | scr-assign 同时塞成员列表+任务网格+点位面板 | 三区域 + 按系统拆屏 |
| 无前进感 | 只有天数增长 | 升级解锁（TWoM 工作台 2 级） |
| 事件随机无导演 | 纯随机池 | RimWorld 叙述者按局势投放 |

## 4. 方案

### 4.1 结构改造：页签导航（不拆文件，纯布局重构）
- 顶栏下方加**页签区**（GameRes 三区域结构）：`🏠 据点 · 👥 队伍 · 🗺 探索 · 🔧 制作 · 📖 手册`
- 各页签内容：
  - 🏠 据点 = 现有日报（资源+士气+电台+天气）+ 未来方案 B 安全屋剖面
  - 👥 队伍 = 成员卡独立屏（状态/关系/伤病/装备，可排序）
  - 🗺 探索 = 搜刮点位屏独立（现有 siteGrid 拆出）
  - 🔧 制作 = 新增工作台
  - 📖 手册 = 现有
- 主循环（安排→执行→夜间→结算）保持时间线串联不变。

### 4.2 深度系统 1：工作台配方树（TWoM 式，低成本）
- 工作台 3 级（升级消耗材料），每级解锁配方：
  - 1 级：木柴捆（燃料+0.5）、窗帘保温（室内+1 一档）、简易武器（夜袭减损）
  - 2 级：陷阱（夜袭风险-5%）、罐头（食物不腐=应急粮）、自制酒（士气+，伤身）
  - 3 级：医疗包（治伤）、发电机维修件（修 gen）
- 材料来自搜刮点位（给点位池加"材料"产出：木材/零件/布条），**搜刮→制作→装备**形成闭环。

### 4.3 深度系统 2：制度卡（Frostpunk 法典简化版）
- 每 5 天一次制度抉择（互斥政策，改全局系数）：
  - 配给制：全员 0.8 食 vs 士气每日-1（或相反）
  - 门禁政策：夜袭-10% vs 士气-2
  - 巡逻强度：燃料消耗 vs 情报获得
- 深度 = 政策组合改变玩法风格，每局不同。

### 4.4 事件导演（RimWorld 简化）
- 把现有隐式规则显式化：士气<40 → 矛盾事件权重↑；储备>X → 劫掠者惦记（暴露度已有）；连续下雪 → 雪灾。
- 界面显示"局势"一行（如"🏴 危险：物资多且暴露度高"），让玩家能读懂并应对。

## 6. 已实现（按用户选择：1→2 先结构后深度）

### 6.1 页签导航拆屏
- 新增页签：`🏠 据点 · 👥 队伍 · 🗺 探索 · 🔧 制作`（TABS / goTab / renderTabs）
- 拆屏：成员卡 → 队伍屏；搜刮点位 → 探索屏（分配页仅显示当前目标）；新增制作屏
- 时间线流程（安排→执行→夜间→结算）不受影响；P1 屏保持原结构

### 6.2 工作台配方树
- 材料（搜刮获得）：🪵 木材（南湖公园/周边）· ⚙️ 零件（汽修厂/周边）· 🧵 布条（东街公寓/周边）
- 工作台 3 级：升 2 级需 木2+件1；升 3 级需 木3+件3；满级需 木5+件5+布2
- 配方 7 种：
  - Lv1：窗帘保温（室内+1）· 木柴捆（燃料+0.5）· 简易武器（夜袭损失减半）
  - Lv2：捕兽陷阱（夜袭-5%）· 暖炉改良（燃料-0.1/夜）· 医疗包（治疗伤员）
  - Lv3：弩（击退一次夜袭，一次性）
- 全部接入结算：goNight 燃料成本 / goReport 室内温度、夜袭风险、损失倍率、弩击退分支
- 闭环：搜刮→材料→制作→装备/建设

### 6.3 已实现：制度卡 + 局势提示
- **制度卡（法典简化版）**：Day 35/40/45/50/55 各一次互斥政策抉择：
  - D35 严格配给（食物-20% · 士气-2/天）
  - D40 宵禁封锁（夜袭-10% · 士气-2/天）
  - D45 分散藏粮（夜袭损失-30% · 士气-1/天）
  - D50 轮班休养（士气+1/天 · 食物+0.2/天）
  - D55 全民巡逻（巡逻柴火+0.3 · 夜袭-5%）
- 全部接入每日结算；据点屏「📜 现行制度」面板展示已选政策
- **局势提示行（事件导演显式化）**：顶栏实时显示「🏴 粮多招贼」「⚔ 灰狼帮寻仇」「😰 士气危机」「🕯 燃料告急」「🌨 暴风雪」等威胁标签
- 顺带修复：无人做饭时食物消耗应为 1.0（此前错误地按 0.9 省粮）
