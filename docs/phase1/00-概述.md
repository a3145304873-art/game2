# 第一阶段（末世前 Day 1~30）— 概述

> 本文是"末世前"的玩法唯一真相。对应原型 `web/index.html` 的 P1 部分（常量名：`P1_*`、`freshP1State`、`enterP1`）。
> 与第二阶段（Day 31~60，docs/phase2）通过 [../phase2/10-阶段继承.md](../phase2/10-阶段继承.md) 衔接。

---

## 1. 阶段定位

| 项 | 内容 |
|----|------|
| 时间跨度 | Day 1 ~ Day 30（30 天） |
| 核心主题 | 还来得及吗？——你知道会发生什么，但世界还不知道 |
| 玩家身份 | 猎人（主动准备、掌控节奏） |
| 情绪 | 焦虑但有掌控感 |
| 资源 | 用钱换物资 |
| 视角 | 向外扩张 |
| 操作 | 每天 3 个行动点，手动选行动 |

## 2. 核心循环

```
日出（消息/新闻/固定事件）
   ↓
行动阶段（3 行动点：采购/升级/拜访/招募/回想/炒股/彩票/卖房）
   ↓
结束今天（股市结算、新闻推进、自动保存）
   ↓
下一天 …… 直到 Day 30 夜 → Day 31 冰封降临（自动转入第二阶段）
```

## 3. 胜利条件

第一阶段没有输赢——**所有人都会活到 Day 31**。真正的"结算"在第二阶段：你囤的东西够不够、拉的人对不对、暴露度低不低。

| 表现 | Day 31 转入时的结果 |
|------|---------------------|
| 储备充足 + 设备齐全 + 保温/加固高 | 第二阶段从容（对应 phase2 的"充分准备型"） |
| 中等准备 | 挣扎求生 |
| 几乎没准备 | 开局即危机 |

## 4. 与第二阶段的继承（原型实现口径）

| 第一阶段 | 第二阶段表现（原型） |
|----------|----------------------|
| 食物/饮水/燃料 天份 | 直接带入，日终扣除 |
| 药品/零食 | 带入，黑市交易硬通货 |
| 工具/厨具/电台 | 任务前置条件 |
| 发电机 | Day37 断电后免"无照明"惩罚（燃料+0.1/天） |
| 保暖装备 | 搜刮受伤概率减半 |
| 保温等级（0~4） | 室内温度 +2°C/级 |
| 加固等级（0~3） | 夜袭风险 -4%/级 |
| 扩建等级（0~3） | 仓储容量 15+10/级（第一阶段生效） |
| 招募到的 NPC | 第二阶段团队（未招募者不出现） |
| 是否接父母 | 未接 → 第二阶段主角精神+15 |
| 周叔人情值 | Day36/44 恩怨线走向（见 phase2/13） |
| 暴露度 | 夜袭风险 +min(8, 暴露/12) |
| 记忆碎片 | 第二阶段"碎片预判"面板提示 |

> 原型对 10-阶段继承做了数值简化（如保温 +2°C/级），完整版见 phase2 文档。
