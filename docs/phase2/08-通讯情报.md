# 通讯情报系统

## 系统概述

通讯系统是玩家获取外部信息的唯一途径，也是重要的"精神支柱"。有无电台会让游戏体验完全不同。

- 有电台：玩家能获得信息、掌握节奏、维持士气
- 无电台：信息真空、精神压力倍增、容易做出错误决策

通讯系统不仅提供实用情报，更是游戏节奏控制和情绪引导的核心机制。

---

## 通讯方式

### 手机（Day 31~37 可用）

| 阶段 | 状态 | 说明 |
|------|------|------|
| Day 31~33 | 正常通讯 | 可拨打/接听电话，收发短信 |
| Day 34~36 | 信号不稳 | 50%概率打不通，通话随时中断 |
| Day 37+ | 无信号 | 基站断电，手机彻底失去通讯功能 |

手机通讯阶段的设计意图：
- 让玩家感受到基础设施逐步崩溃的过程
- Day 34~36的不稳定制造不安感
- Day 37的彻底断联是重要的情绪转折点

### 短波电台

**前提条件：**
- 第一阶段（Day 1~30）准备了电台设备
- 或：有小雨（通讯NPC）帮忙搭建

**电力需求：**
- 太阳能面板（天气好时可用）
- 燃油发电机（需燃料）
- 手摇发电机（应急，效率低）

**功能：**

| 功能 | 说明 |
|------|------|
| 收听政府/军方广播 | 每天1条信息，按时间线推进 |
| 收听幸存者频道 | 随机事件/情报/求助信息 |
| 发送求救信号 | Day 50+有概率获得救援坐标 |

**有小雨（通讯NPC）的加成：**
- 监听效率翻倍（可同时监听多个频段）
- 可解码加密频道（获取军方内部信息）
- 偶尔能联系到其他幸存者团体（触发特殊事件）

## 电台信息时间线（关键设计）

| Day | 广播内容 | 设计意图 |
|-----|----------|----------|
| 31 | "市民请就地避寒，政府正在组织救援" | 给予希望 |
| 35 | "部分地区已设立集中安置点"（你附近没有） | 制造焦虑 |
| 38 | 沉默（3天无广播） → 士气-5 | 恐惧感 |
| 41 | "军方已调配物资，预计X天内分发" | 模糊的希望 |
| 45 | "极寒高峰期，严禁外出，预计5~10天缓解" | 官方确认危险 |
| 50 | "气温开始回升，请再坚持数日" | 假回暖前奏 |
| 52 | "警告：二次寒潮来袭，做好准备" | 关键预警！ |
| 55 | "救援队已出发，预计3~5天到达各社区" | 真正的希望 |
| 58 | "请在住所外放置标识，方便救援队定位" | 行动指引 |
| 60 | "救援到达" → 结局 | 终局 |

### 时间线节奏分析

```
Day 31────35────38────41────45────50────52────55────58────60
 希望 → 焦虑 → 恐惧 → 模糊希望 → 确认危险 → 假曙光 → 警告！→ 真希望 → 行动 → 结局
```

**关键节点：**

- **Day 38 沉默期**：3天无广播是重要的心理压力点，玩家会怀疑政府是否已经崩溃
- **Day 50 假回暖**：配合环境系统的短暂升温，诱导玩家放松警惕
- **Day 52 二次寒潮预警**：整个时间线最关键的信息，有无电台在此刻产生最大分化
- **Day 58 行动指引**：给予玩家明确的操作目标（放置标识），让等待变为行动

### 幸存者频道（随机事件）

除政府广播外，幸存者频道会随机播放以下类型信息：

| 类型 | 示例 | 效果 |
|------|------|------|
| 求助信息 | "这里是XX小区，我们断粮了..." | 触发道德抉择事件 |
| 物资情报 | "XX超市还有物资没被搜刮" | 提供探索目标 |
| 危险警告 | "XX路有武装团伙" | 影响外出路线选择 |
| 生存技巧 | "用XX方法可以..." | 解锁新的生存知识 |
| 沉默/噪音 | 只有电流声 | 加深孤独感 |

## 无电台的惩罚

### 直接影响

- 完全没有外部信息 → 不知道什么时候结束 → **精神压力+3/天**
- 不知道Day 52的二次寒潮警告 → 可能提前放松导致危机
- 不知道Day 55的救援消息 → 可能做出极端决策（弃屋逃跑等）
- 无法收到Day 58的行动指引 → 救援队可能延迟找到你

### 无电台的游戏体验

无电台的游戏体验更黑暗、更焦虑：

- 时间感模糊：不知道还要撑多久，每一天都是煎熬
- 决策盲目：没有信息支撑，所有选择都是赌博
- 士气持续下降：没有任何外部声音，孤独感压倒一切
- 极端决策风险：Day 50+可能因绝望做出危险行为
- 二次寒潮无预警：Day 52~54的温度骤降成为致命陷阱

### 有/无电台对比

| 维度 | 有电台 | 无电台 |
|------|--------|--------|
| 信息量 | 每天获取情报 | 完全信息真空 |
| 士气 | 正常波动 | 持续下降（+3/天） |
| Day 52应对 | 提前准备 | 措手不及 |
| Day 55~60 | 充满希望，主动配合救援 | 可能已做出不可逆决策 |
| 整体体验 | 紧张但有节奏 | 黑暗、压抑、绝望 |

## 系统设计意图

### 双重作用

电台是"精神支柱"和"信息来源"的双重作用：

1. **精神支柱**：外部声音本身就是慰藉，证明"世界还在运转"
2. **信息来源**：提供决策依据，让玩家的选择有据可循

### 体验分化

有/无电台是两种完全不同的游戏体验：

- 有电台 = 信息生存（如何利用情报做出最优决策）
- 无电台 = 盲目生存（在黑暗中摸索、赌博、煎熬）

### 关键分水岭

Day 52的预警信息是关键分水岭：

- 有电台玩家：收到预警 → 加固保温 → 储备燃料 → 安全度过
- 无电台玩家：放松警惕 → 突遭二次寒潮 → 资源不足 → 生存危机

### 鼓励第一阶段准备

通讯系统的设计鼓励玩家在第一阶段（Day 1~30）就重视电台设备的获取：

- 让"是否准备了电台"成为影响第二阶段体验的核心变量之一
- 与通讯NPC（小雨）的关系建立也需要在第一阶段完成
