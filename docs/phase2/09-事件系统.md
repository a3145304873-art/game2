# 事件系统

## 系统概述

事件系统为30天的生存过程提供叙事节奏和决策挑战。分为固定事件、随机事件和道德困境三层。

- **固定事件**：按时间线触发，构成主线叙事骨架，确保游戏节奏可控。
- **随机事件**：每日概率触发，提供重玩价值和不可预测性。
- **道德困境**：无正确答案的抉择，影响最终结局评分和团队状态。

## 2. 随机事件池

每天40~70%概率触发一个随机事件。

### 安全屋相关

| 事件 | 效果 |
|------|------|
| 暖炉故障 | 需维修1天 / 有张叔 → 半天修好 |
| 窗户被风吹裂 | 保温等级暂时-1，需修补 |
| 屋顶积雪太厚 | 需铲雪，否则耐久度每天-5 |
| 发电机没油了 | 必须立即想办法 |
| 储存的食物被老鼠啃了 | 食物-3天份，需要灭鼠 |
| 水管/容器冻裂 | 储水损失一部分 |

### 外部相关

| 事件 | 效果 |
|------|------|
| 远处传来爆炸声 | 什么情况？派人去看看？ |
| 有人在外面呼救 | 出去救 → 风险，不救 → 精神压力+8 |
| 发现附近有另一个幸存者据点 | 友善/敌对？ |
| 动物出现 | 野狗群 → 危险 / 猫 → 士气+3 / 鸟 → 春天预兆 → 士气+5 |
| 雪中发现物资 | 有人丢弃/死去的人的物品 → 道德选择 |

### 团队相关

| 事件 | 效果 |
|------|------|
| 某NPC做了一顿特别好吃的饭 | 小美触发 → 士气+5 |
| 两个NPC吵架 | 需要调解 |
| 某NPC偷偷藏了食物 | 发现 → 对峙 / 不管 → 可能引发矛盾 |
| NPC生日 | 如果有记录 → 庆祝 → 士气+5 |
| NPC分享了过去的故事 | 夜间团队互动 → 关系+5全员 |

## 3. 道德困境事件

这些事件没有"正确答案"，影响最终道德评分和结局。

### 门外的孩子

一个十几岁的孩子在暴风雪中敲你的门，说他家人都死了。

| 选项 | 内容 | 效果 |
|------|------|------|
| A | 让他进来 | +1人口，食物消耗+1/天，士气+5（因为救人） |
| B | 给他一些食物和毯子指个方向 | 食物-5天份 |
| C | 不开门 | 精神压力全员+10 |

### 偷邻居的物资

你知道隔壁的人已经死了（从窗户看到了），他们应该还有物资。

| 选项 | 内容 | 效果 |
|------|------|------|
| A | 去搜刮 | 获得食物8天份+工具，但... |
| B | 不去 | "他们可能没死，只是昏迷" |
| C | 去看看他们是否还活着 | 冒冻伤风险+可能搜刮 |

### 药品不够了

两个人同时生病，但抗生素只剩1份。一个是亲人（父母），一个是有关键技能的NPC。

| 选项 | 内容 | 效果 |
|------|------|------|
| A | 给亲人 | 亲情优先 |
| B | 给NPC | 理性选择但精神压力+20 |
| C | 把药分成两半 | 两人都50%概率恢复 |

### 背叛者回来了

之前出走的NPC，奄奄一息地回来了（他走时偷了你的物资）。

| 选项 | 内容 | 效果 |
|------|------|------|
| A | 再次收留 | 消耗资源+精神压力-5（因为宽恕） |
| B | 拒绝 | 他大概率会死 → 精神压力+15全员 |
| C | 收留但搜身 | 拿回被偷的东西 |

### 弱肉强食

搜刮队发现了一个弱小的幸存者团体，他们有食物但无法保护自己。

| 选项 | 内容 | 效果 |
|------|------|------|
| A | 帮助他们 | 分享情报/物资 |
| B | 无视他们 | 无直接影响 |
| C | 抢他们的东西 | 获得大量物资，但士气-10/精神+15 |
| D | 邀请加入 | 人口+3，但他们能信任吗？ |

---

### 道德困境的影响

这些选择影响：

- **最终结局的"道德评分"**：决定结局文本和评价等级
- **团队士气和精神压力**：即时数值变化影响后续生存难度
- **后续天数中的连锁反应**：某些选择会在之后的天数中触发后续事件
