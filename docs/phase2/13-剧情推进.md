# 13 - 剧情推进设计

> 本文把 02环境 / 05团队 / 07威胁 / 08通讯 / 09事件 的时间线合并为一条四幕叙事弧，并补上人物线与剧情分支。
> 参考末世小说的"铺垫 → 试探 → 背叛 → 高潮 → 清算"结构（原型：《全球冰封》的邻居恩怨线）；所有剧情通过游戏系统呈现（事件、电台、威胁），不依赖过场动画硬推。
> 演出形式：剧情事件以「台词逐句推进」呈现（说话人 + 台词，点击继续），台词播完弹出决策选项。已覆盖：周叔线全段（D5/D12/D20/D36/D44/D45）、灰狼帮上门、黑市交易、敲门求助、团队矛盾、父母电话、冰封降临/停水/断电/假回暖/真回暖等时间线事件。

## 2. 序幕：冰封之梦（开场）

- 开场白：主角在废墟梦境中醒来，碎片文字闪烁——"记住：别开门给任何人。" / "火，比食物重要。"
- 醒后回到现实：Day 1，灾变尚未发生——但"你"知道会发生。
- 二周目：碎片全部点亮，开场白变为"又开始了……"（呼应 11-二周目规则与「重生者的直觉」成就）。

### Day 36 周叔分支细节

- **结恩**：周叔求助——"家里什么都没囤，能不能换点粮食？"选项：换（获得情报/人情）/ 施舍 / 拒绝。
- **中立**：假意寒暄套情报（可获知附近被洗劫的小区）。
- **结怨**：冷嘲热讽——"这世道，你囤的东西迟早是别人的。"→ 仇恨值再+1。

### Day 39 疤哥"保护费"细节

- 三人上门"借"燃料。选项：
  - **给**：开启保护费模式（被袭概率-15%，但每 3 天失血一次）→ 帮派仇恨+0。
  - **打**：战力判定（刘哥加权）；胜 → 士气+5、仇恨+20；败 → 被抢、士气-8。
  - **骗**：有小雨/阿杰可尝试话术拖延（50%成功率）。
- 结果写入"帮派仇恨值"（见 14-小说玩法参考 §2.2）。

### Day 44 周叔线双分支

**A. 结怨线——"窗外的脚印"**：周叔带路，灰狼帮夜袭（防御判定用 07 规则）。
- 防御成功 → 抓到周叔 → 处置三选：
  - **报仇**：周叔死亡，全员精神-10，帮派仇恨再+（后续总攻更凶）。
  - **放过**：周叔悔悟，道德+，Day 56 他提供帮派情报（围攻威胁-30%）。
  - **收编**：人口+1，但团队不信任他（士气-5，闹矛盾概率+）。

**B. 结恩线——"带着全家来敲门"**：周叔一家三口投靠（人口+3、食物/水消耗大增）。
- Day 48 后续事件：他老母亲病重——给药（药品-1，周叔彻底归心）/ 不给（全家离开，士气-8）。

### Day 56 围攻三回合结构（建议实现）

1. **回合1 火力压制**：防御判定（07 武装团伙规则）。
2. **回合2 谈判/拖延**：消耗物资换时间（每回合失血，或交出"贡品"）；周叔若被放过/收编，此回合提供关键情报。
3. **回合3 决战**：战力对比（人数+武器+刘哥+陷阱）；胜 → 缴获+短期安全；败 → 流浪模式（07 已定义）。

## 7. 反派塑造

- **周叔**：不是脸谱坏人。前世他在极寒中背叛主角（抢走物资），这辈子他还没走到那一步——是你的选择决定他成为敌人还是自己人。台词风格：市侩、怂、关键时刻狠。
- **疤哥**：暴力秩序的化身。"现在这世道，房子里的东西叫贡品。"给他恐惧感而非仇恨感——他是乱世的产物，不是原因。

## 9. 多结局映射（与 11 联动）

| 11 的叙事结局 | 剧情条件补充 |
|---------------|--------------|
| 温暖结局 | 全员存活 + 高道德 + 周叔和解或未结怨 |
| 代价结局 | 全员存活 + 低道德（可能触发报仇/掠夺/征用服从） |
| 遗憾结局 | 部分死亡 + 高道德（如为救周叔一家牺牲成员） |
| 孤独结局 | 团队解散/全员离开 |
| 内疚结局 | 未接父母 |
| 假回暖结局 | Day51 冻死（已有） |

建议扩展（不改 11 的现有体系，仅新增可选分支文案）：
- **和解结局**：周叔赎罪，Day56 用情报救了你 → 与"放过"分支绑定。
- **清算结局**：复仇线，仇敌已除，但全员精神-10 的代价写进结算语。

|------|------|------|
