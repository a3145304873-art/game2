# 10 - 阶段继承系统

## 设计理念

第一阶段的每个选择都有后果。没有"浪费"的行动——你买的每样东西都会在第二阶段验证。你以为不重要的东西（如蜡烛、种子、维生素）可能救命。

玩家在第一阶段（Day 1-30）的所有决策、购买、关系建设，都会以具体数值或状态的形式传递到第二阶段（Day 31-60）。这确保了游戏的连贯性和重玩价值——不同的第一阶段路线，将导致截然不同的第二阶段体验。

## 继承详细规则

### 安全屋状态继承

| 保温等级 | 室内温度上限 | 说明 |
|---|---|---|
| 0级（未改造） | 5°C | 仅靠墙体隔热，几乎无效 |
| 1级（基础） | 10°C | 封窗+简易保温层 |
| 2级（标准） | 15°C | 双层窗+墙体保温棉 |
| 3级（优秀） | 18°C | 全屋气密+地暖预留 |

| 加固等级 | 防御能力 | 说明 |
|---|---|---|
| 0级 | 极低 | 普通门锁，一踹即开 |
| 1级 | 低 | 防盗门+窗户加固 |
| 2级 | 中 | 铁栅+报警装置 |
| 3级 | 高 | 全面加固+陷阱预设 |

| 扩建等级 | 储物格 | 床位 |
|---|---|---|
| 0级 | 20格 | 2人 |
| 1级 | 35格 | 4人 |
| 2级 | 50格 | 6人 |
| 3级 | 70格 | 7人（满员） |

### 物资继承

物资继承采用精确数值传递：

- **食物**：第一阶段剩余量直接带入。1单位食物 = 1人1天口粮。
- **饮水**：同上。若有净水设备，每天可净化雪水获得2单位额外水源。
- **燃料**：1单位燃料 = 供暖1天（基础消耗）。保温等级每高1级，日消耗-15%。

### 设备继承

| 设备 | 有 | 无 |
|---|---|---|
| 发电机 | 每天可运行电器4小时，需消耗燃料0.5单位/天 | 停电后无法使用任何电器 |
| 太阳能板 | 晴天提供2小时电力（极寒期极少晴天） | 无辅助电力 |
| 暖炉 | 可烧杂物取暖（效率低但不消耗燃料） | 只能依赖燃料供暖 |
| 净水设备 | 融雪净水，每天+2饮水 | 只能消耗储备水或冒险外出找水 |
| 电台 | 可收听广播（获取事件预警）、联络外部 | 信息闭塞，无法预知危险事件 |

### NPC继承

- **团队组成**：第一阶段带回的NPC直接进入第二阶段。
- **关系值**：精确数值继承。关系值影响初始士气和服从度。
- **模式**：听指挥模式的NPC可被自由分配任务；独立模式的NPC会自行决定行动，但可能带来意外收获。

| 关系值区间 | 初始士气 | 服从度 |
|---|---|---|
| 80-100 | 高（80+） | 完全服从 |
| 60-79 | 中（60） | 基本服从 |
| 40-59 | 低（40） | 偶尔抗命 |
| <40 | 极低（20） | 可能叛变 |

### 特殊继承项

- **暴露度**：影响第二阶段「不速之客」事件触发频率。暴露度越高，越容易被流民、强盗、甚至军方找上门。
- **精神压力**：直接影响主角的判断力和NPC互动。高压力状态下选项会减少、判断会出错。
- **记忆碎片**：确认数量越多，玩家越能预判天气变化和危险事件（以UI提示形式体现）。
- **父母**：接了父母 = 额外2张嘴+精神压力永久-10（减轻），但床位-2、食物消耗+2/天。未接父母 = 精神压力永久+15（内疚加成），某些NPC关系-10。
- **道德选择**：第三幕的关键道德抉择会设定NPC对你的「底色评价」，影响第二阶段关键冲突事件中NPC站队倾向。
- **种子**：买了种子+小美在团队 = Day 40开始可室内种植，Day 55开始每天+1食物。
- **保暖装备**：有装备时外出冻伤概率-50%。无装备时极寒天气（-40°C以下）外出必定冻伤。
- **车辆**：有油+车辆状态良好 = 可进行远程搜刮（更远的地点、更多物资、更高风险）。

## 难度画像

根据第一阶段的综合表现，玩家进入第二阶段时会形成不同的「难度画像」。以下是三种典型情况：

### 充分准备型（Well-Prepared）

**第一阶段特征**：
- 资金利用率 > 80%
- 保温等级 2+，加固等级 2+
- 食物储备 > 40天
- 燃料储备 > 35天
- 拥有发电机+净水设备+电台
- NPC 4人以上，平均关系 > 65
- 暴露度 < 30

**第二阶段体验**：
- 前期（Day 31-40）相对从容，资源充足，可主动选择搜刮或休整
- 中期（Day 41-50）开始感受压力，但有电台预警和净水支撑
- 后期（Day 51-60）即使遭遇极端事件也有缓冲余地
- 主要挑战：团队管理、道德抉择、资源分配优先级
- 预期结局：A-S级

### 中等准备型（Average）

**第一阶段特征**：
- 资金利用率 50-70%
- 保温等级 1-2，加固等级 1
- 食物储备 20-30天
- 燃料储备 15-25天
- 拥有1-2件关键设备
- NPC 2-3人，平均关系 50-65
- 暴露度 30-60

**第二阶段体验**：
- 前期（Day 31-40）就需要开始搜刮补给
- 中期（Day 41-50）资源紧张，需要做出取舍
- 后期（Day 51-60）每一天都是挣扎，一次意外可能导致崩盘
- 主要挑战：资源枯竭倒计时、被迫冒险、团队分歧加剧
- 预期结局：B-C级

### 准备不足型（Underprepared）

**第一阶段特征**：
- 资金利用率 < 40%（可能因信息不足浪费了大量资金）
- 保温等级 0-1，加固等级 0
- 食物储备 < 15天
- 燃料储备 < 10天
- 缺乏关键设备
- NPC 0-1人，关系值不稳定
- 暴露度 > 60

**第二阶段体验**：
- 前期（Day 31-35）就面临生存危机
- 中期：必须频繁高风险搜刮，人员伤亡概率极高
- 后期：几乎不可能全员存活，需要做出极端选择
- 主要挑战：纯粹的生存、每一个决策都是生死攸关
- 预期结局：D-F级（极少数情况下凭借搜刮运气达到C级）

## 难度调节机制

为避免「第一阶段失误 = 第二阶段无法游玩」的情况，系统提供隐性难度调节：

1. **搜刮补偿**：准备不足的玩家在前期搜刮时，物资出现概率略微提高（+10%）。
2. **NPC事件**：即使未带NPC，Day 33-35也会触发一次「求助者来访」事件，给予组建团队的机会。
3. **电台替代**：无电台的玩家可通过搜刮获得收音机（功能弱化版：只能收听，不能发送）。
4. **底线保护**：即使完全没有燃料，安全屋室内温度不会低于外界温度+5°C（墙体基础隔热）。

注意：这些调节是**隐性的**，玩家不会感知到难度被调整。充分准备的玩家不会觉得自己的努力被「平均化」了。
