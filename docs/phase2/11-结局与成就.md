# 11 - 结局评价与成就系统

## 概述

Day 60结束时，系统根据玩家的表现进行全面结算。评价体系从六个维度衡量玩家的生存表现，最终给出综合等级和叙事结局。成就系统则提供额外的挑战目标和重玩激励。

---

## 结局评价体系（Day 60 结算）

### 评分维度

六个维度，各100分，总分600分。

---

### 一、生存分（100分）

核心指标：活着就是胜利。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 主角存活 | +50 | 基础分，死亡则本维度归零 |
| 每个NPC存活 | +10/人 | 最多+50（5个NPC） |
| 主角健康度 | +0~20 | 按百分比折算 |
| 团队平均健康度 | +0~10 | 所有存活成员平均值折算 |

**注**：主角死亡 = 游戏结束（无法到达Day 60），生存分自动为0。

---

### 二、物资分（100分）

核心指标：不仅活了，还有余力。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 剩余食物天数 | 1分/天 | 最多+30 |
| 剩余燃料天数 | 2分/天 | 最多+20 |
| 剩余医疗物资 | 5分/种 | 最多+20（4种医疗物资） |
| 安全屋耐久度 > 70% | +15 | 安全屋未受严重破坏 |
| 设施完好运转 | +15 | 所有已安装设备仍在工作 |

---

### 三、团队分（100分）

核心指标：团队凝聚力与精神状态。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 最终士气 >= 70 | +30 | 团队状态优秀 |
| 最终士气 40~69 | +15 | 团队勉强维持 |
| 最终士气 < 40 | +0 | 团队接近崩溃 |
| NPC平均关系 >= 70 | +25 | 团队关系融洽 |
| 无叛变/出走事件 | +20 | 团队完整度 |
| 全员精神压力 < 50 | +25 | 心理健康 |

---

### 四、道德分（100分）

核心指标：在极端环境下守住人性底线。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 帮助陌生人次数 | 10分/次 | 最多+40（4次） |
| 未抢劫/偷窃 | +20 | 全程未进行掠夺行为 |
| 接纳求助者 | 5分/人 | 最多+20（4人） |
| 善待团队 | +20 | 未强迫NPC、未牺牲NPC |

---

### 五、效率分（100分）

核心指标：资源利用与决策质量。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 第一阶段资金利用率 | +0~30 | 花出去的钱产生了多少实际价值 |
| 空间利用率 | +0~20 | 储物空间使用率 |
| NPC技能覆盖率 | +0~25 | 团队技能是否互补 |
| 信息确认完成度 | +0~25 | 记忆碎片确认比例 |

---

### 六、探索分（100分）

核心指标：对世界的探索和信息获取。

| 评分项 | 分值 | 说明 |
|---|---|---|
| 触发事件比例 | +0~30 | 遇到的事件占总事件池比例 |
| 搜刮不同地点数 | 5分/个 | 最多+30（6个不同地点） |
| 发现隐藏事件 | 10分/个 | 最多+20（2个隐藏事件） |
| 使用电台天数比例 | +0~20 | 电台运行天数/总天数 |

## 结局叙事

根据玩家的选择组合，系统生成对应的叙事结局。每个结局包含一段过场动画和结语文本。

| 条件组合 | 结局名称 | 描述 |
|---|---|---|
| 全员存活 + 高道德分 | 温暖结局 | 冰雪终将融化，而你们彼此温暖着走过了最寒冷的日子。窗外的第一缕阳光照进来时，所有人相视而笑。 |
| 全员存活 + 低道德分 | 代价结局 | 所有人都活了下来。但沉默取代了交谈，眼神中多了些说不清的东西。你们活着——但有些东西永远死在了那60天里。 |
| 部分死亡 + 高道德分 | 遗憾结局 | 你尽力了。真的尽力了。但这个世界不会因为你善良就网开一面。活下来的人会记住那些没能走到最后的名字。 |
| 独自存活（所有NPC死亡/离开） | 孤独结局 | 第60天。暖气还在运转，食物还够吃几天。你活下来了。但房间里只有你自己的呼吸声。这算胜利吗？ |
| 未接父母 + 存活 | 内疚结局 | 你活了下来。父母的电话再也打不通了。你永远不会知道他们最后的日子是怎么度过的。这个问题会跟你一辈子。 |
| Day 51反扑死亡 | 假回暖结局 | Day 50，气温回升到-5°C。你以为最难的日子过去了。你关掉了暖气，打开了窗户。Day 51凌晨，气温骤降至-55°C。你再也没有醒来。 |

**注**：假回暖结局是游戏中设计的「最痛苦的死法」——它发生在玩家以为自己已经成功的时刻。

## 结算流程

1. **Day 60 结束** → 触发结算动画（日出/暴风雪停止）
2. **逐维度展示评分** → 每个维度以动画形式展开，显示各项得分
3. **综合等级揭示** → 显示最终等级和称号
4. **结局叙事播放** → 根据选择组合播放对应结局
5. **成就解锁展示** → 显示本次游戏解锁的所有成就
6. **统计数据** → 展示游戏时长、关键决策节点、对比其他玩家数据
7. **返回主菜单** → 解锁二周目模式（保留记忆碎片知识）

---

## 二周目特殊规则

- 保留所有已确认的记忆碎片信息（不需要重新确认）
- 解锁「重生者的直觉」成就条件
- 部分NPC对话会有微妙变化（暗示轮回感）
- 不影响难度和评分标准
