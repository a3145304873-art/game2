# 外出搜刮系统

## 系统概述

外出搜刮是第二阶段（Day 31-60，极寒30天）获取额外物资的唯一途径，但伴随极高风险——冻伤、敌对人员、迷路。玩家需要在"坐吃山空"与"冒险出门"之间做出艰难权衡。每一次外出都是一场赌博：可能满载而归，也可能有去无回。

---

## 搜刮规则

### 基本流程

1. **选择搜刮地点**（近/中/远距离）
2. **选择派谁去**（1~2人，主角可亲自前往）
3. **自动执行** → 遭遇随机事件 → 返回汇报
4. **获得物资**（或空手而归/受伤）

### 限制条件

- 暴风雪天气 → **禁止外出**
- 每人每次外出 = 占用全天（当日无法执行其他任务）
- 携带容量：基础 **10格** / 老王+50%（15格） / 有车+100%（20格）
- 外出时间越长 → 冻伤风险越高
- 必须有保暖装备（否则冻伤概率**翻倍**）

### 冻伤判定（每次外出）

| 室外温度 | 冻伤概率 |
|----------|----------|
| > -20°C | 5% |
| -20°C ~ -30°C | 15% |
| -30°C ~ -40°C | 35% |
| -40°C ~ -50°C | 60%（极寒高峰期非常危险） |

修正因素：

- 保暖装备齐全：概率**减半**
- 有阿杰（驾驶/有车）：概率 **-20%**（车内暖和）

> 示例：-35°C 外出，基础概率35%。穿戴保暖装备→17.5%。再有阿杰开车→接近0%。反之无保暖装备→70%，几乎必定冻伤。

## 搜刮地点表

### 近距离地点

| 地点 | 距离 | 风险 | 收益 | 说明 |
|------|------|------|------|------|
| 附近超市 | 近 | 中 | 低 | 大概率已被搜刮过，仍可能找到角落食物/日用品，遇到其他搜刮者40% |
| 药店 | 近 | 中 | 中 | 30%找到药品，可能有人蹲守/设陷阱 |
| 居民楼 | 近 | 低 | 低~中 | 搜索空置住户，可找到食物/衣物/燃料/家具，道德成本 |

### 中距离地点

| 地点 | 距离 | 风险 | 收益 | 说明 |
|------|------|------|------|------|
| 加油站 | 中 | 高 | 高 | 燃料珍贵，大概率有人占据/守卫，有刘哥可尝试强行获取 |
| 仓库/工厂 | 中 | 中 | 高 | 可能有大量物资或完全空了，需要撬锁/工具 |
| 学校 | 中 | 低 | 中 | 图书/桌椅(燃料)/食堂存货，相对安全 |
| 医院 | 中 | 高 | 极高 | 药品/医疗器械/毛毯，高概率有人驻守，有小林效率+50% |

### 远距离地点

| 地点 | 距离 | 风险 | 收益 | 说明 |
|------|------|------|------|------|
| 商业中心 | 远 | 高 | 高 | 需要车辆（步行=极高冻伤），多搜刮者竞争 |
| 郊区农场 | 远 | 中 | 中~高 | 粮食/种子/木柴/工具，必须有车，可能有武装农户 |
| 军事区域(后期) | 远 | 极高 | 极高 | Day55+才可能开放，军方物资投放点，需电台收到位置信息 |

### 地点详细说明

**附近超市**
- 可获物资：罐头、饼干、饮用水、打火机、电池
- 特殊事件：遇到其他搜刮者时可选择交易或回避

**药店**
- 可获物资：感冒药、抗生素、绷带、酒精、维生素
- 特殊事件：有人设陷阱（绊线报警），可能引来更多敌对者

**居民楼**
- 可获物资：衣物、毛毯、食物、家具（可拆解为燃料）、书籍
- 道德选择：搜刮明显有人居住但未归的房间 → 士气-3

**加油站**
- 可获物资：汽油、柴油、润滑油、零食、地图
- 特殊条件：有刘哥同行 → 可选择武力驱逐守卫（风险高但收益大）

**仓库/工厂**
- 可获物资：工具、建材、金属件、大量某类物资（随机）
- 特殊条件：需要撬锁工具（铁撬/锤子），否则50%概率进不去

**学校**
- 可获物资：桌椅（燃料）、图书（燃料/士气）、食堂干粮、体育器材
- 相对安全，适合初期过渡

**医院**
- 可获物资：处方药、手术器械、毛毯、消毒用品、担架
- 特殊条件：有小林同行 → 知道哪些药有用，搜刮效率+50%

**商业中心**
- 可获物资：多种类物资、电子设备（可拆解零件）、服装
- 限制：必须有车辆，否则步行前往冻伤概率额外+30%

**郊区农场**
- 可获物资：粮食、种子、木柴、农具、牲畜饲料（可应急食用）
- 限制：必须有车辆
- 风险：武装农户可能开枪警告

**军事区域**
- 可获物资：军用口粮、医疗包、帐篷、燃料、通讯设备
- 开放条件：Day55+且拥有电台且收到军方广播坐标
- 风险：可能遭遇武装巡逻队

## 搜刮衰减机制

每个地点有独立的"残余物资量"，初始为100%，随搜刮次数递减：

| 残余物资量 | 搜刮效果 |
|------------|----------|
| 80%~100% | 正常收益 |
| 50%~80% | 收益减少30% |
| 20%~50% | 收益减少60% |
| < 20% | 该地点基本搜不到东西了 |

衰减规则：

- 每次搜刮消耗 **20%~40%** 残余量（随机）
- 近距离地点衰减**快**（别人也在搜，每天自动衰减5%）
- 远距离地点衰减**慢**（去的人少，每天自动衰减1%）
- 中距离地点每天自动衰减3%

> 策略提示：前期应优先搜刮近距离地点（衰减快，再不去就没了）；中后期转向远距离地点（需要先获取车辆）。

## 搜刮随机事件

每次外出搜刮时随机触发一个事件：

### 好事（30%概率）

| 事件 | 效果 |
|------|------|
| 发现未被搜刮的储藏室 | 物资收获**翻倍** |
| 遇到友善幸存者 | 可交换物资（用多余物资换急需品） |
| 找到一辆还有油的车 | 获得车辆（若无车则极大提升后续搜刮能力） |
| 在废墟中找到宠物（狗） | 获得狗 → 巡逻预警功能 + 全队士气+5 |

### 中性事件（40%概率）

| 事件 | 效果 |
|------|------|
| 正常搜刮 | 获得基础物资（按地点收益表） |
| 路上看到其他幸存者团体 | 互不干涉，无额外影响 |
| 发现留言/信息 | 提供其他地点情报（解锁新地点或显示残余量） |
| 什么也没找到 | 空手而归（浪费一天+冻伤风险白承受） |

### 坏事（30%概率）

| 事件 | 效果 |
|------|------|
| 遇到敌对搜刮者 | 有刘哥 → 可选择战斗（50%胜利保全物资）/ 无刘哥 → 被抢走一半物资 |
| 建筑坍塌被困 | 需要救援（下一天再派人去），被困者受伤（生命值-20） |
| 迷路 | 冻雾天额外+30%触发概率，多消耗半天 → 冻伤风险大增（按1.5倍时间计算） |
| 被埋伏/抢劫 | 失去全部搜刮物资 + 轻伤（生命值-10） |
| 发现尸体 | 精神压力+10；可选择搜刮尸体获取物资 → 道德选择（搜刮则额外精神压力+5，但获得随机物资） |

### 事件概率修正

- **刘哥同行**：遇到敌对者时可战斗，坏事中"被抢劫"降为15%概率
- **阿杰同行**：迷路概率降低50%（熟悉路况），坍塌事件中可快速撤离
- **小林同行**：医院/药店搜刮效率+50%，受伤时可现场急救（减少伤害）
- **老王同行**：携带量+50%，发现储藏室概率+10%（经验丰富）
- **冻雾天气**：迷路概率+30%，所有坏事概率+10%

## 设计意图

1. **资源压力驱动冒险**：室内物资终会耗尽，迫使玩家冒险外出
2. **人员搭配策略**：不同同伴组合影响搜刮效果，形成策略深度
3. **风险-收益权衡**：远距离高收益但高风险，近距离安全但衰减快
4. **叙事驱动**：随机事件提供故事素材和道德选择
5. **中后期节奏变化**：前期近距离为主，中期获车后开拓远距离，后期军事区域成为终极目标
