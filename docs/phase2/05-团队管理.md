# 团队管理系统（第二阶段：Day 31-60）

## 1. 每日任务分配

每个成员每天分配1个任务，不可兼任。

### 任务类型表

| 任务 | 描述 | 产出/效果 |
|------|------|-----------|
| 值守供暖 | 看管火炉/暖炉 | 防火灾+供暖稳定 |
| 做饭 | 准备当天的食物 | 营养度+（需厨具） |
| 取水/融雪 | 收集雪→融化→净化 | 产出水份 |
| 维修 | 修补安全屋结构/设备 | 耐久度恢复 |
| 巡逻/守卫 | 观察周围动静 | 降低被偷袭概率 |
| 外出搜刮 | 出门寻找物资 | 随机物资 |
| 监听电台 | 收听短波（需电台） | 获得情报/救援信息 |
| 休息 | 躺一天 | 精神压力-15 |
| 治疗/照顾 | 照顾伤病员 | 加速伤病恢复 |
| 铲雪 | 清理积雪 | 防入口封堵/屋顶压塌 |
| 清洁整理 | 打扫卫生 | 士气+2，防生病 |

### 分配规则

- 每人每天必须分配1个任务
- 连续工作5天不休息 → 效率-30% + 精神压力+5/天
- NPC可能拒绝不合理安排（士气低时）
- 某些任务需要特定技能/条件（如监听电台需通讯能力+电台设备）

### 人手取舍

| 团队规模 | 情况说明 |
|----------|----------|
| 2人团队 | 每天只能覆盖2项任务，核心任务三选一（供暖/做饭/取水），策略压力极大 |
| 4人团队 | 基本覆盖生存必需，但无余力应对突发 |
| 6人团队 | 效率高，可同时兼顾生存+发展+防御 |

## 2. NPC情绪与士气系统

### 团队士气

范围：0~100，全员共享。

### 士气增加来源

| 来源 | 变化值 | 条件 |
|------|--------|------|
| 吃到热饭 | +3 | 有厨师+烹饪条件 |
| 见到阳光 | +3 | 晴天 |
| 清洁整理日 | +2 | 当天有人执行清洁任务 |
| 电台听到救援消息 | +5 | 有人监听电台+触发事件 |
| 有照明 | +3 | 照明设备正常运转 |
| 分享零食/巧克力 | +5 | 消耗1份零食物资 |
| 夜间团队聊天 | +3 | 全员存活≥3人 |
| 气温开始回升 | +10 | Day53后触发 |

### 士气损耗

| 来源 | 变化值 | 条件 |
|------|--------|------|
| 吃冷食 | -2/天 | 无烹饪条件 |
| 无照明 | -3/天 | 照明设备损坏或无燃料 |
| 空间拥挤 | -2/天 | 人口>床位数 |
| 有人受伤/生病 | -5 | 触发一次 |
| 有人死亡 | -10 | 触发一次 |
| 连续工作无休息 | -3/天 | 某人连续工作≥5天 |
| 入侵者来过 | -5 | 触发一次 |
| Day51假回暖后气温骤降 | -8 | 剧情事件，触发一次 |
| 室温<5°C | -2/天 | 持续判定 |
| 室温<0°C | -5/天 | 持续判定（覆盖上条） |
| 食物/水配给减少 | -3 | 触发一次 |

### 士气影响

| 士气区间 | 状态 | 效果 |
|----------|------|------|
| ≥70 | 高昂 | 效率+10%，NPC主动帮忙（额外小动作如整理物资） |
| 40~69 | 正常 | 无额外加成或惩罚 |
| 20~39 | 低落 | 效率-20%，NPC开始抱怨，触发内部矛盾概率+50% |
| <20 | 崩溃边缘 | NPC可能拒绝工作/吵架/偷物资/出走 |

## 3. 内部矛盾事件

当士气<40或满足特定条件时触发。每天最多触发1次矛盾事件。

### 事件1："凭什么他能休息我不能？"

**触发条件：** 某NPC连续工作≥4天 + 同期有人休息 + 士气<50

| 选项 | 描述 | 后果 |
|------|------|------|
| A | 让抱怨者也休息一天 | 当天少一个劳动力，该NPC精神压力-10，关系+5 |
| B | 解释排班理由 | 50%接受（无后果），50%不满（关系-5，士气-3） |
| C | 强制要求服从 | 关系-10，士气-5，该NPC效率-20%持续2天 |

### 事件2："食物为什么分得不一样多？"

**触发条件：** 食物配给<满足量 + 士气<45

| 选项 | 描述 | 后果 |
|------|------|------|
| A | 平均分配（包括主角减量） | 士气+3，主角饥饿度+5 |
| B | 按劳分配（干活多的多吃） | 劳动者满意（关系+3），休息者不满（关系-5） |
| C | 主角多留一份 | 全员关系-8，士气-5，但主角状态维持 |

### 事件3：刘哥想当领导

**触发条件：** 刘哥关系<50 + 士气<30 + 刘哥存活

| 选项 | 描述 | 后果 |
|------|------|------|
| A | 与刘哥谈判，分享决策权 | 刘哥关系+15，士气+5，但部分决策需刘哥同意 |
| B | 公开对质，让团队投票 | 士气-3；若团队关系均值≥50则主角胜（刘哥关系-10）；否则刘哥胜（失去部分控制权） |
| C | 私下警告刘哥 | 关系-15，刘哥30%概率隐忍/70%概率带人出走（带走1名NPC+部分物资） |

### 事件4：某NPC精神崩溃

**触发条件：** 某NPC精神压力≥90

| 选项 | 描述 | 后果 |
|------|------|------|
| A | 全员停工一天陪伴 | 该NPC压力-30，全员当日无产出，士气+5 |
| B | 安排小林心理安抚（需小林在队） | 该NPC压力-20，小林当日无法执行其他任务 |
| C | 不管，让其自行恢复 | 50%概率自行缓解（压力-10），50%概率恶化（该NPC次日拒绝工作+攻击他人或自伤） |

### 事件5：有人想离开

**触发条件：** 某NPC士气<20 + 与主角关系<40

| 选项 | 描述 | 后果 |
|------|------|------|
| A | 挽留（承诺改善条件） | 需在3天内将士气提升至30以上，否则仍会离开 |
| B | 给予物资让其离开 | 失去该NPC+消耗部分物资，其余成员士气-3 |
| C | 强制不让走 | 关系-20，该NPC效率-50%，3天后可能偷物资逃跑 |
