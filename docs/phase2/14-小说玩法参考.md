# 14 - 热门末世小说玩法参考与移植

> 目的：把《全球冰封：我打造了末日安全屋》等热门末世小说的"爽点结构"翻译成本作的玩法语言。
> 原则：只借结构、不抄文本；不破坏本作写实基调（无系统面板、无超能力空间）。

## 1. 题材公式拆解

热门末世安全屋小说的通用公式：

```
末世灾害 + 重生预知 + 囤货爽点 + 安全屋升级 + 人性抉择（背叛/圣母/黑化） + 势力对抗
```

## 2. 建议新增 / 增强的玩法点（按优先级）

### ★★★ 2.1 邻居恩怨系统（周叔线）

- **借鉴**：原作"前世被自己帮助过的人杀死，今生重新抉择"的核心恩怨结构。
- **方案**：三态（结恩 / 中立 / 结怨）+ 两级分支（Day36 / Day44），完整分支见 13-剧情推进。
- **数值草案**：
  - 结恩：Day5 帮忙 +1，Day20 救人 +2。
  - 结怨：Day5 揭穿 +1，Day12 威胁 +2。
  - 恩 ≥ 2 → Day44 投靠线；怨 ≥ 2 → Day44 夜袭线；否则走"中立冷处理"（Day44 不触发，但 Day56 周叔带着灰狼帮一起出现）。

### ★★★ 2.2 帮派仇恨值与"保护费"

- **借鉴**：原作里盘踞地盘的暴力团伙不断升级的压迫。
- **方案**：新增全局值"帮派仇恨 0~100"：
  - Day39 交保护费 → 被袭概率-15%，仇恨不变（但每 3 天失血一次）。
  - 打退疤哥 → 仇恨+20，士气+5。
  - 仇恨 ≥ 60 → Day45 夜袭提前且烈度+1 档；Day56 必触发总攻。
- **落地位置**：07-威胁系统 新增一列"仇恨修正"；原型中作为全局变量。

### ★★☆ 2.3 以物易物与硬通货

- **借鉴**：原作"一块面包换明星、一包泡面换别墅"的稀缺定价爽点。
- **方案**：搜刮遇幸存者交易时（06 已有），按 Day 动态定价：
  - 硬通货：打火机 / 抗生素 / 巧克力（永远有人要）。
  - 食物价格指数：Day31 1:1 → Day45 1:3 → Day52 1:4（二次寒潮后回落）。
- **落地位置**：06-外出搜刮"遇到友善幸存者"事件 + 交易界面显示"今日行情"。

### ★★☆ 2.4 记忆碎片剧情化（闪回事件）

- **借鉴**：原作重生者"前世画面"的既视感写法。
- **方案**：每次确认碎片时插入一句闪回文案（前世的惨烈画面），让"预知"有叙事重量而非纯 UI 提示。碎片文案见 12-世界观 §2.3。
- **落地位置**：10-阶段继承的碎片 UI 旁挂文案字段。

### ★★☆ 2.5 安全屋科技树化

- **借鉴**：原作安全屋从毛坯到堡垒的建造爽感。
- **方案**：衔接 docs/html/04 优化清单 #2（木材/建造），把升级做成树：
  `火炉改造(油耗-25%) → 墙体隔热(+2°C) → 医疗角(治疗+50%) → 工坊(制作) → 种植架(每5天+0.5食物)`
- **落地位置**：原型建造模块。

### ★★ 2.6 "安置点"诱饵事件

- **借鉴**：原作"官方承诺不可信"的核心悬念。
- **方案**：Day35 广播"集中安置点" → Day52 玩家可抉择：
  - **信**：冒险外出寻安置点（事件链：可能获救 / 可能扑空 / 可能遭遇埋伏）。
  - **不信**：守家（保守但错过机会线）。
- **落地位置**：08-通讯情报 + 09-事件系统（新增一条事件链）。

### ★★ 2.7 爽点节奏表

- **借鉴**：网文"三章一小爽、十章一大爽"的节奏。
- **方案**：见 13-剧情推进 §10 的兑现点排布（准备兑现 / 打脸 / 反转 / 决战 / 希望）。
- **落地位置**：09-事件系统的固定时间线已含大部分节点，仅补 Day36/39/44/56。

### ★ 2.8 二周目"仇敌记忆"

- **借鉴**：原作重生者与仇敌的宿命感。
- **方案**：二周目继承碎片之外，第一次游玩结怨的对象（周叔/疤哥）在二周目开场有特殊台词："我们是不是……在哪见过？"
- **落地位置**：11-二周目特殊规则下追加一行。

## 4. 不建议借鉴的（及替代方案）

| 小说元素 | 原因 | 替代 |
|----------|------|------|
| 空间异能 / 随身储物 | 破坏写实基调 | 储物格 + 扩建等级 |
| 系统面板 / 数值爆表 | 与"算账式恐惧"冲突 | 生存手册 + 电台 |
| 无脑圣母 / 无脑黑化 | 没有选择的道德无意义 | 道德困境 + 成本（09） |
| 后宫 / 感情线泛滥 | 与题材无关 | NPC 关系线（轻量，05） |
| 无限爽 / 无敌流 | 消灭生存压力 | "知道但买不起"的焦虑结构（12 §5） |
