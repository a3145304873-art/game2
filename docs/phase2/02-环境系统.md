# 02 - 环境系统

## 系统概述

环境系统是第二阶段的"外部压力源"，通过气温和天气两个维度持续给玩家制造生存压力。它直接驱动资源消耗速度、搜刮可行性和安全屋状态。

### 关键设计节点

**Day 50~52 "假回暖-反扑"：**
- 这是对玩家"资源分配能力"的最终考验
- Day 49~50 气温回升 → 玩家以为快结束了，放松警惕
- Day 51 气温骤降 → 如果燃料快用完了就极度危险
- 有电台的玩家会在 Day 52 收到"二次寒潮警告"，可提前准备
- 无电台的玩家措手不及

## 天气系统

### 天气类型表

| 天气 | 概率 | 效果 |
|------|------|------|
| 阴天 | 30% | 正常，无特殊效果 |
| 小雪 | 25% | 室外体感温度-3 / 搜刮效率-10% |
| 大雪 | 20% | 室外体感-8 / 搜刮效率-30% / 需要铲雪（否则出入口被封） |
| 暴风雪 | 10% | 室外体感-15 / 禁止外出 / 安全屋结构承压 / 太阳能无效 |
| 晴天 | 10% | 体感温度正常 / 太阳能+50% / 士气+3 |
| 冻雾 | 5% | 能见度极低 / 外出迷路风险+20% / 搜刮无法精确前往目标地点 |

### 暴风雪连续机制

- 暴风雪出现后，有40%概率第二天继续
- 最长连续3天暴风雪
- 连续3天暴风雪 + 食物见底 = 极度危机场景

## 室内温度计算

### 公式

```
室内温度 = 室外温度 + 保温等级加成 + 供暖加成
```

### 保温等级加成（第一阶段施工决定）

| 等级 | 加成 | 描述 |
|------|------|------|
| 0级 | +5 | 未改造 |
| 1级 | +10 | 基础保温 |
| 2级 | +15 | 标准保温 |
| 3级 | +20 | 强化保温 |
| 4级 | +25 | 专业保温 |

### 供暖加成

| 方式 | 加成 | 备注 |
|------|------|------|
| 电暖器+发电机 | +40~50 | 需汽油5L/天 |
| 柴油暖炉 | +35~45 | 需柴油3L/天 |
| 燃木壁炉/火炉 | +25~35 | 需木柴10kg/天 |
| 应急取暖 | +10~15 | 暖宝宝/厚被子 |
| 无供暖 | +0 | - |

### 计算示例

**Day 43, 室外-48, 保温3级, 柴油暖炉：**
- -48 + 20(保温) + 40(暖炉) = +12 → 可生存

**Day 43, 室外-48, 保温1级, 无供暖设备：**
- -48 + 10(保温) + 12(应急) = -26 → 致命

### 室温安全阈值

| 室温范围 | 状态 | 效果 |
|---------|------|------|
| > 10 | 舒适 | 正常 |
| 0 ~ 10 | 不适 | 士气-2/天 |
| -10 ~ 0 | 危险 | 士气-5/天，冻伤风险 |
| < -10 | 致命 | 持续24小时 → 每人每小时10%冻死概率 |
