# 末世后30天（第二阶段）— 概述

## 阶段定位

- 时间跨度：Day 31 ~ Day 60
- 核心主题：你准备得够不够？活下去。
- 玩法转变：从"策略准备"转为"生存管理"

## 核心体验转变

| 维度 | 第一阶段 | 第二阶段 |
|------|----------|----------|
| 视角 | 向外扩张 | 向内收缩 |
| 情绪 | 焦虑但有掌控感 | 恐惧且不确定 |
| 资源 | 用钱换物资 | 物资只出不进（大部分） |
| 时间 | "还来得及" | "还能撑几天？" |
| NPC | 你决定带谁 | 他们决定留不留 |
| 节奏 | 忙碌但自由 | 等待中的煎熬 |
| 角色 | 执行者 | 指挥官 |

核心隐喻：
- 第一阶段：你是猎人（主动准备、掌控节奏）
- 第二阶段：你是猎物（被动应对、资源耗尽的倒计时）

## 胜利条件

**核心目标：** 活过30天（Day 31~60），等待救援或气温回升

**胜利判定：**
- 存活到 Day 60 → 胜利（政府组织的救援队到达/气温开始回升）
- 全员死亡 → 失败
- 部分成员死亡 → 惨胜（影响结局评价）

**死亡条件（任一触发 = 该角色死亡）：**
- 连续2天无食物 → 虚弱状态
- 连续4天无食物 → 死亡
- 连续2天无饮水 → 死亡
- 安全屋室内温度降至 -10 以下持续24小时 → 冻死风险（每人每小时10%）
- 受伤未治疗超过3天 → 感染死亡
- 精神压力达到100 → 精神崩溃（NPC可能出走/自我伤害）
- 主角精神压力100 → Game Over

## 隐藏的不确定性

玩家在第一阶段不知道的关键参数（通过记忆碎片系统部分确认）：

**极寒到底持续多久？**
- 实际答案：30天
- 玩家可能只确认了"至少20天"或"大概一个月"
- 如果只准备了20天食物，最后10天就得搜刮或挨饿

**最低气温是多少？**
- Day 31~35: -15 → -25（渐冷）
- Day 36~45: -25 → -45（极寒高峰）
- Day 46~55: -45 → -35（缓慢回升）
- Day 56~60: -35 → -20（开始解冻）

**电力什么时候彻底断？**
- Day 33: 开始不稳定（每天50%概率停电几小时）
- Day 37: 彻底断电（无自备电源 = 无电）

**自来水什么时候停？**
- Day 32: 水压降低
- Day 35: 彻底停水（水管冻裂）

## 操作模式对比

| 维度 | 第一阶段 | 第二阶段 |
|------|----------|----------|
| 操作 | 每天3个时间段 × 手动选行动 | 分配任务 + 处理事件 |
| 感受 | 高操作感 | 管理感 |
| 定位 | 行动游戏 | 经营游戏 |
